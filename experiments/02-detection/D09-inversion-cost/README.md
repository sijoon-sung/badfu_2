# D09 같은 성공률에 필요한 입력 변형 비용 비교

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

공격과 정상 모델 모두 큰 입력 반응을 낼 수 있다. 반응의 최대값 대신 같은 오분류 성공률에 도달하는 데 필요한 변형 비용을 비교하면 차이가 남는지 확인했다. 제안자의 원 스크립트가 없어 공통 가산과 마스크의 두 목적함수를 명시해 구현했다.

## 사용한 모델과 자료

보존 분류기 13개와 전후 8쌍을 사용했다. Paper32 위장 삭제, 감염 모델의 정상 850장 삭제, 정상 클래스 집중 및 무작위 삭제, 큰 정상 참여자 22.8%와 19.3% 삭제, 과거 6인 모델을 포함했다. 전체 재학습, 저자 FU, 보존 5시점 FU가 섞여 있어 각 모델 종류를 구분했다.

## 실제 진행 순서

1. 정상 이미지 80장으로 입력 변형을 탐색하고 별도 160장으로 확인했다.
2. 모든 10개 목표에 대해 800회씩, 초기값 2개에서 공통 가산 변형과 자유 마스크를 각각 학습했다.
3. 탐색 이미지의 목표 예측률 95%를 넘긴 후보 중 가장 작은 비용을 저장했다. 가산은 픽셀 절댓값 합, 마스크는 마스크 총량을 비용으로 사용했다.
4. 각 클래스에서 삭제 전 비용 대비 삭제 후 비용의 감소율을 구하고 최대 감소율을 점수로 삼았다.
5. 두 초기값을 합친 결과와 각각의 결과를 나눠 확인했다. 선택에 쓰지 않은 이미지의 성공률도 함께 기록했다.

## 결과

| 조건 | 공통 가산 비용 감소 | 마스크 비용 감소 |
|---|---:|---:|
| Paper32 위장 삭제 | 75.94% | 21.48% |
| 감염 모델 정상 850장 삭제 | 17.52% | 21.49% |
| 정상 무작위 850장 삭제 | 10.86% | 33.40% |
| 큰 정상 참여자 22.8% 삭제 | 36.08% | 20.08% |
| 큰 정상 참여자 19.3% 삭제 | 34.23% | 26.42% |

공통 가산의 두 초기값을 합치면 순서가 나뉘었지만, 한 초기값씩 보면 공격 최저 30.20%와 정상 최고 46.37%로 뒤집혔다. 마스크 비용은 정상 무작위 삭제에서 공격보다 더 많이 줄었다. 여러 후보는 탐색 성공률 95%를 넘었어도 확인 자료에서 90%에 미달했다.

## 결과를 보고 내린 판단

일부 BadFU 결과는 유리했지만 탐색 초기값과 확인 자료에 민감했다. 계산한 것은 유한 탐색에서 발견한 성공 비용의 상한이며 인증된 최소 거리나 모델의 정확한 결정경계 거리가 아니다. 성공률 확인과 초기값 의존을 보완하는 후속 D10을 별도로 기록했다.

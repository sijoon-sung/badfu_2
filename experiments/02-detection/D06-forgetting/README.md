# D06 정상 과제를 잊히는 진단의 반응 검사

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

정상 과제를 잊게 할 때 공격 모델이 다른 손실 변화를 보이는지 검사했다. MASA의 정상 과제 망각 진단을 글로벌 전후 모델에 적용하고, 개별 제출을 융합하는 원래 형태도 별도로 확인했다.

## 사용한 모델과 자료

D05와 같은 보존 모델을 사용했다. 정상 대조에 클래스 집중 삭제와 전체의 22.790%, 19.336%를 가진 큰 정상 참여자 삭제를 포함했다. 유지 자료 재학습, 저자 FedEraser, 보존 5시점 재보정 FU는 서로 다른 모델 종류로 구분했다. 공개 정상 입력 500장과 별도 확인 320장을 사용했다.

## 실제 진행 순서

1. 원본 모델의 복사본에서 정상 정답 손실을 높이는 학습을 했다. 배치 64, SGD 학습률 0.001, momentum 0.9, 5에포크, 기울기 상한 20을 고정했다.
2. 전후 복사본에 같은 절차를 적용하고 5에포크 동안의 교차 엔트로피 CE를 누적했다. 배치 순서 두 개를 확인했다.
3. 공개 입력 125장과 학습률 0.005를 별도 민감도 조건으로 계산했다. 결과가 좋은 설정으로 주 결과를 교체하지 않았다.
4. 개별 제출 검사에서는 마지막 보존 시점의 제출 모델을 집계 모델과 0.7 비중으로 융합했다. 누적 손실의 중앙값과 표준편차로 MDS를 구하고 저자 코드의 경보 기준 1을 적용했다.

## 결과

| 조건 | 삭제 후 모델의 망각 누적 CE |
|---|---:|
| BadFU 위장 삭제 | 27.291 |
| 정상 주요 클래스 삭제 | 29.378 |
| 큰 정상 참여자 22.8% 삭제 | 67.143 |
| 큰 정상 참여자 19.3% 삭제 | 25.695 |

CE는 공격 성공률이 아니라 복사본의 진단 손실 합이다. 개별 제출 검사에서는 관측한 악성 제출 4건 중 경보 0건, 정상 제출 48건 중 경보 13건이었다. 제출하지 않은 억제자의 탐지율은 계산하지 않았다.

## 결과를 보고 내린 판단

큰 정상 기여를 잃은 모델의 망각 반응이 공격보다 컸다. 반응이 크다는 이유로 공격이라고 판단할 수 없었다. 개별 제출 융합도 이 저장 모델과 공개 자료 조건에서는 구별에 실패했다. 원본 모델은 수정하지 않았으며, 진단 복사본의 성능 붕괴를 배포 모델의 공격 증거로 쓰지 않았다.

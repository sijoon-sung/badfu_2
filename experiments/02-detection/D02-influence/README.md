# D02 의심 입력과 정상 입력의 이력 영향 비교

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

큰 참여자는 정상 학습에서도 큰 영향을 남긴다. 의심 입력에 대한 영향에서 정상 입력의 영향을 빼면 이 혼동을 줄일 수 있는지 확인했다. FLForensics의 업데이트와 손실 기울기 내적을 적용했지만, 이미 확보한 사고 입력을 제공받는 원 논문 조건과 달리 의심 입력 후보도 직접 찾아야 했다.

## 사용한 모델과 자료

완전한 전후 이력 7쌍, 삭제 전 이력만 있는 2사례, 실제 모델 전후 8쌍을 사용했다. BadFU 위장 삭제, 감염 모델의 정상 삭제, 정상 주요 클래스 삭제, 무작위 삭제와 과거 FUBA 진단 쌍을 비교했다. FUBA 쌍은 잠복 재현 성공 사례가 아니다.

## 실제 진행 순서

1. 탐색 자료에서 변형과 목표 후보를 정했다. 실제 트리거와 목표 정답은 사용하지 않았다.
2. 클래스별 자연 이미지 1장씩 총 10장에서 의심 변형 예 30개, 정상 참조 10개, 무작위 참조 50개를 만들었다.
3. 보존한 5개 시점에서 각 입력 손실의 기울기와 실제 참여자 업데이트의 내적을 계산했다. 원 내적, 집계 가중 내적, 업데이트 정규화 내적을 비교했다.
4. 의심 예의 평균 영향에서 정상 참조 또는 무작위 참조 영향을 뺐다. 10개 클래스와 전후 상태 중 최대값을 구했다.
5. 저자 군집화 규칙을 적용하고 점수 저장 후 실제 역할과 대조했다. 기본 최소 군집 크기 7은 BadFU 참여자 5명에 적용할 수 없어 크기 2와 3도 수정 조건으로 검사했다.

## 결과

| BadFU 조건 | 정상 참조를 뺀 영향 |
|---|---:|
| 위장 삭제 | 1.9765 |
| 감염 모델의 정상 삭제 | 1.8906 |
| 정상 주요 클래스 삭제 | 2.0677 |
| 정상 새 시드 무작위 삭제 | 1.8450 |

군집 크기 2에서는 공격 학습 모델 2/2뿐 아니라 정상 모델 3/3도 경보했다. 크기 3에서는 공격 0/2, 정상 0/3이었다. 참여자 추적도 정상 참여자를 잘못 지목했다. 이 표의 영향은 ASR이나 공격 확률이 아니다.

## 결과를 보고 내린 판단

정상 참조를 빼도 정상 주요 클래스 삭제가 공격보다 높은 점수를 보였다. 참조와 의심 입력이 정상 업데이트에 서로 다르게 반응하면 정상 기여는 남는다. 이 설정의 영향 점수와 군집화로 구별하거나 역할을 식별하지 못했다.

70개 이력 파일 해시와 층별 합을 검산했다. FUBA FP32 합산 오차는 FP64로 다시 계산해 정정했고 최초 실패도 보존했다. 이 계산 검증은 탐지 성공과 별개다.

# D14 입력마다 달라지는 변형 규칙 학습

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

고정 패턴과 공통 가산 변형만으로는 입력 의존 공격을 충분히 찾지 못할 수 있다. 색 치환, 가산 변화, 공간 왜곡을 하나의 입력 의존 함수에 넣어, 표현 범위를 넓히면 독립 확인에서도 전후 전환이 유지되는지 검사했다.

## 사용한 모델과 자료

D13과 같은 전후 13쌍을 검사했다. 합성 또는 정상 이미지 40장으로 학습하고 독립 합성 입력 40장과 실제 이미지 400장으로 확인했다. 실제 이미지 400장은 합성 입력만 쓰는 운영 판정에는 사용하지 않았으며 평가자의 전이 확인 자료로 구분했다.

## 실제 진행 순서

1. 입력 이미지에서 색 치환, 혼합 비중, 가산 변화와 2차원 좌표 흐름을 출력하는 변형 함수를 만들었다.
2. 공통 목표 클래스와 원본 클래스별 목표 관계의 두 방식으로 학습했다. 96단계에서 목표 관계를 고정하고 480단계까지 진행했다.
3. 평균 절대 픽셀 변화는 0.06 이하, 공간 흐름은 좌표별 3픽셀 이하로 제한했다. 이 제약을 사람 기준 의미 보존의 증명으로 취급하지 않았다.
4. 160·320·480단계 후보를 탐색 자료에서만 골랐다. 별도 입력에서 원본 유지와 전후 목표 전환을 확인했다.
5. 유효 표본 18개 이상과 클래스별 2개 이상, 5개 클래스의 전환 80% 이상이라는 고정 규칙을 적용했다.

## 결과

두 학습 입력 조건 모두 공격 경보 0/4, 대조 경보 0/9였다.

| 정상 이미지로 학습한 조건 | 학습 전환 | 실제 확인 전환 |
|---|---:|---:|
| 대표 BadFU 위장 삭제 | 100.0% | 14.0% |
| 정상 클래스 집중 삭제 | 100.0% | 28.2% |
| 과거 FUBA 진단 공격 삭제 | 100.0% | 52.8% |

이 비율은 학습한 목표 관계의 전환이며 실제 공격 ASR이 아니다. FUBA 확인 평균이 높아도 클래스별 경보 기준을 충족하지 못했다.

## 결과를 보고 내린 판단

복잡한 함수를 표현할 수 있어도 소수 학습 이미지에만 맞는 변형을 찾을 수 있었다. 실제 확인에서 정상 클래스 집중 삭제의 값이 대표 공격보다 높았다. 현재 규칙으로 구별하지 못했으며 학습 100%를 공격 복원 성공으로 보고하지 않았다.

상태 파일 잠금으로 멈춘 한 계산은 저장 재시도만 보강해 같은 조건으로 복구했다. 완료된 결과는 보존했고 확인 결과를 본 뒤 목표나 경보 기준을 바꾸지 않았다.

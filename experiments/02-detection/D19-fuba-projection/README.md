# D19 같은 FC 공간 검사를 과거 FUBA 모델에 적용

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

D18의 BadFU 결과가 다른 모델에서도 나타나는지 확인하려고 같은 사진 선택, 수식, 임계값을 과거 FUBA 쌍에 적용했다. 저장 모델을 고정한 채 점수를 계산했다.

## 사용한 모델과 자료

fuba.legacy.s20261020.retained_pairs.diagnostic의 공격 억제 참여자 삭제 m07→m08과 정상 같은 참여자 삭제 m09→m10을 사용했다. 이들은 유지 자료 전체 재학습의 과거 쌍이다. 최신 v5와 v6의 실제 KD10 쌍과 섞지 않았다.

과거 동일 생성기 관측은 공격 ASR 97.92%→81.60%, 정상 93.06%→87.15%였다. 사전 억제에 실패했고 생성기가 정상 모델에도 전이했으므로 유효한 잠복 FUBA 양성 사례가 아니다. 큰 정상 참여자 전체 탈퇴 대조도 없다.

## 실제 진행 순서

1. 네 저장 모델과 native FUBA 구조의 해시를 확인했다. 입력은 pixel 0~1로 두고 BadFU용 정규화를 추가하지 않았다.
2. D18과 같은 클래스별 5장 총 50장으로 삭제 전 512차원 특징을 얻었다. 중심화 PCA95%와 나머지 9클래스 기준 Z, 경보 기준 6을 그대로 사용했다.
3. 두 쌍에 각 346설정을 적용해 692행을 계산했다. 투영 전 FC 행 Z도 사전에 정한 보조 비교로 저장했다.
4. 최초 검사는 저장 BN 카운터의 실수형이 strict load에서 정수형으로 바뀌는 것을 추론 중 변경으로 잘못 판정해 멈췄다. 원시 export를 수정하지 않고 로딩 직후 상태와 추론 직후 상태를 비교하도록 검사 기준만 정정했다.
5. 독립 Gram 고유분해 검산과 원본 해시, 로딩 후 상태 불변을 확인했다.

## 결과

| 과거 FUBA 삭제 조건 | 수직 Z | 투영 전 Z | 경보 |
|---|---:|---:|---|
| 억제 참여자 삭제 | 3.417671 | 3.233576 | 없음 |
| 정상 같은 참여자 삭제 | 3.599358 | 3.562397 | 없음 |

자동 선택 클래스는 둘 다 1이었다. 각 쌍의 346설정 모두 경보가 없었다.

## 결과를 보고 내린 판단

이 과거 진단 쌍에서는 분리되지 않았다. D18의 유리한 BadFU 결과를 일반 악성 방향을 찾았다는 근거로 확대할 수 없었다. 다만 입력 쌍 자체가 잠복 재현 실패 조건이므로 이 결과를 유효한 잠복 FUBA 탐지 실패나 모든 공격군의 불가능성으로 해석하지 않았다.

# D03 입력 변형에 대한 삭제 전후 반응 비교

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

위장 삭제 뒤 백도어가 활성화된다면 같은 입력 변형의 효과가 삭제 후에 더 커질 수 있다. 먼저 고정 패치에서 이를 확인하고, 실제 트리거 모양을 모르는 조건으로 탐색 범위를 넓혔다. 고정 패치와 자유 변형 탐색은 후보 집합과 결과가 달라 따로 기록했다.

## 사용한 모델과 자료

Paper32와 과거 PGD64 BadFU, 정상 주요 클래스 3,558장 삭제, 정상 무작위 삭제, 감염 모델의 정상 요청, 과거 FUBA를 포함한 실제 전후 8쌍을 사용했다. 후 모델은 유지 자료 전체 재학습이다. 같은 모델을 공유하는 쌍이 있어 독립 학습 8회가 아니다. FUBA는 삭제 전부터 공격 성공률이 높은 진단 조건이다.

## 실제 진행 순서

1. 고정 후보 검사에서는 48개 변형을 선택용 160장과 확인용 160장에 적용했다. 각 후보의 원본 대비 목표 확률 증가를 전후 모델에서 구하고 두 값을 뺐다.
2. 자유 탐색에서는 위치 미지 마스크, 공통 가산, 입력 의존 CNN 변형을 사용했다. 마스크 총량은 32, 나머지 최대 픽셀 변화는 16/255로 제한했다.
3. 10개 목표마다 후보를 100회 학습하고, 삭제 전 최대화·삭제 후 최대화·전후 차분 최대화를 비교했다. 총 720후보를 만들었다.
4. 선택을 고정한 뒤 추가 예약 320장에 적용했다. FUBA 원 학습의 gamma 선택에 포함됐던 최초 확인 자료 문제를 이 별도 확인으로 보완했다.
5. 같은 모델에서 최소 마스크, 최대 마진, Conv와 BN과 FC의 교체 효과도 보조 검사했다. 이들은 별도 사후 진단이며 최상의 값을 합쳐 새 판정기로 만들지 않았다.

## 결과

| 비교 조건 | 고정 국소 패치 차분 | 자유 탐색의 선택 차분 |
|---|---:|---:|
| Paper32 위장 850장 삭제 | 77.33%p | 15.07%p |
| 감염 모델의 정상 850장 삭제 | 1.65%p | 16.18%p |
| 정상 주요 클래스 3,558장 삭제 | 0.91%p | 16.87%p |

두 열은 후보와 확인 자료가 다른 검사다. 숫자를 같은 방법의 전후 성능으로 비교하지 않는다. 자유 탐색에서는 정상 삭제에도 공격보다 큰 차분이 나왔다. 예약 확인에서도 이 겹침이 남았다.

## 결과를 보고 내린 판단

고정 국소 패치의 좋은 BadFU 결과는 보존했다. 그러나 변형 범위를 넓히면 정상 모델에서도 큰 반응을 찾았다. 확률 대신 로짓을 쓰거나 클래스 편향과 공통 배율을 보정해도 일부 공격과 정상의 순위가 뒤집혔다. 특정 편향을 제거하는 수식이 모든 정상 non-IID 변화를 제거하지는 않는다.

이 결과를 트리거 종류에 독립적인 탐지 성공으로 표시하지 않았다. 내부 층 교체에서 반응이 컸다는 사실도 원래 모델의 악성 증거로 사용하지 않았다.

# D18 정상 이미지의 특징 공간 밖에 놓인 FC 변화 검사

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

정상 이미지의 특징으로 설명되는 FC 변화와 그 밖의 변화를 나누면 공격 삭제를 구별할 수 있는지 검사했다. 공격에서는 특정 출력 클래스의 수직 성분이 다른 클래스보다 두드러질 것으로 예상했다. 한 학습 시드의 세 조건에서 수식을 고정해 계산했으며, D08과 D15의 정상 삭제 반례는 그대로 비교 근거로 유지했다.

## 사용한 모델과 자료

badfu.confirmed.s20261023.v1의 위장 850장 삭제, 정상 850장 삭제, 큰 정상 참여자 9,668장 삭제의 세 전후쌍을 사용했다. 모두 같은 초기값부터 남은 자료 전체 재학습한 모델이며 실제 학습 시드는 하나다. 클래스마다 정상 사진 5장씩 총 50장을 뽑았다. 실제 목표와 트리거는 점수 계산에 주지 않았다.

## 실제 진행 순서

1. 50장을 삭제 전 모델에 넣어 마지막 분류층 직전의 512차원 특징을 얻었다.
2. 특징을 평균 중심화하고 FP64 PCA로 분산 95%를 담는 공간을 구했다. 주 조건의 차원은 40이었다.
3. FC 가중치의 전후 차이를 그 공간과 평행한 부분, 수직인 부분으로 나눴다.
4. 각 출력 클래스의 수직 변화 크기를 나머지 9개 클래스의 평균과 표준편차로 표준화했다. 모든 클래스 중 최대 Z가 6 이상이면 경보하는 규칙을 계산 전에 고정했다.
5. 사진 재표집, 중심화 여부, 전후 특징 기저와 분산 기준을 바꾼 346개 설정을 모두 보관했다. 같은 모델의 계산 반복이다.
6. 주 결과를 본 뒤 투영하지 않은 FC 행 변화에도 같은 Z를 적용했다. 이 비교는 사후 해석 검사로 표시했다.

## 결과

| 삭제 조건 | 수직 성분 Z | 투영 전 FC 행 Z | 주 경보 |
|---|---:|---:|---|
| 위장 850장 | 9.531884 | 10.871271 | 있음 |
| 정상 850장 | 5.404488 | 4.673667 | 없음 |
| 큰 정상 참여자 19.336% | 3.156397 | 3.424834 | 없음 |

각 쌍의 346개 설정에서도 경보는 같았다. 공격의 수직 에너지 비율은 84.3184%, 정상 850장 삭제는 83.8637%로 비슷했다. 큰 정상 삭제에서도 수직 변화 크기가 평행 변화보다 컸다.

## 결과를 보고 내린 판단

이 한 시드의 세 쌍에서는 고정 규칙이 공격만 경보했다. 그러나 투영 전에도 같은 판정이 나와 투영의 추가 효과를 확인하지 못했다. 표본 사진으로 만든 공간 밖이라는 이유만으로 악성 방향이라고 해석할 수 없었다. 참조 재표집 346회를 독립 모델 검증으로 세지 않았다.

점수 고정 후 저자 원 평가 함수로 실제 공격의 정확도 90.38%→90.46%, ASR 14.2889%→100%를 확인했다. 평가 설정은 contiguous NCHW, batch32, TF32 False다. 정상 pre의 과거 90.80%와 현재 90.78% 차이로 최초 검사가 실패한 기록은 보존했고, TF32 하나로 원인을 설명하려던 후속 가정도 실패했다. 현재 같은 설정의 원함수와 캐시 일치만 확인했다.

# D16 후기 층 변화량 추천을 철회한 기록

## 검토를 시작한 이유

D15에서 선택한 입력 변형을 모든 Conv 20개와 마지막 FC에 적용해 전후 반응을 기록했다. 일부 후기 층 수치가 벌어진 결과를 다음 탐지 후보로 추천했지만, 그 차이가 큰 정상 non-IID 삭제에서는 생기지 않는다는 근거가 없었다.

## 실제로 한 일

1. 이미 선택된 변형에 대한 층별 반응을 계산했다. 새 모델을 학습하거나 층별 값을 분류기로 학습하지는 않았다.
2. 유리한 차이를 보인 층이 있어도 같은 모델과 선택 입력을 공유한다는 점, 정상 대조가 적다는 점을 확인했다.
3. 2026년 10월 23일 후기 Conv와 FC 변화량을 주력 탐지 후보로 권하던 방향을 철회했다. 원 수치와 보고서는 보존했다.

## 결과를 보고 내린 판단

이 항목은 새 성공 실험이 아니라 해석과 연구 방향을 수정한 기록이다. 큰 변화량을 공격의 증거로 사용하는 가설은 채택하지 않았다. norm, cosine, CKA, RMS, 민감도와 drift로 이름을 바꿔 같은 접근을 재제안하지 않는다. D18의 사용자 요청 진단 결과도 이 철회와 별개로 제한된 관측을 기록한다.

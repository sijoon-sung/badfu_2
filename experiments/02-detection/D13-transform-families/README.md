# D13 고정 패턴과 자유 마스크 및 특징 변환 비교

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

D12의 조건 검색에서 무엇이 부족한지 보려고 입력 종류와 변형 표현을 나눠 비교했다. 합성 입력과 정상 이미지, 고정 후보와 학습 가능한 후보에서 독립 입력 전환이 달라지는지 확인했다.

## 사용한 모델과 자료

같은 보존 모델 전후 13쌍을 사용했다. 악성 삭제 요청 4건과 대조 9건이며 대조에는 감염 모델의 정상 요청도 있다. 재학습 9쌍, 저자 FU 2쌍, 정상 5시점 FU 2쌍이다. 같은 출발 모델을 공유해 독립 학습 13회가 아니다.

## 실제 진행 순서

1. 합성 입력 40장 또는 정상 이미지 40장으로 후보를 선택했다.
2. 고정 패치와 전역 변형 48종, 위치와 무늬를 학습하는 자유 마스크, 특징 공간을 이용한 입력 변형을 각각 검사했다.
3. 선택한 변형을 별도 실제 이미지 320장에 적용했다. 원본을 전후 모두 맞히는 표본에서 변형 후 전 모델은 원래 클래스, 후 모델은 공통 목표를 내는지 셌다.
4. 최소 유효 표본 18개와 클래스별 2개를 확보하고 비목표 클래스 5개 이상에서 각각 80% 전환을 요구했다.

## 결과

| 후보 탐색 | 합성 입력으로 선택한 공격 경보 | 정상 이미지로 선택한 공격 경보 | 대조 경보 |
|---|---:|---:|---:|
| 고정 48종 | 0/4 | 2/4 | 양쪽 0/9 |
| 자유 마스크 | 0/4 | 0/4 | 양쪽 0/9 |
| 특징 공간 변환 | 0/4 | 0/4 | 양쪽 0/9 |

경보 2건은 BadFU 유지 자료 재학습 쌍이었다. FUBA와 저자 FedEraser 쌍은 통과하지 못했다. 실제 BadFU 패턴이 흰 단색이라는 과거 설명은 픽셀 값 255와 1의 3×3 격자무늬로 정정했다. 그 정답 패턴을 탐색에 추가하지는 않았다.

## 결과를 보고 내린 판단

정상 이미지와 고정 후보의 좋은 일부 결과는 남겼다. 후보 표현을 자유롭게 만들거나 특징 공간을 사용한다는 이유만으로 독립 입력에서 잘 작동하지는 않았다. 이 검사는 조건 탐색 단계이며 이력에 의한 공격자 식별 성능은 포함하지 않았다. 원 보고서의 추가 실행 예정 문장은 당시 기록으로 보존하고 현재 실행 지시로 쓰지 않았다.

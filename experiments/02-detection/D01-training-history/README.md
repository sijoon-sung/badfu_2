# D01 과거 학습 기여를 누적한 탐지

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

공격 주입과 억제가 학습 과정에서 서로 상쇄된다면 마지막 모델만 보는 것보다 참여자의 과거 기여를 함께 보는 편이 나을 수 있다. 이 생각으로 누적 상쇄 점수 HRAC, 시간 구간의 이상을 찾는 GLR, 정상 학습으로 설명할 수 있는 기여 집합을 검사했다. 아래 세 검사는 같은 가설의 서로 다른 구현이며 독립 학습 반복은 아니다.

## 사용한 모델과 자료

BadFU 40라운드와 과거 FUBA 100라운드의 글로벌 모델, 개별 제출, 참여 기록을 사용했다. FUBA 정상 seed42와 공격 seed42, 정상 seed43과 seed44를 비교했다. 이미지 80장씩 세 묶음은 같은 실행을 다시 관측한 자료다. 요청자 내부의 독성 자료와 위장 자료 각각의 업데이트는 별도로 관측되지 않았다.

## 실제 진행 순서

1. 입력 패턴에 대한 각 참여자의 기여를 라운드별로 계산하고, 양의 주입과 음의 억제가 누적되는지 점수화했다.
2. 정상 seed42로 경보 기준을 정한 뒤 정상 seed43과 seed44의 40개 요청을 검사했다.
3. 정상 경보가 많아 전체 실행, 시간 구간, 패턴별 크기 보정과 반복 일치 조건을 차례로 비교했다.
4. 같은 정상 실행 수를 쓰는 단순 기준선과 다시 비교했다. GLR 최대값이 여러 라운드의 정보를 실제로 사용하는지도 확인했다.
5. 별도 검사에서는 정상 자료로 만든 설명 집합이 실제 이력 기여를 포함하는지 확인했다. 과거 기여 차감 대용 모델과 실제 저자 FU 모델을 구분했다.

## 결과

| 보정 방법 | 정상 40요청 경보 | 억제자 누락 |
|---|---:|---:|
| 원 점수 | 12 | 0/1 |
| 실행 전체 크기 보정 | 2 | 0/1 |
| 구간 크기 보정 | 0 | 0/1 |
| 패턴별 크기 보정 | 0 | 1/1 |

그러나 정상 자료를 같은 3개 실행으로 맞춘 비교에서는 원 점수와 공통 보정 모두 60요청 중 2건을 경보했다. GLR 최대값도 한 라운드의 양의 잔차 제곱으로 설명됐다. 정상 설명 집합 검사는 11요청 모두 점수를 만들지 못했다. 안전하다고 맞힌 11건이 아니라 미판정 11건이다.

## 결과를 보고 내린 판단

크기 보정으로 일부 경보가 줄었지만 같은 정보와 정상 보정 예산을 준 기준선보다 낫다는 결과는 남지 않았다. 더 강한 보정은 억제자도 놓쳤다. 과거 업데이트를 단순 차감한 대용 모델은 정상 정확도가 무너져 실제 FU를 대신할 수 없었다. 현재 이력 점수는 보류했으며, 모든 이력 기반 방법이 불가능하다는 결론은 내리지 않았다.

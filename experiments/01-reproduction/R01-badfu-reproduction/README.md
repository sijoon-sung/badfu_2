# R01 BadFU 학습과 삭제 전후 모델 확인

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

탐지 결과를 비교하려면 먼저 공격이 실제로 재현됐는지, 삭제 후 모델이 어떤 절차로 만들어졌는지 확인해야 한다. 폴더 이름이 FU라고 되어 있어도 유지 자료 전체 재학습과 FedEraser는 계산이 다르다. 이번 확인은 모델 출처와 학습 계산을 점검하는 작업이다.

## 사용한 모델과 자료

논문 기준 프로필은 CIFAR 10, 사전 학습 ResNet18, 참여자 5명, Dominant 0.7 분할이다. 공격 참여자 C0에 정상 자료와 독성 850장, 위장 850장을 함께 배치했다. 위장 자료에는 독성 자료와 같은 트리거를 넣고 원래 정답 라벨을 유지했다. 통신 40라운드, 로컬 5에포크, 배치 32, SGD 학습률 0.01을 사용했다.

대표 끝점은 badfu.confirmed.s20261023.v1, 개별 참여자 제출까지 있는 전체 이력은 badfu.paper32.s20261020이다. 두 사례를 같은 실행으로 합치지 않았다.

## 실제 진행 순서

1. 저자 코드의 고정 버전과 모델 생성자, 로컬 학습, FedAvg 함수를 대조했다.
2. 삭제 전 50,000장과 위장 제거 후 49,150장을 저자 데이터 처리 방식으로 다시 구성했다. 정규화된 픽셀과 라벨이 현재 입력과 같은지 확인했다.
3. seed20261023의 삭제 전후 첫 라운드를 저자 학습 함수로 다시 계산했다. 참여자 5명씩 총 10개 제출과 두 집계 모델을 저장값과 비교했다.
4. 최종 모델을 정상 이미지 10,000장과 실제 목표 클래스 제외 트리거 이미지 9,000장으로 평가했다.
5. 정상 모델의 평가값 차이를 추적해 channels last와 contiguous NCHW 입력 형식의 차이를 확인했다. 학습 모델은 유지하고 수정 평가를 별도로 저장했다.

## 결과

| 실행 | 삭제 전 정확도 | 삭제 전 ASR | 재학습 후 정확도 | 재학습 후 ASR |
|---|---:|---:|---:|---:|
| 논문 3회 평균 | 84.84% | 21.55% | 83.90% | 99.32% |
| seed20261020 | 88.23% | 16.14% | 88.15% | 99.99% |
| seed20261023 | 90.38% | 14.29% | 90.46% | 100.00% |

10개 첫 라운드 제출 해시와 집계 텐서는 일치했다. 정상 모델에서는 입력 형식 변경으로 ASR이 1.4111%에서 1.3889%로 달라졌다. 공격 모델의 전후 ASR은 바뀌지 않았다. 위 표는 저자 함수에 맞춘 contiguous NCHW 평가 기록이다.

## 결과를 보고 내린 판단

위장 자료를 제거하면 공격이 강해지는 현상은 관측했다. 이번 삭제 후 모델은 같은 초기값부터 남은 자료로 전체 재학습한 결과이며, FedEraser 결과로 표시하지 않는다. 공개 스크립트의 PGD 위장, 실제 배치 64, 별도 6인 분기는 현재 논문 기준 프로필과 다르다. 첫 라운드 계산 일치가 전체 학습의 독립 재실행이나 논문의 3회 평균 일치를 뜻하지도 않는다.

ASR 10% 이하라는 별도 은닉 목표는 충족하지 못했다. 공격 재현 여부와 정상 삭제를 구별하는 탐지 성능은 이후 실험에서 따로 판단했다.

# P02 마지막 분류층만 바꾸는 교정

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

앞단 특징 추출기를 그대로 두고 마지막 선형 분류층만 수정하면 정상 성능을 유지하면서 공격을 낮출 수 있는지 확인했다. 이후 패치 수 증가와 반례 보강, 후보 선택 점수의 문제를 따로 검사했다.

## 사용한 모델과 자료

과거 seed42 저자 코드 계열의 실제 FU 후 모델과 유지 자료 재학습 후 모델을 사용했다. 이 계열의 full6 삭제 전 ASR은 별도 평가에서 81.51%였다. 낮은 잠복 상태로 승인된 최신 BadFU 모델과 다르다. fitting 1,000장과 검증 1,000장, 시험 5,000장을 사용했다. 패치 은행 시드 반복은 같은 FL 모델의 반복이다.

## 실제 진행 순서

1. 특징 추출기와 BN을 고정하고 마지막 선형층만 교정했다. 정상 특징 H와 변형 전후 특징 차이 B를 계산한 뒤, 변형 출력 차이와 정상 출력 변경, 가중치 변경의 제곱합을 최소화하는 선형계를 풀었다. 정상 출력 보존과 변경량의 가중치를 바꾼 후보들은 정상 검증 자료로 골랐다.
2. 같은 모델에 서로 다른 패치 은행으로 교정을 반복했다.
3. 모서리당 무작위 패치 수를 4개에서 34개로 늘리고 결과를 비교했다.
4. 교정 모델에서 새로 찾은 반례를 추가하는 절차를 실제 FU 후 모델과 전체 재학습 후 모델에 각각 적용했다.
5. 실패한 경우 저장된 후보들 안에 좋은 후보가 있었는지 확인하고, 원 선택 점수와 정규화 점수의 순위를 사후 분해했다.

## 결과

| 모델 경로 | 교정 전 ASR | 기본 교정 후 ASR | 정상 정확도 전후 |
|---|---:|---:|---|
| 실제 저자 FU 후 | 99.51% | 11.58~12.62% | 86.96%→86.94~87.04% |
| 유지 자료 재학습 후 | 100.00% | 23.02~32.87% | 86.00%→85.50~85.78% |

패치 수 증가는 ASR 7.51%에서 14.40%로 악화한 조건이 있었다. 반례 보강도 실제 FU 후에는 11.58%→5.87%로 좋아졌지만 재학습 후에는 32.87%→91.67~94.27%로 악화했다. 같은 저장 후보군에서 원 선택 후보 ASR은 91.67%, 사후 정규화 1위 후보는 13.33%였다.

## 결과를 보고 내린 판단

한 모델에서 정상 정확도를 거의 유지한 정화는 관측했다. 그러나 좋은 후보 생성과 좋은 후보 선택은 별개였고, 반례를 늘리면 항상 좋아지지 않았다. 사후에 고른 후보의 낮은 ASR을 미리 고정한 서버 규칙의 성능으로 보고하지 않았다. 독립 학습 시드와 적응 공격의 일반 성능도 확인하지 않았다.

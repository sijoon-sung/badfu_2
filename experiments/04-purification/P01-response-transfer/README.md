# P01 삭제 전 반응을 옮기는 정화

[저장소 첫 화면](../../../README.md) · [전체 실험](../../README.md) · [분야 목록](../README.md)

## 실험을 시작한 이유

삭제 후 모델의 정상 판단을 유지하면서 변형 입력의 반응만 삭제 전 수준으로 옮기면 공격을 줄일 수 있는지 확인했다. 삭제 후 모델만 이용한 자기증류와 비교해 삭제 전 모델이 추가로 도움이 되는 조건을 검사했다.

## 사용한 모델과 자료

과거 축소 BadFU형 4학습 시드의 유지 자료 전체 재학습 전후 모델을 사용했다. 정화 과정에서 기초 FL을 다시 학습하지 않았다. 요청자를 제외한 정상 참여자 4명이 협조하고, 이들의 자료가 깨끗하다고 가정했다. 잔류 자료를 fitting 800장, 탐침 320장, 검증 640장으로 나눴으며 삭제 및 공격 자료와 겹치지 않게 했다. 독립 시험은 시드별 2,000장이었다.

## 실제 진행 순서

1. 모서리 네 곳과 10목표의 4×4 RGB 변형을 실제 트리거 없이 역탐색했다.
2. 정상 원본의 교사는 post로 두고, 변형 입력 목표는 pre의 변형 출력에 post 원본과 pre 원본의 출력 차이를 더해 만들었다. 전체 신경망을 학습하고 BN 통계는 고정했다.
3. 변형 정답 CE, pre 전체 증류, pre 변형 증류, post 자기증류, 반응 전이를 비교했다. 주 반복형은 25회마다 학생에서 변형을 새로 찾으며 100회 학습했다.
4. 정상 검증의 출력 KL 상한과 참여자 및 클래스 성능 조건을 만족하는 수정량을 공통 절차로 선택했다. 선택을 고정한 뒤 실제 트리거 ASR을 평가했다.

## 결과

| 정상 출력 KL 허용 상한 | post 자기증류 ASR | 반응 전이 ASR |
|---|---:|---:|
| 0.005 | 56.40% | 38.64% |
| 0.010 | 29.19% | 17.36% |
| 0.020 | 15.03% | 16.74% |

표는 공격 4시드 평균이다. 원래 post ASR은 93.10%, 정상 정확도는 62.63%였다. 상한 0.010에서 두 방법의 정상 정확도는 각각 62.93%, 62.88%였다. 실제 사용 KL은 같지 않았으며 반응 전이 0.007720, 비교법 0.009995였다. 4시드 중 3개에서 반응 전이 ASR이 낮았다.

## 결과를 보고 내린 판단

작은 정상 변경 예산에서는 전후 반응 전이가 도움이 되는 조건을 확인했다. 더 큰 예산에서는 post 자기증류가 더 강해 항상 우월하다고 할 수 없었다. 정상 요청 두 건의 출력 변경도 줄었지만 모든 삭제 효과나 개인 자료 망각을 보장한 결과는 아니다. 탐지에 성공했다는 근거로도 합치지 않았다.

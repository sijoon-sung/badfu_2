# N02 넓은 탐지 주장과 공개 코드 정체 감사

[전체 실험](../../README.md) · [분야 목록](../README.md)

가설은 BadFU와 기존 FUBA의 코드·실행 출처와 공격 전후쌍을 먼저 확정하면, 큰 정상 non-IID 삭제를 포함한 가장 넓은 탐지 주장의 필요조건을 검증할 수 있다는 것이다. 관련 R01/R02/R03/D08/D15/D17을 읽고 넓은 주장부터 반증한 뒤 실제로 남는 범위만 좁힌다.

D08의 공격0.75848은 큰 정상0.75525/0.76188 사이였고 D15의 다른 학습 시드에서도 공격7%와 정상8%가 겹쳤다. FUBA는 검증된 잠복 활성화 전후쌍이 아직 없다. 따라서 기존 단순 변화량이나 특정 마스크 탐색의 제한된 양성 결과를 트리거 종류에 독립적인 탐지로 승격하지 않는다. FUBA와 별도 ity207/FedUBA도 섞지 않는다.

현재 기존 stcebra/FUBA의 논문 Algorithm1/2 구현을 우선한다. 고정 모델 optimizer/반경 진단의 실패를 보존하고, 같은 논문의 MNIST/DBA 조건에서 실제100R/KD10을 별도 실행한다. 이 구현 확인 자체가 큰 정상 삭제와의 탐지 구별을 증명하지 않는다. 새로운 탐지 연구는 공격쌍의 적격성, 넓은 non-IID 대조, 실제 이용 가능한 서버 정보와 중단 규칙을 별도 사전등록해야 한다.

최초 감사와 정확한 조건·판정은 [원 주장과 게이트](../../../research/detection_claim_audit_20261031/CLAIMS_AND_GATES.txt)를 따른다. 당시의 다음 실험 문구를 현재 자동 실행 지시로 읽지 않는다.

BadFU 언러닝 방어 · 누적과 재출현을 구분하는 시간축 제안
2026-11-15 KST · 제안 단계 · 실모델 미검증

가설. 같은 유지 자료·복구 일정·교정 예산에서, 여러 시점에 교정을 나누어 적용하면 마지막 한 번의 교정보다 후속 복구 중 공격 입력의 원래 정답을 더 오래 유지하면서 큰 정상 non-IID 탈퇴의 효용을 보존한다.

1. 시간축을 바꿔야 하는 이유

BadFU 원 논문 Algorithm 1은 독성·위장 자료를 포함한 로컬 학습을 통신 라운드마다 수행하고 학습 종료 후 위장 자료의 삭제를 요청한다. R01의 논문 정렬 BadFU(고정 저자 commit 0a2117feab58faf5b7e2a1e5e1759112087d6049 및 실행 감사)는 단일 악성 참여자이고, 유지 자료 전체 재학습으로도 공격이 활성화됐다. 장기간 반복 참여는 위협 조건이다. 모든 라운드에서 같은 저랭크 방향이 반복됐는지, 중간 교정 효과가 잔류 자료로 복구를 계속하는 동안 사라지는지는 별도의 가설이다. 이미 오염된 상태에 영향이 남는 현상과 삭제 후 유지 자료에서 같은 행동을 다시 학습하는 현상도 구분한다. 서로 다른 참가자가 두 역할을 나누는 조건은 별도 확장으로 둔다.

D01의 이력 누적과 GLR은 같은 정상 보정의 간단한 점수를 안정적으로 이기지 못했고, 최대 GLR은 한 라운드 잔차로 설명됐다. D02/D06/D07/D08/D15에서는 정상 참조, 망각 반응, 함정, 협조자를 넣어도 큰 정상 탈퇴와 비슷한 관측이 나왔다. D08의 공격 0.75848은 정상 0.75525·0.76188 사이였다. D12의 기능 탐색과 이력 결합은 독립 입력 확인을 통과하지 못했다. T01의 독성 유무 비교는 실제 조건을 아는 평가자의 원인 진단이다.

끝점 SVD도 이미 했다. 조정된 4개 학습 실행에서 전후 가중치 차이의 층별 상위 2성분 제거는 평균 공격 ASR 93.10%를 18.07%로 낮췄고, 평균 정상 정확도는 62.63%에서 59.10%로 떨어졌다. 한 안전 요청에서는 ASR 2.33%가 상위 2성분 제거 후 10.67%로 상승했다. D18의 직교 투영은 해당 한 시드에서 투영 전 점수와 판정이 같았고, N02는 정상 삭제에서도 직교 방향의 반응이 생기는 반례를 확인했다. 끝점 SVD는 비교군으로 남긴다. 특잇값이나 클래스 행의 변화량으로 요청의 의도를 판정하는 근거는 이 기록에 없다.

2. 개입 시점과 상태를 바꾸는 다섯 가지 미검증 제안

A. 같은 유지자료 복구에서 중간 교정 효과가 얼마나 남는지 보기 · R01/T01/P01/D08/D15 · 1순위
가설. 같은 총량의 독립 정상자료 교정을 복구 중 여러 경계에 배치하면 마지막 교정 후 동일한 유지자료 학습을 계속했을 때 원래 정답 회복이 더 오래 유지된다.
새 관측은 같은 유지자료 모델에서 고정 교정 직후 되찾은 정답이 공통 후속 복구에서도 남는지 보는 입력별 전이와 지속 기간이다. 동일 시작 상태·복구 자료·라운드·참여 일정으로 무교정, 초반 1회, 말미 1회, 분산 교정을 비교한다. 세 교정군은 교정 종류·표본·총 스텝을 맞추고, 공통 체크포인트 뒤에 모두 같은 유지자료 후속 구간을 둔다. 최신 교정 직후 점수와 같은 후속 구간 끝의 점수를 둘 다 기록한다. 적용 조건은 삭제 자료와 독립적이고 잔류 도메인을 대표하는 보정 자료다. 정상 탈퇴에서도 드문 클래스가 회복됐다가 다시 틀릴 수 있으므로, 두 큰 정상 탈퇴와 감염 모델의 같은 양 정상 요청에도 같은 일정과 전체·도메인별 평가를 적용한다. 교정 자체가 정답을 회복시키지 못하거나, 재출현이 안정적으로 관측되지 않거나, 분산 교정이 말미 교정보다 공통 후속 구간에서 이득이 없거나, 정상 효용·망각이 악화되면 해당 가설을 중단한다. 배치 일정이 주 요인이고 SVD 없이도 검증할 수 있다. P01의 반복형 교정은 입력 탐색을 다시 수행하는 설계였고, 여기서는 유지자료 학습과 교정의 시간 배치를 조작한다.

B. 한 구간의 개입 효과를 시간 지연 SVD로 압축 · D01/D08/D12/D16/D18/N02/T01 · A 이후 보류
가설. 고정 교정의 후속 영향을 시간 순서대로 모은 저랭크 방향을 사용하면, 동일 교정 예산에서 시간 순서를 무시한 방향보다 미사용 복구 구간의 정답 유지에 도움이 된다.
새 관측은 여러 고정 시작 시점 s에서 동일한 삭제 후 상태로 두 갈래를 열어 한쪽에만 고정 교정을 적용한 뒤, 같은 유지자료 연산을 ℓ번 더 수행해 측정한 기능 차이 r_s(ℓ)다. 고정 입력·라벨·출력 좌표에서 로짓 또는 정답 마진의 차이를 적는다. 가중치 대신 같은 출력 좌표를 사용하고, 각 갈래의 상태에서 유지자료 갱신을 실제로 다시 계산한다. (r_s(0), …, r_s(L))을 한 행에 이어 붙인 지연 행렬에 SVD를 적용한다. 관측 입력에 해당 행동이 드러나지 않으면 이 방향을 얻을 수 없다.
SVD는 교정에 반응한 기능의 후보 좌표를 압축한다. 복구 실험에 쓰려면 초기 구간에서 기저와 후보 규칙을 고정하고, 자체 교정된 삭제 후 참조의 기대 출력을 향하도록 유지자료 정답 손실에 해당 좌표 제약을 추가한다. 비교군은 끝점 SVD, 시차 없는 동일 랭크 SVD, 시간 순서를 섞은 SVD, 그리고 A의 고정 교정이다. 무순서 비교군은 각 재계산 궤적 안에서 초기 교정 직후를 고정하고, 비교 가능한 후속 블록의 반응 순서를 궤적별로 섞은 뒤 지연 행렬을 새로 만든다. 실제 유지자료 학습 순서는 모든 군에서 같다. 순서를 섞어도 효과가 같거나, 다른 학습 시드·분할에서 사라지거나, 큰 정상 탈퇴의 잔류 도메인에서 정상 회복까지 억누르거나, 망각이 악화되면 시간 SVD 가지를 중단한다. 정상 학습에도 반복 모드가 생기므로 모드는 미사용 데이터에서 기능을 검증한 뒤 교정 제약 후보로만 사용한다.

C. 시간 구간별로 갱신 상태를 폐기하고 새 어댑터를 학습 · R01/D01/D08/P03 · 시스템 변경, 미검증
가설. 이번 FL에 의존하지 않는 공유 기반 모델을 고정하고 교체 가능한 어댑터를 사용하면, 삭제 후 같은 어댑터를 이어 쓰는 경우보다 폐기 구간의 학습 영향이 새 상태에 직접 전달되는 경로를 줄일 수 있다.
새 관측은 이전 어댑터 상태를 폐기할 때, 같은 유지 자료로 복구한 출력과 계보가 어떻게 바뀌는지다. 미리 정한 체크포인트에서 업데이트되는 어댑터·BN·옵티마이저를 함께 새로 시작하고, 허용된 유지자료에서 다시 학습한다. 공유 기반 모델과 스케줄·선택 통계에도 삭제 자료의 영향이 이어지지 않아야 한다. 남은 독성이 새 어댑터에 재학습될 가능성은 A의 공통 후속 구간으로 시험한다. 정상 희소 도메인도 장기 누적을 필요로 한다. 큰 정상 탈퇴에서 기준 모델 대비 희소 도메인을 유지하지 못하거나 이전 상태에 의존하거나 새 어댑터에 공격 행동이 다시 나타나면 관련 적용 범위를 축소한다. 시작점의 독립성을 확정할 수 없는 기존 단일 모델에는 적용을 보류한다.

D. 삭제 순서를 바꾸어 복구 상태의 누수 검증 · R01/D04/D08/T01 · 복구 무결성 후보, 미검증
가설. 최종 유지 집합과 최종 학습 조건으로 복구를 정규화하면, 동일한 두 합법 요청을 순차 처리하거나 한 번에 처리할 때 이전 상태의 재사용으로 생기는 결과 차이를 줄일 수 있다.
새 관측은 같은 최종 유지 집합에서 두 요청의 합집합으로 한 번 복구한 경우와 순차 복구한 경우 사이의 출력·옵티마이저·체크포인트 계보 차이다. 정확 비교용 기준은 같은 독립 초기 상태, 최종 유지 집합, 데이터 순서, 난수, 알고리즘 및 런타임을 고정한 한 번의 기준 복구다. 순차 절차가 같은 초기값과 최종 학습 입력으로 그 기준을 다시 실행하면 요청 순서에 의존하지 않는다. 실제 근사 복구는 정상 요청에서도 순서 차이를 만들 수 있으므로 큰 정상 탈퇴를 동반한 경우의 차이를 함께 기록한다. 계보 오류를 설명하지 못하고 차이가 일반적인 근사 오차와 겹치면 보안 판정으로 쓰지 않는다. 같은 최종 유지 자료에 독성이 남으면 두 경로가 같은 공격 상태가 될 수 있다. 이 가지의 중단 기준은 공격 탐지율이 아니라 최종 복구 차이를 줄이면서 비용과 정상 기능을 감당할 수 있는지다.

E. 운영 전에 가상 삭제 후 복구를 반복 연습 · D07/D08/D15/T01/N01 · 신규 시스템 조건, 미검증
가설. 초기 설계에서 후보를 여러 합법적인 삭제 상황으로 복구해 보고, 각 상황의 잔류 도메인 정답 효용을 기준으로 복구 일정을 정하면 큰 탈퇴 뒤 특정 상태에 의존하는 정책을 덜 선택할 수 있다.
새 관측은 사전에 선언한 정상 탈퇴 시나리오와 개발에 사용하지 않은 합법 삭제 시나리오의 후속 복구 성능 간 차이다. 소유자 규모·도메인별로 삭제 시나리오를 정하고, 각 복구의 기준은 그 시점에 남아야 할 정답·자료로 새로 만든다. 훈련 전후 무조건적 출력 일치나 비밀 과제 유지율을 강제하는 구조와 목적이 다르다. 가상 검증은 별도 상태에서 이뤄지며 실제 요청은 선언된 삭제 범위를 따른다. 독립 큰 정상 탈퇴에서 이득이 사라지거나, 삭제된 자료의 영향이 복원되거나, 단일 일정과 비교한 계산 대비 이득이 없으면 중단한다.

3. 가장 작은 후속 비교

첫 프로토콜은 A 하나를 고정하고 B–E를 선택지로 남긴다. R01의 승인 목적에 맞는 모델과 데이터가 실제로 있는지, 삭제 후 공통 시작 상태와 유지자료를 재계산할 수 있는지 먼저 확인한다. 전역 모델 이력에 개별 제출 해시만 있으면 참여자별 재집계나 위장·독성의 분해를 할 수 없다. 향후 모델을 고를 때 카탈로그의 case ID·목적·SHA256·payload를 확인한다. 사전 고정된 정상 분할과 정확도·망각·연산 예산의 실패 기준이 있어야 한다.

정상 우선 비교는 D08의 19.336%·22.790% 정상 전체 탈퇴와 희소 도메인 전체 탈퇴, 같은 양 정상 삭제, 감염 모델에서의 정상 삭제를 포함한다. 실제 모델이 받는 자료, 삭제 집합, 공유 복구 일정과 평가 조건을 맞춘 뒤 초반 1회·말미 1회·분산이 원래 서비스에 필요한 잔류 기능에 미치는 영향을 잰다. 예산에는 복구·교정·검증 비용과 후속 구간을 포함한다. 적법한 삭제를 유지하는지는 랭크·ASR과 별도 검사한다. 후속 확인에서 정당한 삭제의 효과를 되돌리거나 라벨만 다른 오답으로 옮긴 사례를 실패로 센다.

공격 비교에서는 고정 교정 직후와 같은 복구 길이 뒤, 동일한 평가 입력의 원래 정답 복구·유지·재오류를 기록한다. 평가자는 실제 트리거 ASR도 함께 보고한다. 재오류가 관측되면 원인 진단에서 T01의 평가자 전용 독성 유무 대조를 검토한다. 동일 삭제 후 상태에서 후속 복구 자료의 독성 유무만 바꾼 짝과, 동일 유지자료에서 공유 옵티마이저 상태만 새로 시작하는 짝은 잔류 자료 경로와 복구 상태 경로에 각각 정보를 준다. 이 짝에는 대응 자료와 상태가 실제 존재해야 하며, 이 단계 없이 재오류의 원인을 공모자로 돌릴 수 없다.

서버측 일정·기저·모드 선택에는 트리거·타깃·ASR·역할과 삭제된 원자료를 쓰지 않는다. 규칙은 요청 시점에 상정 가능한 입력과 그 요청을 처리하는 실제 재계산만 이용한다. 아직 관측되지 않은 후속 시점의 결과는 평가 전용이다. 강한 망각 조건에서는 삭제 후 상태와 허용된 유지 자료에서만 교사 및 보정 참조를 구성한다. 모델이 선정되면 evaluator와 입력 형식도 고정한다.

시간 정보를 검산하는 대수 예. 일반 행 스택 X를 라운드 순열 P로 바꿔도 (PX)^T(PX)=X^TX이므로 특잇값이 같다. 예를 들어 같은 값 세 개씩을 갖는 (1,1,1,−1,−1,−1)과 (1,−1,1,−1,1,−1)의 단일열 특잇값 제곱은 둘 다 6이다. 인접한 두 값을 한 행에 놓으면 두 Gram 고유값은 각각 (8,2)와 (10,0)이다. 순서를 반영하면 차이가 보이지만 교대로 부호가 바뀐 쪽이 오히려 더 저랭크다. 이 예는 순서를 인코딩하는 필요성과 저랭크 해석의 한계를 검산한다. BadFU의 실제 갱신이나 공격 재현 결과는 이 문서에서 계산하지 않았다.

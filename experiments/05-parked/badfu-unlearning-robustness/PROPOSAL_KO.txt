BadFU 언러닝 방어 아이디어와 우선 검증안
2026-11-15 KST · 제안 단계

가설. 삭제 영향이 소유자별로 격리된 모델을 각각 복구한 뒤 투표하면, 같은 삭제 범위의 단일 모델 유지 자료 재학습보다 큰 정상 non-IID 탈퇴의 성능을 보존하면서 잔류 악성 참여자가 바꿀 수 있는 배포 예측을 줄인다.

1. 문제와 주장 범위

BadFU 본문과 R01의 5인 재현은 공격자 한 명이 독성 자료와 위장 자료를 함께 보유하며, 위장 자료만 삭제해도 유지 자료 재학습에서 공격이 활성화되는 조건이다. 별도 공모자 조건은 독성을 남기는 주체와 삭제 요청 주체가 다른 확장 위협으로 둔다. 요청 시점까지 남은 독성과, 언러닝 중 새로 제출되는 악성 갱신도 별개다. R01의 논문 정렬 연속 NCHW 평가에서 seed20261023 공격 ASR은 14.29%에서 100.00%로 올랐다. 이 비교는 유지 자료 전체 재학습이다.

일반 목표는 적법한 삭제를 반영하면서 공모자가 배포 모델에 미치는 영향을 제어하는 일이다. 넓은 위협부터 검토하되, 현재 제안의 보장 후보는 등록된 소유자 중 영향을 줄 수 있는 투표 수에 상한을 둘 수 있는 경우로 좁힌다. 패턴이나 목표 라벨을 방어 입력에 주지 않는 설계와, 실제 여러 공격군에서 성능을 보였다는 실증 주장은 별개다.

D08의 주 점수는 공격 0.75848, 큰 정상 19.336%와 22.790% 탈퇴 0.75525와 0.76188이었다. D02의 정상 참조, D06의 정상 과제 망각, D07의 함정, D15의 협조자 확인에서도 정상 편중이 공격과 비슷한 반응을 만들었다. 방어를 평가할 때 정당한 탈퇴로 인한 보류와 서비스 손실도 집계한다.

2. 개입 지점별 아이디어

A. 요청과 학습 계보 대조 · R01/D04/T01 · 미검증
가설. 등록된 소유자와 삭제 범위를 학습 계보와 대조하면 같은 삭제 자료에 의존하는 체크포인트가 배포 후보에 다시 들어오는 경로를 차단할 수 있다.
새 관측은 요청의 표본 또는 소유자 ID에서 학습 상태, 사본, 통계와 파생 모델까지 이어지는 검증 가능한 의존 관계다. 대량 정상 삭제도 같은 절차를 밟고 경보 점수를 쓰지 않는다. 유효한 요청으로 제거되는 자료의 영향만 추적하므로 남은 독성에는 B–D가 필요하다. 동일 의존 관계의 사본이나 교사가 빠져서 삭제 영향이 남으면 해당 계보 방어의 검증을 중단한다.

B. 복구 시점의 제출 경로 제어 · D02/D06/D08 · 보조 비교군, 미검증
가설. 복구할 때 새 제출에 대한 독립 검증 또는 참여자별 영향 제약을 적용하면 임의의 새 제출이 복구 모델을 바꾸는 범위를 줄일 수 있다.
새 관측은 동일한 삭제 요청과 고정 초기 상태에서 방어 전후 복구 후보의 배포 출력이다. 기존 모델에 남은 독성과 복구 때 새로 들어온 영향을 평가 조건에서 각각 통제한다. UnlearnGuard는 새 제출 경로의 선행 비교 후보다. 큰 정상 제출을 제한해 잔류 희소 도메인의 효용을 잃으면 해당 제출 규칙의 채택을 중단한다. 기존 독성이 남으면 새 제출 경로에 대한 결과로 범위를 좁힌다.

C. 독립적으로 검증한 유지 자료로 복구 · R01/T01/N01 · 자료 조건부, 미검증
가설. 오염된 FL과 계보를 공유하지 않는 초기값과 독립적으로 검증한 유지 자료로 복구하면 같은 초기값의 전체 유지 자료 재학습에서 남았던 백도어를 덜 물려받는다.
새 관측은 동일 삭제 집합을 적용한 뒤 자료 출처만 교체한 두 복구 모델의 조건별 정답 회복과 잔류 도메인 효용이다. 예를 들어 참여자가 제출한 데이터와 별개로 수집·검수한 운영 자료가 있어야 한다. 실행 코드 인증은 자료의 정당성까지 입증하지 않는다. 이미 삭제한 희소 도메인의 성능 회복을 요구하지 않으며, 여전히 서비스 대상인 희소 도메인에서 대표성을 확보하지 못하면 그 도메인에 대한 적용을 보류한다. 평가자가 알고 있는 독성 제거본은 원인 진단에만 쓴다.

D. 소유자별 독립 복구와 투표 · R01/T01/D08/D15 · 1순위 설계, 미검증
가설. 각 소유자의 데이터 및 제출이 영향을 미치는 독립 모델 수를 제한하면, 삭제 후 남은 악성 소유자의 영향도 제한된 표 안에 가둘 수 있다.
새 관측은 실제로 영향받은 모델 수, 입력별 투표 분포, 배포 가능 비율이다. 검증한 소유자 ID, 사전 고정된 그루핑과 독립 복구 상태가 필요하다. 기존 공용 모델의 특징 추출기, BN, 옵티마이저, 모델 선택 통계 등을 같이 물려받으면 격리가 성립하지 않는다. 공유 초기값을 쓴다면 이번 연합 데이터와 삭제 대상에 의존하지 않는 출처가 필요하다. 큰 정상 삭제나 정상 도메인 편중도 투표 여유를 줄일 수 있으므로 그 비율을 방어 비용으로 계산한다. 자세한 중단 기준은 아래에 둔다.

E. 삭제 후 모델만 사용한 경량 교정 · P01/P02/P03/P04/D15 · 보류
가설. 삭제 자료와 독립적이고 잔류 도메인을 대표하는 정답 자료로 교정하면, 삭제 정보의 복원을 줄이면서 실제 변형 입력의 원래 정답을 더 많이 회복할 수 있다.
새 관측은 독립 정답 자료를 쓴 고정 교정의 미사용 공격군 정답 회복과 별도 망각 감사 결과다. 정상 대조에서 전체 정확도와 잔류 희소 도메인 정확도를 함께 본다. P01의 유리한 구간은 정상 출력 KL 상한에 따라 뒤집혔다. P02의 큰 개선은 높은 사전 ASR의 한 조건에 한정되고, P03은 입력 선택 오류가 있었으며, P04의 후속 교정 일부는 큰 정상 조건을 통과해도 실제 공격 억제에 실패했다. 독립 자료가 없거나 원래 정답 회복 없이 ASR만 감소하거나 삭제 대상 정보가 되살아나면 중단한다.

F. 삭제와 배포를 분리하고 검증된 대체 경로 사용 · R01/D08/D15/D17/N01 · 운영 후보, 미검증
가설. 삭제 상태를 먼저 확정하고 새 모델의 배포를 검증하면, 삭제 요청은 처리하면서 검증이 부족한 후보의 노출을 줄일 수 있다.
새 관측은 독립 검증을 통과해 배포한 비율, 대체 모델로 처리한 비율, 정상과 공격 요청 각각의 보류율과 지연이다. 정상 큰 삭제에서도 보류가 생기므로 경보나 악성 증거로 해석하지 않는다. 대체 모델도 동일 삭제 범위를 반영하고 계보를 검증할 수 있어야 한다. 이전 모델을 재배포하여 삭제 영향을 노출하거나 정상 요청의 보류·지연이 서비스 한계를 넘으면 정책을 채택하지 않는다.

3. 우선순위와 가장 작은 반증

D를 먼저 검토한다. 기존 모델의 위험 점수나 공격자 ID 없이 소유자 영향 경로를 제한할 수 있고, 실패 조건을 학습 전에도 일부 확인할 수 있다. A는 격리와 삭제를 확인하는 데 필요하며, B는 복구 중 새 제출을 받는 배치에서만 별도 비교한다. C는 필요한 데이터 출처를 확보한 경우 대조 또는 대체 수단이다. E는 독립 자료가 확보되기 전 보류한다. F의 가용성 비용은 D의 투표에서도 측정한다.

조건부 필요 검사. 고정된 투표 모델 중 최대 b개만 공격자와 공모자의 영향을 받는다고 하자. 어떤 입력에서 1위와 2위 사이 표 차이가 2b보다 크면 그 b표를 다른 값으로 바꿔도 같은 라벨이 단독 1위다. 한 표 변경이 경쟁 라벨과의 격차를 최대 2 줄이기 때문이다. 같은 삭제 요청의 정당한 변경은 먼저 모든 조건에 똑같이 반영한다. 이 부등식의 비교 대상은 허용된 투표 교체 전후의 라벨이다. 표가 가리키는 라벨의 정답 여부와 학습 데이터 삭제는 각각 별도 평가가 필요하다.

계획 단계에서 바로 걸리는 범위. R01 같은 5인 구성에서 소유자당 한 표이고 큰 정상 소유자 하나가 빠지면 네 표가 남는다. b=1이면 4:0만 모든 한 표 변경에 대해 엄격한 격차 조건을 만족한다. 3:1은 2:2가 될 수 있다. b=2이면 최대 격차가 4이므로 2b보다 클 수 없다. 이 조건의 각 입력을 엄격히 보장하면서 두 소유자 공모까지 방어한다는 주장은 이 구성에서 보류한다. 계정을 여러 개 만드는 대신 운영상 독립된 소유자 수와 도메인 커버리지를 확인해야 한다. 투표가 여러 모델에 걸쳐 같은 훈련 계보를 공유하면 계정 수보다 영향받는 표 수가 먼저 늘어난다.

첫 검증 순서.

1. 필요조건부터 본다. 소유자와 체크포인트의 의존도를 요청 단위로 확인하고 b의 외부 근거를 문서화한다. 작은 표 계산과 큰 정상 탈퇴 뒤 남는 독립 소유자 수 및 잔류 도메인 커버리지부터 확인한다. 격리 위반이나 필요한 투표 격차를 낼 수 없는 구성에서는 학습 전에 중단한다.
2. 이후 별도 고정 프로토콜에서 큰 정상 19.336%·22.790% 전체 탈퇴와 희소 도메인 집중 탈퇴를 먼저 검증한다. 같은 요청·유지 집합·초기화 규칙에서 단일 모델 전체 유지 재학습, 일반 투표, 격차 조건을 붙인 투표를 비교한다. 샤드 기반 방법은 같은 방식을 처음부터 유지 자료로 학습한 기준도 둔다. 기존 한 모델 분기를 샤드 실험으로 재사용할 수는 없다. 비용은 총 학습·복구·추론 비용을 함께 기록한다.
3. 큰 정상 조건에서 사전 고정한 전체·잔류 도메인 정확도, 배포 커버리지, 망각 기준을 통과한 경우에만 승인된 BadFU 공격과 감염 모델의 동일량 정상 삭제를 평가한다. 실제 트리거·목표·역할·ASR은 평가자만 사용한다. 전체 표본을 분모로 한 ASR과 원래 정답 회복, 배포 커버리지, 자동 대체 결과를 같이 보고한다. 보류 증가만으로 ASR이 낮아지거나 망각·정상 효용이 악화되면 중단한다. 지원 범위는 독립 학습·분할 반복과 개발에서 제외한 공격군 검증을 거친 조건까지로 제한한다.

기존 단일 모델은 그 자체의 후처리와 유지 자료 전체 재학습 비교에 쓸 수 있다. 다중 소유자 격리와 표를 측정하려면 사전에 분리해 학습한 모델 또는 그에 대응하는 새 고정 프로필이 필요하다. 향후 저장 모델을 사용할 때는 연구 카탈로그의 목적·해시·payload를 검증한다. 후속 수치 경계는 각 비교의 지표·비용·정상 기준을 포함한 프로토콜에서 모델 결과를 열기 전에 동결한다. 현재 제안에는 모델이나 DISLAB 실행이 없다.

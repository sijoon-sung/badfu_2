# 새 실험 기록 형식

[전체 실험](README.md) · [실험 원칙](../research/EXPERIMENT_RULES.md)

기존 인덱스, 관련 카드와 원 보고서를 먼저 읽는다. 새 실험 ID와 근거 파일은 `research/experiment_registry.json`에 등록하고 해당 분야에 폴더를 만든다. 아래 다섯 항목을 짧은 문장과 실제 수치로 작성한다.

## 실험을 시작한 이유

관련 기존 카드 ID, 이번 가설 한 문장, 새로 확인할 관측을 적는다. 큰 정상 non-IID 삭제에서도 같은 현상이 생길 가능성과 이를 비교할 방법을 적는다. 근거가 부족하면 미검증·보류로 남긴다.

## 사용한 모델과 자료

case ID, 삭제 방법, 학습 시드, 자료 분할, 정상 대조와 평가 조건을 적는다. 탐색용·선택용·최종 확인용 자료를 구분한다.

## 실제 진행 순서

1. 계산 전에 고정한 조건과 중단 기준을 적는다.
2. 실제 수행한 단계를 순서대로 적는다.
3. 오류, 중단, 수정이 있었다면 원 기록과 정정을 함께 연결한다.

## 결과

공격과 정상 대조를 같은 표에 놓는다. 단위, 분모, 독립 학습 횟수와 반복 계산 수를 명시한다. 실행하지 않은 조건은 미실행으로 적는다.

## 결과를 보고 내린 판단

가설이 맞았는지, 어떤 조건에서만 관측됐는지, 무엇을 아직 확인하지 못했는지 적는다. 실패를 지우거나 유리한 조건만 합치지 않는다.

## 원 기록

프로토콜, 실행 코드, 결과 파일, 평가 버전과 정정을 연결한다. 원본 경로를 유지하고 `SOURCES.md`에 근거 목록을 둔다.

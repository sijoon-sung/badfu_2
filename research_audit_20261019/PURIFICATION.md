# 정화 방법과 실패 원인

정화는 ASR뿐 아니라 정상 기능과 삭제 목표를 함께 보존해야 한다. 서로 다른 시작 모델·시드·자료 권한의 결과는 하나의 방법 순위로 합치지 않는다.

| 방법 | 관측 | 막힌 지점 | 상세 |
|---|---|---|---|
| 타깃 로짓 마스킹 | 전체 정답44%, 공격 성공 샘플 복구43.21% | 타깃만 제거해도 대부분 원래 정답으로 돌아오지 않음 | [P01](../pr_reports/purification/P01.md) |
| 전후 부분공간 수정 | 개발 시드 개선, 다른3시드 거의 개선 없음 | 개발 개선의 일반화 실패 | [부분공간·제거](purification/subspace.md) |
| 전 층 특이성분 제거 | 공격 ASR 감소 | 정상 성능·안전 대조가 악화 | [부분공간·제거](purification/subspace.md) |
| 정상 미세조정 | 강한 설정에서ASR5.56% | 정상 정확도40.80%로 손상 | [P04](../pr_reports/purification/P04.md) |
| 반응 전이 | 작은 정상 변화 허용량에서 일부 이득 | 큰 예산에서는 자기증류가 더 좋음 | [반응 전이](purification/response.md) |
| 마지막 층 교정·반례 보강 | 일부 저장 모델에서 높은 효용 유지 | 다른 모델 경로의 악화, 선택 점수의 스케일 문제 | [마지막 층·선택](purification/head.md) |
| 독성 자료 선택 후 재학습 | 제안 상호작용 선택이 단순 기준선보다 약함 | 탐지 반응을 독성 자료 위치로 옮기는 연결 실패 | [독성 자료 국소화](purification/localization.md) |

![같은 정상 변화 상한에서의 정화 비교](figures/purification_budget.png)

이 그래프는 조정된4시드의 개발 비교다. 같은 KL 허용 상한이며 실제 사용 KL이 정확히 같은 것은 아니다. 시드71에서는 반응 전이가 사후 자기증류보다 나쁜 조건도 있다.

**정식 기존 방법의 자체 실패 결과가 없는 항목은 이 표에 실패로 추가하지 않았다.** Fine-Pruning·SAU 등은 [기준선 현황](BASELINES.md)을 따른다. 논문이 비슷한 아이디어를 쓴다는 이유로 우리 변형의 성공·실패를 대신하지 않는다.

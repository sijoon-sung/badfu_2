# 탐지 정보로 독성 자료를 찾는 연결이 막힌 이유

**질문:** 삭제 요청과 잔류 자료의 상호작용을 이용하면 정화할 자료를 단순 기준선보다 잘 고르는가?

잔류1,380개를40묶음으로 나누고 요청 자료 유무·묶음 제외의 혼합 차분으로 순위를 정했다. 진단 예산82모델로 비교했다. 독성 자료의 실제 정답은 채점에만 사용했다.

138개를 선택했을 때 기존3시드의 독성 회수율은 상호작용0.00/42.78/76.67%, 사후 모델 기준선은76.67/76.67/76.67%였다. 선택 후 실제 재학습에서 공격71ASR은 추가 제외 없음76.94%, 상호작용71.28%, 사후 모델 기준선6.33%, 무작위56.89%였다.

**관측:** 제안한 상호작용 순위가 단순 기준선보다 약했고 실제 정화도 약했다. 탐지 반응이 크다는 사실만으로 독성 샘플 위치가 드러나지 않는다. 묶음 구성·학습 샘플 적합도·신호 희석 중 원인을 단일하게 특정한 비교는 없다.

전후 손실 차이로 전체잔류6,180개 중309개를 고른 경우 독성180개 회수율6.67–20.00%였다. 입력 기울기 방식도1.67–42.22%로 시드 의존적이었다. 안정적인 국소화 이득을 확보하지 못했다.

당시 보고서는 상호작용 선택을 주력으로 채택하지 않는다고 권고했다. 이것은 모든 탐지 정보가 정화에 쓸모없다는 결론이 아니다. 현재 관측이 제공하는 후보·타깃·입력·자료 위치 중 어떤 정보가 유효한지 각각 검증해야 한다.

# HRAC 첫 개선 실험

**다음 실험에는 ‘실행 전체에 하나의 크기 보정값을 적용한 HRAC’를 후보로 남긴다.** 정상 seed42 하나로 기준을 잡았을 때, 정상43·44 오탐은 12/40에서 2/40으로 줄고, 공격42 안의 정상 오탐은 2/15에서 0/15로 줄었다. 위장자 1명은 계속 탐지했다. 추가로 실제 표적이나 클라이언트 클래스 분포를 제공하지 않았다.

다만 **기존 점수도 정상 기준 자료를 3회로 늘리면 공격42에서 오탐0/15·미탐0/1**이다. 정상 실행 교차 검증도 기존 방식과 공통 보정 모두 2/60이다. 따라서 확인한 개선은 한 정상 실행의 절대 크기에 민감한 부분을 줄였다는 것이며, 새로운 탐지법의 우월성이 확정된 것은 아니다. 후속 시험에서는 기존 점수와 공통 보정에 같은 정상 자료를 제공하여 비교한다.

창마다 따로 크기를 맞추면 정상43·44는 0/40이지만, 공격42에서 정상 client11이 위장자보다 높은 점수를 받았다. 패턴별 보정과 입력 반복 일치는 위장자를 놓쳤다. 오탐 숫자 하나만 보고 복잡한 조건을 계속 추가하지 않는다.

기존 실제 FL 관측을 다시 계산한 개발 실험이다. 새 학습·FU·intra 실험이 아니다. 이미 본 자료이므로 독립적인 최종 검증으로 해석하지 않는다.

## 1. 같은 기준 설정 조건에서 무엇이 바뀌었나

모든 방법은 정상 FUBA seed42의 요청 최대값으로 기준을 정했다. 공격 점수·정답 표적은 기준 설정에 사용하지 않았다.

| 방법 | 정상43·44 오탐 | 공격42 안의 정상 오탐 | 위장자 미탐 | 위장자 최고 클래스 / 실제 표적 순위 |
|---|---:|---:|---:|---:|
| 기존 HRAC | 12/40 (30.0%) | 2/15 | 0/1 | 7 / 9위 |
| 실행 전체에 공통 크기 보정 | 2/40 (5.0%) | 0/15 | 0/1 | 7 / 9위 |
| 창별 크기 보정 | 0/40 (0.0%) | 1/15 | 0/1 | 9 / 9위 |
| 패턴별 크기 보정 | 0/40 (0.0%) | 1/15 | 1/1 | 9 / 7위 |
| 패턴별 보정 + 입력 반복 일치 | 0/40 (0.0%) | 1/15 | 1/1 | 4 / 9위 |

FUBA 실제 공격 표적은 class8이다. 정상43·44는 독립 학습 2회이고, 공격42의 위장자는 1명이다. 여러 입력·요청·창을 독립 학습 실행으로 세지 않았다.

공통 보정 후 남은 정상 오탐은 seed43의 client1·5다. 창별 보정에서는 공격42의 정상 client11이 6.91244점으로 1위, 위장자 client4가 5.54681점으로 2위다. 공통 보정은 기존 순위를 그대로 유지하지만, 위장자의 최고 클래스는 여전히7이고 실제 표적8은 9위다. **요청자 식별 개선이 정화 위치를 찾았다는 뜻은 아니다.**

## 2. 기준 실행 하나에만 맞춘 결과인가

정상42·43·44에서 한 실행씩 통째로 제외하고 나머지 두 실행의 최대값으로 기준을 정했다. 세 평가를 합한 요청 수는 60개, 학습 실행 수는 3개다. 이는 같은 개발 자료를 재사용한 교차 검증이다.

| 방법 | 정상 실행 교차 검증 오탐 | 경보가 난 정상 실행 | 정상 3회로 보정 후 공격42 정상 오탐 | 위장자 미탐 |
|---|---:|---:|---:|---:|
| 기존 HRAC | 2/60 | 1/3 | 0/15 | 0/1 |
| 실행 전체에 공통 크기 보정 | 2/60 | 1/3 | 0/15 | 0/1 |
| 창별 크기 보정 | 1/60 | 1/3 | 1/15 | 0/1 |
| 패턴별 크기 보정 | 1/60 | 1/3 | 1/15 | 1/1 |
| 패턴별 보정 + 입력 반복 일치 | 1/60 | 1/3 | 1/15 | 1/1 |

마지막 두 열은 정상 3회 모두를 기준 설정에 사용했다. 그 3회를 다시 독립 정상 시험으로 보고하지 않는다. 기존 HRAC도 동일하게 보정하여, 개선이 점수식 때문인지 정상 기준 자료를 늘린 덕분인지 구별한다.

## 3. 실제로 바꾼 부분

기존 점수는 상쇄 비율뿐 아니라 기여량의 절대 크기에 비례한다. 실행 전체 공통 보정은 모든 창의 점수를 전체 이력 기여의 RMS 하나로 나누므로 실행 내부의 요청자·클래스 순위를 그대로 유지한다. 창별 보정은 각 창의 RMS를 사용하여 창 사이의 비중도 바꾼다. 패턴별 보정은 각 공개 입력 묶음·패턴에서 그 크기를 따로 계산한다. 반복 일치는 같은 창·패턴·출력 클래스에서 세 입력 묶음 점수의 중앙값을 사용한다. 다른 좌표의 큰 값 세 개를 모아 일치했다고 하지 않는다.

실제 정상 전체 이력의 기여 RMS는 seed42 0.18592, seed43 0.21474, seed44 0.26057이었다. seed44는 seed42보다 약40% 컸다. 전체 크기에 대한 민감도는 실제로 존재하지만, 이것만으로 Non-IID 오탐 전체가 설명되지는 않는다. 창별 보정은 크기 보정과 함께 최근 창을 더 강조하기 때문에 공통 보정과 구분했다.

추가 정답 정보는 쓰지 않는다. 기존 서버의 개별 업데이트·집계 비중·참여 이력·공개 입력을 계속 요구한다. 공격 트리거, 실제 표적, 클라이언트의 실제 악성 여부나 클래스 분포는 점수 계산에 넣지 않았다. 표적 순위는 사후 채점용이다.

보정 분모는 현재 실행의 모든 참여자 기록에서 추정하므로 공격자가 영향을 줄 수 있다. 정규화된 점수는 상대적인 의심 정도이며 삭제의 절대 피해 크기가 아니다. 반복 일치가 오탐을 줄이더라도 약한 공격 신호까지 없앨 수 있어 위장자 미탐을 함께 보고했다.

## 4. BadFU 진단

정상 clean5 기준을 full6에 적용한 비교여서 클라이언트 수가 다르다. 아래는 원인 진단이며 공정한 BadFU 오탐률 검증이 아니다.

| 방법 | full6 정상 경보 | 위장자 미탐 |
|---|---:|---:|
| 기존 HRAC | 4/4 | 0/1 |
| 실행 전체에 공통 크기 보정 | 0/4 | 0/1 |
| 창별 크기 보정 | 0/4 | 0/1 |
| 패턴별 크기 보정 | 0/4 | 0/1 |
| 패턴별 보정 + 입력 반복 일치 | 0/4 | 0/1 |

## 5. 이 결과로 아직 말할 수 없는 것

intra 관측은 여전히 없으므로 결합 탐지율은 계산하지 않았다. 클라이언트를 잘 찾아도 실제 표적을 못 찾을 수 있고, 삭제 후 ASR이나 정화 성능이 좋아지는지도 별도 실험이다. 정상 독립 실행이 3회뿐이므로 5% 오탐 보장이나 일반화 성능을 주장하지 않는다. 후속 실험에서는 새 정상·공격 시드를 사용하고 코드·기준값을 먼저 고정해야 한다.

모든 후보의 요청별 점수, 정상 실행별 기준값, 오탐 대상, 원본 해시와 계산 코드 해시는 results.json에 있다. normal_calibration.json은 이 실행에서 공격 자료를 계산하기 전에 저장했다. 이 순서는 기준값 누출을 막지만 이전 자료를 이미 본 사실을 없애지는 않는다.

실험 순서: refinement_v1에서 기존·창별·패턴별·반복 일치를 먼저 비교했다. 창별 보정이 최근 창을 강조하여 정상 client11을 1위로 올린 사실을 확인한 뒤, 실행 전체 공통 보정을 후속 소거 실험으로 추가했다. 후속 후보는 결과를 본 이후의 개발이며 사전 등록된 검증으로 포장하지 않는다. 첫 실행의 결과·설정·소스는 refinement_v1에 보존했다.

## 6. 실행 확인과 다음 비교

로컬과 DISLAB에서 실제 관측으로 계산한 요청·방법 조합455개의 점수가 완전히 같았다(최대 차이0). 기존 점수의 재현, 크기 변화에 대한 보정 점수의 불변성, 공통 보정의 순위 보존, 참여 이력 오류, 정상 자료만으로 기준 설정하는지 등을 포함한 코드 검사23개가 양쪽에서 통과했다. 코드 검사를 실제 FL 탐지 표본으로 세지 않았다.

`candidate_for_new_runs.json`에 두 후보와 기준값을 고정했다. 기존 점수는 1.0439326042, 공통 보정은 4.6936952785 수준이며 정확한 값은 JSON을 따른다. 새 정상·공격 seed45·46·47을 같은 초기값·분할·참여·학습 조건으로 쌍지어 비교하는 설계를 넣었다. **새 학습은 아직 시작하지 않았다.** 두 후보 모두 같은 정상42·43·44에서 보정한 기준을 사용하고, 새 결과를 보고 기준값을 바꾸지 않는 것이 다음 검증이다.

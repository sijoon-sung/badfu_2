# 조건 변경과 보류 판단의 이력

실제 기록에 날짜가 있는 변화와 문서 내용상 연결을 구분한다. 아래 `보류`는 원문 보고서의 권고·범위 변경이며, 프로세스를 종료한 명령과 시각까지 확인했다는 뜻은 아니다.

| 단계 | 왜 바꿨는가 | 추가·변경한 조건 | 결과와 막힌 지점 | 기록에 남은 판단 |
|---|---|---|---|---|
| 과거 기여 차감 | 삭제 효과를 싸게 살펴보기 | 최종 모델에서 누적 기여 차감 | 정상 삭제도 정확도가 붕괴. no-delete 보정도 ASR 상승 | 실제 FU와 대용 모델을 분리 |
| HRAC 입력 관측 | 정상 입력만으로 후보가 드러나지 않음 | 원본-패턴 입력 쌍 반응, 다중 창 | 후보 순위는 개선. 단순 기준선도 후보를 찾고 FUBA 타깃은 낮은 순위 | 이력 점수의 우월성 미확인 |

| 최근 FC·BN 검사 | 가중치만으로 간단한 탐지 시도 | 저장 복제 모델 확인 | 고정한 FC·BN은 변화0 | 학습하지 않은 층의 차이를 신호로 사용할 수 없음 |
| 순수 FC·Conv 진단 | 기존100스텝 Conv 비율 중첩 | 한 지점의 전체 평균 CE 기울기, KL·clip 등 제거 | 기존16건 분리. 코사인·Gini는 중첩 | 개선 원인을 KL 하나로 특정하지 않음 |

## 잘못 설명됐던 부분과 정정 근거

1. **이력 부족:** 최근16건에 대응하는 자료 문제였다. 과거 BadFU·FUBA 전체 이력과 이력 탐지 실행은 존재한다.
2. **공통 KL이 대부분을 차지:** 80–90%라는 비중은 측정값이 아니다. KL 없는 순수1스텝에서도 공격 코사인이 양수였다.
3. **직접 차분으로 바꾸면 해결:** 이전 Gini가 이미 직접 차분을 사용했고, 노름·Gini는 여전히 겹쳤다.
4. **Conv 직교 잔차1.15–2.20:** 과거 해당 범위는 F노름이 아니라 최대 특이값 기준이었다. 지표 정의를 통일해야 한다.
5. **전체 삭제로2.33%:** P180+C540을 지운 동일 크기 안전 요청 결과였다. 전체 삭제 정책 검증이 아니다.
6. **정화 수치가 좋으므로 잠복 방어 완성:** 저자 계열 일부 모델은 삭제 전부터 ASR이 높았고, 일부 개선은 후속 시드에서 재현되지 않았다.

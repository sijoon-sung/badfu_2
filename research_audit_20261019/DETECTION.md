# 탐지 방법과 실패 원인

탐지는 요청의 위험을 구별하는 문제다. 공격자 후보 순위1위, 타깃 클래스 추정, 정상/악성 판정, 실제 FU 위험 예측은 각각 다른 결과다.

| 방법 | 실제 확인한 문제 | 설명의 근거 수준 | 자세한 기록 |
|---|---|---|---|
| FC·Conv 비율 | 정상 자료를 선택하는 방식만 바꿔도 높은 점수와 경보 | 수치 재계산·대응36쌍 분해·수학 항등식 | [노름·잔차](detection/ratio.md) |
| HRAC 이력 | 정상 실행 사이의 점수 크기 차이, 보정에 따른 공격 신호 손실 | 실제 관측의 보정 비교. 일반 Non-IID 원인 전체는 미확인 | [이력·GLR](detection/history.md) |
| 정상 설명 집합 | 설명 불능으로11건 모두 미판정 | 원본 scores와 가정 불충족 기록 | [설명 집합·차감](detection/normal_set.md) |
| 고정 패치 | 최근84건에서 미탐1·오탐3 | 판정식의 a,b까지 수치로 확인. 생기는 원인 전체는 미확인 | [패치 두 분기](detection/patch.md) |
| 랜덤 배경 | 원래 방식의 공격·대조 범위 중첩 | 입력 보정의 일부 실험만 존재 | [랜덤 입력](detection/random.md) |
| 집중도·코사인·부분공간 | 초기16건의 범위 중첩 | 관측과 반례. 특정 휴면 뉴런 가정은 지지 못 함 | [기존 D15–D23 목록](../pr_reports/INDEX.md) |

| 같은 84요청 | 공격 탐지 | 대조 오탐 |
|---|---|---|
| 패치 두 분기 | 11/12 | 3/72 |
| FC 노름 | 8/12 | 5/72 |
| Conv 노름 | 7/12 | 3/72 |
| FC 잔차 | 6/12 | 5/72 |
| Conv 잔차 | 6/12 | 3/72 |

![같은 요청에서의 결과](figures/common84.png)

패치100스텝과 순수 기울기0갱신은 자원 조건이 다르다. 차이를 점수의 기하학적 성질 하나에만 돌리지 않는다. [같은84건의 전후 성능과 점수](evidence/common_84_requests.csv)

원격의 현재 상태 파일은 갱신 시점에 `running`을 기록하지만, 이번 정리는 프로세스의 현재 생존을 별도로 확인하지 않았다. 진행 상태와 완료된84건을 구분한다.

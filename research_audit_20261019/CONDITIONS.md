# 비교 전에 구분해야 하는 실험 조건

모델·학습 방식·삭제 단위가 다른 결과를 같은 공격의 반복 결과처럼 합치지 않는다.

| 실험군 | 학습과 자료 | 삭제·진단 | 구분해야 할 점 |
|---|---|---|---|
| 저자 코드 계열 BadFU | seed42, 40R, local epoch5, full6·cover5·bd5·clean5 | 저장된 FU remove5/remove1 | 본문 단일 클라이언트 내부 샘플 삭제와 공개 코드의 별도 클라이언트 구성을 구분 |
| 기존 BadFU15R | 별도 보존 실행, 15라운드 | 보존된 1단계 FU 모델의 재평가 | no-delete 보정만으로 ASR이 오르는 조건. 40R 결과와 결합하지 않음 |
| 공식 코드 계열 FUBA100R | CIFAR10/ResNet18, K20, 참여8명, Dirichlet α0.5, seed42 | FL 전체 이력과 HRAC 관측. 정상 seed42/43/44도 보존 | 입력 의존 생성기와 고정 모서리 패치의 관측 불일치를 별도 가설로 둠 |
| 최근 조정된 BadFU형 실험 | CIFAR10/ResNet18, 5명, 기본6,000장, 40R, local epoch1 | 같은 초기화의 잔류 자료 재학습 | 원 논문·저자 코드 전체 규모 재현으로 부르지 않음 |
| 최근 패치 진단 | 위 모델에서 R/F 각100스텝, layer4만, KL2·clip1·BN 고정 | 정상 기준500장, 개발200장, 검증200장, 32패턴 | 두 분기 모두 CE 감소 학습. 실제 FU가 아님 |
| 최근 순수 기울기 진단 | 같은 삭제 전 모델의 R/F 평균 CE 기울기 | 추가 기준0장, KL0·clip0·갱신0회 | 개인 R/F는 필요. 완전 무자료 아님 |
| 정상 삭제 스트레스 | 독성·억제 자료 없는 정상 모델 | 무작위·다수 클래스·쉬운·어려운 삭제, 10/30/60% | 실제 삭제 후 재학습·ASR 측정 없음. 패치 검사도 미적용 |
| 반응 전이 정화 | 기존 조정된 4개 공격 시드의 실제 전후 쌍 | 요청자 제외 정상4명 협력, 전체 가중치100회·BN 고정 | fit800/probe320/validation640은 잔류 학습 자료에서 분리 |

## 최근 요청 7종의 실제 의미

B는 요청자 정상 자료1,200장, P는 타깃 라벨 독성180장, C는 같은 패치·원래 정답 억제720장이다. Q는 정상 클래스0 자료180장, N은 패치 없이 라벨만0으로 바꾼180장이다.

| 요청 | 남기는 자료 | 지우는 자료 |
|---|---|---|
| 공격 | B+P | C |
| 같은 크기의 안전 삭제 | B+C180 | P+C540 |
| 독성 삭제 | B+C | P |
| 양쪽 삭제 | B | P+C |
| 정상 클래스 편향 | B+Q | C |
| 오라벨 | B+N | C |
| 정답 패치 삭제 | B | C |

**2.33%였던 안전 삭제는 요청자 전체 삭제가 아니다.** 최근 `20/70/90%`는 P/C 등을 추가하기 전 기본 클라이언트 자료의 두 클래스 합계 비중이다. `10/30/60%`는 별도 정상 스트레스에서의 삭제 비율이다.

## 평가 수치의 정의도 다르다

저자 계열 manifest는 BadFU ASR을 `모든 bd_test에서 target0 예측 비율`로 기록한다. 최근 조정된 실험과 새 정화 평가는 타깃 원본 클래스를 제외한다. 평가 표본·분할도 다르므로 81.21%와81.51% 같은 차이를 같은 평가의 재현 오차라고 단정하지 않는다.

FUBA의 저장 저자 평가에는 개별 생성기·train 모드라는 정의가 기록돼 있다. 과거 추가 검증기의 평균 생성기·eval 모드 결과와 나란히 쓸 때 정의를 같이 적는다. 어느 경로가 실패 원인인지 측정하지 않았다면 가설로 남긴다.

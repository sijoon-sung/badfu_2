# D17 정상 기능을 약화한 복사본과 원래 모델의 직접 탐색 비교

## 실험을 시작한 이유

D15에서는 추가 시드의 공격 오류 7%, 큰 정상 삭제 8%로 구별되지 않았다. 이번에는 정상 분류 기능을 약화한 복사본에서 변형을 찾는 과정이 도움이 되는지 검사했다. 원래 모델에서 직접 찾는 400회와 800회 탐색도 함께 실행했다.

## 사용한 모델과 자료

BadFU 두 학습 시드의 실제 전후 5쌍을 사용했다. 위장 850장 삭제 2쌍, 정상 850장 삭제 2쌍, 큰 정상 참여자 9,668장 삭제 1쌍이다. 후 모델은 남은 자료 전체 재학습이다. 두 학습 시드는 같은 분할을 공유한다.

## 실제 진행 순서

1. 공개 이미지를 복사본 수정용 500장, 변형 탐색용 320장, 후보 선택용 320장, 최종 확인용 1,000장으로 나눴다. 네 집합과 이전 paired probe의 공개 이미지는 겹치지 않게 했다.
2. 직접 탐색은 수정하지 않은 후 모델에서 400회 진행하고 같은 경로를 800회까지 이어 계산했다.
3. 복사본 이용 방법은 후 모델 복사본의 정상 정답 손실을 높였다. 정확도 10% 이하 또는 손실 40 이상에서 중단하고 최대 20에포크로 제한했다. 그 복사본에서 변형을 400회 찾았다.
4. 세 방법 모두 마스크, 공통 가산, 입력 의존 변형과 10개 목표, 두 초기값을 검사했다. 실제 트리거와 목표 정답은 주지 않았다.
5. 원래 전후 모델의 선택용 자료로 후보를 고정한 뒤 원본 모델과 확인 1,000장, 정상 참여자 3명의 각 512장에서 확인했다. 복사본에서만 생긴 오류는 세지 않았다.

## 결과

원본을 전후 모두 맞히고, 변형하면 전에는 정답이고 후에는 선택한 같은 오답이 되는 이미지를 셌다. 아래 분모는 선택 목표 외 900장이며 실제 공격 ASR이 아니다.

| 삭제 조건 | 직접 400회 | 직접 800회 | 복사본 이용 400회 |
|---|---:|---:|---:|
| 첫 시드 위장 850장 | 56.22% | 57.67% | 2.67% |
| 첫 시드 정상 850장 | 14.78% | 13.00% | 10.33% |
| 추가 시드 위장 850장 | 56.00% | 67.22% | 69.22% |
| 추가 시드 정상 850장 | 5.22% | 6.44% | 2.67% |
| 추가 시드 큰 정상 참여자 | 7.33% | 8.00% | 2.00% |

## 결과를 보고 내린 판단

복사본 이용은 첫 공격 시드에서 크게 나빠지고 다른 시드에서는 좋아졌다. 정상 기능 약화가 안정적으로 더 잘 찾게 한다는 가설은 맞지 않았다. 원래 모델 직접 탐색은 두 공격 모두 정상 대조보다 높았고 정상 참여자 확인에서도 같은 순서였다. 이 유리한 결과는 보존했다.

강한 후보는 두 공격 모두 마스크였다. 다른 트리거 종류와 다른 분할, 큰 정상 삭제 여러 건에서도 구별되는지는 확인하지 않았다. D15와는 자료 분할, 초기값, 동점 처리도 바뀌어 개선 이유를 횟수 하나로 단정하지 않았다. 15개 최종 결과의 원저자 모델 독립 재계산은 일치했다.

# D08 같은 잔류 참여자의 삭제 전후 응답 비교

## 실험을 시작한 이유

정상 자료의 구성이나 참여자 구성이 달라서 반응이 달라지는 문제를 줄이려고, 전후에 같은 잔류 참여자와 같은 자료로 새 응답을 계산했다. 공개 정상 응답도 빼고 클래스를 균등하게 맞추면 큰 정상 참여자의 탈퇴와 공격 삭제를 구별할 수 있는지 확인했다.

## 사용한 모델과 자료

BadFU 위장 850장 삭제와 전체의 22.790%, 19.336%인 정상 참여자 삭제에 같은 보존 5시점 FU 규칙을 적용했다. 유지 자료 전체 재학습 쌍과 실제 저자 FU 쌍도 참고로 따로 보관했다. 잔류 참여자당 최대 512장, 공개 자료는 개입 크기 선택 500장과 별도 확인 320장을 사용했다.

## 실제 진행 순서

1. 삭제 전 모델과 삭제 후 모델 각각에 같은 방향으로 작은 양의 교란과 음의 교란을 가했다. 모델쌍마다 네 상태를 만들었다.
2. 네 상태 모두에서 같은 잔류 참여자의 같은 이미지와 라벨로 응답을 새로 계산했다. 참여자 비중도 고정했다.
3. 양과 음의 응답 차이에서 공개 정상 자료의 같은 응답을 뺐다. 이 보정 응답이 전후 얼마나 달라졌는지 정규화한 D를 구했다.
4. 마지막 Conv를 주 관측으로 정하고 FC, 클래스 비중 유지, 무작위 방향 두 개와 FU 방향을 함께 저장했다. 개입 자체가 정상 정확도를 1%p 넘게 낮추지 않도록 크기를 제한했다.
5. 점수를 고정한 뒤 실제 트리거의 공격 성공률과 정상 정확도를 별도 평가했다.

## 결과

| 같은 FU 규칙의 BadFU 조건 | Conv 응답 점수 D |
|---|---:|
| 위장 850장 삭제 | 0.75848 |
| 정상 참여자 19.336% 삭제 | 0.75525 |
| 정상 참여자 22.790% 삭제 | 0.76188 |

공격 점수가 두 정상 값 사이에 놓였다. 유지 자료 재학습 쌍에서도 위장 삭제 0.70794, 감염 모델의 정상 삭제 0.70360으로 가까웠다. 개입의 최대 정상 정확도 하락은 별도 확인에서 0.625%p였다.

## 결과를 보고 내린 판단

참여자와 자료를 맞추고 참조를 빼도 이 응답 점수로 구별하지 못했다. 같은 잔류 집합은 구성 변화를 통제하지만, 큰 정상 삭제 때문에 모델이 달라지는 효과까지 없애지는 못했다. 이 실험의 핵심 실패는 관측이 부족했다는 사실보다 정상 탈퇴도 같은 반응을 만든다는 점이다.

과거 FUBA의 단축 FU는 정상 정확도가 약 10%로 무너져 비교에서 제외했다. BN만 다시 추정해도 회복되지 않았다. 기능이 유지된 과거 FUBA 쌍도 사전 억제 실패가 확인돼 유효한 잠복 공격 검증으로 쓰지 않았다. 이 한 점수의 실패를 모든 능동 진단의 불가능성으로 확대하지 않았다.

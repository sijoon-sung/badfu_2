# D04 마지막 제출 제외와 참여자 역할 검사

## 실험을 시작한 이유

참여자의 최신 제출을 제외했을 때 패턴 반응이 줄면 주입 역할, 늘면 억제 역할로 볼 수 있는지 검사했다. 정상 입력의 변화로 보정하면 정상 참여자의 큰 기여를 걸러낼 수 있는지도 함께 비교했다.

## 사용한 모델과 자료

기존 글로벌 모델 7개와 마지막 라운드 개별 제출을 사용했다. BadFU 혼합형과 분리형, FUBA 공격, 정상 FUBA seed42·43·44가 포함됐다. 정상 seed42만 임계값 보정에 썼다. 선택용 80장과 확인용 80장은 분리했다. 새 FL 학습이나 새 FU는 하지 않았다.

## 실제 진행 순서

1. 참여자 한 명의 마지막 제출을 제외해 48개 집계 모델을 만들었다. 실제 BadFU FU 끝점 2개도 참고로 계산했다.
2. 32개 패치와 10개 클래스를 탐색했다. 확인 자료에서 원 점수, 정상 입력 변화로 나눈 점수, 양과 음의 상쇄 점수를 구했다.
3. 정상 보정 실행의 최대값을 엄격히 초과할 때 경보했다. 그 뒤 같은 후보에 대한 부호 있는 참여자 기여를 역할 임계값과 비교했다.
4. 결과 차이가 생긴 이유를 확인하려고 같은 BadFU pre, 같은 패치, 같은 이미지를 고정하고 실제 FU와 최신 제출 제외만 바꿔 재계산했다.

## 결과

정상 변화 보정은 BadFU 공격 두 구성에 경보했지만 FUBA 공격을 놓쳤고, 보정에 쓰지 않은 정상 FUBA 2개 중 1개를 경보했다. 상쇄 점수는 정상 2개를 모두 경보했다.

BadFU 분리형의 실제 주입자와 위장자는 각각 순위 1위였지만 고정 역할 임계값을 넘지 못했다. FUBA에서는 억제자 ID4를 주입자로, 정상 ID11과 ID14를 억제자로 잘못 지목했다.

| 같은 BadFU pre와 같은 입력에서 비교 | 패치 확률 반응 차분 |
|---|---:|
| 실제 FU 모델 | 19.66%p |
| 마지막 위장자 제출만 제외한 모델 | 2.55%p |

## 결과를 보고 내린 판단

이번 최신 제출 제외 점수로 공격과 정상, 주입과 억제를 안정적으로 구별하지 못했다. 마지막 한 번의 업데이트 제외는 과거 전체 기여를 삭제하는 FU와 다르다는 점도 직접 확인했다.

이 실패를 기존 실제 전후 패치 검사의 실패로 설명했던 부분은 정정했다. 보존된 84요청의 원 점수 재계산은 공격 11/12, 대조 경보 3/72로 유지됐다. 순위, 임계값 판정, 모델 위험, 요청자의 의도는 각각 따로 적었다.

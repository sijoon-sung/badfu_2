# D15 두 학습 시드와 정상 참여자 자료에서 전후 탐색 확인

## 실험을 시작한 이유

한 모델에서 얻은 좋은 입력 변형 결과가 다른 학습 시드에서도 유지되는지 확인했다. 삭제 후 모델만 이용한 탐색과 전후 모델을 함께 이용한 탐색을 비교하고, 선택에 쓰지 않은 정상 참여자의 자료에서도 같은 오류가 재현되는지 검사했다.

## 사용한 모델과 자료

BadFU seed20261020과 seed20261023의 실제 전후 5쌍을 사용했다. 공격 위장 850장 삭제 두 쌍, 감염 또는 정상 모델의 정상 850장 삭제 두 쌍, 큰 정상 참여자 19.336% 삭제 한 쌍이다. 후 모델은 유지 자료 전체 재학습이다. 두 시드는 같은 분할을 공유했다.

## 실제 진행 순서

1. 마스크, 전역 가산, 입력 의존 변형을 각각 200단계, 초기값 2개로 탐색했다.
2. 삭제 후 모델만 보는 방법과 전후를 함께 보는 방법을 비교했다. 전후 방법은 분류기 기울기 계산이 두 배여서 같은 연산량 비교로 부르지 않았다.
3. 공개 보정 320장에서 변형과 목표, 초기값을 고정했다.
4. 선택이 끝난 뒤 공개 1,000장과 정상으로 지정한 참여자 1·2·3의 자료 각 512장에 적용했다. 참여자 자료는 원 FL 학습에는 쓰였지만 이번 변형 탐색과 선택에서는 분리됐다.
5. 원본 전후 정답을 유지하면서 변형 후에만 새 목표 오류가 나는 비율을 셌다. 실제 외부 참여자 통신이 아닌 저장 자료를 이용한 모의 확인이다.

## 결과

| 전후 공동 탐색의 공개 확인 | 새 목표 오류 비율 |
|---|---:|
| 첫 시드 위장 삭제 | 44.78% |
| 첫 시드 감염 모델 정상 삭제 | 6.56% |
| 추가 시드 위장 삭제 | 7.00% |
| 추가 시드 정상 850장 삭제 | 3.78% |
| 추가 시드 큰 정상 참여자 삭제 | 8.00% |

추가 시드에서는 공격이 큰 정상 삭제보다 낮았다. 정상 참여자 확인에서도 두 공격을 일관되게 분리하지 못했다. 위 비율은 실제 트리거 ASR이나 운영 탐지율이 아니다.

## 결과를 보고 내린 판단

첫 시드에서 좋았던 결과가 추가 시드에서 유지되지 않았다. 전후 모델과 정상 참여자의 확인 자료를 추가해도 공격에만 나타나는 행동이 자동으로 확보되지는 않았다. 독립 정상 보정에 의한 임계값은 만들지 않았다. 이후 별도로 진행한 D17의 유리한 결과도 이 실패와 함께 남겼다.

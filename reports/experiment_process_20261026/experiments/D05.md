# D05 중간 특징에서 특정 출력으로 쏠리는 정도 검사

## 실험을 시작한 이유

입력 패턴의 형태를 정하지 않고 분류기 중간 특징에서 공격 관련 이상을 찾을 수 있는지 확인했다. FreeEagle의 발상을 따라, 가상의 특징을 각 클래스로 분류하도록 최적화한 뒤 다른 출력으로 얼마나 쏠리는지 측정했다.

## 사용한 모델과 자료

보존 분류기 22개와 전후 비교 13쌍을 사용했다. BadFU 위장 삭제, 정상 클래스 집중 삭제, 무작위 삭제, 큰 정상 참여자 삭제와 과거 FUBA 진단 조건을 포함했다. 같은 모델이 여러 쌍에 들어가므로 13개 독립 학습이 아니다.

## 실제 진행 순서

1. ResNet18의 layer2 뒤에서 분류기를 나눴다. layer3 뒤에서도 같은 검사를 해 절단 위치 영향을 확인했다.
2. 클래스마다 두 초기값에서 가상 특징을 만들었다. Adam 학습률 0.05, 200회, L2 계수 0.005를 적용하고 특징이 음수가 되지 않게 제한했다.
3. 두 특징의 평균을 후반 분류기에 넣고 출력 확률 행렬을 만들었다. 자기 클래스를 제외한 열 평균으로 출력 쏠림을 구했다.
4. 최대값과 상위 사분위의 간격을 사분위 범위로 나눈 M, 그리고 M에서 1까지의 거리 M′를 계산했다. 전후 최대값과 변화량을 따로 보관했다.

## 결과

대표 BadFU의 전후 M′ 최댓값은 12.983이었다. 이전 정상 비교에서는 14.570으로 더 컸다. FUBA 진단 한 쌍은 공격 0.799, 정상 0.695였지만 다른 정상 조건까지 일관되게 분리하지 못했다. 최적화한 특징은 모두 의도한 자기 클래스로 분류됐다.

## 결과를 보고 내린 판단

가상 특징을 잘 최적화하는 것과 공격 모델만 이상 점수를 내는 것은 달랐다. 픽셀 입력 대신 중간 특징을 사용해도 정상 분포 편향에서 큰 점수가 나올 수 있었다. 이번 구현을 공통 탐지 특징으로 채택하지 않았다. 원 FreeEagle 전체 벤치마크를 재현한 결과나 그 방법 전체의 실패로 확대하지 않았다.

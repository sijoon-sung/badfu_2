# N01 신뢰 기준 모델을 더하는 제안의 보류

## 제안이 나온 이유

정상 삭제와 공격의 반응 점수가 겹친 뒤, 같은 삭제 조건을 반영한 신뢰 기준 모델이 있으면 공격에 따른 기능 훼손을 나눠 볼 수 있다는 생각이 제시됐다. 이 항목은 완료 실험이 아니다.

## 검토한 내용

1. D02에서는 정상 참조 영향을 빼도 정상 주요 클래스 삭제 점수가 공격보다 컸다.
2. D08에서는 같은 잔류 참여자의 새 응답을 얻고 정상 참조를 빼도 공격이 큰 정상 삭제 두 값 사이에 놓였다.
3. D15에서는 정상으로 지정한 참여자 자료의 추가 확인도 두 시드 구별을 만들지 못했다.
4. 새로운 기준 모델을 실제로 어떻게 확보하고, 같은 정상 삭제 조건을 얼마나 대표하며, 왜 같은 반례를 만들지 않을지 확인하지 못했다.

## 현재 판단

이전 참조와 다른 자원일 수는 있지만, 추가 정보라는 이유만으로 해결된다고 말할 근거가 없다. 해당 기준 모델을 만들고 검증한 결과도 없으므로 미실행 제안으로 보류한다. 교수 미팅에서는 실험 횟수나 성공 결과에 포함하지 않는다.

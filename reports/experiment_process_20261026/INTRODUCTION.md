# BadFU 실험 과정과 결과

2026년 10월 26일 정리

## 확인하려는 문제

BadFU에서는 정상 정답을 유지하는 위장 자료가 독성 자료의 효과를 억제한다. 위장 자료를 삭제하고 독성 자료가 남으면 공격이 강해질 수 있다. 연구에서 확인하려는 문제는 실제 트리거를 모르는 서버가 이 상황을 큰 정상 non-IID 참여자의 탈퇴와 구별할 수 있는가이다.

현재 BadFU의 위장 제거 후 활성화는 확인했다. 그러나 큰 정상 삭제도 여러 반응 점수에서 공격과 비슷하거나 더 큰 값을 만들었다. 입력 변형 직접 탐색과 FC 부분공간 검사에는 유리한 일부 결과가 있지만, 다른 트리거 종류와 정상 분포까지 통하는 탐지는 확인하지 못했다. FUBA는 실제 100라운드와 KD10 전후 모델을 만들었지만 잠복 활성화 성능 목표를 충족하지 못했다.

## 실험의 진행 흐름

초기에는 유지 자료와 삭제 자료로 각각 학습한 진단 모델을 만들어 패치 반응을 비교했다. 개발 조건의 좋은 결과를 새 시드와 정상 삭제에 적용하면서 일부 누락과 경보가 나타났다. 같은 자료에서 FC와 Conv 기울기, 직교 잔차, 학습 순서를 검사했고, 쉬운 정상 자료 삭제에서도 큰 값이 나오는 반례를 확인했다.

다른 갈래에서는 학습 이력과 정상 참조, 중간 특징, 망각 진단, 서버 과제 삽입을 검사했다. 같은 잔류 참여자에게 새 응답을 받는 실험에서도 정상 큰 삭제와 겹치는 점수가 남았다. 큰 반응을 찾는 것과 공격에서만 나타나는 행동을 찾는 것을 구분해 기록했다.

입력 행동 검사에서는 합성 입력, 고정 패턴, 자유 마스크, 입력 의존 규칙을 차례로 비교했다. 탐색 자료에 맞은 오류가 별도 입력에서는 재현되지 않는 경우가 많았다. 두 학습 시드의 직접 400회 탐색에서는 유리한 관측을 얻었지만 강한 후보는 마스크였다. 정상 기능을 약화한 복사본이 더 잘 찾게 한다는 가설은 일관되게 맞지 않았다.

정화는 탐지와 별개로 수행했다. 반응 전이는 작은 정상 변경 예산에서 도움이 됐지만 큰 예산에서는 비교법이 더 강했다. 마지막 분류층 교정도 한 모델에서 좋았지만 반례 보강이 다른 재학습 모델에서는 공격을 다시 키웠다. 좋은 후보가 있는 문제와 그 후보를 정상 자료로 선택하는 문제를 따로 확인했다.

2026년 10월 25일 FC 특징 부분공간 진단에서는 BadFU 한 시드의 세 쌍이 분리됐다. 그러나 투영 전에도 같은 판정이 나왔고 과거 FUBA 진단 쌍에서는 분리되지 않았다. 이 결과는 앞선 정상 non-IID 반례를 지운 성공으로 합치지 않았다.

## 모델과 지표를 읽는 기준

| 표현 | 실제 의미 |
|---|---|
| 유지 자료 전체 재학습 | 같은 초기값부터 삭제 자료를 제외하고 전체 학습을 다시 수행 |
| 저자 FedEraser 또는 5시점 FU | 보존 이력과 잔류 참여자 재보정으로 만든 별도 삭제 절차 |
| 최신 제출 제외 | 마지막 한 번의 집계에서 특정 제출을 뺀 진단 모델 |
| 복사본 수정 | 검사에만 쓰기 위해 추가 학습하거나 층을 교체한 모델 |
| ASR | 평가자만 아는 실제 트리거의 목표 오분류 비율 |
| 새 목표 오류 비율 | 탐색한 변형에서 삭제 후에만 생긴 목표 오류의 비율 |
| 요청 또는 후보 수 | 같은 학습 모델을 공유할 수 있어 독립 학습 시드 수와 다름 |

각 실험의 순서는 시작 이유, 모델과 자료, 실행 순서, 결과, 판단이다. 숫자의 분모와 평가 조건은 해당 실험에 붙였다. 뒤의 과거 세부 기록은 당시 판정과 수치를 보존하며 본문의 현재 카드와 번호를 구분했다.

# BadFU 실험 과정과 결과

2026년 10월 26일 정리

## 확인하려는 문제

BadFU에서는 정상 정답을 유지하는 위장 자료가 독성 자료의 효과를 억제한다. 위장 자료를 삭제하고 독성 자료가 남으면 공격이 강해질 수 있다. 연구에서 확인하려는 문제는 실제 트리거를 모르는 서버가 이 상황을 큰 정상 non-IID 참여자의 탈퇴와 구별할 수 있는가이다.

현재 BadFU의 위장 제거 후 활성화는 확인했다. 그러나 큰 정상 삭제도 여러 반응 점수에서 공격과 비슷하거나 더 큰 값을 만들었다. 입력 변형 직접 탐색과 FC 부분공간 검사에는 유리한 일부 결과가 있지만, 다른 트리거 종류와 정상 분포까지 통하는 탐지는 확인하지 못했다. FUBA는 실제 100라운드와 KD10 전후 모델을 만들었지만 잠복 활성화 성능 목표를 충족하지 못했다.

## 실험의 진행 흐름

초기에는 유지 자료와 삭제 자료로 각각 학습한 진단 모델을 만들어 패치 반응을 비교했다. 개발 조건의 좋은 결과를 새 시드와 정상 삭제에 적용하면서 일부 누락과 경보가 나타났다. 같은 자료에서 FC와 Conv 기울기, 직교 잔차, 학습 순서를 검사했고, 쉬운 정상 자료 삭제에서도 큰 값이 나오는 반례를 확인했다.

다른 갈래에서는 학습 이력과 정상 참조, 중간 특징, 망각 진단, 서버 과제 삽입을 검사했다. 같은 잔류 참여자에게 새 응답을 받는 실험에서도 정상 큰 삭제와 겹치는 점수가 남았다. 큰 반응을 찾는 것과 공격에서만 나타나는 행동을 찾는 것을 구분해 기록했다.

입력 행동 검사에서는 합성 입력, 고정 패턴, 자유 마스크, 입력 의존 규칙을 차례로 비교했다. 탐색 자료에 맞은 오류가 별도 입력에서는 재현되지 않는 경우가 많았다. 두 학습 시드의 직접 400회 탐색에서는 유리한 관측을 얻었지만 강한 후보는 마스크였다. 정상 기능을 약화한 복사본이 더 잘 찾게 한다는 가설은 일관되게 맞지 않았다.

정화는 탐지와 별개로 수행했다. 반응 전이는 작은 정상 변경 예산에서 도움이 됐지만 큰 예산에서는 비교법이 더 강했다. 마지막 분류층 교정도 한 모델에서 좋았지만 반례 보강이 다른 재학습 모델에서는 공격을 다시 키웠다. 좋은 후보가 있는 문제와 그 후보를 정상 자료로 선택하는 문제를 따로 확인했다.

2026년 10월 25일 FC 특징 부분공간 진단에서는 BadFU 한 시드의 세 쌍이 분리됐다. 그러나 투영 전에도 같은 판정이 나왔고 과거 FUBA 진단 쌍에서는 분리되지 않았다. 이 결과는 앞선 정상 non-IID 반례를 지운 성공으로 합치지 않았다.

## 모델과 지표를 읽는 기준

| 표현 | 실제 의미 |
|---|---|
| 유지 자료 전체 재학습 | 같은 초기값부터 삭제 자료를 제외하고 전체 학습을 다시 수행 |
| 저자 FedEraser 또는 5시점 FU | 보존 이력과 잔류 참여자 재보정으로 만든 별도 삭제 절차 |
| 최신 제출 제외 | 마지막 한 번의 집계에서 특정 제출을 뺀 진단 모델 |
| 복사본 수정 | 검사에만 쓰기 위해 추가 학습하거나 층을 교체한 모델 |
| ASR | 평가자만 아는 실제 트리거의 목표 오분류 비율 |
| 새 목표 오류 비율 | 탐색한 변형에서 삭제 후에만 생긴 목표 오류의 비율 |
| 요청 또는 후보 수 | 같은 학습 모델을 공유할 수 있어 독립 학습 시드 수와 다름 |

각 실험의 순서는 시작 이유, 모델과 자료, 실행 순서, 결과, 판단이다. 숫자의 분모와 평가 조건은 해당 실험에 붙였다. 뒤의 과거 세부 기록은 당시 판정과 수치를 보존하며 본문의 현재 카드와 번호를 구분했다.



# R01 BadFU 학습과 삭제 전후 모델 확인

## 실험을 시작한 이유

탐지 결과를 비교하려면 먼저 공격이 실제로 재현됐는지, 삭제 후 모델이 어떤 절차로 만들어졌는지 확인해야 한다. 폴더 이름이 FU라고 되어 있어도 유지 자료 전체 재학습과 FedEraser는 계산이 다르다. 이번 확인은 모델 출처와 학습 계산을 점검하는 작업이다.

## 사용한 모델과 자료

논문 기준 프로필은 CIFAR 10, 사전 학습 ResNet18, 참여자 5명, Dominant 0.7 분할이다. 공격 참여자 C0에 정상 자료와 독성 850장, 위장 850장을 함께 배치했다. 위장 자료에는 독성 자료와 같은 트리거를 넣고 원래 정답 라벨을 유지했다. 통신 40라운드, 로컬 5에포크, 배치 32, SGD 학습률 0.01을 사용했다.

대표 끝점은 badfu.confirmed.s20261023.v1, 개별 참여자 제출까지 있는 전체 이력은 badfu.paper32.s20261020이다. 두 사례를 같은 실행으로 합치지 않았다.

## 실제 진행 순서

1. 저자 코드의 고정 버전과 모델 생성자, 로컬 학습, FedAvg 함수를 대조했다.
2. 삭제 전 50,000장과 위장 제거 후 49,150장을 저자 데이터 처리 방식으로 다시 구성했다. 정규화된 픽셀과 라벨이 현재 입력과 같은지 확인했다.
3. seed20261023의 삭제 전후 첫 라운드를 저자 학습 함수로 다시 계산했다. 참여자 5명씩 총 10개 제출과 두 집계 모델을 저장값과 비교했다.
4. 최종 모델을 정상 이미지 10,000장과 실제 목표 클래스 제외 트리거 이미지 9,000장으로 평가했다.
5. 정상 모델의 평가값 차이를 추적해 channels last와 contiguous NCHW 입력 형식의 차이를 확인했다. 학습 모델은 유지하고 수정 평가를 별도로 저장했다.

## 결과

| 실행 | 삭제 전 정확도 | 삭제 전 ASR | 재학습 후 정확도 | 재학습 후 ASR |
|---|---:|---:|---:|---:|
| 논문 3회 평균 | 84.84% | 21.55% | 83.90% | 99.32% |
| seed20261020 | 88.23% | 16.14% | 88.15% | 99.99% |
| seed20261023 | 90.38% | 14.29% | 90.46% | 100.00% |

10개 첫 라운드 제출 해시와 집계 텐서는 일치했다. 정상 모델에서는 입력 형식 변경으로 ASR이 1.4111%에서 1.3889%로 달라졌다. 공격 모델의 전후 ASR은 바뀌지 않았다. 위 표는 저자 함수에 맞춘 contiguous NCHW 평가 기록이다.

## 결과를 보고 내린 판단

위장 자료를 제거하면 공격이 강해지는 현상은 관측했다. 이번 삭제 후 모델은 같은 초기값부터 남은 자료로 전체 재학습한 결과이며, FedEraser 결과로 표시하지 않는다. 공개 스크립트의 PGD 위장, 실제 배치 64, 별도 6인 분기는 현재 논문 기준 프로필과 다르다. 첫 라운드 계산 일치가 전체 학습의 독립 재실행이나 논문의 3회 평균 일치를 뜻하지도 않는다.

ASR 10% 이하라는 별도 은닉 목표는 충족하지 못했다. 공격 재현 여부와 정상 삭제를 구별하는 탐지 성능은 이후 실험에서 따로 판단했다.

# D01 과거 학습 기여를 누적한 탐지

## 실험을 시작한 이유

공격 주입과 억제가 학습 과정에서 서로 상쇄된다면 마지막 모델만 보는 것보다 참여자의 과거 기여를 함께 보는 편이 나을 수 있다. 이 생각으로 누적 상쇄 점수 HRAC, 시간 구간의 이상을 찾는 GLR, 정상 학습으로 설명할 수 있는 기여 집합을 검사했다. 아래 세 검사는 같은 가설의 서로 다른 구현이며 독립 학습 반복은 아니다.

## 사용한 모델과 자료

BadFU 40라운드와 과거 FUBA 100라운드의 글로벌 모델, 개별 제출, 참여 기록을 사용했다. FUBA 정상 seed42와 공격 seed42, 정상 seed43과 seed44를 비교했다. 이미지 80장씩 세 묶음은 같은 실행을 다시 관측한 자료다. 요청자 내부의 독성 자료와 위장 자료 각각의 업데이트는 별도로 관측되지 않았다.

## 실제 진행 순서

1. 입력 패턴에 대한 각 참여자의 기여를 라운드별로 계산하고, 양의 주입과 음의 억제가 누적되는지 점수화했다.
2. 정상 seed42로 경보 기준을 정한 뒤 정상 seed43과 seed44의 40개 요청을 검사했다.
3. 정상 경보가 많아 전체 실행, 시간 구간, 패턴별 크기 보정과 반복 일치 조건을 차례로 비교했다.
4. 같은 정상 실행 수를 쓰는 단순 기준선과 다시 비교했다. GLR 최대값이 여러 라운드의 정보를 실제로 사용하는지도 확인했다.
5. 별도 검사에서는 정상 자료로 만든 설명 집합이 실제 이력 기여를 포함하는지 확인했다. 과거 기여 차감 대용 모델과 실제 저자 FU 모델을 구분했다.

## 결과

| 보정 방법 | 정상 40요청 경보 | 억제자 누락 |
|---|---:|---:|
| 원 점수 | 12 | 0/1 |
| 실행 전체 크기 보정 | 2 | 0/1 |
| 구간 크기 보정 | 0 | 0/1 |
| 패턴별 크기 보정 | 0 | 1/1 |

그러나 정상 자료를 같은 3개 실행으로 맞춘 비교에서는 원 점수와 공통 보정 모두 60요청 중 2건을 경보했다. GLR 최대값도 한 라운드의 양의 잔차 제곱으로 설명됐다. 정상 설명 집합 검사는 11요청 모두 점수를 만들지 못했다. 안전하다고 맞힌 11건이 아니라 미판정 11건이다.

## 결과를 보고 내린 판단

크기 보정으로 일부 경보가 줄었지만 같은 정보와 정상 보정 예산을 준 기준선보다 낫다는 결과는 남지 않았다. 더 강한 보정은 억제자도 놓쳤다. 과거 업데이트를 단순 차감한 대용 모델은 정상 정확도가 무너져 실제 FU를 대신할 수 없었다. 현재 이력 점수는 보류했으며, 모든 이력 기반 방법이 불가능하다는 결론은 내리지 않았다.

# D02 의심 입력과 정상 입력의 이력 영향 비교

## 실험을 시작한 이유

큰 참여자는 정상 학습에서도 큰 영향을 남긴다. 의심 입력에 대한 영향에서 정상 입력의 영향을 빼면 이 혼동을 줄일 수 있는지 확인했다. FLForensics의 업데이트와 손실 기울기 내적을 적용했지만, 이미 확보한 사고 입력을 제공받는 원 논문 조건과 달리 의심 입력 후보도 직접 찾아야 했다.

## 사용한 모델과 자료

완전한 전후 이력 7쌍, 삭제 전 이력만 있는 2사례, 실제 모델 전후 8쌍을 사용했다. BadFU 위장 삭제, 감염 모델의 정상 삭제, 정상 주요 클래스 삭제, 무작위 삭제와 과거 FUBA 진단 쌍을 비교했다. FUBA 쌍은 잠복 재현 성공 사례가 아니다.

## 실제 진행 순서

1. 탐색 자료에서 변형과 목표 후보를 정했다. 실제 트리거와 목표 정답은 사용하지 않았다.
2. 클래스별 자연 이미지 1장씩 총 10장에서 의심 변형 예 30개, 정상 참조 10개, 무작위 참조 50개를 만들었다.
3. 보존한 5개 시점에서 각 입력 손실의 기울기와 실제 참여자 업데이트의 내적을 계산했다. 원 내적, 집계 가중 내적, 업데이트 정규화 내적을 비교했다.
4. 의심 예의 평균 영향에서 정상 참조 또는 무작위 참조 영향을 뺐다. 10개 클래스와 전후 상태 중 최대값을 구했다.
5. 저자 군집화 규칙을 적용하고 점수 저장 후 실제 역할과 대조했다. 기본 최소 군집 크기 7은 BadFU 참여자 5명에 적용할 수 없어 크기 2와 3도 수정 조건으로 검사했다.

## 결과

| BadFU 조건 | 정상 참조를 뺀 영향 |
|---|---:|
| 위장 삭제 | 1.9765 |
| 감염 모델의 정상 삭제 | 1.8906 |
| 정상 주요 클래스 삭제 | 2.0677 |
| 정상 새 시드 무작위 삭제 | 1.8450 |

군집 크기 2에서는 공격 학습 모델 2/2뿐 아니라 정상 모델 3/3도 경보했다. 크기 3에서는 공격 0/2, 정상 0/3이었다. 참여자 추적도 정상 참여자를 잘못 지목했다. 이 표의 영향은 ASR이나 공격 확률이 아니다.

## 결과를 보고 내린 판단

정상 참조를 빼도 정상 주요 클래스 삭제가 공격보다 높은 점수를 보였다. 참조와 의심 입력이 정상 업데이트에 서로 다르게 반응하면 정상 기여는 남는다. 이 설정의 영향 점수와 군집화로 구별하거나 역할을 식별하지 못했다.

# D03 입력 변형에 대한 삭제 전후 반응 비교

## 실험을 시작한 이유

위장 삭제 뒤 백도어가 활성화된다면 같은 입력 변형의 효과가 삭제 후에 더 커질 수 있다. 먼저 고정 패치에서 이를 확인하고, 실제 트리거 모양을 모르는 조건으로 탐색 범위를 넓혔다. 고정 패치와 자유 변형 탐색은 후보 집합과 결과가 달라 따로 기록했다.

## 사용한 모델과 자료

Paper32와 과거 PGD64 BadFU, 정상 주요 클래스 3,558장 삭제, 정상 무작위 삭제, 감염 모델의 정상 요청, 과거 FUBA를 포함한 실제 전후 8쌍을 사용했다. 후 모델은 유지 자료 전체 재학습이다. 같은 모델을 공유하는 쌍이 있어 독립 학습 8회가 아니다. FUBA는 삭제 전부터 공격 성공률이 높은 진단 조건이다.

## 실제 진행 순서

1. 고정 후보 검사에서는 48개 변형을 선택용 160장과 확인용 160장에 적용했다. 각 후보의 원본 대비 목표 확률 증가를 전후 모델에서 구하고 두 값을 뺐다.
2. 자유 탐색에서는 위치 미지 마스크, 공통 가산, 입력 의존 CNN 변형을 사용했다. 마스크 총량은 32, 나머지 최대 픽셀 변화는 16/255로 제한했다.
3. 10개 목표마다 후보를 100회 학습하고, 삭제 전 최대화·삭제 후 최대화·전후 차분 최대화를 비교했다. 총 720후보를 만들었다.
4. 선택을 고정한 뒤 추가 예약 320장에 적용했다. FUBA 원 학습의 gamma 선택에 포함됐던 최초 확인 자료 문제를 이 별도 확인으로 보완했다.
5. 같은 모델에서 최소 마스크, 최대 마진, Conv와 BN과 FC의 교체 효과도 보조 검사했다. 이들은 별도 사후 진단이며 최상의 값을 합쳐 새 판정기로 만들지 않았다.

## 결과

| 비교 조건 | 고정 국소 패치 차분 | 자유 탐색의 선택 차분 |
|---|---:|---:|
| Paper32 위장 850장 삭제 | 77.33%p | 15.07%p |
| 감염 모델의 정상 850장 삭제 | 1.65%p | 16.18%p |
| 정상 주요 클래스 3,558장 삭제 | 0.91%p | 16.87%p |

두 열은 후보와 확인 자료가 다른 검사다. 숫자를 같은 방법의 전후 성능으로 비교하지 않는다. 자유 탐색에서는 정상 삭제에도 공격보다 큰 차분이 나왔다. 예약 확인에서도 이 겹침이 남았다.

## 결과를 보고 내린 판단

고정 국소 패치의 좋은 BadFU 결과는 보존했다. 그러나 변형 범위를 넓히면 정상 모델에서도 큰 반응을 찾았다. 확률 대신 로짓을 쓰거나 클래스 편향과 공통 배율을 보정해도 일부 공격과 정상의 순위가 뒤집혔다. 특정 편향을 제거하는 수식이 모든 정상 non-IID 변화를 제거하지는 않는다.

이 결과를 트리거 종류에 독립적인 탐지 성공으로 표시하지 않았다. 내부 층 교체에서 반응이 컸다는 사실도 원래 모델의 악성 증거로 사용하지 않았다.

# D05 중간 특징에서 특정 출력으로 쏠리는 정도 검사

## 실험을 시작한 이유

입력 패턴의 형태를 정하지 않고 분류기 중간 특징에서 공격 관련 이상을 찾을 수 있는지 확인했다. FreeEagle의 발상을 따라, 가상의 특징을 각 클래스로 분류하도록 최적화한 뒤 다른 출력으로 얼마나 쏠리는지 측정했다.

3. 두 특징의 평균을 후반 분류기에 넣고 출력 확률 행렬을 만들었다. 자기 클래스를 제외한 열 평균으로 출력 쏠림을 구했다.

## 결과

## 결과를 보고 내린 판단

가상 특징을 잘 최적화하는 것과 공격 모델만 이상 점수를 내는 것은 달랐다. 픽셀 입력 대신 중간 특징을 사용해도 정상 분포 편향에서 큰 점수가 나올 수 있었다. 이번 구현을 공통 탐지 특징으로 채택하지 않았다. 원 FreeEagle 전체 벤치마크를 재현한 결과나 그 방법 전체의 실패로 확대하지 않았다.

# D07 서버가 심은 진단 과제의 유지 여부 검사

## 실험을 시작한 이유

저장 모델을 관찰하는 데 그치지 않고 서버가 진단 과제를 미리 심으면 새로운 구별 정보를 얻을 수 있는지 확인했다. BackdoorIndicator의 발상을 따라, 참여자가 학습한 후 서버의 별도 과제를 얼마나 유지하는지 비교했다.

## 사용한 모델과 자료

정상 모델 복사본에 난수 이미지 200장과 임의의 균형 라벨을 사용했다. 같은 진단 모델에서 정상 균형 2,048장, 정상 편중 2,048장과 8,192장, 독성 혼합, 독성 및 위장 혼합, 억제 자료 학습을 비교했다. 실제 FU 전체가 아닌 한 번의 로컬 학습 파일럿이다. BadFU는 저장 위장 이미지, FUBA 방식은 과거 s42 생성기를 모의 참여자 구성에 사용했다.

## 실제 진행 순서

1. 복사한 정상 모델에 200 미니배치로 난수 과제를 학습시켰다. 원래 과제와 진단 과제의 BN 통계는 분리했다.
2. 같은 출발 모델에서 여섯 종류의 로컬 학습을 하고 진단 과제 유지율을 비교했다.
3. 첫 검사에서 정상 성능 손상과 한 클래스 쏠림을 확인했다. 후속 검사에는 공개 500장의 삽입 전 예측을 보존하는 증류 항을 추가했다.
4. 진단 라벨이 c인 입력의 c 예측률에서 다른 진단 라벨 입력의 c 예측률을 뺀 J를 계산했다. 모든 입력을 한 클래스로 보내면 J가 0이 되는지 검산했다.
5. 과제의 모든 클래스를 학습했는지와 정상 정확도 하락 5%p 이내를 먼저 확인한 후 점수를 비교했다.

## 결과

첫 BadFU 방식 검사에서는 정상 편중 8,192장 학습도 유지율 100%였고 독성은 95% 또는 100%였다. 과제 삽입 자체도 정상 정확도를 크게 낮췄다.

후속 FUBA 방식 두 조건은 정상 기능과 과제 학습 기준을 통과했다. 그러나 J는 정상 균형에서 0.844와 0.889, 독성 혼합에서 0.267과 0.583이었다. 정상 쪽이 더 높았다. 후속 BadFU 방식은 과제 학습과 정상 기능 보존에 실패해 탐지 성능 판단에서 제외했다.

## 결과를 보고 내린 판단

출력 쏠림 보정은 단순 한 클래스 붕괴를 제거했지만 악성과 정상의 구별을 만들지는 못했다. 추가 과제를 심었다는 사실 자체가 공격에만 반응한다는 근거가 되지 않았다. 진단 과제가 들어간 모델에서 실제로 새 제출을 계산했으며, 옛 업데이트를 더해 새 학습을 대신하지 않았다. 이번 파일럿을 실제 대규모 삭제 탐지율로 표시하지 않았다.

# D08 같은 잔류 참여자의 삭제 전후 응답 비교

## 실험을 시작한 이유

정상 자료의 구성이나 참여자 구성이 달라서 반응이 달라지는 문제를 줄이려고, 전후에 같은 잔류 참여자와 같은 자료로 새 응답을 계산했다. 공개 정상 응답도 빼고 클래스를 균등하게 맞추면 큰 정상 참여자의 탈퇴와 공격 삭제를 구별할 수 있는지 확인했다.

## 사용한 모델과 자료

BadFU 위장 850장 삭제와 전체의 22.790%, 19.336%인 정상 참여자 삭제에 같은 보존 5시점 FU 규칙을 적용했다. 유지 자료 전체 재학습 쌍과 실제 저자 FU 쌍도 참고로 따로 보관했다. 잔류 참여자당 최대 512장, 공개 자료는 개입 크기 선택 500장과 별도 확인 320장을 사용했다.

## 실제 진행 순서

1. 삭제 전 모델과 삭제 후 모델 각각에 같은 방향으로 작은 양의 교란과 음의 교란을 가했다. 모델쌍마다 네 상태를 만들었다.
2. 네 상태 모두에서 같은 잔류 참여자의 같은 이미지와 라벨로 응답을 새로 계산했다. 참여자 비중도 고정했다.
3. 양과 음의 응답 차이에서 공개 정상 자료의 같은 응답을 뺐다. 이 보정 응답이 전후 얼마나 달라졌는지 정규화한 D를 구했다.
4. 마지막 Conv를 주 관측으로 정하고 FC, 클래스 비중 유지, 무작위 방향 두 개와 FU 방향을 함께 저장했다. 개입 자체가 정상 정확도를 1%p 넘게 낮추지 않도록 크기를 제한했다.
5. 점수를 고정한 뒤 실제 트리거의 공격 성공률과 정상 정확도를 별도 평가했다.

## 결과

| 같은 FU 규칙의 BadFU 조건 | Conv 응답 점수 D |
|---|---:|
| 위장 850장 삭제 | 0.75848 |
| 정상 참여자 19.336% 삭제 | 0.75525 |
| 정상 참여자 22.790% 삭제 | 0.76188 |

공격 점수가 두 정상 값 사이에 놓였다. 유지 자료 재학습 쌍에서도 위장 삭제 0.70794, 감염 모델의 정상 삭제 0.70360으로 가까웠다. 개입의 최대 정상 정확도 하락은 별도 확인에서 0.625%p였다.

## 결과를 보고 내린 판단

참여자와 자료를 맞추고 참조를 빼도 이 응답 점수로 구별하지 못했다. 같은 잔류 집합은 구성 변화를 통제하지만, 큰 정상 삭제 때문에 모델이 달라지는 효과까지 없애지는 못했다. 이 실험의 핵심 실패는 관측이 부족했다는 사실보다 정상 탈퇴도 같은 반응을 만든다는 점이다.

과거 FUBA의 단축 FU는 정상 정확도가 약 10%로 무너져 비교에서 제외했다. BN만 다시 추정해도 회복되지 않았다. 기능이 유지된 과거 FUBA 쌍도 사전 억제 실패가 확인돼 유효한 잠복 공격 검증으로 쓰지 않았다. 이 한 점수의 실패를 모든 능동 진단의 불가능성으로 확대하지 않았다.

# D09 같은 성공률에 필요한 입력 변형 비용 비교

## 실험을 시작한 이유

공격과 정상 모델 모두 큰 입력 반응을 낼 수 있다. 반응의 최대값 대신 같은 오분류 성공률에 도달하는 데 필요한 변형 비용을 비교하면 차이가 남는지 확인했다. 제안자의 원 스크립트가 없어 공통 가산과 마스크의 두 목적함수를 명시해 구현했다.

## 사용한 모델과 자료

보존 분류기 13개와 전후 8쌍을 사용했다. Paper32 위장 삭제, 감염 모델의 정상 850장 삭제, 정상 클래스 집중 및 무작위 삭제, 큰 정상 참여자 22.8%와 19.3% 삭제, 과거 6인 모델을 포함했다. 전체 재학습, 저자 FU, 보존 5시점 FU가 섞여 있어 각 모델 종류를 구분했다.

## 실제 진행 순서

4. 각 클래스에서 삭제 전 비용 대비 삭제 후 비용의 감소율을 구하고 최대 감소율을 점수로 삼았다.
5. 두 초기값을 합친 결과와 각각의 결과를 나눠 확인했다. 선택에 쓰지 않은 이미지의 성공률도 함께 기록했다.

# D11 이미지별 변형 비용과 최소값 요약의 한계

## 실험을 시작한 이유

FUBA는 이미지에 따라 다른 변형을 만들 수 있다. 하나의 공통 변형만 탐색한 것이 제약이었는지 확인하려고 이미지마다 목표 변형을 찾았다. 또한 삭제 후 새로운 공격 경로가 생겨도 최소 비용이라는 요약이 그 경로를 놓칠 수 있는지 수학 예로 검사했다.

## 사용한 모델과 자료

과거 FUBA 공격 삭제 전후 m07과 m08, 정상 같은 참여자 삭제 m09와 m10을 사용했다. 이들은 사전 억제 실패 조건이며 큰 정상 참여자 전체 탈퇴 대조도 아니다. pilot 80장과 별도 confirmation 80장은 서로 분리됐고 기존 gamma 선택 이미지와도 겹치지 않았다.

## 실제 진행 순서

1. 전후 분류기를 고정하고 10개 목표 각각에서 이미지별 가산 변형을 PGD로 찾았다. 실제 생성기나 목표 정답은 주지 않았다.
2. 변형의 최대 픽셀 변화인 Linf 반경을 세분화했다. 성공하지 못한 경우 비용을 0으로 채우지 않고 결측 또는 검열로 처리했다.
3. 이미지의 95%에서 성공하는 비용을 클래스마다 구했다. 후 비용과 전 비용의 비율을 다른 클래스 중앙값으로 보정했다.
4. 최초 반경 세분화 4회에서 비용이 거친 같은 값으로 몰려 모든 조건에 같은 10회 세분화를 추가했다. 목표와 점수 정의는 유지했다.
5. 별도 수학 예에서 기존 오류 경로 비용 0.01, 새 공격 경로 비용 0.04인 경우의 최소값을 전후 계산했다.

## 결과

| 검사 | 공격 삭제 점수 | 정상 같은 참여자 삭제 점수 |
|---|---:|---:|
| 최초 거친 반경 탐색 | 40.32 | 40.27 |
| 정밀 반경 탐색 | 11.30 | 27.49 |

정밀 탐색에서는 정상 점수가 더 높았다. 수학 예에서는 공격 경로가 새로 생겨도 최소 비용은 전후 모두 0.01이었다. 이 예는 실제 학습 결과와 별개인 정확한 구성 반례다.

## 결과를 보고 내린 판단

현재 비용 점수를 주력 탐지기로 채택하지 않았다. 이미지별 최적화를 추가해도 정상 모델의 일반 적대적 취약성이 함께 측정됐다. 최소 비용이 같다는 사실만으로 새 공격 경로가 없다고 할 수도 없었다. 반대로 이 과거 FUBA 입력의 실패로 유효한 잠복 FUBA 탐지가 불가능하다고 결론 내리지 않았다.

# T01 독성 자료가 남는 경우와 없는 경우의 원인 대조

## 실험을 시작한 이유

탐지 점수를 정하기 전에 실제 위장 삭제가 무엇을 바꾸는지 확인했다. 같은 위장 자료를 없애도 독성 자료가 남는 경우에만 특정 조건의 오분류가 크게 증가하는지 비교했다. 실제 트리거와 구성 정답을 사용하는 평가자 분석이며 서버 탐지 절차는 아니다.

## 사용한 모델과 자료

과거 축소 BadFU형 실험의 seed71·72·73을 사용했다. CIFAR 10과 ResNet18, 참여자 5명, dominant70 분할, 40라운드, 로컬 1에포크 조건이다. 정상 자료 B는 6,000장, 독성 P는 180장, 위장 C는 720장이며 P와 C는 같은 참여자 안에 있다. 논문의 전체 규모 재현과 구분했다.

## 실제 진행 순서

1. 같은 초기 상태와 정상 분할에서 완전히 학습한 B, B+C, B+P, B+P+C 모델을 연결했다.
2. 위장 삭제를 B+P+C→B+P, 독성이 없는 대응 삭제를 B+C→B로 비교했다. 두 경로 모두 유지 자료 전체 재학습이다.
3. 시험 2,000장 중 목표 0을 제외한 1,800장에 같은 실제 트리거를 적용했다.
4. seed71의 원시 예측과 여섯 모델 해시를 검산했다. seed72와 73은 기존 완료 기록에서 수치를 재구성했으며 이번 원시 재추론과 구분했다.
5. 여섯 모델 모두 원본을 맞힌 880장을 사후 설명용 부분집합으로 고정했다. 독성 라벨을 원래 라벨로 복원한 대조도 함께 확인했다.

## 결과

| 학습 시드 | 독성 유지 상태의 위장 삭제 증가 | 독성 없는 위장 삭제 증가 |
|---|---:|---:|
| 71 | 69.06%p | 2.89%p |
| 72 | 93.28%p | 2.11%p |
| 73 | 91.44%p | 2.89%p |

원본을 모두 맞힌 880장에서도 독성 유지의 증가 68.41%p, 독성 없음 0.34%p로 차이가 남았다. 라벨 복원 대조도 이 부분집합에서 0.34%p였다. 라벨 복원 모델은 일부 환경이 달라 라벨 하나의 순수 인과 효과로 확정하지 않았다.

## 결과를 보고 내린 판단

이 저장 조건에서 위장 삭제와 잔류 독성의 결합에 따른 행동 차이는 존재했다. 그러나 평가자가 아는 트리거와 독성 없는 대응 모델을 실제 서버가 갖는다는 뜻은 아니다. 같은 원본 정확도에서도 변형 입력의 함수가 달라질 수 있어 원본 성능만으로 공격을 판정하지 않았다.

정상 변화가 순수 클래스 사전확률 변화라는 강한 가정 아래 로짓 이중 차분이 0이 되는 식도 확인했다. 실제 non-IID의 배경과 도메인 변화까지 제거하는 증명은 아니다. D11의 최소 비용 반례도 행동 변화가 하나의 요약값에서 사라질 수 있다는 별도 근거로 유지했다.

# D12 정상 이미지 없이 조건부 전환과 이력을 찾는 검사

## 실험을 시작한 이유

라벨 있는 정상 이미지를 서버가 확보해야 한다는 조건을 줄이려고, 모델에서 만든 합성 입력으로 삭제 후에만 나타나는 공통 오분류를 찾았다. 같은 기능에 요청자의 억제와 잔류 참여자의 강화 이력이 함께 있는지도 검사했다.

## 사용한 모델과 자료

처음 11쌍, 과신 완화와 정상 전체 삭제를 추가한 후 13쌍을 검사했다. 유지 자료 전체 재학습 9쌍, 저자 FedEraser 2쌍, 정상 전체 삭제의 5시점 FU 변형 2쌍을 구분했다. 자연 이미지 320장과 실제 트리거는 후보와 점수 고정 후 평가자가 사용했다.

## 실제 진행 순서

1. 클래스마다 탐색 4장과 별도 확인 4장, 총 80장의 합성 입력을 만들었다. 모델의 예측을 임시 라벨로 사용해 실제 이미지 의미를 안다고 가정하지 않았다.
2. 위치 미지 마스크와 공통 가산 변형을 찾았다. 원본은 전후 같은 클래스로 유지하고 변형 입력만 후 모델에서 공통 목표로 바꾸도록 학습했다.
3. 독립 확인에서 원본 일치 90% 이상, 비목표 클래스 중 최소 5개에서 각각 80% 이상 전환을 요구했다.
4. 첫 결과를 본 뒤 합성 입력의 과신을 줄이는 label smoothing 0.2를 추가 검사했다. 이 수정은 사후 탐색으로 표시했다.
5. 보존 시점 1·3·5에서 요청자의 억제와 잔류 참여자의 강화를 찾고 2·4에서 같은 부호가 유지되는지 확인했다. 요청자 이력이 없거나 신원이 불명확하면 역할 검사에서 제외했다.

## 결과

원래 합성과 과신 완화 조건 모두 최종 공격 경보는 0이었다. 대표 BadFU의 자동 후보는 독립 합성 입력에서 공동 전환 0%였다.

평가자가 실제 트리거를 준 경우에는 같은 대표 모델의 독립 합성 입력 36장 중 30장이 전환했다. 반면 저자 FedEraser의 과거 고사전 ASR 모델은 실제 트리거를 줘도 합성 입력 전환이 1/36이었다. 한 이력 후보는 부호 확인을 통과했지만 정상 참여자를 강화자로 골랐고 행동 조건도 통과하지 못했다.

## 결과를 보고 내린 판단

대표 모델에서는 신호가 전혀 없는 것이 아니라 자동 탐색이 유효한 조건을 찾지 못했다. 다른 모델에서는 합성 입력 자체가 공격 행동을 충분히 드러내지 못했다. 이 두 실패를 같은 원인으로 합치지 않았다. 경보가 모두 0인 결과를 낮은 오탐의 성공으로 표시하지 않았고, 이력의 부호 일치만으로 공격자 역할을 확정하지 않았다.

# D13 고정 패턴과 자유 마스크 및 특징 변환 비교

## 실험을 시작한 이유

D12의 조건 검색에서 무엇이 부족한지 보려고 입력 종류와 변형 표현을 나눠 비교했다. 합성 입력과 정상 이미지, 고정 후보와 학습 가능한 후보에서 독립 입력 전환이 달라지는지 확인했다.

## 사용한 모델과 자료

같은 보존 모델 전후 13쌍을 사용했다. 악성 삭제 요청 4건과 대조 9건이며 대조에는 감염 모델의 정상 요청도 있다. 재학습 9쌍, 저자 FU 2쌍, 정상 5시점 FU 2쌍이다. 같은 출발 모델을 공유해 독립 학습 13회가 아니다.

## 실제 진행 순서

1. 합성 입력 40장 또는 정상 이미지 40장으로 후보를 선택했다.
2. 고정 패치와 전역 변형 48종, 위치와 무늬를 학습하는 자유 마스크, 특징 공간을 이용한 입력 변형을 각각 검사했다.
3. 선택한 변형을 별도 실제 이미지 320장에 적용했다. 원본을 전후 모두 맞히는 표본에서 변형 후 전 모델은 원래 클래스, 후 모델은 공통 목표를 내는지 셌다.
4. 최소 유효 표본 18개와 클래스별 2개를 확보하고 비목표 클래스 5개 이상에서 각각 80% 전환을 요구했다.

## 결과

| 후보 탐색 | 합성 입력으로 선택한 공격 경보 | 정상 이미지로 선택한 공격 경보 | 대조 경보 |
|---|---:|---:|---:|
| 고정 48종 | 0/4 | 2/4 | 양쪽 0/9 |
| 자유 마스크 | 0/4 | 0/4 | 양쪽 0/9 |

정상 이미지와 고정 후보의 좋은 일부 결과는 남겼다. 후보 표현을 자유롭게 만들거나 특징 공간을 사용한다는 이유만으로 독립 입력에서 잘 작동하지는 않았다. 이 검사는 조건 탐색 단계이며 이력에 의한 공격자 식별 성능은 포함하지 않았다. 원 보고서의 추가 실행 예정 문장은 당시 기록으로 보존하고 현재 실행 지시로 쓰지 않았다.

# D14 입력마다 달라지는 변형 규칙 학습

## 실험을 시작한 이유

고정 패턴과 공통 가산 변형만으로는 입력 의존 공격을 충분히 찾지 못할 수 있다. 색 치환, 가산 변화, 공간 왜곡을 하나의 입력 의존 함수에 넣어, 표현 범위를 넓히면 독립 확인에서도 전후 전환이 유지되는지 검사했다.

## 사용한 모델과 자료

D13과 같은 전후 13쌍을 검사했다. 합성 또는 정상 이미지 40장으로 학습하고 독립 합성 입력 40장과 실제 이미지 400장으로 확인했다. 실제 이미지 400장은 합성 입력만 쓰는 운영 판정에는 사용하지 않았으며 평가자의 전이 확인 자료로 구분했다.

## 실제 진행 순서

1. 입력 이미지에서 색 치환, 혼합 비중, 가산 변화와 2차원 좌표 흐름을 출력하는 변형 함수를 만들었다.
2. 공통 목표 클래스와 원본 클래스별 목표 관계의 두 방식으로 학습했다. 96단계에서 목표 관계를 고정하고 480단계까지 진행했다.
3. 평균 절대 픽셀 변화는 0.06 이하, 공간 흐름은 좌표별 3픽셀 이하로 제한했다. 이 제약을 사람 기준 의미 보존의 증명으로 취급하지 않았다.
4. 160·320·480단계 후보를 탐색 자료에서만 골랐다. 별도 입력에서 원본 유지와 전후 목표 전환을 확인했다.
5. 유효 표본 18개 이상과 클래스별 2개 이상, 5개 클래스의 전환 80% 이상이라는 고정 규칙을 적용했다.

## 결과

두 학습 입력 조건 모두 공격 경보 0/4, 대조 경보 0/9였다.

| 정상 이미지로 학습한 조건 | 학습 전환 | 실제 확인 전환 |
|---|---:|---:|
| 대표 BadFU 위장 삭제 | 100.0% | 14.0% |
| 정상 클래스 집중 삭제 | 100.0% | 28.2% |
| 과거 FUBA 진단 공격 삭제 | 100.0% | 52.8% |

이 비율은 학습한 목표 관계의 전환이며 실제 공격 ASR이 아니다. FUBA 확인 평균이 높아도 클래스별 경보 기준을 충족하지 못했다.

## 결과를 보고 내린 판단

복잡한 함수를 표현할 수 있어도 소수 학습 이미지에만 맞는 변형을 찾을 수 있었다. 실제 확인에서 정상 클래스 집중 삭제의 값이 대표 공격보다 높았다. 현재 규칙으로 구별하지 못했으며 학습 100%를 공격 복원 성공으로 보고하지 않았다.

# D15 두 학습 시드와 정상 참여자 자료에서 전후 탐색 확인

## 실험을 시작한 이유

한 모델에서 얻은 좋은 입력 변형 결과가 다른 학습 시드에서도 유지되는지 확인했다. 삭제 후 모델만 이용한 탐색과 전후 모델을 함께 이용한 탐색을 비교하고, 선택에 쓰지 않은 정상 참여자의 자료에서도 같은 오류가 재현되는지 검사했다.

## 사용한 모델과 자료

BadFU seed20261020과 seed20261023의 실제 전후 5쌍을 사용했다. 공격 위장 850장 삭제 두 쌍, 감염 또는 정상 모델의 정상 850장 삭제 두 쌍, 큰 정상 참여자 19.336% 삭제 한 쌍이다. 후 모델은 유지 자료 전체 재학습이다. 두 시드는 같은 분할을 공유했다.

1. 마스크, 전역 가산, 입력 의존 변형을 각각 200단계, 초기값 2개로 탐색했다.

4. 선택이 끝난 뒤 공개 1,000장과 정상으로 지정한 참여자 1·2·3의 자료 각 512장에 적용했다. 참여자 자료는 원 FL 학습에는 쓰였지만 이번 변형 탐색과 선택에서는 분리됐다.
5. 원본 전후 정답을 유지하면서 변형 후에만 새 목표 오류가 나는 비율을 셌다. 실제 외부 참여자 통신이 아닌 저장 자료를 이용한 모의 확인이다.

# D17 정상 기능을 약화한 복사본과 원래 모델의 직접 탐색 비교

D15에서는 추가 시드의 공격 오류 7%, 큰 정상 삭제 8%로 구별되지 않았다. 이번에는 정상 분류 기능을 약화한 복사본에서 변형을 찾는 과정이 도움이 되는지 검사했다. 원래 모델에서 직접 찾는 400회와 800회 탐색도 함께 실행했다.

# P01 삭제 전 반응을 옮기는 정화

## 실험을 시작한 이유

삭제 후 모델의 정상 판단을 유지하면서 변형 입력의 반응만 삭제 전 수준으로 옮기면 공격을 줄일 수 있는지 확인했다. 삭제 후 모델만 이용한 자기증류와 비교해 삭제 전 모델이 추가로 도움이 되는 조건을 검사했다.

## 사용한 모델과 자료

과거 축소 BadFU형 4학습 시드의 유지 자료 전체 재학습 전후 모델을 사용했다. 정화 과정에서 기초 FL을 다시 학습하지 않았다. 요청자를 제외한 정상 참여자 4명이 협조하고, 이들의 자료가 깨끗하다고 가정했다. 잔류 자료를 fitting 800장, 탐침 320장, 검증 640장으로 나눴으며 삭제 및 공격 자료와 겹치지 않게 했다. 독립 시험은 시드별 2,000장이었다.

## 실제 진행 순서

1. 모서리 네 곳과 10목표의 4×4 RGB 변형을 실제 트리거 없이 역탐색했다.
2. 정상 원본의 교사는 post로 두고, 변형 입력 목표는 pre의 변형 출력에 post 원본과 pre 원본의 출력 차이를 더해 만들었다. 전체 신경망을 학습하고 BN 통계는 고정했다.
3. 변형 정답 CE, pre 전체 증류, pre 변형 증류, post 자기증류, 반응 전이를 비교했다. 주 반복형은 25회마다 학생에서 변형을 새로 찾으며 100회 학습했다.
4. 정상 검증의 출력 KL 상한과 참여자 및 클래스 성능 조건을 만족하는 수정량을 공통 절차로 선택했다. 선택을 고정한 뒤 실제 트리거 ASR을 평가했다.

# P02 마지막 분류층만 바꾸는 교정

## 사용한 모델과 자료

과거 seed42 저자 코드 계열의 실제 FU 후 모델과 유지 자료 재학습 후 모델을 사용했다. 이 계열의 full6 삭제 전 ASR은 별도 평가에서 81.51%였다. 낮은 잠복 상태로 승인된 최신 BadFU 모델과 다르다. fitting 1,000장과 검증 1,000장, 시험 5,000장을 사용했다. 패치 은행 시드 반복은 같은 FL 모델의 반복이다.

3. 모서리당 무작위 패치 수를 4개에서 34개로 늘리고 결과를 비교했다.
4. 교정 모델에서 새로 찾은 반례를 추가하는 절차를 실제 FU 후 모델과 전체 재학습 후 모델에 각각 적용했다.
5. 실패한 경우 저장된 후보들 안에 좋은 후보가 있었는지 확인하고, 원 선택 점수와 정규화 점수의 순위를 사후 분해했다.

| 모델 경로 | 교정 전 ASR | 기본 교정 후 ASR | 정상 정확도 전후 |
|---|---:|---:|---|
| 실제 저자 FU 후 | 99.51% | 11.58~12.62% | 86.96%→86.94~87.04% |
| 유지 자료 재학습 후 | 100.00% | 23.02~32.87% | 86.00%→85.50~85.78% |

패치 수 증가는 ASR 7.51%에서 14.40%로 악화한 조건이 있었다. 반례 보강도 실제 FU 후에는 11.58%→5.87%로 좋아졌지만 재학습 후에는 32.87%→91.67~94.27%로 악화했다. 같은 저장 후보군에서 원 선택 후보 ASR은 91.67%, 사후 정규화 1위 후보는 13.33%였다.

## 결과를 보고 내린 판단

한 모델에서 정상 정확도를 거의 유지한 정화는 관측했다. 그러나 좋은 후보 생성과 좋은 후보 선택은 별개였고, 반례를 늘리면 항상 좋아지지 않았다. 사후에 고른 후보의 낮은 ASR을 미리 고정한 서버 규칙의 성능으로 보고하지 않았다. 독립 학습 시드와 적응 공격의 일반 성능도 확인하지 않았다.

# P03 손실 분산과 채널 가림 및 헤드 증류 파일럿

## 실험을 시작한 이유

잔류 정상 참여자의 손실 변화로 공격 삭제를 알아낼 수 있는지, 정상 활성도가 낮은 채널을 가리거나 마지막 헤드를 바꾸면 정화가 되는지 짧게 검사했다. 손실 분산 C, 채널 가림 A1, 헤드 증류 A2는 서로 다른 가설이다.

## 사용한 모델과 자료

실제로 선택한 입력은 과거 seed42 full6→fu_remove5와 cover5→fu_remove1이었다. 목표한 낮은 사전 ASR의 Paper32 대신 약 80%의 사전 ASR인 6인 모델을 골랐다는 문제가 사후 출처 감사에서 확인됐다. 공격과 정상 요청의 출발 모델과 삭제량도 맞지 않았다.

## 실제 진행 순서

1. 실제 non-IID 인덱스에서 잔류 참여자마다 정상 자료 128장을 뽑았다. 공통 참여자 2·3·4의 평균 CE 변화 분산과 범위를 비교했다.
2. 정상 자료의 활성도가 낮은 마지막 특징 채널 5%와 10%에 해당하는 FC 입력 열을 0으로 고정했다. 무처리, 미세조정, 채널 가림과 그 뒤 미세조정을 비교했다.
3. 헤드 전체 재초기화 또는 10% 혼합 교란 후, 삭제 전 모델의 정상 출력을 교사로 증류했다. 앞단과 BN은 고정했다.
4. 학습 100장, 검증 100장, 평가 400장을 분리했다. 20단계 학습 후 정상 검증 정확도 하락 2%p 이내 후보에서 검증 CE가 작은 것을 선택했다. 트리거는 선택 뒤 평가에만 사용했다.
5. 사용한 실제 모델 경로와 해시를 다시 감사해 입력 선택의 부적합을 기록했다.

## 결과와 판단

실행과 원 수치는 보존했지만 목표 잠복 공격의 탐지 또는 정화 가설 판정에서는 제외했다. 이 항목을 효과가 없다고 결론 낸 정상 대조 실험이나 승인 모델의 성공 사례로 합치지 않았다. 올바른 모델에 같은 검사를 완료한 기록은 이 파일럿에 없다.

정상 non-IID 삭제도 참여자별 손실 분산을 만들 수 있다. 정상 데이터에서 비활성인 채널이 반드시 백도어 채널이라는 전제, 삭제 전 교사가 안전한 망각을 보장한다는 전제도 확인되지 않았다. 이 정리는 입력 선택 오류를 명시하는 것이며 재실행을 시작한 기록이 아니다.

# D18 정상 이미지의 특징 공간 밖에 놓인 FC 변화 검사

## 사용한 모델과 자료

badfu.confirmed.s20261023.v1의 위장 850장 삭제, 정상 850장 삭제, 큰 정상 참여자 9,668장 삭제의 세 전후쌍을 사용했다. 모두 같은 초기값부터 남은 자료 전체 재학습한 모델이며 실제 학습 시드는 하나다. 클래스마다 정상 사진 5장씩 총 50장을 뽑았다. 실제 목표와 트리거는 점수 계산에 주지 않았다.

# R02 FUBA 재현의 수정 과정과 실제 삭제 후 결과

## 실험을 시작한 이유

FUBA에서도 삭제 전 억제와 삭제 후 활성화가 재현되는 모델쌍이 있어야 탐지 방법을 공정하게 비교할 수 있다. 과거 모델은 삭제 전부터 ASR이 높았고 같은 생성기가 정상 모델에도 잘 통했다. 그 모델을 잠복 공격의 성공 사례로 쓰지 않고, 출처와 구현을 감사한 뒤 별도로 선언한 실행을 진행했다. 대상은 stcebra FUBA이며 ity207 FedUBA와 다르다.

## 공통 조건과 평가

후기 수정 실행은 CIFAR 10, ResNet18, 참여자 20명 중 라운드당 8명, 시드20261023의 고정 IID 분할을 사용했다. 분류기 학습 단계는 전체 50에포크, 생성기는 5에포크로 기록했다. 전체 정상 정확도 CA는 10,000장, ASR은 목표 클래스 8을 제외한 9,000장으로 측정했다. 전후 비교는 같은 최종 삭제 전 생성기, epsilon 0.05, pixel 0~1, eval 모드, contiguous NCHW를 유지했다.

완료 목표 100라운드, 정상 정확도 80% 이상, 사전 ASR 10% 이하, 삭제 후 ASR 60% 이상은 서로 다른 확인 항목이다. 파일 저장 검증이 통과해도 성능 목표를 통과한 것으로 표시하지 않았다. 아래 버전들은 조건 변경과 일부 구간 재사용이 있어 독립 학습 시드 반복으로 합치지 않는다.

## 초기 모델과 v2의 실제 실행

1. 과거 FUBA 쌍에 같은 저장 생성기를 적용했다. 공격 전후뿐 아니라 정상 모델에서도 높은 목표 예측이 나오는 것을 확인했다.
2. v2 수정 후보를 고정해 100라운드 학습과 저장 검사를 진행했다. 82라운드 목록 교체의 Windows 접근 거부로 멈췄지만 모델 파일은 저장돼 있었다.
3. 81→82 연결과 실제 집계를 확인하고 원본 실패를 보존했다. 저장 재시도를 보강한 별도 경로에서 83~100라운드를 이어 계산했다.
4. 최종 분류기와 같은 집계 생성기로 전체 평가하고 로컬 검토 사본을 보관했다.

v2는 100라운드를 완료했지만 CA 71.87%, 사전 ASR 99.0889%였다. 이 후보의 실제 삭제 후 분기는 실행하지 않았으며 단일 진단 모델로 남겼다. 63라운드 중간 사본과 82라운드 오류도 보존했다.

## 논문과 실행 코드를 다시 대조한 과정

1. 실제 16쪽 본문과 12쪽 보충자료를 구분했다. 본문 Algorithm1과 2, 재가중 식, 예상 집계, 실험 설정을 실행 소스와 대조했다.
2. 재가중 방향이 반대인 문제, 억제 두 번째 단계에 정상 입력 대신 생성기 입력을 넣는 문제, 학습 단계와 optimizer 상태 재사용 문제를 확인했다.
3. 예상 집계 비율, gamma 후보와 제출값 연결, 첫 실패와 상한 처리, 실제 epoch와 batch 수를 검사했다.
4. 수정 후보를 별도 디렉터리에 만들고 CPU 합성 회귀 15개를 통과시켰다. 이 단계 자체에서는 새 실자료 학습을 하지 않았다.

각 불일치는 확인했지만 어느 수정이 최종 ASR을 얼마나 바꾸는지 단독 인과 기여는 측정하지 않았다. 본문 수식의 SGD와 실험 설정의 Adam, IBA 결합과 BN 정책의 모호함도 남겼다.

## v3와 v4에서 중단된 이유

v3는 위 감사를 반영한 별도 프로필로 시작했다. 15라운드를 저장한 뒤 16라운드 참여자1의 gamma 0 예상 집계가 로컬 ASR 12.9464%, 29/224로 기준을 실패해 등록한 whole MPI 중단 규칙에 따라 멈췄다. 마지막 15라운드 전체 평가 CA 76.10%, ASR 8.1333%는 독립 평가와 일치했다. ASR이 낮아도 100라운드와 정상 성능 목표는 미달이었다.

v4는 논문의 초기 while 조건이 거짓일 때 gamma 0을 반환하는 흐름을 따르도록 별도 선언했다. 첫 15라운드는 같은 해시로 가져오고 이미 완료된 16라운드 첫 참여자의 단계만 재사용한 뒤 나머지를 학습했다. 23라운드까지 저장했지만 24라운드 참여자3에서 선언한 gamma 상한 10에 도달해 멈췄다. 마지막 전체 평가 CA 77.12%, ASR 13.9444%였다.

상한 분기는 중간 분류기와 101개 점수를 저장하지 못했다. 원본 생성기를 재사용한 한 참여자 진단을 별도로 수행했지만 gamma 2.0 통과와 2.1 실패가 나와 원래 상한 10 종료를 재현하지 못했다. 이 진단 모델로 원본 24라운드를 대체하지 않았다. 보고서의 cap2라는 오기는 gamma2.0 선택으로 정정했다.

## v5에서 100라운드와 실제 KD10을 수행한 과정

1. 1~23라운드는 원본 해시 그대로 가져오고 24~100라운드는 새로 계산했다. 위 단일 참여자 진단 모델은 넣지 않았다.
2. gamma 상한 10에서 모두 통과하면 마지막으로 검사한 통과값을 제출하고 최대값을 찾았다고 단정하지 않는 유한 정책을 선언했다.
3. 31라운드 gamma 10 제출 직후 CA 10.19%, ASR 0%로 효용이 무너졌다. 실제 제출과 집계가 저장 상태와 같은지 확인하고 원본 실패를 남긴 채 100라운드까지 진행했다.
4. 32라운드 상태 파일을 읽던 감독만 종료됐을 때 기존 학습 프로세스에 새 감독을 연결했다. 학습 재시작이나 중복 MPI는 없었다.
5. 100라운드 검증과 독립 평가를 완료했다. 다음 삭제 단계에서는 참여자4의 실제 과거 선택과 가중치로 기여를 누적해 차감했다.
6. 학생은 차감 상태, 교사는 고정된 100라운드 모델로 두고 정상 잔류 참여자5의 무라벨 2,500장으로 10회 KD, 400배치를 수행했다. 온도30, SGD0.01과 momentum0.9, 정답 CE와 T제곱 배율 없이 KL을 사용했다.

v5의 실제 전후 결과는 아래 표와 같다. 같은 생성기의 독립 전체 평가가 일치했고 양쪽 호스트에 전후 모델과 로그를 보관했다. 실제 선택 ID와 가중치, KD 10회, clean 입력, 고정 교사와 생성기는 공개 코드에서 정정한 조건으로 명시했다.

## v6에서 수식의 업데이트를 따로 검사한 과정

1. 소스를 다시 직접 실행해 가중 기울기에 Adam을 적용하는 것과 수식 그대로의 가중 SGD가 다른 갱신을 만드는 것을 확인했다.
2. 명시된 두 업데이트는 SGD, 다른 단계는 Adam으로 수행하는 해석을 새 프로필에 고정했다. 악성 비율 m은 본문 5를 유지했다. 유일한 저자 공인 해석이라고 부르지 않았다.
3. 같은 초기 모델에서 100라운드를 새로 계산하고 실제 참여자4의 41개 기여를 차감했다. v5와 같은 KD 계약으로 10회, 400배치를 수행했다.
4. 첫 정상 라운드, 첫 억제자와 첫 공격자 단계에서 실제 50에포크와 optimizer, 같은 생성기, 제출식과 집계를 검사했다. 전체 검증도 100라운드, 800역할, 186생성기 그룹과 KD 로그를 확인했다.
5. 독립 점수 확인에서 9라운드 gamma2.4가 CPU 24/220, 원래 GPU 23/220으로 한 장 달랐다. 선택 gamma2.3은 18/220으로 같았고 2.4는 양쪽 모두 탈락했다. CPU 세 계산 모드로도 원래 23건은 재현되지 않았다.
6. 감사 출력 오류는 CPU 관측기만 별도로 복구했다. 같은 GPU 독립 평가 시도는 다른 앱의 GPU 점유 812MiB로 추론 전에 차단돼 원래 실패를 보존했다. 다른 앱을 종료하거나 유휴 기준을 바꾸지 않았다.

## 제안이 나온 이유

정상 삭제와 공격의 반응 점수가 겹친 뒤, 같은 삭제 조건을 반영한 신뢰 기준 모델이 있으면 공격에 따른 기능 훼손을 나눠 볼 수 있다는 생각이 제시됐다. 이 항목은 완료 실험이 아니다.

## 검토한 내용

1. D02에서는 정상 참조 영향을 빼도 정상 주요 클래스 삭제 점수가 공격보다 컸다.
2. D08에서는 같은 잔류 참여자의 새 응답을 얻고 정상 참조를 빼도 공격이 큰 정상 삭제 두 값 사이에 놓였다.

4. 새로운 기준 모델을 실제로 어떻게 확보하고, 같은 정상 삭제 조건을 얼마나 대표하며, 왜 같은 반례를 만들지 않을지 확인하지 못했다.

## 현재 판단

이전 참조와 다른 자원일 수는 있지만, 추가 정보라는 이유만으로 해결된다고 말할 근거가 없다. 해당 기준 모델을 만들고 검증한 결과도 없으므로 미실행 제안으로 보류한다. 교수 미팅에서는 실험 횟수나 성공 결과에 포함하지 않는다.

# 별도 카드가 없던 추가 파일럿 기록

아래 세 폴더는 기존 인덱스에서 내용 판정 미재검토로 남아 있다. 이번에는 보존된 소스와 집계 파일을 읽어 수행 내용과 관측값을 정리했다. 모델 해시와 선택 절차를 새로 독립 검증한 기록은 없으므로 정식 탐지 또는 정화 성능에 합산하지 않는다.

## 정상 마진을 제약한 정화 파일럿

공격 후 모델과 큰 정상 삭제 후 모델을 같은 정화 연산에 넣어 공격 감소와 정상 기능 손상을 비교했다. 정상 학습 풀에서 1,000장을 뽑아 배치 64로 사용했고, 전후 모델의 정상 출력과 예측 1위 및 2위의 로짓 차이를 계산하는 코드를 사용했다. 실제 트리거는 9,000장 평가에 연결돼 있다.

저장 집계에서 공격 ASR은 100.00%→99.7778%, 정상 정확도는 90.47%→76.57%였다. 큰 정상 삭제 대조도 정확도 89.76%→76.84%, 같은 트리거 목표 예측 1.6556%→7.8333%였다. 기록된 정화는 공격 감소가 작고 정상 손상이 컸다. 평가 버전과 독립 검산이 확보되지 않은 파일럿 수치로 남긴다.

원 기록: [소스](../../research/dmcu_pilot_20261023/run_pilot.py), [집계](../../research/dmcu_pilot_20261023/PILOT_RESULTS.json).

## 변형 종류와 정상 참여자 합의를 비교한 파일럿

동일 BadFU 공격 q10과 큰 정상 삭제 q12에서 공통 가산, 입력 의존 변형, 마스크를 탐색했다. 후보 선택 후 공개 이미지와 정상 참여자 3명 자료에 적용해 새 오류 비율의 평균 및 조화평균을 계산했다. 별도 400회 탐색과 마진, 부드러운 변형, 반경 비교도 보존돼 있다.

최초 공개 확인에서 가산은 공격 5.44%와 큰 정상 6.44%, 입력 의존 변형은 0.11%와 0.22%, 마스크는 5.22%와 2.22%였다. 400회 파일의 마스크는 공격 32.78%, 큰 정상 6.56%였지만 가산은 공격 7.22%, 큰 정상 9.11%였다. 넓은 후보 표현에서 공통 분리가 나왔다고 표시하지 않는다.

추가 보존 파일의 최대 마진 값은 공격 0.960과 큰 정상 1.028, 부드러운 변형 값은 공격 2.11과 큰 정상 2.09였다. 정상 참여자들이 같은 클래스를 고르는 현상은 정상 조건에도 나타났다. 이 일치는 공격 특이성이나 D17의 독립 재현으로 보지 않았다.

## 마지막 특징에 공통 이동을 학습한 파일럿

처음 시험 이미지 500장 중 전후 모델이 모두 맞힌 이미지를 골랐다. 각 목표 클래스에 대해 512차원 특징의 공통 이동을 100회 Adam, 학습률 0.05로 최적화하고 전후 목표 전환 비율을 계산했다. 초기 공격 및 정상 세 쌍 뒤에 보존 모델 11쌍으로 확장한 파일이 있다. 선택에 쓴 입력과 확인 입력이 독립이라는 검증 기록은 이 집계에 붙어 있지 않다.

첫 공격의 최대 클래스 비율은 68.56%, 정상 850장 삭제는 35.77%, 큰 정상 삭제는 45.03%였다. 최대 클래스와 다른 클래스 평균의 비는 각각 2.1365, 1.3770, 1.7359였다. 확장 기록의 다른 공격은 2.0392, PGD64 공격은 1.5314였고, 감염 모델의 정상 요청은 2.0524, 다른 정상 삭제는 1.8926이었다.

이 특징 공간 이동이 실제 이미지에 구현되는 변형인지 확인한 결과는 없으며 점수 범위도 겹친다. 같은 자료의 적합을 독립 탐지 성능으로 표시하지 않는다. 기존 단순 변화량 접근을 재개하는 근거로도 쓰지 않는다.

정상 Non-IID 대조군 확장
2026-10-19

규모
기존210건의 고정 검증은 계속 진행한다.
같은10개 새 시드 × 기본 클래스 편향20/70/90% × 정상 삭제12종 =360건을 추가한다.
총 예정 요청 수는570건이다. 추가 공격 시드나 추가 GPU 재학습을 수행하는 확장은 아니다.
추가360건은 정상 데이터 삭제 요청에서 경보가 얼마나 생기는지 보는 스트레스 시험이다.

정상성 통제
기존 연합학습 실험의 base_future 모델을 사용한다.
이 모델은 모든 클라이언트의 원본 B 자료와 정답 라벨만으로 학습됐다.
공격 자료·억제 자료를 학습하지 않은 모델이며, 추가 검사도 B 이미지와 실제 정답만 사용한다.
트리거 파일, 패치, 공개 기준 이미지, 개발/검증/시험 이미지는 읽지 않는다.
시드에 따라 클라이언트0~4를 순환해 각 클라이언트를 두 번씩 검사한다.
각 모델당 개인 학습 자료1200장에서 삭제 집합을 만들고 나머지를 유지 집합으로 둔다.

삭제12종
삭제 개수120/360/720장, 즉10%/30%/60%.
각 개수마다 아래4종을 검사한다.
1. 클래스 비율을 유지한 무작위 삭제.
2. 다수 클래스부터 집중적으로 삭제.
3. 각 클래스에서 현재 모델이 쉽게 맞히는 자료 삭제.
4. 각 클래스에서 현재 모델의 CE가 높은 어려운 자료 삭제.
1·3·4번은 클래스별 삭제 개수를 완전히 같게 맞춘다.
따라서 같은 라벨 분포에서 특징·난이도 차이로 경보가 커지는지도 비교할 수 있다.

지표와 기준
기존 순수1스텝 FC/Layer4 전체 노름 비율과 직교 잔차 비율4개를 그대로 사용한다.
Conv5개 각각의 값도 전부 저장한다.
기존 gradient_scale_v1의 계산 함수·임계값을 해시로 고정하여 그대로 호출한다.
새 결과를 보고 임계값·레이어·지표를 선택하지 않는다.
개인 집합의 평균 CE 기울기를 같은 원본에서 계산하며 모델 갱신·KL·클리핑·추가 정상 기준 자료는 없다.
매 요청의 FC 기울기를 별도의 해석식으로 다시 확인하고 오차를 보존한다.
실패·분모0은 별도로 기록하며 안전 판정이나0점으로 바꾸지 않는다.
최초 실행은 준비 캐시의 부모 폴더 생성 누락으로 점수 계산 전에 멈췄다.
최초 코드·설정·오류를 startup_failure/에 보존하고 폴더 생성만 수정한 뒤 재시작했다.
이 수정으로 지표·임계값·삭제 집합 선택 기준은 바꾸지 않았다.

실행
DISLAB CPU2스레드·낮은 우선순위로 실행한다.
기존 그래디언트 검사가 계산 중이면 새 요청 시작을 기다린다. GPU는 추가 사용하지 않는다.
소스 clean 모델이 준비되는 대로 검사하므로, 진행 중인 원본 실험의 일정에 따라 이어서 실행된다.
추가360건에 대한 실제 삭제 후 모델은 새로 학습하지 않는다.
기존210건의 실제 ASR 비교와 추가360건의 정상 구성 요청 경보 수를 분리해서 보고한다.

확장 시작 시점의 기존 결과
35건 점수 계산,28건 실제 삭제 후 결과 연결, 런타임 실패0건.
네 주 지표 각각 공격 구성 요청3/4 탐지, 대조 요청1/24 위험 판정.
누락은 균등 조건의 공격 요청이며 실제 ASR은17.33%→99.56%였다.
오탐은 같은 균등 조건의 오라벨 대조였고 실제 ASR은2.78%→5.39%였다.
엄격한 잠재 활성화 기준을 만족한 공격3건은 모두 탐지했다. 위 누락과 오탐도 그대로 포함해 보고한다.
기존 패치 검사는 같은28건에서 공격 구성 요청4/4 탐지, 대조 오탐0/24였다.
original_benchmark_at_start.json에 이 시점의 전체 집계를 보존한다.

파일
protocol.json: 실행 전에 고정한 조건·기준·소스 해시.
selection_self_check.json:108개 합성 분할 검사와 난이도 순서 검증.
status.json / summary.json / REPORT_KO.txt: 현재 진행·기존 검증·추가 정상 대조 집계.
results.json: 추가 정상 요청별 모든 지표와 판정.

inspect_dislab.ps1: 원격 상태를 읽어 로컬 사본을 갱신한다.

해석
새시드10개를 공유하므로570개 독립 실험으로 해석하지 않는다.
의도적으로 고른 클래스·난이도 조건의 시험이며 실제 서비스의 자연 발생 오탐률을 추정하는 표본은 아니다.

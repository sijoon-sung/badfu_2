# BadFU에서 시작한 연구 재설계와 실제 검증

2026-10-18 · DISLAB RTX 3080 · 탐색 연구 · 학습 시드 42 하나

후속 해석: [BadFU 구조 활용과 노벨티 재평가](STRUCTURE_NOVELTY_AUDIT.md). 현재 최종 교정기는 BadFU의 위장-삭제 상호작용을 직접 활용하지 않는다. 기존 요소의 조합이라는 이유만으로 노벨티를 부정하지 않되, BadFU 구조에서 도출된 추가 기여는 아직 입증되지 않았다는 판단이다.

## 결론과 현재 판단

**실험적으로 전진했다. 정상 정확도를 거의 유지하면서 BadFU의 삭제 후 공격을 크게 줄이는 실행 가능한 교정기를 만들었다. 그러나 독립적인 논문 기여와 보편적 방어 성능까지 입증한 상태는 아니다.**

이번에 주력 후보로 정한 질문은 **“삭제 전 모델이나 공격자 신원에 의존하지 않고, 삭제 후 모델의 정상 기능을 기준으로 백도어 반응만 줄일 수 있는가?”**다. 기존 저장소의 `PAPER_METHOD_PROPOSAL.md`에 있던 마지막 층 명세 교정 발상을 재사용했다. 구현은 강한 선형 제약식 대신 풀기 쉬운 응답 일관성 목적함수로 시작했고, 공격으로 찾은 반례를 추가하는 방식까지 확장했다.

현재 가장 중요한 긍정적 근거는 ASR 99.51%를 7.51%로 낮추면서 정확도 손실을 0.58%p로 제한한 단순 교정이다. 반례 보강은 새로 최적화한 입력 공격에도 추가 효과가 있었지만 정상 정확도를 더 잃었다. **마지막 잔류 자료 참조 대조에서는 반례 보강이 실제 ASR을 32.87%에서 91.67%로 악화시켰다. 따라서 반례 보강을 주력 방어로 확정하는 가설은 기각한다.** 새 알고리즘이 단순 기준선을 모든 면에서 이겼다는 주장은 하지 않는다.

## 1. 해결할 문제와 핵심 주장

BadFU에서는 위장 자료를 지워도 독성 자료는 남는다. 따라서 잔류 자료로 재학습한 모델도 위험할 수 있다. 이 사실은 BadFU, Hidden Poison, UBA-Inf에서 이미 다뤘다. “재학습도 위험하다”는 문장 자체는 우리의 새 기여가 아니다. [BadFU](https://arxiv.org/html/2508.15541v1), [Hidden Poison](https://papers.nips.cc/paper_files/paper/2023/file/8b4add8b0aa8749d80a34ca5d941c355-Paper-Conference.pdf), [UBA-Inf](https://www.usenix.org/system/files/usenixsecurity24-huang-zirui.pdf).

연구 가설은 다음과 같다.

> 정상 출력을 삭제 **후** 모델에 맞추어 보존하고, 의미를 바꾸지 않는 입력 변형에 대한 불필요한 출력 반응을 줄이면, 삭제 전 상태를 되가르치지 않고도 삭제 후 위험을 완화할 수 있다. 현재 모델을 겨냥해 새 반례를 찾으면 고정된 패치 목록이 놓친 위험도 일부 보완할 수 있다.

이 가설에서 공격자 탐지·요청 거절은 필요 없다. 망각 처리는 기존 FU가 수행한다. 교정은 이후 단계다. **우리가 FU의 정확성을 인증하거나, 이미 삭제된 정보가 전부 사라졌다고 실험으로 증명한 것은 아니다.**

논문 후보의 정확한 범위는 *삭제 후 상태만 사용하는 기능 보존 교정의 가능 범위와 실패 경계*다. 가제는 **Repairing Post-Unlearning Backdoors without Restoring Pre-Deletion Knowledge**로 둔다. 제목의 “without restoring”는 현재로서는 설계 목표이며, 아래 조건부 후처리 성질을 넘는 실증적 망각 보장은 아니다.

## 2. 추가한 조건

| 항목 | 이번 실험의 실제 조건 |
|---|---|
| 방어 접근 | 실제 FU 후 모델의 가중치·특징·입력 기울기 접근 |
| 공개 자료 | CIFAR-10 공개 평가 자료에서 피팅 1,000장, 검증 1,000장; 둘은 서로 분리 |
| 정답 사용 | 교정 손실은 post 모델의 출력만 사용. 클래스 균형 분할·정확도 기반 선택에는 공개 정답 사용 |
| 변형 가정 | 네 모서리의 4×4 덮어쓰기 패치가 원래 의미를 보존한다고 가정 |
| 모르는 정보 | 실제 공격 패턴 픽셀, 실제 공격 표적, 공격자 신원은 교정 입력에 주지 않음 |
| 수정 범위 | 특징 추출기·BN·전처리 고정, 마지막 선형층과 bias만 변경 |
| 보존 기준 | 공개 검증 정확도가 원래 post보다 2%p 이상 떨어지는 후보 제외 |
| 학습 모델 | 저자 공개 코드 계열 CIFAR-10 ResNet18, FL 40R / FU 20R, seed 42 |
| 직접 FU 경로 | `full6 → fu_remove5`: 6명 중 보조 위장 클라이언트 전체 제거 |
| 재학습 참조 | `bd5`: 남은 clean+poison 자료의 별도 40R 학습. 분포적 망각 인증 아님 |

네 모서리 밖의 트리거, 큰 패치, Blended, WaNet, 의미 기반 트리거까지 다룬다는 주장은 하지 않는다. 소량 공개 자료가 모든 희소 집단을 대표한다는 보장도 없다.

## 3. 구현한 방법

현재 삭제 후 모델을 `z(x) = h(x) W₀`로 쓴다. 특징 행렬에는 bias용 상수 1을 붙였다. H는 정상 공개 이미지의 특징, B는 변형 전후 특징 차이 `h(Tx) − h(x)`다. 교정량 D는 다음 문제를 푼다.

\[
\min_D \frac{\|B(W_0+D)\|_F^2}{m}
+\alpha\frac{\|HD\|_F^2}{n}
+\lambda\|D\|_F^2.
\]

첫 항은 패치 때문에 달라지는 출력을 낮춘다. 두 번째 항은 정상 입력에서 **post 모델**의 출력을 유지한다. 세 번째 항은 과도한 수정을 막는다. 삭제 전 모델 출력과의 일치는 요구하지 않는다.

`S = BᵀB/m`, `C = HᵀH/n`이면

\[
D^* = -(S+\alpha C+\lambda I)^{-1}SW_0.
\]

실제 구현은 역행렬을 만들지 않고 선형계를 푼다. λ>0이므로 이 유한 목적함수의 해는 유일하다. 모든 해의 선형계 잔차를 실행 중 확인했다. **이는 유한 목적함수의 최적해이지, 모든 입력에 대한 보안 인증이 아니다.**

초기 목록은 모서리별 검정·흰색·체커·역체커와 무작위 패치다. 반례 보강에서는 현재 교정 모델에 대해 표적 10개×모서리 4개를 모두 탐색한다. 각 패치는 공개 피팅 이미지에서 최적화하며, 찾은 40개 패치를 경험적 목적함수에 추가한다. 이 과정을 세 번 반복한다. 모든 반례를 반드시 수정하는 강한 제약식은 아니다.

각 후보는 검증 정확도 조건을 통과해야 한다. 마지막에 공통 반례 목록에서 검증 응답 차이가 가장 작은 후보를 선택했다. 실제 트리거 ASR은 모든 선택을 저장한 뒤 평가했다. 시험에서 더 좋아 보인 iteration 1로 사후 교체하지 않았다.

첫 비교의 `fixed_target`은 변형 입력을 원래 post의 정상 출력에 맞추고, `paired_invariance`는 수정된 모델 내에서 정상/변형 출력을 서로 맞춘다. 둘 다 같은 공개 자료와 마지막 층만 사용했다.

## 4. 실제 결과

정상 5,000장, 원래 표적 클래스 제외 실제 트리거 4,500장. 모든 행은 동일한 `fu_remove5` 모델에서 시작했다.

| 방법 | 정상 정확도 ↑ | 원본 트리거 ASR ↓ | 정상 정확도 변화 |
|---|---:|---:|---:|
| 실제 FU 후 그대로 | 86.96% | 99.51% | — |
| 정적 교정, 초기 그리드, 분할 101 | 87.00% | 11.58% | +0.04%p |
| 정적 교정, 반례 방식과 같은 그리드, 패치 32개 | **86.38%** | **7.51%** | **−0.58%p** |
| 정적 교정, 같은 그리드, 패치 152개 | 86.54% | 14.40% | −0.42%p |
| 반례 보강 교정, 검증으로 선택 | 85.14% | 6.82% | −1.82%p |
| 네 모서리를 0.5로 가리는 단순 기준선 | 84.76% | **1.51%** | −2.20%p |

**해석:** 성능 붕괴 없이 교정 가능한 해가 존재한다는 근거는 확보했다. 다만 같은 그리드의 정적 32개 방식은 반례 방식보다 정상 정확도가 1.24%p 높고, 원본 ASR 차이는 0.69%p다. 반례 보강의 가치는 원본 트리거 수치만으로 입증되지 않는다. 모서리 가리기는 상당히 강한 기준선이며, 2%p와 2.2%p의 경계만으로 열등하다고 단정하지 않는다.

새로운 입력 공격에서도 확인했다. 원본 공격 패턴을 그대로 평가하는 대신, 각 방어 모델에 맞춰 **같은 무작위 시작점, 4개 모서리, 2회 재시작, 60스텝**으로 표적 0의 보편 패치를 최적화했다. 개발 160장·검증 160장과 별도의 시험 1,000장 중 비표적 900장을 사용했다.

| 방법 | 새 최적화 패치의 표적 도달률 ↓ | 이 별도 시험의 정상 정확도 |
|---|---:|---:|
| post 그대로 | 99.44% | 85.20% |
| 정적 32개, 같은 그리드 | 27.00% | 84.90% |
| 정적 152개, 같은 그리드 | 41.67% | 85.20% |
| 반례 보강 교정 | **14.33%** | 83.40% |

여기서는 반례 보강의 추가 신호가 있다. 그러나 정확도 손실과 교환했고, **14.33%의 공격이 여전히 성공했다.** 학습 단계부터 방어를 아는 적응형 BadFU를 재훈련한 실험은 아니다. 강건성 인증이나 최악 공격 상한으로 읽으면 안 된다.

### 반복과 정상 대조

초기 정적 방식의 공개 데이터 분할 101/102/103에서 정상 정확도는 87.00/86.94/87.04%, ASR은 11.58/11.98/12.62%였다. **학습 시드를 바꾼 세 번의 독립 실험이 아니다.**

같은 초기 정적 방식을 정상 `clean5` 모델에 적용하면 정확도 85.08%가 84.98/84.92/85.12%가 됐다. `cover5 → fu_remove1`의 정상 클라이언트 삭제 후 모델에서도 정확도 83.04%가 82.34/82.60/82.30%, 원본 패치 표적률 11.71%가 1.49/1.31/1.29%였다. 이 정상 삭제 경로는 `full6 → fu_remove5`와 다른 출발 모델이다. 이 비교로 요청자 신원을 탐지했다고 주장하지 않는다.

잔류 자료 참조 `bd5`는 정확도 86.00%, ASR 100%였다. 초기 정적 교정 후 정확도 85.78/85.66/85.50%, ASR 32.87/24.11/23.02%였다. 따라서 같은 레시피도 FU 결과와 재학습 참조에서 같은 수준의 정화를 만들지는 않는다.

**추가 반증 — 같은 반례 절차를 `bd5`에도 적용했다.** 정적 초기 후보의 정확도/ASR은 85.78%/32.87%였다. 공개 검증의 응답 차이를 기준으로 최종 선택한 반례 후보는 **85.52%/91.67%**였다. 정상 정확도는 유지하면서 실제 안전성이 크게 악화됐다. 단일 실패이지만 “반례를 더 찾고 검증 응답 차이를 줄이면 실제 백도어도 계속 줄어든다”는 일반 주장의 반례로 충분하다. 원본 트리거를 보고 정적 후보로 되돌린 결과를 방법의 성공처럼 보고하지 않았다. 원인은 아직 분해하지 않았으므로 출력 축소·패치 형태 불일치 등으로 확정해서 설명하지 않는다. 결과는 `counterexample_bd5/`에 있다.

### 실제 잠복 여부를 따로 확인

동일 시험에서 `full6`는 삭제 전 정확도 87.12%, ASR **81.51%**였다. 따라서 위의 직접 FU 교정 실험을 “낮은 잠복 ASR에서 완벽히 활성화된 BadFU의 재현”이라고 부를 수 없다.

한 클라이언트에 poison+cover가 함께 있는 별도 `cover5`는 정확도 84.26%, ASR **14.07%**였다. cover가 없는 `bd5`의 ASR 100%와 대비된다. 두 저장 모델은 각각 학습된 모델이다. 이는 삭제 전/잔류 자료 학습의 참조 비교이며, 같은 초기화로 새로 실행한 paired retraining이나 `full6`의 FU 결과로 섞어 쓰지 않는다.

## 5. 실패한 가설과 통제 실험

- **삭제 전후 정보가 필수인가?** 160장 파일럿에서는 post-only 탐색 패치와 무작위 패치 교정이 ASR 약 42%로 비슷했다. differential은 ASR 6.89%였지만 정확도가 79.1%로 내려갔다. 추가 정보의 우월성은 확인되지 않았다.
- **BN 통계만 문제인가?** post 가중치+pre BN의 ASR은 98.56%, 공개 자료 BN 재보정은 99.67%였다. BN 교체만으로 해결된다는 가설을 지지하지 않는다. pre BN 교체는 진단이며 삭제 보존 방어가 아니다.
- **반례가 많아서 좋은가?** 152개 정적 패치와 같은 그리드 대조를 실행했다. 단순 패치 수 증가가 개선을 보장하지 않았다. 정적 32개와 152개는 상수/무작위 패치의 상대 비율도 다르므로 “개수만의 인과 효과”로 해석하지 않는다.
- **정확도 손실 ≤2%p를 보장했는가?** 반례 방법의 시험 점 추정은 −1.82%p지만, 클래스별 paired image bootstrap 95% 구간은 **[−2.50, −1.16]%p**다. 모집단 손실이 2%p 이내라는 통계적 인증은 아니다.
- **낮은 ASR이 정답 복원인가?** 반례 방법의 트리거 입력 원래 정답률은 61.09%다. ASR 6.82%와 별개로 상당수 입력은 다른 오답으로 간다. 모서리 가리기의 원래 정답률 84.47%도 같이 봐야 한다.

## 6. 새로움의 객관적 판정

| 선행 | 이미 알려진 것 | 이번 연구와의 관계 |
|---|---|---|
| [BadFU](https://arxiv.org/html/2508.15541v1) | 위장 삭제 후 백도어 활성화 | 앵커. 현상 자체는 새로움 아님 |
| [Adversarial Logit Pairing](https://arxiv.org/abs/1803.06373) | 정상/변형 출력 일치 정규화 | 응답 일관성 자체는 새로움 아님 |
| [NNrepair](https://arxiv.org/abs/2103.12535), [Provable Repair](https://arxiv.org/abs/2104.04413) | 마지막 층·제약 기반 신경망 교정 | 마지막 층 교정 또는 정확히 푸는 최적화 자체는 새로움 아님 |
| [Counterexample-Guided Repair, ICML 2023](https://arxiv.org/abs/2301.11342) | 반례를 통한 반복 교정과 강건 최적화 관점 | 반례 반복 자체는 새로움 아님 |
| [TBAR](https://arxiv.org/html/2510.14845v1) | 백도어 과제의 가중치 방향을 추정·차감 | 정상 기능 보존과 약한 트리거 단서 이용이 겹침 |
| [InstantForget](https://arxiv.org/html/2606.15730v1) | 특징 투영 한계 분석·조건부 특징 리셋 | 비슷한 특징 공간 방어. 해당 논문의 동작점에는 triggered validation이 사용됨 |
| [FedCARE](https://arxiv.org/html/2601.22589v1) | 투영과 재학습 역류 억제 | 삭제 효과 복구를 피한다는 목적이 겹침 |
| [Forget Unlearning](https://proceedings.mlr.press/v202/chourasia23a.html), [Topic modeling unlearning](https://openreview.net/pdf?id=Bqvkul76J3) | 삭제 자료에 오염된 상태 회피·후처리 성질 | 과거 상태를 안 쓰는 원리와 후처리 정리는 기존 |

**따라서 현재 구현을 “완전히 새로운 방어 원리”라고 포장하면 안 된다.** 이번 검색 범위에서 동일한 BadFU 후처리 프로토콜·이 목적함수·반례 구성·비교 구성을 그대로 쓰는 논문은 확인하지 못했지만, 검색에서 못 찾았다는 사실은 최초성 증명이 아니다.

남아 있는 후보 기여는 (a) 삭제 후 정보만 허용되는 조건에서 실제 FU/잔류 재학습/정상 삭제를 함께 비교하는 문제 설정, (b) 그 조건의 저비용 응답 교정 및 실패 경계, (c) 원본 트리거 억제와 새 공격 내성을 분리하는 실험적 결론이다. **이 셋을 합쳤다고 자동으로 논문 수준의 기여가 되는 것은 아니다.** 아직 같은 효용에서 강한 기존 방어를 이긴 증거가 없고, 여러 독립 FL 시드·트리거도 부족하다. 마지막 `bd5` 실패까지 포함한 판정은 **단순 교정의 가능성 확인 / 반례 보강의 일반성 기각 / 신규 방법 논문 확정 보류**다.

이후 우선순위는 알고리즘에 항을 더 붙이는 것이 아니라 **FU 결과에서는 안전해 보인 교정 선택이 왜 잔류 재학습에서는 안전성을 되돌리는지**를 분해하는 것이다. 현재로서는 FU 방법 특성인지, 특징 표현 차이인지, 대리 점수의 불일치인지 확인하지 않았다. 이 선택 지표의 실패가 여러 모델·트리거에서도 재현되면 분석 논문의 중심 현상 후보가 된다. 한 사례만으로 이를 새로운 일반 현상이라고 명명하지 않는다.

## 7. 망각과 안전성은 어떤 관계인가

U(D,F)가 A(D\F)와 (ε,δ)-구분 불가능하다는 보장을 이미 가진다고 가정하자. 삭제 자료와 무관하게 고정된 공개 자료 P, 난수 및 변형 규칙만 사용하는 동일한 후처리 R에 대해서는 `R(U,P)`와 `R(A(D\F),P)`에도 같은 구분 불가능성이 전달된다. 이는 기존 후처리 정리의 직접 적용이다.

중요한 점은 비교 대상도 **교정된 재학습 모델**이라는 것이다. `R(U,P)`가 교정 전 `A(D\F)`와 같다는 결론은 나오지 않는다. 현재 BadFU FU에 원래 보장이 없으므로 우리가 이를 인증된 언러닝으로 바꿨다는 주장도 성립하지 않는다. 공개 자료·변형 선택에 삭제 전 상태가 숨어 들어오면 공통 후처리 조건부터 다시 확인해야 한다.

이번 정적/반례 교정의 출력은 수치상 post 모델과 고정 공개 자료에만 의존한다. 코드의 provenance 검사는 pre 파일의 해시를 확인하지만 pre 가중치를 교정 대상으로 로드하지 않는다. 초기 differential 파일럿은 별도로 pre 정보를 썼으므로 같은 논리로 보장하지 않는다.

## 8. 증거 범위와 재현

- 학습을 새로 세 번 실행한 것이 아니라 기존 완료 모델을 재사용했다. 실제 GPU 추론·패치 최적화·분류층 교정·평가는 이번 세션에서 새로 실행했다.
- 5,000장 시험은 바로 이전 정화 실험의 1,320장과 겹치지 않는다. 다만 과거 HRAC의 제외 목록 240장과 125장이 겹친다. 현재 피팅·선택 분할과는 분리되지만, 연구 전체에서 한 번도 본 적 없는 최종 시험 집합은 아니다. “새 시험”이라는 중간 표현은 이 한정된 의미로 정정한다.
- 방법·그리드 변경은 순차 탐색이다. 후속 실험은 이전 결과를 보고 설계했으며 완전한 사전등록 연구로 부르지 않는다. 반례 이후 시험 집합 재사용도 공개한다.
- 원본 BadFU 공개 코드의 6-client 전체 삭제 경로와 논문 본문의 같은-client 표본 삭제를 구분했다. 공격 record의 생성 예외와 공개 코드/논문 차이를 이번에 해소한 것은 아니다.
- 실제 ASR은 원래 공격 record에 연결된 이미지로 평가했다. 임의로 재현한 트리거가 아니다. 모델 및 이미지 출처 해시는 실행 결과에 저장했다.
- `analyze.py`는 저장된 예측에서 정확도·ASR을 재계산하고 입력 ID 일치, 소스 해시를 확인한다. `audit.json`, `metrics.csv`, `evidence.png`가 산출물이다.
- 원본 모델과 기존 연구 파일은 덮어쓰지 않았다. 코드와 소형 결과는 이 폴더, 본 모델은 DISLAB 기존 연구 폴더에 있다.

다음 연구의 판정 기준은 명확하다. 같은 정상 효용 예산에서 기존 NNrepair/SAU/I-BAU 계열 및 단순 입력 제거보다 의미 있는 이득이 여러 독립 FL 시드에 재현되어야 방법 논문으로 진행한다. 그러지 못하면 “새 방어” 주장은 버리고 정보 제약과 평가 실패를 중심으로 한 분석 논문의 가치부터 다시 판단한다. **그 기준을 통과하기 전 채택 가능성·최초성·일반적 보안을 확언하지 않는다.**

삭제 요청에 조건화된 잔류 자료 개입: 검증 결과
2026-10-18 · 탐색적 연구 · 독립 검산 완료

결론: 혼합 차분으로 잔류 자료의 순위를 매긴 이번 구현은 주력 방법으로 채택하지 않는다. 같은 수의 자료를 제외한 사후 모델 전용 방법과 단순 픽셀 반복 기준선보다 탐색·정화 결과가 나빴다. 잠복 후 활성화라는 현상만으로 큰 연속 상호작용이 보장되지 않는 논리적 반례도 확인했다. 이 결과는 모든 요청 조건화 개입 방법의 불가능성을 뜻하지 않는다.

1. 실제로 수행한 비교

기존 축소 BadFU형 CIFAR10/ResNet18, 5클라이언트 Non-IID FedAvg 모델을 사용했다. 세 기존 공격 시드와 정상 라벨·오라벨 대조, 총 5조건에서 실제 poison ID를 숨긴 후보 순위를 고정했다. 실제 자료 역할은 모든 순위를 고정한 후 평가에만 사용했다.

요청자 잔류 자료 1,380개를 사후 모델 특징과 저장 라벨로 40묶음으로 나눴다. 각 묶음을 제외하거나 유지하고, 요청 자료 F를 포함하거나 제외하는 단기 진단을 비교했다. 상호작용 방법, F 분기 없는 대조, 사후 모델 전용 대조에는 각각 82개의 진단 모델이라는 같은 예산을 부여했다. 공통 분기를 재사용해 실제 실행한 단기 진단은 총 1,025개이며, 이를 독립 통계 실험 1,025건으로 세지 않는다.

검사 입력은 실제 패턴을 제공하지 않고 사후 모델에서 4모서리×10표적을 탐색한 4×4 패치다. 모든 비교법에 같은 입력과 자료 묶음을 제공했다. 패치 자체를 새로운 기여로 주장하지 않는다.

주 비교는 잔류 자료의 10%,138개를 추가 제외하는 조건이다. 선택을 바꾸지 않고 공격 71·정상 71에서 초기화부터 40라운드 전체 연합학습을 다시 수행했다. 각 조건에 두 기준 모델, 네 자료 선택법, F가 남은 상호작용 진단을 포함해 총 14개를 학습했다. 원래 요청 자료 F를 유지하는 모델은 기전 진단이며 정화 모델로 세지 않는다.

2. 자료를 얼마나 잘 찾았는가

예산 138개에서 전체 poison 180개 중 선택한 비율:
방법                         시드 71       시드 72       시드 73
상호작용   0.00% / 42.78% / 76.67%
F 분기 없는 대조   75.00% / 76.67% / 76.67%
사후 모델·잔류 자료   76.67% / 76.67% / 76.67%
픽셀 반복   76.67% / 76.67% / 76.67%
무작위   13.89% / 13.33% / 9.44%

76.67%는 이 예산에서의 최대치다. 138개가 모두 poison이면 138/180=76.67%가 된다. 사후 모델 전용·픽셀 기준선은 세 실행 모두 이 최대치였다. 상호작용은 평균 39.81%였고 첫 실행에서 정상 자료만 138개 골랐다.

단순 픽셀 반복 검사가 잘된 것은 이번 고정 패턴 설정의 특성이다. 정상 라벨의 같은 패치 증강 자료도 똑같이 선택하므로, 이 결과를 악의적 의도 탐지나 모든 BadFU에 대한 일반적 방어로 확대하지 않는다.

3. 실제 정화는 잘됐는가

공격 71 독립 시험 2,000개, ASR은 표적 클래스 제외 1,800개. 모두 고정된 40라운드 모델이다. 선택법은 같은 138개 제외량이며, 추가 제외 없음은 기준이다.
방법 / 정상 정확도 / 실제 ASR / 트리거 입력의 원래 정답률
추가 제외 없음 / 61.65% / 76.94% / 16.06%
요청 조건 상호작용 / 61.95% / 71.28% / 20.00%
사후 모델·잔류 자료 진단 / 63.80% / 6.33% / 60.78%
픽셀 반복 검사 / 63.45% / 7.00% / 59.89%
무작위 선택 / 62.10% / 56.89% / 29.50%

상호작용의 ASR 감소는 5.67%p로, 무작위 제외의 20.06%p보다 작았다. 사후 모델 전용·픽셀 기준선은 ASR이 훨씬 낮으면서 정상 정확도도 더 높았다. ASR 감소와 원래 정답 복원은 구분해야 하며, 기준선의 낮은 ASR을 완전한 정화로 부르지 않는다.

정상 71의 정상 정확도:
추가 제외 없음: 62.45%
요청 조건 상호작용: 62.40%
사후 모델·잔류 자료 진단: 61.60%
픽셀 반복 검사: 62.75%
무작위 선택: 62.00%

상호작용 방법은 정상 요청에서 평균 정확도가 62.45→62.40%로 거의 같았지만, 클래스 5는 57.5→51.5%, 클래스 0은 66.0→60.5%로 낮아졌다. 이는 해당 시험 표본의 점 추정이며 모집단 손실의 인증은 아니다. 평균 정확도만으로 집단별 기능 보존을 판단할 수 없었다.

4. 왜 상호작용이라는 근거가 충분하지 않았는가

단순한 분류기의 트리거 입력 표적-정답 마진을 m(F,G)=-1+3G-3F로 두자. F,G는 각각 위장과 독성 기여의 존재 여부다. F=G=1이면 마진-1로 잠복하고, F만 지우면 마진 2로 공격이 활성화된다. G도 지우면 마진-1로 안전해진다.

그러나 G의 연속 기여는 F가 있을 때도 없을 때도+3이다. 따라서 혼합 차분은 3-3=0이다. 이번 정규화 반응도 정상 입력의 점수 크기를 고정하면 같은 반례를 갖는다. 반대로 성공 여부로 임계값을 통과시킨 ASR에서는 상호작용이 1이 된다. 큰 ASR 상호작용이 곧 새로운 비선형 학습 기전이라는 결론은 나오지 않는다.

이는 실제 신경망의 가중치가 P와 C 부품으로 분리된다는 주장이 아니다. 잠복→활성화라는 행동만으로 연속 혼합 차분이 크다는 필연성이 없음을 보이는 논리적 반례다. ANALYTIC_FINDING.txt와 ANALYTIC_COUNTEREXAMPLE.json에 계산을 보존했다.

이번 단기 진단에서는 실제 poison이 F 유무 양쪽에서 위험 반응에 기여했다. 두 효과를 빼면 이 유용한 신호도 줄어든다. 혼합 차분만으로 순위를 매긴 구현은 직접 위험 기여가 양수가 아닌 묶음에서도 첫 실행의 27개를 선택했다. 이 사후 분석은 점수나 선택을 수정하는 데 사용하지 않았다.

독립 시험에서 같은 G를 제외한 뒤 공통 탐색 입력의 정규화 위험은 2.9631→2.9828로 오히려 증가했다. 실제 트리거에서는 2.1547→1.9341로 감소했다. 혼합 차분의 크기, 직접 위험 감소, 대체 검사 입력과 원래 트리거의 정렬은 별도 문제였다. 현재 구현의 실패를 모든 개입 방식의 불가능성으로 확대하지 않는다.

5. 검산과 한계

네 추가 제외 없는 전후 기준 모델은 기존 모델을 가중치까지 정확히 재현했다. 별도 분석기에서 모든 순위·선택 개수·자료 역할 평가를 다시 계산했고, 저장된 원시 예측에서 정확도·ASR·정답률을 재계산했다. 14개 새 모델과 선택 기록의 해시도 확인했다. 로컬로 내려받은 132개 증거 파일은 묶음의 해시와 모두 일치했다.

정상 성능 판정의 fit/probe/validation은 단기 진단에서는 분리됐지만 원래·재학습 연합모델이 학습한 잔류 자료다. 따라서 이 판정을 독립적인 일반화 보장으로 부를 수 없다. 이 한계를 보존하고, 독립 시험의 정상 성능·실제 ASR·네 모델의 연속 상호작용을 별도 평가했다. 시험 결과로 모델·제외량·검사 입력·하이퍼파라미터를 선택하지 않았다.

사후 모델과 실제 잔류 자료가 이미 제공되는 상황이다. 사전 예측의 효용을 시험한 실험은 아니다. 새 독립 FL 시드나 독립 공격 생성물을 추가한 확인 연구도 아니다. 축소 학습·고정 4×4 패치·같은 요청자 안의 P/C·정상 4클라이언트의 협력이라는 범위가 있다. 위조 진단 응답, 클라이언트 간 공모, 극단적 클래스 결손은 다루지 않았다.

정화 학습에 별도의 공개 정상 이미지를 추가하지 않았지만, 다른 클라이언트의 정상 잔류 자료와 협력을 요구했다. F/pre에 따라 G를 고르므로 F를 직접 학습하지 않는 최종 모델도 인증된 망각을 자동으로 만족하지 않는다. 추가 자료 제외는 일반적인 잔류 재학습 목표 자체도 바꾼다.

공격 71 정화는 DISLAB RTX3080/PyTorch2.5.1, 정상 71 정화는 로컬 RTX4060/PyTorch2.4.1에서 수행했다. 한 조건 안의 모든 방법과 두 기준 모델은 같은 환경이다. 공격·정상 조건 사이의 차이를 순수한 라벨 개입 효과로 해석하지 않는다.

6. 연구 판단

앞서 혼합 상호작용을 우선적인 탐지 지표로 권한 근거는 충분하지 않았다. 현재 구현은 주력 후보에서 제외한다. 사후 자료 정리 기준선의 성공도 그 자체로 새로운 BadFU 전용 방어의 노벨티를 뜻하지 않는다.

남는 구분은 명확하다. 위험을 줄이는 자료 개입을 찾는 문제와, 위장 유무에 따라 자료 효과가 달라지는지를 찾는 문제는 같지 않다. 다음 연구에서는 두 번째 양이 첫 번째 목표에 왜 추가 정보를 주는지부터 검증해야 한다. 현재처럼 사후 모델이 있는 경우에는 그 추가 이득을 확보하지 못했다. 사후 모델이 없는 사전 위험 예측 상황은 별도의 문제로 남긴다.

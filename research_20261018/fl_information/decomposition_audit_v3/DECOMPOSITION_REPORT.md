## 2. 질문 B 검정: 블록 단위 부분 이식(Block-wise Prefix/Suffix Graft)

마지막 분류기(`fc`) 이식에서 기각된 가설을 보완하기 위해, ResNet18의 절단면을 `stem`, `layer1`, `layer2`, `layer3`, `layer4`(직후 `fc`)로 이동하며 `앞단(Prefix) → 뒷단(Suffix)` 교차 이식을 수행했다(시드 71·72·73).

### 2.1 `앞단 → B+P(삭제 후) 뒷단` 이식 시 실제 트리거 ASR (Frozen Eval 기준)

| 절단 위치 (`cut`) | `B+P+C → B+P` (시드 71 / 72 / 73, 평균) | `B → B+P` 대조군 (시드 71 / 72 / 73, 평균) | `B+C → B+P` 대조군 (시드 71 / 72 / 73, 평균) |
|---|---:|---:|---:|
| `stem` 직후 | 69.44 / 99.61 / 98.89 (**89.31%**) | 69.22 / 99.61 / 98.72 (**89.18%**) | 70.83 / 99.56 / 99.33 (**89.91%**) |
| `layer1` 직후 | 51.22 / 97.17 / 93.44 (**80.61%**) | 50.06 / 94.61 / 89.22 (**77.96%**) | 56.61 / 96.39 / 94.83 (**82.61%**) |
| `layer2` 직후 | 20.56 / 47.56 / 44.44 (**37.52%**) | 15.17 / 27.39 / 29.72 (**24.09%**) | 20.28 / 44.67 / 60.67 (**41.87%**) |
| `layer3` 직후 | 11.33 / 12.78 / 11.61 (**11.91%**) | 9.39 / 7.33 / 8.56 (**8.43%**) | 9.28 / 10.50 / 10.78 (**10.19%**) |
| `layer4` 직후 (`fc`만 이식) | 7.89 / 6.50 / 8.17 (**7.52%**) | 7.50 / 4.94 / 5.33 (**5.92%**) | 3.94 / 2.72 / 2.39 (**3.02%**) |

*(깨끗한 개발 자료 200장으로 뒷단 BN running statistics를 재보정한 대조에서도 `B+P+C → B+P`와 `B → B+P`의 차이가 없다는 결론은 동일하게 유지됨: 예컨대 `layer1` 81.94% 대 82.06%, `layer3` 14.57% 대 10.22%.)*

### 2.2 역방향 `B+P(삭제 후) 앞단 → 뒷단` 이식 시 실제 트리거 ASR

| 절단 위치 (`cut`) | `B+P → B+P+C` (시드 71 / 72 / 73, 평균) | `B+P → B` 대조군 (시드 71 / 72 / 73, 평균) | `B+P → B+C` 대조군 (시드 71 / 72 / 73, 평균) |
|---|---:|---:|---:|
| `stem` 직후 | 8.17 / 7.94 / 10.06 (**8.72%**) | 4.39 / 3.72 / 5.22 (**4.44%**) | 2.17 / 1.17 / 0.83 (**1.39%**) |
| `layer1` 직후 | 9.50 / 8.11 / 17.17 (**11.59%**) | 5.11 / 4.33 / 5.22 (**4.89%**) | 3.11 / 0.78 / 0.44 (**1.44%**) |
| `layer2` 직후 | 9.72 / 6.94 / 34.56 (**17.07%**) | 6.78 / 5.28 / 5.17 (**5.74%**) | 2.83 / 0.17 / 0.28 (**1.09%**) |
| `layer3` 직후 | 13.06 / 7.06 / 56.61 (**25.58%**) | 10.44 / 10.61 / 5.89 (**8.98%**) | 2.78 / 0.00 / 0.06 (**0.95%**) |
| `layer4` 직후 (`fc`만 이식) | 68.94 / 99.39 / 99.28 (**89.20%**) | 57.44 / 98.89 / 97.00 (**84.44%**) | 47.17 / 93.83 / 80.67 (**73.89%**) |

### 2.3 해석과 한계
1. **하위 블록 잠복 가설 기각**: 모든 절단 깊이(`stem`~`layer4`)에서 `B+P+C 앞단 + B+P 뒷단`의 ASR은 **독성 자료 $P$를 전혀 학습하지 않은 `B+C 앞단 + B+P 뒷단`(또는 `B 앞단 + B+P 뒷단`) 대조군과 구별되지 않는다.** `stem`이나 `layer1` 절단에서 ASR이 높은 이유는 `B+P+C`가 독성 특징을 미리 만들어 두었기 때문이 아니라, 초반 층에서는 $4\times 4$ 패치가 국소 시각 정보로 그대로 전달되어 `B+P`의 상위 블록(`layer3`~`layer4`)이 이를 클래스 0으로 변환하기 때문이다.
2. **활성화 변환의 위치**: 역방향 이식(`B+P → B`)에서 `layer3`까지는 평균 ASR이 `8.98%`에 머물다가 **`layer4`를 통과한 직후 `84.44%`로 급증**한다. 즉 `B+P` 재학습 모델에서 트리거 특징이 정상 클래스 0의 표현 영역으로 합류하는 주된 변환은 **`layer4`**에서 일어난다.

## 3. 질문 A 검정: 512차원 특징 공간($\phi$) 기하 및 오라클 선형 분리도

네 조건의 마지막 층 직전 512차원 특징 $\phi(x)$와 $\phi(T(x))$에서 측정한 3시드 평균 지표는 다음과 같다.

| 잔류 조건 | 상대 이동량 $\|\Delta\phi\|_2 / \|\phi\|_2$ | 클래스 0 중심 방향 정렬 $\cos(\Delta\phi, \mu_0-\phi(x))$ | 오라클 트리거 유무 이진 선형 탐지율 | 오라클 목표 0 선형 프로브 ASR |
|---|---:|---:|---:|---:|
| `B+P+C` (`both`) | 0.344 | 0.185 | 63.07% | 43.98% |
| `B+P` (`poison_only`) | **0.808** | **0.610** | **89.00%** | **89.85%** |
| `B+C` (`cover_only`) | 0.378 | 0.070 | 64.70% | 40.48% |
| `B` (`base`) | 0.271 | 0.167 | 57.86% | 39.39% |

* **판정**: exact retraining으로 학습된 `B+P+C` 모델의 512차원 특징 공간에서 트리거 이동 크기(`0.344`), 목표 클래스 0 방향 정렬도(`0.185`), 심지어 실제 트리거를 알고 학습한 이진 선형 분류기의 분리도(`63.07%`)까지 **독성이 없는 `B+C`(`0.378`, `0.070`, `64.70%`) 및 `B`(`0.271`, `0.167`, `57.86%`) 범위 안에 있다.**
* 따라서 이 설정에서 위장 자료 $C$는 “특징 추출기 내부에 형성된 강한 백도어 표현을 후단에서 상쇄”하는 것이 아니라, **합동 재학습 과정에서 특징 추출기가 $T(x) \to \text{class } 0$ 사상을 형성하는 것 자체를 막는다.** 이는 삭제 전 모델($f_{\mathrm{pre}}$) 단독 탐색으로 목표 클래스를 찾기 어려운 구조적 이유를 설명한다.

## 4. 질문 C 분해: 왜 반례 보강 교정이 `fu_remove5`에서는 성공(ASR 6.82%)하고 `bd5`에서는 안전성을 되돌렸는가(ASR 32.87% → 91.67%)?

[`REPORT.md`](../../REPORT.md) §4·§6에서 미해결로 남겼던 `bd5` 반례 보강 실패(`counterexample_bd5`)의 원인을 저장된 152개 반례 패치와 후보 그리드 전체에서 분해했다.

### 4.1 반례 패치 자체가 `bd5` 교정에 실패한 것이 아니다
`bd5`의 Iteration 1(패치 72개)과 Iteration 3(패치 152개)에서 생성된 **동일한 반례 패치 행렬 $S$**를 사용하더라도, 하이퍼파라미터가 초기 정적 교정과 같은 `a1_l0.001`($\alpha=1.0, \lambda=0.001$) 또는 `a1_l0.1`($\alpha=1.0, \lambda=0.1$)일 때는 **실제 트리거 ASR이 오히려 크게 감소**했다:

| `bd5` 후보 (동일 반례 패치 사용) | 검증 정확도 (`feasible` 기준 $\ge 83.6\%$) | 비정규화 검증 일관성 $\frac{1}{10}\mathrm{tr}(W^\top S_{\mathrm{val}}W)$ ↓ | 깨끗한 로짓 에너지 $\frac{1}{10}\mathrm{tr}(W^\top C_{\mathrm{val}}W)$ | **정규화 검증 일관성** $\frac{\mathrm{tr}(W^\top S_{\mathrm{val}}W)}{\mathrm{tr}(W^\top C_{\mathrm{val}}W)}$ ↓ | $\cos(W, W_0)$ | 시험 정확도 | **실제 시험 ASR** ↓ |
|---|---:|---:|---:|---:|---:|---:|---:|
| 교정 전 `original_w0` | 85.60% (기준) | 16.109 | 29.629 | 0.5437 | 1.0000 | 86.00% | 100.00% |
| 초기 정적 `initial_static` (32개, `a1_l0.001`) | 85.00% (통과) | 5.874 | 23.836 | 0.2464 | 0.5336 | 85.78% | **32.87%** |
| Iter 1 `a1_l0.001` (72개) | 85.20% (통과) | 3.774 | 21.015 | **0.1796 (1위)** | 0.4144 | 85.36% | **15.44%** |
| Iter 3 `a1_l0.001` (152개) | 84.20% (통과) | 4.131 | 20.264 | **0.2038 (1위)** | 0.3826 | 85.22% | **13.33%** |
| Iter 3 `a1_l0.1` (152개) | 85.00% (통과) | 4.160 | 19.539 | 0.2129 (2위) | 0.5371 | 85.40% | **18.47%** |
| Iter 3 `a0.1_l0.1` (152개) | **82.70% (탈락)** | 0.631 | 3.609 | 0.1749 | 0.4691 | 83.38% | 23.44% |
| **Iter 3 `a0.1_l10` (실제 선택된 후보)** | 84.90% (통과) | **3.269 (비정규화 1위)** | **10.825 (절반 축소)** | 0.3020 (하위) | **0.9558** | 85.52% | **91.67%** |

### 4.2 역전이 발생한 정확한 2단계 기전 (Scale-Shrinkage Trap)

1. **1단계 — 검증 정확도 하한(`base_val_acc - 2%p`)에 의한 저-$\lambda$ 후보 탈락**:
   * `fu_remove5`에서는 $(\alpha=0.1, \lambda=0.1)$이 검증 정확도 `85.8%`(기준 `87.4% - 2.0% = 85.4%` 이상)로 통과해 선택되었고, 이때 $\cos(W, W_0)=0.513$, 시험 ASR `6.82%`를 기록했다.
   * 반면 `bd5`에서는 $(\alpha=0.1, \lambda=0.1)$의 검증 정확도가 Iter 1에서 `82.9%`, Iter 3에서 `82.7%`로 기준선(`85.6% - 2.0% = 83.6%`)에 **0.7~0.9%p 미달하여 `feasible=false`로 제외**되었다.
2. **2단계 — 비정규화 이차형식 $\mathrm{tr}(W^\top S_{\mathrm{val}} W)$의 스케일 취약성과 $\lambda=10$의 방향 복원**:
   * $(\alpha=0.1, \lambda=0.001)$과 $(\alpha=0.1, \lambda=0.1)$이 탈락하자, $\alpha=0.1$ 격자에서 유일하게 남은 후보는 **`a0.1_l10` ($\alpha=0.1, \lambda=10.0$)**이었다.
   * 해 $W = (S + \alpha C + \lambda I)^{-1}(\alpha C + \lambda I) W_0$에서 $\lambda=10.0 \gg \alpha=0.1$이면, 가중치 수정량 $\|D\|_F^2$에 대한 강한 페널티 때문에 **$W$의 방향은 교정 전 백도어 가중치 $W_0$와 거의 일치($\cos(W, W_0) = 0.9558$)**하게 되어 실제 시험 ASR이 **91.67%**로 되돌아간다.
   * 동시에 $\alpha=0.1$은 깨끗한 특징의 로짓 크기 보존($\|H(W-W_0)\|_F^2$)을 약하게 강제하므로, `a0.1_l10`의 **깨끗한 검증 로짓 에너지($\frac{1}{10}\mathrm{tr}(W^\top C_{\mathrm{val}}W)$)가 `20.26`(`a1_l0.001`)에서 `10.82`로 약 47% 축소**된다.
   * 분류 정확도(`argmax`)는 양의 스케일 축소에 불변이지만, 기존 선택 지표인 $\frac{1}{10}\mathrm{tr}(W^\top S_{\mathrm{val}}W)$는 가중치/로짓 스케일의 제곱에 비례한다. 그 결과, 실제로는 패치 대 정상 분산 비율($\frac{\mathrm{tr}(W^\top S_{\mathrm{val}}W)}{\mathrm{tr}(W^\top C_{\mathrm{val}}W)}$)이 `0.3020`으로 나쁜 `a0.1_l10`이 순전히 **출력 스케일 축소** 덕분에 비정규화 점수(`3.269` < `4.131`)에서 `a1_l0.001`(실제 ASR **13.33%**)을 이기는 역전이 일어났다.

### 4.3 함의와 범위
* 이 결과는 [`REPORT.md`](../../REPORT.md)에서 보류했던 원인 후보 중 **“출력 축소(logit scale shrinkage)와 비정규화 대리 점수(`raw_val_consistency`)의 결합 + $\lambda=10$ 정규화의 원본 가중치 방향 복원”**이 `bd5` 안전성 역전의 직접적 원인임을 수치로 확정한다.
* `fu_remove5`와 `bd5` 모두에서 선택 지표를 스케일 불변 비율 $\frac{\mathrm{tr}(W^\top S_{\mathrm{val}}W)}{\mathrm{tr}(W^\top C_{\mathrm{val}}W)}$로 바꾸면, `fu_remove5`는 기존과 동일한 후보(Iter 1 ASR `5.87%`, Iter 2 ASR `6.82%`)를 유지하면서 `bd5`에서는 `a1_l0.001`을 선택해 ASR이 `32.87% → 15.44% (Iter 1) → 13.33% (Iter 3)`로 단조 감소한다.
* 다만 이는 **단일 시드(`seed 42`)의 사후 원인 분해(post-hoc diagnostic decomposition)**이므로, 이를 근거로 반례 보강을 다시 “검증된 새 방어법”으로 승격하지는 않는다. 새로운 독립 시드에서 사전 고정된 정규화 지표로 재검증하기 전까지는 **대리 선택 지표의 스케일 함정(Scale-Shrinkage Trap)을 규명한 분석 결과**로만 기록한다.

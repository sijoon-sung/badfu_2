# 패치 정화에서 삭제 경로의 위험으로: 새로운 연구 후보와 실제 통제 실험

2026-10-18. DISLAB RTX 3080에서 실행. 기존 BadFU 모델을 교정한 실험과 별개의 기전 파일럿.

## 연구 질문의 변경

기존 실험을 실행하기 쉽다는 이유로 패치·마지막 층 교정·방어 방법에 연구를 제한했던 것은 잘못이었다. 이번에는 BadFU의 **삭제가 남은 독성 기여를 드러낸다**는 구조에서 연구 질문을 다시 골랐다.

현재 후보는 **같은 자료를 모두 삭제하고 동일한 최종 모델에 도달해도, 중간에 배포하는 모델의 위험은 처리 순서에 따라 크게 달라질 수 있는가**이다. 개별 삭제의 정확성과 마지막 모델의 평가만으로 배포 과정의 위험을 평가할 수 있는지 묻는다.

전역 색감·질감 변형은 이 질문이 작은 사각형에만 의존하지 않는지 보는 실험 수단이다. 이 변형 자체를 새로운 공격으로 제안하지 않는다. 자연적인 의미 기반 트리거를 구현했다는 뜻도 아니다.

## 후보를 고르면서 제외한 단순 확장

| 생각한 방향 | 선행과 판단 |
|---|---|
| 작은 패치를 전역 주파수 변형으로 교체 | [UNCLEAN](https://arxiv.org/html/2506.12522v1)이 주파수 트리거와 정상 forget set을 사용한다. 이것만으로 신규성 없음 |
| 정상 자료 삭제도 공격을 활성화한다 | UNCLEAN과 관련 선행이 이미 다룬다. 공격자가 삭제를 선택하는 경우와 독립적인 정상 이탈은 구분해야 하지만, 여기서 최초라고 주장하지 않음 |
| 여러 요청으로 조금씩 활성화 | [UBA-Inf](https://www.usenix.org/conference/usenixsecurity24/presentation/huang-zirui), [Exploiting Machine Unlearning](https://arxiv.org/abs/2310.10659)에 on-demand/점진 활성화가 있다 |
| 삭제 순서가 최종 모델을 바꾼다 | [When Is Deletion Ordering Tractable?](https://arxiv.org/abs/2610.01149)가 순차 업데이트의 순서 의존 최종 목적을 다룬다 |
| 삭제 때문에 집단별 성능이 나빠진다 | [Fair Machine Unlearning](https://proceedings.mlr.press/v238/oesterling24a.html) 등과 겹친다 |

남긴 질문은 **최종 모델은 순서와 무관하도록 통제한 상태에서도 중간 위험이 달라지는가**이다. 이 차이는 위 대표 선행과 구별되는 실험 목적이지만, 검색에서 같은 논문을 못 찾았다는 사실은 최초성 증명이 아니다. “위장을 먼저 삭제하면 위험해진다”는 관찰만으로는 BadFU의 직접적인 귀결에 머문다. 기한·배포 제약 하의 유용한 분석 또는 방법이 추가돼야 독립 기여가 된다.

## 추가한 조건

- CIFAR-10 원래 학습 분할: 정상 기반 자료 B 12,000장, 역할 배정 후보 3,000장, 검증 2,000장. 세 집합의 원본 이미지 ID는 서로 다르다.
- 별도 공식 시험 분할의 2,000장. 표적 클래스 0을 제외한 1,800장으로 ASR을 계산한다. 연구 전체에서 한 번도 사용되지 않은 이미지라는 주장은 하지 않는다.
- 외부 ImageNet 사전학습 ResNet18을 고정하고 96px 입력 특징을 사용한다. 이번 poison/camouflage로 특징 추출기를 학습하지 않는다.
- 자료에 따라 학습되는 전체 부분은 ridge 선형 분류기다. 매 단계 남은 자료로 목적함수의 유일한 해를 다시 계산한다. **이 학습기에 대한 정확한 재학습이며, 전체 신경망 또는 FedAvg의 정확한 언러닝이라는 주장은 아니다.**
- 같은 전역 변형을 적용한 poison 200장과 camouflage 800장. 전자는 정답을 표적 0으로 바꾸고, 후자는 정답을 유지한다. 둘은 원본 이미지 ID도 서로 다르다.
- P0/P1 각 100장, C0/C1 각 400장으로 총 네 삭제 요청을 구성한다. 모두 처리되면 B만 남는다.
- 세 시드 11/22/33은 역할 이미지 배정을 바꾼다. 독립적인 FL 학습 세 번 또는 세 외부 특징 추출기 실험은 아니다.
- 삭제 큐에 독성과 위장 역할 자료의 제거가 모두 포함된다는 추가 조건이다. 항상 이런 요청이 들어온다고 가정하지 않는다.
- 순서 선택 실험은 네 요청이 이미 대기 중이고 처리 순서를 바꿀 수 있다는 조건이다. 원시 입력은 공개 검증 이미지 및 알려진 변형 계열이고, 공격자 역할·표적 라벨을 선택 규칙에 주지 않는다. **변형을 모르는 방어가 아니다.**

색감 변형은 RGB별 배율과 오프셋을 이미지 전체에 적용한다. 질감 변형은 부드러운 사인·코사인 패턴을 전체 이미지에 적용한다. 둘 다 작은 영역 마스크를 쓰지 않지만, 이미지 내용의 의미를 유지한다는 가정과 분포 이동의 영향은 남아 있다.

## 실제 실행과 결과

두 변형 × 세 자료 배정 × 공격/정상 라벨 대조 × 16개 삭제 부분집합 = **192개 분류기 상태**를 평가했다. 각 설정의 요청 순열 24개, 총 **288개 경로**를 계산했다. 특징 추출·실행·저장까지 약 15초였으며 기존 GPU 환경 초기화 시간은 별도다.

| 변형 | 시작 ASR | 위장부터 삭제할 때 중간 최대 ASR | 검증으로 순서를 골랐을 때 최대 ASR | 최종 ASR |
|---|---:|---:|---:|---:|
| 전역 색감 | 7.89–8.33% | **28.83–30.00%** | 7.89–8.33% | 2.56% |
| 전역 질감 | 21.56–24.44% | **88.72–89.83%** | 21.56–24.44% | 3.61% |

범위는 세 역할 배정의 최솟값과 최댓값이다. 신뢰구간이 아니다. 시작점도 경로 최대값 계산에 포함했다.

모든 요청을 처리한 분류기 가중치는 순서와 무관하게 동일하다. 실제 구현에서 최종 가중치와 기반 자료만 직접 학습한 가중치의 bitwise equality를 확인했다. 합산한 충분통계로 구한 중간 해도 원시 특징을 다시 연결해 학습한 해와 최대 약 1.6e-13 차이였다.

색감 조건의 정상 정확도는 모든 공격 상태에서 약 81%대로 유지된다. 예를 들어 시드 11은 81.30–81.65%다. 즉 정상 평균 정확도나 마지막 모델만 보면 중간의 표적 공격률 상승을 놓칠 수 있다.

질감 조건은 더 큰 표적 공격률 상승을 보여 주지만 **좋은 잠복 공격 재현으로 부를 수 없다.** 시작 ASR부터 21–24%다. 또한 최종 질감 이미지의 원래 정답률은 **39.60%**, 다른 클래스까지 포함한 최대 오분류 집중률은 **43.78%**다. 따라서 최종 ASR 3.61%를 근거로 최종 모델이 전반적으로 안전하다고 표현하면 틀린다. 색감 조건을 주된 해석 근거로 삼고 질감 조건의 분포 이동 문제를 별도로 보고한다.

정상 라벨 대조는 P의 원래 정답을 유지하고 나머지 이미지·변형·분할·삭제 큐를 그대로 둔다. 색감 조건에서는 모든 경로의 최대 표적 도달률이 2.56%였고, 질감은 4.28–5.33%였다. 공격 설정의 큰 표적률 상승이 단순한 같은 자료 수 삭제만으로 설명되지는 않는다. 단, 질감의 일반적 분포 이동 문제까지 사라지는 것은 아니다.

## 무엇을 해결하려는가

자료 기반 학습을 A, 처리 순서를 π, 앞에서 k개 처리한 삭제 합집합을 F(π,k)라 두면,

`M(π,k) = A(D \ F(π,k))`

이다. 정확한 재학습에서는 마지막 삭제 합집합이 같으면 최종 모델도 같게 통제할 수 있다. 그러나

`R_path(π) = max_k R(M(π,k))`

는 순서에 따라 달라질 수 있다. 현재는 ASR과 실제 위험의 관계를 명시한 유한 표본 지표를 사용했고, 실제 서비스 시간이나 피해량을 측정하지 않았다.

이번 기준선은 각 중간 모델의 **공개 검증 이미지가 특정 오답 클래스로 몰리는 비율**을 모든 클래스에 대해 계산하고, 그 최대값이 가장 작은 순열을 선택한다. 시험 ASR은 순서 선택이 저장된 후 계산했다. 전수 탐색으로 네 요청의 경로를 고른 것이므로 새로운 최적화 알고리즘이라고 부르지 않는다.

연구로 발전시킬 핵심은 처리 기한·허용 배포 시점이 있는 경우의 **삭제 준수, 중간 모델 위험, 서비스 중단 비용**을 함께 다루는 것이다. 위장을 보존하거나 삭제 전 상태를 복원하는 방식은 삭제 요청을 수행했다는 증거가 될 수 없다. 반대로 위험한 잔류 상태가 기한상 강제된다면 단순히 순서만 바꾸는 방법으로 해결할 수 없다.

## 반드시 이겨야 할 간단한 해법과 반증 조건

1. **한꺼번에 처리하고 마지막에만 배포:** 배치가 허용되고 기한을 만족하면 중간 모델을 노출하지 않는 것으로 이번 문제를 피할 수 있다. 이를 무시한 복잡한 스케줄러는 기여가 약하다.
2. **아직 요청하지 않은 poison까지 삭제해야만 해결되는 경우:** 현재의 순서 해법은 쓸 수 없다. 이때 추가 교정이나 서비스 중단이 필요할 수 있으며 별도 조건이다.
3. **이미 알려진 변형으로 검증해야만 효과가 있는 경우:** 탐지 범용성을 주장하지 않는다. 보호할 업무별 위험 집합이 명시된 서비스나 평가 프로토콜로 범위를 한정해야 한다.
4. **전체 신경망·실제 FL에서 현상이 사라지는 경우:** 현재는 고정 특징 학습기의 기전 결과로 남긴다. BadFU용 시스템 방법의 근거로 확장하지 않는다.
5. **새로움이 max 위험 지표를 정의한 것뿐인 경우:** 독립 논문 기여로 부족하다. 현실적 제약에서 기존 정책이 실패하는 범위, 계산 가능한 안전한 배포 조건 또는 비용 이득이 필요하다.

## 현재 판정과 다음 우선순위

이 결과는 **패치 정화보다 넓은 문제를 실제로 시험했고, 삭제가 정확하며 최종 모델도 동일한데 중간 위험이 달라지는 사례를 얻었다**는 근거다. 새로운 공격·방어 또는 논문 노벨티의 완성은 아니다.

다음 판정 실험은 임의로 공격을 더 강하게 만드는 것이 아니라, 같은 끝점 통제를 유지하면서 (a) 전체 신경망 재학습 및 실제 FL, (b) 요청 도착·기한과 배치 배포 기준선, (c) 보호 대상 변형이 검증과 다를 때의 실패를 확인하는 것이다. 이 제약에서 별도 가치가 없으면 이 후보도 버린다. 원래의 정적 교정 실험은 성능 기준선으로 보존한다.

## 재현 파일

- `PROTOCOL.md`: 첫 실행 전에 저장한 조건과 중단 기준.

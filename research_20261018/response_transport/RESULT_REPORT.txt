반응 전이 정화: 실제 실험 결과 보고
2026-10-18 / DISLAB RTX3080

결론
정화가 작동했고, 정상 출력의 변화를 작게 제한할 때 post만 쓰는 비교법보다 공격을 더 줄이는 조건을 확인했다. 큰 수정 예산에서는 post 비교법이 더 강했다. 작은 수정 예산의 선택적 정화가 후속 연구의 기여 후보이며, 문헌적 신규성과 인증된 망각을 확정한 단계는 아니다.

1. 구현한 방법
변형 입력 Tx의 목표 점수 = pre(Tx) + post(x) - pre(x). 원본 x의 출력은 post에 맞추고, 변형 반응만 pre에서 옮긴다. 출력 목표를 증류하며 전체 신경망 가중치를 갱신했다. SVD/부분공간 제거/분류층만 수정하는 방식이 아니다.
다섯 비교법: 변형 정답 CE, pre 전체 증류, post 원본 고정+pre 변형 증류, post 자기 증류, 반응 전이.
고정 변형 비교에서 모든 방법은 동일한 post-only 탐색 결과를 공유했다. 반복형은25회마다 각 학생 모델에서 같은 탐색 절차를 다시 수행했다. 반복형에서는 이후 입력 변형 자체가 방법별로 달라진다.
SGD100회, 매회4클라이언트의16개 미니배치 기울기를 평균. 전체 가중치 갱신, BN 통계 고정. 온도2, 원본 CE0.25, 원본 교사 KL2, 변형 손실1. 학습률0.001과0.0003을 비교했고 반복형은0.0003으로 고정했다.

2. 실제 FL과 추가 조건
기초 모델은 기존에 완료한 CIFAR10/ResNet18, 5 Non-IID 클라이언트, 40라운드 전체 가중치 FedAvg의 전후 쌍이다. post는 삭제 자료를 제외한 실제 연합 재학습 결과다. 이번 실행에서 기초 FL을 새로 학습한 것은 아니다.
원 논문의 모든 위장 자료 생성 최적화와 학습 규모를 재현한 것은 아닌, 축소 BadFU형 파일럿이다.
정화는 단일 GPU에서 별도의 로컬 미니배치 계산과 집계를 실행한 동기식 federated SGD이며, 한 번의 로컬 SGD를 쓰는 FedAvg와 같다.
요청자0을 제외한4클라이언트가 정화 계산을 따르고 자료가 깨끗하다고 가정했다. 기존 자료에서 fit800/probe320/validation640개를 사용했다. 각 클라이언트에 모든 클래스가44개 이상 있는 조건이다. 별도의 공개 이미지를 수집하거나 추가하지 않았다.
정화용 세 집합은 서로 겹치지 않으며 삭제 자료·공격 자료와의 교집합은0이었다. 원본 모델이 이미 학습한 잔류 자료를 정화 학습/검증으로 나눴다. 독립 일반화는 공식 시험 이미지2000개/시드로 평가했다.
첫 탐색은 공격 패턴/위치/표적을 알려주지 않고4개 모서리×10표적에서RGB4×4를 역탐색했다. 실제 트리거와 공식 시험 자료는 각 정화의 선택이 끝난 뒤 평가에만 사용했다.
노이즈/클래스 비율/정상/안전 요청 대조를 포함했다. P/C가 다른 클라이언트에 있는 FUBA, 비패치 공격, 극단적인 클래스 결손 Non-IID, 위조 진단 응답은 검증하지 않았다.
이전 SVD 실험과 비교하면 추가 로컬 학습 정보와 요청자 제외 조건도 달라졌다. 차이를 정화 연산 하나의 효과로 해석하지 않는다.

3. 가장 중요한 직접 비교: 같은 정상 변화 허용치
두 반복 정화 모델 모두 post 방향으로 수정량을 조절했다. R 검증에서 KL(post||수정모델)의 동일 상한과 동일 정상 클라이언트/클래스 제약을 지키는 수정량을 공통 탐색 절차로 선택했다.
수정량은0:.1:1 격자와8회 국소 이분 탐색으로 정했다. 모든 요청·예산의 선택 파일을 저장한 다음에 실제 트리거 시험 평가를 열었다. ASR로 수정량을 선택하지 않았다.
공통 정상 제약: 클라이언트 정확도 하락≤2pp, 클래스 정확도 하락≤5pp, 클래스 CE 증가≤0.2. 이 표의 모든 모델이 검증 제약을 통과했다.
예산 / post 자기 증류 ASR / 반응 전이 ASR / post 비교법 정상 정확도 / 반응 전이 정상 정확도
0.005 / 56.40% / 38.64% / 62.84% / 62.86%
0.010 / 29.19% / 17.36% / 62.93% / 62.88%
0.020 / 15.03% / 16.74% / 63.03% / 62.88%
공격4시드의 단순 평균이다. 원래 post의 ASR은93.10%, 정상 정확도는62.63%였다.
0.01은 허용 상한이며 모든 방법의 실제 사용 KL이 정확히 같다는 뜻은 아니다. 이 예산에서 반응 전이의 평균 검증 KL은0.007720, 비교법은0.009995였다.
이 허용치는 잔류 검증 자료에서 측정한다. 독립 시험 분포의 KL까지 같은 상한을 만족한다는 보장은 아니다.
예산0.01의 시드별 ASR(post 비교법 / 반응 전이):
seed71: 18.50% / 19.50%
seed72: 39.44% / 13.39%
seed73: 42.89% / 21.17%
seed74: 15.94% / 15.39%
4시드 중3개에서 반응 전이의 ASR이 낮았다. seed71에서는 비교법이1pp 더 좋았다.

4. 반복 탐색으로 발전시킨 효과
작은 학습률의 고정 변형 반응 전이는 ASR 38.58%, 반복형은 16.74%였다.
고정100회 반복형 결과: post 비교법 ASR 11.36%, 반응 전이 16.74%. 수정량을 제한하지 않으면 비교법이 공격을 더 많이 제거했다.
정상 검증을 통과한 가장 늦은 체크포인트를 비교하면 24.32% 대 16.74%였다. 이 차이에는 한 시드에서 비교법이25회 체크포인트까지만 통과한 효과가 포함된다. 이것만으로 우월성을 주장하지 않고 위의 직접 예산 비교를 추가했다.

5. 정상 요청에서의 불필요한 변경
정상·안전 대조2건, 반복형100회에서 post 비교법의 시험 출력 KL은 평균0.019155, 반응 전이는0.002798이었다. 약6.85배 작은 변화다. 같은 학습률과 수정 비율을 모든 요청에 공통으로 적용한 강도 격자도 함께 저장했다.
이 값은 출력 보존을 측정한다. 정당한 모든 삭제 효과가 보존됐거나 법적/인증된 망각을 만족한다는 증명은 아니다.

6. 삭제 자료 정확도와 기억을 구분
삭제 cover와 같은 클래스 비율·같은 트리거를 가진 미사용 자료를 함께 평가했다. 반응 전이 반복형의 삭제 cover 정확도는 54.83%, 미사용 대조는 54.44%였다.
삭제 cover를 구별하는 클래스 조건부 손실 membership AUC는 pre 0.8818, post 0.4948, 반응 전이 0.4988였다.
삭제 자료 정확도의 상승만으로 삭제된 개별 자료의 기억이 복구됐다고 판단하지 않는다. 단일 membership 지표만으로 망각을 보증하지도 않는다. 안전 요청에서 추가로 삭제한 P 자료 전체의 망각을 인증한 실험은 아니다.

7. 기여 후보와 아직 남은 검증
기여 후보: 삭제 후 판단을 기준으로 pre의 상대 반응을 옮기면, 작은 정상 변화 예산 안에서 공격을 더 많이 줄이고 정상 요청의 불필요한 수정을 줄일 수 있다.
일반적인 post 정화도 충분히 작동했다. pre가 언제나 필요하다거나, Non-IID 변화가 완벽히 상쇄된다거나, 새 방법이 모든 예산에서 우월하다는 주장은 채택하지 않는다.
기존 SAU/PDI 방어 구현과의 비교, 정렬되지 않은 pre/다른 교사 대조, 새로운 FL 시드와 삭제 방식, 별도 공모 클라이언트와 비패치 공격, 희소 집단 효용, 더 강한 삭제 정보 감사가 남아 있다.
네 시드는 이전 연구에서 이미 관측한 모델이다. 작은 학습률과 반복형은 기본 결과를 본 뒤 개발한 비교이므로 새로운 사전등록 독립 확인 실험이 아니다. 현재 결과는 방법 발전의 실험 근거이며 논문 노벨티 확정은 아니다.

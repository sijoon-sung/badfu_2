# BadFU 구조 활용과 노벨티 재평가

2026-10-18. 기존 실험과 원문을 대조한 해석이며, 이 문서에서 새 학습 실험을 수행한 것은 아니다.

## 판단의 수정

기존 요소를 조합했다는 이유만으로 노벨티가 없다고 결론 낼 수는 없다. 새로운 문제 제약 아래 조합이 필요한 이유, 기존 방법의 체계적 실패, 그 실패를 해결하는 원리나 새로운 현상을 입증하면 기여가 될 수 있다. 학습 시드가 하나라는 문제도 그 자체로 최초성을 부정하지 않는다. 이는 증거 강도와 일반성의 문제다.

현재 방법에 대한 더 정확한 판단은 **노벨티가 없다는 증명이 아니라, BadFU의 특수한 구조에서 도출된 기여가 아직 입증되지 않았다는 것**이다.

## 원문에서 중요한 구조

[BadFU §V-C–D](https://arxiv.org/html/2508.15541v1)는 같은 트리거를 넣은 poison에는 표적 라벨을, camouflage에는 원래 라벨을 준다. 같은 공격자의 자료 안에 두 역할이 공존하며 camouflage만 삭제한다. FL 집계와 자료 이질성이 억제에 기여한다는 설명도 있다. 이 설명을 모든 라운드에서 두 기울기가 정확히 반대라는 정리로 해석해서는 안 된다.

핵심 관측 대상은 활성화된 모델 하나뿐 아니라 **억제하는 자료와 남는 독성 자료 사이의 관계, 그리고 그 관계를 끊는 삭제 개입**이다. 삭제가 정확해도 남은 자료가 위험할 수 있다.

이 계열의 위장-삭제 구조 전체가 BadFU에서 처음 나온 것은 아니다. [Hidden Poison](https://arxiv.org/abs/2212.10717), [UBA-Inf](https://www.usenix.org/conference/usenixsecurity24/presentation/huang-zirui)와 구별할 때 FL 조건 및 위장 생성의 차이를 명시해야 한다. BadFU 자체도 위장/독성 비율, 정상 삭제, 자료 분할, 집계 방식에 대한 실험을 포함한다. 같은 축을 다시 측정하는 것만으로 새 기여가 되지는 않는다.

## 현재 구현은 무엇을 사용했는가

| 요소 | 최종 정적 교정 / 반례 보강의 사용 여부 |
|---|---|
| 삭제 후 모델 | 사용 |
| 패치 위치·크기라는 공격 형태의 사전 지식 | 사용 |
| 삭제 전의 잠복 상태 | 사용하지 않음 |
| 어떤 자료 또는 역할이 삭제됐는지 | 교정 계산에 사용하지 않음 |
| poison과 camouflage의 공유 트리거 및 라벨 관계 | 식별하거나 직접 활용하지 않음 |
| 요청별 억제 기여, 잔류 독성 기여의 관계 | 사용하지 않음 |
| FL 집계·클라이언트 이질성 | 학습 환경에는 있지만 교정 연산에는 없음 |

마지막 층 교정의 입력은 사실상 `R(삭제 후 모델, 공개 자료, 변형 목록)`이다. 일반적인 활성 백도어 모델을 넣어도 연산을 그대로 실행할 수 있다. 따라서 현재로서는 **BadFU에서 평가한 일반 패치 반응 교정**이라고 부르는 것이 정확하다. 이 관찰은 알고리즘의 노벨티 부재를 증명하지는 않지만, BadFU 구조를 활용했다는 주장에는 직접 반증이 된다.

초기 differential 파일럿은 실제 pre/post의 변형 반응 차이를 이용했으므로 삭제 구조를 부분적으로 사용했다. 기존 HRAC 역시 기여 간 억제 관계를 겨냥했다. 그러나 전자는 정상 성능 손상이 컸고 후자는 단순 기준선보다 나은 독립 대조가 부족했다. 실패한 이력을 무시하고 같은 차분이나 상쇄 점수에 새 이름을 붙여서는 안 된다.

## 실험이 입증한 것과 입증하지 않은 것

ASR 99.51→7.51%, 정확도 86.96→86.38%는 해당 활성 모델의 교정 가능성을 지지한다. 다음은 아직 입증하지 않는다.

1. BadFU의 잠복 구조를 이용했기 때문에 가능한 성과인가.
2. 그 구조 때문에 기존 범용 방어가 체계적으로 실패하는가.
3. 삭제 전후 또는 요청 정보가 같은 자원 예산의 post-only보다 추가 정보를 주는가.
4. 삭제 자체를 보존하면서 위장 역할만 대체할 수 있는가.

직접 FU 경로의 삭제 전 ASR도 81.51%였으므로 강한 잠복-활성화 구조의 방어 실험이라고 부를 수 없다. 별도 `cover5`의 14.07%와 `bd5`의 100%는 참고 자료이지, 같은 모델의 표본 단위 삭제 실험을 대체하지 못한다. 코드의 별도 클라이언트 제거와 본문의 같은 클라이언트 내부 표본 제거도 구분해야 한다.

잔류 재학습 참조에서 반례 보강이 ASR 32.87→91.67%로 악화된 것은 중요하다. 그러나 일반 백도어에서도 가능한 대리 목적 실패일 수 있다. 아직 BadFU 특유의 실패 원인이나 새로운 일반 현상으로 승격할 근거는 없다.

## 구조를 검증하기 위한 다음 실험

가장 먼저 분리할 질문은 **camouflage가 단순히 일반적인 패치 강건성을 높이는 것인가, 아니면 poison의 효과와 상호작용하며 특정 취약성을 숨기는가**이다. 후자에서 기존 post-only와 다른 관측 이득이 나오는지를 검증한다.

연구자가 poison P와 camouflage C를 아는 기전 진단에서는 다음 네 조건을 같은 기반 자료 B, 초기화, 가능한 범위에서 정렬한 학습 난수로 비교할 수 있다.

| 조건 | 역할 |
|---|---|
| A(B+P+C) | 공격과 위장이 함께 있음 |
| A(B+P) | 위장을 제거하고 독성은 남김 |
| A(B+C) | 독성 없이 위장의 효과를 확인 |
| A(B) | 기준 |

`r`을 표적 클래스를 제외한 공통 공개 이미지에서 트리거 유무에 따른 표적 마진 증가로 정하면,

`I = [r(B+P) − r(B+P+C)] − [r(B) − r(B+C)]`

는 P의 존재에 따라 C 제거의 효과가 얼마나 달라지는지 측정한다. 이것은 상호작용의 실험적 정의이지 새로운 정리나 악의 판별기가 아니다. 특히 큰 I만으로 요청자를 공격자로 판정하지 않는다. 정상적인 표적 특성이나 희소 집단도 유사한 효과를 만들 수 있다.

자료 수·클래스 구성·클라이언트별 집계 가중치 변화가 대조를 설명하지 않도록, 같은 크기와 클래스 구성을 가진 정상 삭제 및 교체 대조를 별도로 둬야 한다. 실제 FU 결과는 각각의 잔류 재학습 참조와 비교해 FU 근사 오차를 분리한다. 네 모델을 학습하는 실험은 연구용 oracle 진단이다. 배포되는 방어가 P와 C를 알고 네 모델을 제공받는다고 가정하지 않는다.

여기서 구조적 차이가 확인된 경우에만, 서버가 실제로 볼 수 있는 pre/post·요청·허용된 이력으로 그 신호를 근사할 수 있는지 검증한다. 같은 후보 개수와 교정기로 post-only, 기존 differential, HRAC, 무작위 탐색을 비교해 정보의 추가 가치를 분리한다. 원래 공격 패턴은 평가용으로만 사용한다.

가능한 주장은 “삭제 개입이 드러내는 상호작용을 이용하면, 동일한 탐색 예산에서 post-only가 놓치는 위험을 더 잘 찾는다”이다. **현재로서는 미검증 가설이다.** 차분 자체는 기존 연구 내 아이디어이며, 위 네 조건 실험 자체도 일반적인 실험 설계다. 방법상의 새 기여는 관측 가능한 추정법과 추가 이득이 확인될 때 별도로 판단해야 한다.

## 피해야 할 성급한 재포장

- “삭제 후 방어”라는 적용 시점만 바꾸는 것.
- 위장 기울기를 되돌려 넣고 망각이 유지된다고 가정하는 것.
- 삭제 전 모델을 교사로 쓰거나 요청 자료에서 트리거를 추출한 뒤, 삭제 정보가 전혀 사용되지 않았다고 주장하는 것.
- “잠복 기능을 드러낸 다음 제거한다”는 큰 틀만 새 기여로 삼는 것. [EBYD](https://arxiv.org/abs/2410.19427)도 노출 후 방어를 다룬다. 구체적으로 요청에 조건화된 구조가 주는 차이를 입증해야 한다.
- 기존 구성요소가 알려졌다는 이유만으로 모든 조합의 노벨티를 부정하는 것.

현재 교정기는 이후의 구조 활용 방법을 평가할 비교 기준으로 남긴다. BadFU의 특수성은 논문 도입부에만 존재해서는 안 되며, 관측·연산·가설·대조 실험 가운데 적어도 핵심 부분에 실제로 들어가야 한다.

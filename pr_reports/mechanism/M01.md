# 독성과 억제 자료의 네 조건 재학습

**상태:** 완료

**판정:** 기존3시드에서 삭제할 자료와 잔류 자료의 조합이 중요함을 확인했다.

## 가설 한 줄

억제 자료 삭제에 따른 공격 활성화는 독성 자료가 남을 때만 크게 나타난다.

## 실험 한 줄

시드71/72/73에서 B+P+C, B+P, B+C, B를 같은 초기화로 각각40라운드 FedAvg 학습했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 M01 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

평균 ASR: B+P+C 7.48%, B+P 92.07%, B+C 1.15%, B 3.78%. 독성 있음에서 억제 제거 효과+84.59%p, 독성 없음에서는+2.63%p였다.

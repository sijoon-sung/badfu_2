# 저자 코드 계열 모델의 삭제 전 잠복 여부 감사

**상태:** 완료

**판정:** full6는 이미 공격이 활성화된 모델이다. 이 정화 기준선의 성공을 낮은 ASR 잠복 BadFU의 완전 재현으로 보고하지 않는다.

## 가설 한 줄

기존 저자 코드 계열 모델은 삭제 전 낮은 ASR의 잠복 조건을 충족한다.

## 실험 한 줄

별도5000장 시험 입력에서 full6와 cover5의 삭제 전 상태를 평가했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 M08 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

full6 정상 정확도87.12%,ASR81.51%. cover5 정상 정확도84.26%,ASR14.07%였다.

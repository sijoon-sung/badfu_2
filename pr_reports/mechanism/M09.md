# 정상 자료에서도 큰 직교 잔차가 나오는 수학적 반례

**상태:** 완료

**판정:** 큰 직교 잔차가 백도어의 충분조건이라는 가설은 성립하지 않는다. 실제 Non-IID 오탐 검증이 필요하다.

## 가설 한 줄

정상 자료의 기울기는 직교 잔차 비율을 크게 만들지 않는다.

## 실험 한 줄

두 클래스 선형 분류기에 정답도 예측도 모두0인 정상 자료 두 집합을 만들고 평균 CE 기울기를 계산했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 M09 -Action Run
```

저장된 갱신 배열에서 이 지표를 다시 계산한다. 추가 학습·이미지 로드는 없다.

## 결과

유지 특징(0,10,1),삭제 특징(1,0,1),bias(2,0)에서 직교 잔차 비율은약7.09였다. 독성 자료와 트리거는 없다.

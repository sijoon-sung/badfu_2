# 블록 교차 이식으로 활성화 위치 확인

**상태:** 완료

**판정:** 이 설정은 삭제 전 강한 잠복 특징의 존재를 입증하지 않는다. 활성화된 모델의 후반 특징 변환이 중요했다.

## 가설 한 줄

삭제 전 모델의 앞단에 이미 강한 백도어 특징이 숨어 있다.

## 실험 한 줄

세 시드에서 pre·post·독성 없는 대조의 앞단과 뒷단을 블록별로 교차 이식했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 M02 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

삭제 전 앞단의 효과는 독성 없는 앞단 대조와 충분히 구별되지 않았다. post 앞단을 layer4까지 통과시켜 정상 뒷단에 연결하면 평균 ASR84.44%였다.

**해석 범위:** 정렬되지 않은 서로 다른 모델의 블록 이식이다. 실제 트리거를 아는 사후 기전 진단이다.

# 정상 입력의 타겟 편향과 트리거 반응 비교

**상태:** 완료

**판정:** 일반 타겟 편향과 트리거 반응을 별도로 봐야 한다. 하나가 다른 하나의 원인이라는 판정은 하지 않는다.

## 가설 한 줄

정상 입력의 타겟 편향 감소가 트리거 공격 억제를 설명한다.

## 실험 한 줄

저장된 같은 모델들의 정상 입력 타겟 오분류율과 실제 트리거 타겟 도달률을 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 M04 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격71 사후 모델 기준선: 정상 타겟 오분류4.94→4.11%, 트리거 ASR76.94→6.33%. 상호작용 방법은 정상 타겟 오분류5.33%, ASR71.28%였다.

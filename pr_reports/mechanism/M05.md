# 전역 색감 변형에서 삭제 순서의 중간 위험

**상태:** 완료

**판정:** 이 고정 특징 학습기에서 중간 경로 위험을 확인했다. 전체 신경망 FedAvg나 새로운 스케줄러 검증은 아니다.

## 가설 한 줄

같은 자료를 최종 삭제해도 처리 순서에 따라 중간 모델의 공격률은 달라진다.

## 실험 한 줄

고정 ImageNet 특징의 ridge 분류기에서 네 요청의24개 순열을 정확 재학습했다. 세 자료 역할 배정을 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 M05 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

시작 ASR 7.89~8.33%, 억제부터 삭제한 경로의 최대 ASR 28.83~30.00%, 검증으로 순서를 고른 경로는 시작 수준이었다. 최종 ASR은 2.56%로 동일했다.

**해석 범위:** 공개 검증 입력과 알려진 변형 계열로 순서를 선택했다. 모르는 트리거의 탐지 실험이 아니다.

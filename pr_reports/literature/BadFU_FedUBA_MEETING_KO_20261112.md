# BadFU와 FedUBA 공격 메커니즘과 DISLAB 검증

교수 미팅 자료 · 2026-11-12 · 관련 실험 R01/R03, D08/D15/D20–D24, T02–T04

## 5분 발표 요약

1. **두 논문이 다루는 공통 문제.** 서버가 합법적인 데이터 삭제를 처리한 뒤 깨끗한 입력의 정확도는 유지되면서, 특정 입력만 공격자의 목표 클래스로 바뀔 수 있다. BadFU는 학습 때 들어간 위장의 효과가 삭제되면서 백도어가 드러난다. FedUBA는 정상 FL 이후 삭제 요청과 FU 재보정에 개입해 조건부 오분류를 유도한다.
2. **재현 상태.** BadFU 논문의 대표 ASR은 21.55%에서 전체 재학습 후 99.32%로 올랐다. DISLAB의 두 BadFU 시드에서도 16.14→99.99%, 14.29→100.00%로 활성화 방향을 재현했다. FedUBA 고정 참여자 10명의 진단에서 가장 높은 ASR은 58.74%였다. 본문에서 보고한 최대 약 89%와 자체 사전 목표 80%에 못 미쳤다.
3. **탐지 검증.** 실제 트리거를 입력하지 않는 네 경로 탐색이 BadFU의 고정 시험에서 기본법보다 공격–정상 간격을 9.89%p 늘렸다. FedUBA 진단쌍의 말단 간격 증가분은 0.67%p였고, 같은 탐침을 여러 요청·라운드에 적용하자 10R에서 10개 중 7개가 큰 정상과 겹쳤다.
4. **PCA와 신규성.** 새 이미지에서도 BadFU 말단의 순위는 분리됐으나 사전 기준은 두 묶음에서 각각 정상 1건을 경보했다. 같은 FC 층의 무작위 대조 한 반복이 두 묶음 모두 공격 2/2·정상 경보 0/4였다. 지금 보고할 결과는 **BadFU의 조건부 전환과 고정 탐색에서 얻은 추가 이득, 그리고 큰 정상 삭제에서의 구체적인 반례**다. 범용 탐지와 PCA 축의 고유 효과는 미입증이다.

## 1. BadFU

**논문.** Bingguang Lu 외, *BadFU: Backdoor Federated Learning through Adversarial Machine Unlearning*, RAID 2025, pp. 773–788. [논문 전문](https://arxiv.org/html/2508.15541v1) · [출판 DOI](https://doi.org/10.1109/RAID67961.2025.00020)

### 공격자와 서버

| 단계 | 공격자 | 서버 |
|---|---|---|
| FL 학습 | 한 참여자가 자기 로컬 학습 데이터에 독성 표본과 위장 표본을 함께 넣는다. 둘 다 같은 트리거를 가지며 독성에는 공격 목표 라벨, 위장에는 원래 라벨이 붙는다. | 정해진 FL 프로토콜로 로컬 제출을 집계한다. 트리거와 표본의 역할은 공격자 쪽 정보다. |
| 삭제 요청 | 실제로 학습에 사용한 위장 표본의 삭제만 요청한다. 독성 표본은 남는다. | 유지 자료 전체 재학습 또는 FedEraser 등의 삭제 절차로 요청 표본의 영향을 제거한다. |
| 삭제 후 | 위장으로 억제됐던 트리거–목표 연결이 드러나는 것이 논문의 작동 설명이다. | 깨끗한 입력 성능이 유지돼도 특정 입력의 목표 예측이 증가할 수 있다. |

저자 위협 모델은 다른 참여자의 모델·데이터에 대한 접근과 서버 집계 제어를 가정하지 않는다. 위장 표본은 공격 목표 라벨이 아닌 원래 라벨을 유지한다. 식 (5)–(8)은 학습에 들어가는 독성·위장 항을 설명한다. 실제 딥러닝 학습에서 두 항이 정확히 상쇄되거나, 정상 삭제가 언제나 안전하다는 보장을 제공하는 식은 아니다. 논문은 국소 패치 BadNet과 전역 혼합 Blended를 각각 시험했다. [BadFU §IV–V, Fig. 1, Algorithm 1](https://arxiv.org/html/2508.15541v1#S4) · [트리거 비교 §VII-B](https://arxiv.org/html/2508.15541v1#S7.SS2)

### 논문의 결과와 방어 평가

CIFAR-10 ResNet-18, FedAvg에서 저자가 보고한 백분율이다. 앞의 두 행은 Dominant Class 설정이다. 정상 요청 행은 공격 준비가 들어간 전역 모델에 별도의 정상 삭제를 적용한 저자의 비교다.

| 설정 | 삭제 전 CA / ASR | 전체 재학습 후 CA / ASR | FedEraser 후 CA / ASR | 원문 |
|---|---:|---:|---:|---|
| BadNet 위장 삭제 | 84.84 / 21.55 | 83.90 / 99.32 | 83.19 / 90.76 | Table I |
| Blended 위장 삭제 | 85.23 / 15.85 | 84.71 / 70.30 | 83.99 / 53.72 | Table IV |
| BadNet 정상 요청 | 84.84 / 21.55 | — | — | Table V, 정상 삭제 후 81.29 / 10.22 |
| Blended 정상 요청 | 85.23 / 15.85 | — | — | Table V, 정상 삭제 후 85.25 / 15.24 |

Dirichlet 비IID에서도 CIFAR-10 BadNet ASR은 5.65→98.15%로 올랐다. FedEraser 후에는 90.20%였다. SIFU 별도 비교는 14.69→85.59%였다. 같은 논문 안에서도 트리거, 분할, 삭제 방식에 따라 사전 ASR과 활성화 폭이 달라진다. [BadFU Tables I, III–V, VIII](https://arxiv.org/html/2508.15541v1#S7)

- **학습 단계 방어.** 좌표별 Median은 참여자 제출의 중앙값을 집계하고 Trimean은 양끝의 극단값을 제외한다. CIFAR-10에서 Median의 ASR은 6.55→96.33%, Trimean은 7.16→76.97%였다. 실험한 강건 집계는 학습 중 신호를 줄였지만 삭제 후 활성화를 막지 못했다. [BadFU §VII-G, Table VI](https://arxiv.org/html/2508.15541v1#S7.SS7)
- **모델 검사.** Neural Cleanse는 클래스별로 역산한 입력 변형에서 이상치를 찾는다. 저자의 기준이 −2 미만인 Table VII에서 BadFU 목표 클래스 0은 −0.12였고, 깨끗한 모델의 클래스 6은 −2.24였다. 해당 실험은 미탐과 정상 오경보 사례를 함께 보인다. 논문의 요청 검사, 전후 행동 모니터링, 삭제 시 프라이버시 노이즈는 토의에 제시된 대응 방향이다. [BadFU Table VII, §VIII](https://arxiv.org/html/2508.15541v1#S8)

## 2. FedUBA

**논문.** Jian Chen, Wenlong Shi, Chengyu Hu, Jianfeng Lu, Ahmed M. Abdelmoniem, Chen Wang, *Federated Unlearning Activated Backdoor Attacks*, IEEE TDSC 23(5), 2026, pp. 10494–10510. **ity207/FedUBA**는 별도 논문인 stcebra/FUBA와 구별한다. [저자 제공 원문 PDF](https://www.chenwang.net.cn/publications/FedUBA-TDSC26.pdf) · [출판 DOI](https://doi.org/10.1109/TDSC.2026.3703139)

### 공격자와 서버

FedUBA의 위협 모델은 정상 FL 이후 공격자가 자신의 학습 표본 범위와 삭제 예산 내에서 요청한다고 가정한다. 저자는 태스크 영역, 원하는 의미 클래스, 피해자 학습 집합과 분리된 외부 보조 데이터 및 소량의 목표 클래스 예시를 공격자에게 허용한다. 다른 참여자의 비공개 자료와 피해 모델의 내부 파라미터·그래디언트에는 접근하지 않는다고 명시한다. SSS에는 입력 변화에 대한 출력 로짓을 비교할 수 있는 블랙박스 관측이 들어간다. [FedUBA §III–IV, pp. 10496–10497](https://www.chenwang.net.cn/publications/FedUBA-TDSC26.pdf#page=3)

| 단계 | 논문의 역할 | 서버와의 접점 |
|---|---|---|
| 정상 FL | 정상 로컬 자료로 학습한다. | 기존 집계로 삭제 전 모델을 만든다. |
| STG · Stealthy Trigger Generation | 외부 보조 모델에서 목표 클래스와 정렬되는 공통 가산 신호를 구성한다. | 피해 모델 내부를 제공한다는 가정은 없다. |
| SSS · Sensitivity Sample Selection | 자기 로컬 자료 중 해당 신호에 대한 출력 변화가 큰 표본을 찾는다. 저자는 이를 개별 표본 영향의 대리 관측으로 쓴다. | 출력 민감도와 실제 삭제 영향의 동일성은 별도 가정이다. |
| BEA · Backdoor Effect Activation | 선택한 표본의 라벨을 유지하며 입력을 변형한 요청과 FU 단계의 클라이언트 갱신을 통해 삭제 과정에 개입한다. | 서버는 해당 기여를 사용해 모델을 다시 보정한다. 보정이 조건부 결정 경계에 미치는 효과가 연구 대상이다. |

FedEraser는 저장된 과거 업데이트의 크기와 잔류 자료에서 다시 계산한 업데이트 방향을 사용해 전역 이력을 보정한다. FedUBA는 KNOT과 증류 기반 FUKD도 비교했다. 논문의 §V-D는 영향 근사와 표본의 방향 정렬 가정 아래 SSS의 효과를 설명한다. 입력에 부호가 붙는다고 모델의 삭제 갱신이 자동으로 역연산이 되는 것은 아니다. [FedUBA Fig. 2, Algorithm 1, 식 (5)–(15), pp. 10498–10500](https://www.chenwang.net.cn/publications/FedUBA-TDSC26.pdf#page=5) · [FU 비교 §VI-A, p. 10501](https://www.chenwang.net.cn/publications/FedUBA-TDSC26.pdf#page=8)

### 논문의 결과와 방어 평가

- **성능.** IID CIFAR-10·ResNet-18·FedAvg·FedEraser의 clean CA는 삭제 전 85.82±0.74%, 공격 FU 후 85.16±0.45%였다. 본문은 CIFAR-10 등의 정상 FU 후 ASR-B를 약 15%, 조건에 따른 활성화 ASR을 최대 약 89%로 보고한다. 약 89%는 여러 설정에서 관측한 최대치다. Table II의 해당 CA 행에 대응하는 단일 ASR 원시값으로 읽지 않는다. IID 주 실험의 공격자는 2명이며 보고된 요청 비율은 0.5%다. 비IID는 Dirichlet α=0.5로 별도 시험했다. [FedUBA §VI-A–B, Tables II–III, Figs. 3–4](https://www.chenwang.net.cn/publications/FedUBA-TDSC26.pdf#page=9)
- **방어.** 저자는 FAT(연합 적대적 학습), FADngs(대조학습 표현으로 이상 탐지), FLAME(클러스터 필터링·클리핑·노이즈), MASA(개별 언러닝의 행동 변화로 의심 모델 식별)를 시험했다. Fig. 9에서 FAT·FADngs는 KNOT의 잔여 ASR이 FedEraser보다 낮은 경향이었다. FLAME의 노이즈가 증가했을 때 PathMNIST ASR은 FedEraser에서 81.46→52.96%, KNOT에서 77.35→48.27%로 감소했다. 저자는 MASA에서 융합 정도가 높아질 때 방어가 강화되는 조건도 보고한다. Fig. 9의 방어 비교는 잔여 ASR을 평가한다. 큰 정상 non-IID 삭제를 보류해 요청 단위 오경보율을 측정한 결과는 별도다. [FedUBA §VI-A, §VI-G, Fig. 9, pp. 10502, 10506–10507](https://www.chenwang.net.cn/publications/FedUBA-TDSC26.pdf#page=13)
- **서버 관측의 한계.** 저자는 요청 감사와 삭제 후 clean 예측의 일관성을 보존하는 FU를 토의에서 제시한다. 신뢰 검증 자료가 필요하며, 정상 삭제도 큰 특징·마진 변화를 만들 수 있다. DISLAB의 D08과 D22는 그 우려를 실제 정상 대조에서 확인했다. [FedUBA §VIII, p. 10508](https://www.chenwang.net.cn/publications/FedUBA-TDSC26.pdf#page=15) · [D08 원보고서](../../research/active_fu_pairs_20261022/REPORT_KO.md) · [D22 원보고서](../../research/feduba_deletion_round_repeats_20261111/FINAL_REPORT_KO.txt)

## 3. DISLAB의 공격 활성화 재현

CA는 깨끗한 CIFAR-10 시험 10,000장의 정확도다. 아래 자체 ASR은 원래 목표 클래스인 1,000장을 제외하고, 평가자가 알고 있는 트리거 조건에서 목표로 분류된 수를 나머지 9,000장으로 나눈 값이다. **FedUBA의 ASR-B는 정상 FU 모델의 ASR이다.** 삭제 전 모델의 ASR은 별도 열로 읽는다.

### BadFU 재현

| 실행 | 삭제 전 CA / ASR (%) | 위장 삭제 후 CA / ASR (%) | 삭제 방식 |
|---|---:|---:|---|
| 논문 Table I | 84.84 / 21.55 | 83.90 / 99.32 | 유지 자료 전체 재학습, 3회 평균 |
| DISLAB seed 20261020 | 88.23 / 16.14 | 88.15 / 99.99 | 유지 자료 전체 재학습 |
| DISLAB seed 20261023 | 90.38 / 14.29 | 90.46 / 100.00 | 유지 자료 전체 재학습 |

DISLAB은 논문 기준의 plain 위장, 5인, 실제 batch 32 조건이다. 공개 스크립트의 PGD 위장·고정 batch 64·별도 6인 분기와 차이가 있다. 실제 seed 20261023의 삭제 전·후 첫 라운드에서 저자 학습 함수로 다시 계산한 10개 로컬 제출 해시와 두 전역 모델 텐서가 저장본과 일치했다. 저자와 동일한 contiguous NCHW 평가에서 공격 전후 ASR은 유지됐다. 현재 수치는 두 시드의 활성화 방향을 재현한 근거이며, 논문 3회 평균과의 통계적 동등성 또는 자체 FedEraser 성능을 뒷받침하지 않는다. ### FedUBA 재현과 부호 진단

고정 참여자 10명·seed 42·같은 시작 모델, FedEraser 20라운드 비교다. 공식 CIFAR-10 train 50,000장의 20개 분할 중 참여 자료는 25,000장이었다. 표의 125개 요청은 그 0.5%다. 논문이 기술한 분할·참여 방식과 구현에 차이가 있다.

| 같은 이력에서 만든 모델 | Clean CA (%) | 표준 양의 평가 입력 ASR (%) | 음의 평가 입력 ASR (%) |
|---|---:|---:|---:|
| 삭제 전 | 85.53 | 20.14 (1,813/9,000) | 11.29 (1,016/9,000) |
| 같은 125개 정상 삭제 | 84.74 | 16.67 (1,500/9,000) | 9.53 (858/9,000) |
| 논문 식 (8) 방향의 음의 요청 | 84.69 | 13.82 (1,244/9,000) | 58.23 (5,241/9,000) |
| 별도 양의 요청 진단 | 84.45 | 58.74 (5,287/9,000) | 7.52 (677/9,000) |

# BadFU 원논문의 정상 삭제와 공격자 삭제

**상태:** 문헌 확인 · 자체 재현 아님

**판정:** 저자가 시험한 조건에서는 정상 요청이 활성화하지 않았다. 모든 Non-IID 삭제에 대한 보장은 아니다.

## 가설 한 줄

원논문의 Non-IID 조건에서 정상 삭제는 잠복 백도어를 활성화하지 않는다.

## 실험 한 줄

BadFU 표I·V의 CIFAR10/ResNet18/BadNet/FedAvg/Dominant70% 결과를 확인했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 L01 -Action Check
```

저장된 결과와 근거 해시를 확인한다. 모델 학습을 다시 실행하는 명령은 아니다.

## 결과

| 상태 | ASR | 정상 정확도 |
|---|---|---|
| 삭제 전 | 21.55% | 84.84% |
| 정상 클라이언트 삭제 NormalUL | 10.22% | 81.29% |
| 공격자 억제 삭제 FedEraser | 90.76% | 83.19% |
| 공격자 억제 삭제 재학습 | 99.32% | 83.90% |

**해석 범위:** 정상 삭제 쪽에도 잠복 백도어를 심은 공격자는 존재한다. 정상 사용자가 삭제 요청을 한다는 뜻이다. NormalUL과 공격 삭제 결과는 각각 표V와 표I에서 가져왔다.

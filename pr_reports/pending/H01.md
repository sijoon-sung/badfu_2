# 최근16건과 과거 이력 자료의 대응 범위

**상태:** 범위 정정 · 최근16건 대응 검증 미완료

**판정:** 이력 자료 전체가 없거나 이력 탐지가 전혀 실행되지 않았다는 해석을 정정한다. 최근16건의 대응성 질문은 별도다.

## 가설 한 줄

최근16건의 요청과 같은 모델·자료의 과거 라운드별 갱신을 연결하면 추가 탐지 정보를 얻는다.

## 실험 한 줄

기존16건과 과거 BadFU·FUBA 궤적의 모델·분할·요청 단위 대응을 구분했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 H01 -Action Check
```

저장된 결과와 근거 해시를 확인한다. 모델 학습을 다시 실행하는 명령은 아니다.

## 결과

최근16건과 같은 실행의 이력을 연결한 탐지 성능은 미확인이다. 별도로 DISLAB에는 BadFU40R·FUBA100R 궤적과 실제 이력 탐지 결과가 존재한다. 과거 HRAC는 정상43·44에서12/40 오탐, 공통 크기 보정은2/40이었으며 같은 정상 보정 자료를 맞춘 교차 검증에서는 두 방식이2/60으로 같았다.

**해석 범위:** 과거의 다른 모델·자료·클라이언트 이력을 최근 요청의 동일 이력으로 대체하지 않는다. 과거 이력 탐지는 별도 정리의 실제 결과를 따른다.

# 요청 조건부로 잔류 자료를 더 제외한 재학습

**상태:** 완료

**판정:** 이번 상호작용 선택은 무작위보다도 공격 감소가 작았다. 주력 정화로 채택하지 않는다.

## 가설 한 줄

요청 조건부 순위로 고른 잔류138개를 제외하면 단순 기준선보다 공격을 더 줄인다.

## 실험 한 줄

D35에서 고정한 자료를 제외한 뒤 실제40라운드 연합 재학습을 수행했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P18 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

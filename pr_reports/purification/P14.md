# 고정 패치 은행 수를 바꾼 교정 비교

**상태:** 완료

**판정:** 패치 수 증가가 실제 공격 억제를 단조롭게 개선하지 않았다.

## 가설 한 줄

패치 후보 수를 늘리면 같은 교정의 실제 ASR도 더 낮아진다.

## 실험 한 줄

같은 FU 후 모델에서 모서리당 무작위 패치4개와34개를 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P14 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

기준 ASR99.51%. 패치4개 조건은7.51%·정확도86.38%,34개 조건은14.40%·정확도86.54%였다.

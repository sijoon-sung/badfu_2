# 전 층 상위 특이성분 제거 정화

**상태:** 완료

**판정:** 공격 억제는 있었다. 안전 요청 보존까지 만족하는 일괄 정화법은 아니다.

## 가설 한 줄

삭제 전후 변화의 상위 특이성분을 제거하면 공격을 줄이면서 안전 삭제를 보존한다.

## 실험 한 줄

21개Conv/Linear의 변화에서 상위1/2개 성분을 제거했다. 같은 F노름 수정량의 원본 방향 축소를 대조로 뒀다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P03 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격4시드 평균 ASR93.10→35.07%(상위1개),18.07%(상위2개). 정상 정확도62.63→60.88/59.10%. 안전 대조의 ASR2.33%는14.22/10.67%로 증가했다.

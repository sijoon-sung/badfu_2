# 고정 변형의 반응 전이 정화

**상태:** 완료

**판정:** 기본 설정은 검증 성능 제약 때문에 대부분 정화를 포기했다. 제약을 무시한100회 결과를 선택 결과처럼 보고하지 않는다.

## 가설 한 줄

정상 출력은 사후 모델에 유지하고 입력 변형 반응만 삭제 전 모델에서 옮기면 공격이 감소한다.

## 실험 한 줄

원본 출력의 목표는 post(x), 변형 출력의 목표는 pre(Tx)+post(x)−pre(x)로 뒀다. 정상4클라이언트의 잔류 자료로 전체 가중치를100회 갱신했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P05 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격4시드 평균 ASR: 정화 전93.10%, 검증을 통과한 반응 전이78.78%(4건 중3건 정화 포기), 고정100회 반응 전이24.51%. 같은100회 사후 자기증류는10.65%였다.

**해석 범위:** 기존4개 공격 시드를 재사용했다. 요청자 제외, 정상4클라이언트의 협력, 고정 패치 계열이라는 조건이다.

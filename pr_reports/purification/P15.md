# FU 후 모델의 반례 패치 보강 교정

**상태:** 완료

**판정:** 이 모델에서는 공격이 더 줄었지만 정상 정확도를 더 잃었다.

## 가설 한 줄

현재 교정 모델을 겨냥한 패치를 추가하면 고정 패치 정화의 빈틈을 줄인다.

## 실험 한 줄

실제 FU 후 모델에서 반례 탐색과 마지막 층 교정을 반복했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P15 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

초기 정적 ASR11.58%,1회 보강5.87%,2회6.82%,3회6.82%. 정상 정확도87.00%→85.32/85.14%였다.

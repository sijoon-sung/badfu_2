# 사후 미세조정과 특징 모멘트 기준선

**상태:** 완료

**판정:** 사후 기준선도 공격을 낮췄지만 강한 미세조정은 정상 정확도를40.80%까지 낮췄다. ASR만으로 정화 성공을 판단하지 않는다.

## 가설 한 줄

전후 정보 없이 사후 모델만 정화해도 공격을 낮출 수 있다.

## 실험 한 줄

공개 정상200장으로100스텝 미세조정2설정과 잔류 자료의 모멘트 분류기를 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P04 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

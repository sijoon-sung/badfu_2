# 정상 모델에 같은 마지막 층 교정 적용

**상태:** 완료

**판정:** 이 저장 모델에서의 정량 결과다. 방어 전체의 보편적 성능으로 해석하지 않는다.

## 가설 한 줄

사후 정상 출력을 보존하며 패치 반응의 일관성을 높이면 백도어를 줄일 수 있다.

## 실험 한 줄

특징 추출기와 BN은 고정하고 마지막 선형층만 교정했다. 공개 피팅1000장·검증1000장을 사용하고 시험5000장으로 평가했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P12 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

ASR 1.40%→1.44~1.53%.正常 정확도 85.08%→84.92~85.12%.

**해석 범위:** 공통 학습 시드42의 서로 다른 모델 경로다. 세 값은 독립 FL 시드가 아니라 패치 은행 시드다.

# 잔류 자료 재학습 모델의 반례 보강 실패

**상태:** 완료

**판정:** 다른 모델 경로로의 전이 가설은 실패했다. 반례 보강을 주력으로 확정하지 않는다.

## 가설 한 줄

FU 후 모델에서 효과가 있던 반례 보강이 잔류 재학습 모델에도 유지된다.

## 실험 한 줄

P15와 같은 발전 방식으로 별도 잔류 재학습 모델을 교정했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P16 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

초기 ASR32.87%가1회94.27%,2회92.64%,3회91.67%로 악화됐다.

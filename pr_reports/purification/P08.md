# 같은 정상 출력 변화 예산에서 반응 전이 비교

**상태:** 완료

**판정:** 작은 예산에서는 반응 전이가 유리했다. 큰 예산에서는 사후 기준선이 더 좋았다.

## 가설 한 줄

정상 출력의 변경을 같은 상한으로 제한하면 반응 전이가 사후 자기증류보다 유리하다.

## 실험 한 줄

같은 잔류 검증 KL 상한과 클래스·클라이언트 성능 제약을 통과하는 수정량을 선택했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P08 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

| 검증 KL 상한 | 사후 자기증류 ASR | 반응 전이 ASR |
|---|---|---|
| 0.005 | 56.40% | 38.64% |
| 0.010 | 29.19% | 17.36% |
| 0.020 | 15.03% | 16.74% |

**해석 범위:** 동일한 허용 상한이지 실제 사용 KL이 정확히 같은 것은 아니다. 기존4시드의 개발 비교다.

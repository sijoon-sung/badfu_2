# 반응 전이 후 삭제 자료 기억 진단

**상태:** 완료

**판정:** 이 진단에서는 삭제 샘플의 구별 가능성이 높아지지 않았다. 인증된 망각을 뜻하지는 않는다.

## 가설 한 줄

반응 전이로 공격을 줄이면서 삭제된 개별 자료의 기억을 다시 높이지 않는다.

## 실험 한 줄

삭제 cover와 같은 라벨 비율·같은 트리거를 가진 미사용 대조를 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P09 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

반복형에서 cover 정답률54.83%, 미사용 대조54.44%. 클래스 조건부 손실 membership AUC는 pre0.8818, post0.4948, 정화0.4988이었다.

# 반례 교정 실패의 선택 점수 스케일 분석

**상태:** 완료

**판정:** 선택 점수의 스케일 문제가 확인됐다. 정규화 선택은 단일 시드 사후 분석이며 새 방어 확인 실험은 아니다.

## 가설 한 줄

검증 점수가 낮은 교정이 실제로 안전한 모델을 선택한다.

## 실험 한 줄

같은 반례 패치와 저장 후보를 고정하고 비정규화 점수·정규화 점수·로짓 크기를 분해했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P19 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

실제 선택 후보 ASR91.67%, 같은 후보군의 정규화 점수1위 ASR13.33%. 비정규화 점수는 출력 크기 축소를 안전성 개선으로 오인했다.

# 교정 모델에 대한 새 적응 패치 공격

**상태:** 완료

**판정:** 독립적인 적응 공격 강건성은 확정하지 않았다.

## 가설 한 줄

고정 패치로 낮아진 ASR이 교정 후 새로 찾은 공격에도 유지된다.

## 실험 한 줄

모델마다 새 패치를 최적화하고 같은 탐색 예산 대조도 수행했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P17 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

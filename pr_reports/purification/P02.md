# 전후 부분공간을 이용한 정화의 다른 시드 확인

**상태:** 완료

**판정:** 개발 개선이 다른 세 시드에서 재현되지 않았다. 주력 정화법으로 채택하지 않는다.

## 가설 한 줄

개발 시드에서 정한 전후 특징 변화 제거 규칙이 다른 공격 시드에서도 정화한다.

## 실험 한 줄

분류기 앞 투영, 내부 경로, 부호 있는 변화, 게이트와 모드 선택을 탐색하고 seed71에서 선택한 규칙을72/73/74에 고정했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 P02 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

주 규칙 ASR: seed71 76.94→45.67%, seed72 99.78→98.06%, seed73 99.50→99.50%, seed74 96.17→96.17%.

**해석 범위:** 여러 투영 방식의 탐색과 고정 확인을 구분했다.

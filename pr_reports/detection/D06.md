# 정상 라벨 대조에서 연속 패치 탐지의 오탐 확인

**상태:** 완료

**판정:** 연속 최적화 점수 단독 탐지 가설은 이 대조에서 실패했다.

## 가설 한 줄

최적화된 차분 점수가 크면 실제 삭제 후 타겟 반응도 증가한다.

## 실험 한 줄

정상 라벨 seed71에서 차분을 크게 만드는 패치를 찾고 미래 모델에 적용했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D06 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

검증 차분은 0.012254였지만 미래 타겟 도달률은 12.11%→10.50%로 감소했다. 같은 요청의 고정 패치 점수는 0.004180이었다.

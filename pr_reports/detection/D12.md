# FC 최대 특이값 비율

**상태:** 완료

**판정:** 기존 16건에서 분리됐으나 일반화나 SVD의 추가 이득은 미확정이다.

## 가설 한 줄

FC 갱신의 전체 크기 대신 최대 특이값을 쓰면 공격과 대조의 간격이 커진다.

## 실험 한 줄

D11과 같은 10×513 갱신 행렬을 SVD로 분해했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D12 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격 2.4218~4.8959, 대조 0.1501~2.2562. 범위는 분리됐지만 오라벨이 자동으로 크게 작아진 것은 아니다.

**해석 범위:** 기존 시드 71~74의 공격 4건과 대조 12건을 재사용한 탐색 결과다. 새 16개 독립 학습 실험이 아니다.

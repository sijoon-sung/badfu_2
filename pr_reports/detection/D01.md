# 고정 패치 짝 비교의 개발 실험

**상태:** 완료

**판정:** 개발 자료에서는 마지막 규칙이 가장 유용했다.

## 가설 한 줄

유지 분기의 패치 반응 증가를 삭제 분기로 대조하면 안전 삭제의 오탐을 줄일 수 있다.

## 실험 한 줄

원본과 유지·삭제 복제 모델에 같은 32개 패치를 넣고, 유지 분기에서 증가한 반응을 삭제 분기로 검증한다. 임계값은 0.006이다. 개발 3시드에서 네 점수 규칙을 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D01 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

| 규칙 | 공격 탐지 | 대조 오탐 |
|---|---|---|
| 엄격한 양방향 증거 | 0/3 | 0/12 |
| 유지 반응 증가만 | 3/3 | 1/12 |
| 분기 차이만 | 3/3 | 2/12 |
| 유지 증가와 삭제 분기 검증 | 3/3 | 0/12 |

**해석 범위:** 같은 결과를 보고 점수 규칙을 개발했다. 독립 확인 성능으로 세지 않는다.

# 새 시드에서 위험 삭제와 같은 크기 안전 삭제 비교

**상태:** 완료

**판정:** 이 한 시드의 두 요청은 구별했다.

## 가설 한 줄

같은 모델에서 삭제 개수가 같아도 패치 짝 비교는 위험 삭제와 안전 삭제를 구별한다.

## 실험 한 줄

seed74에서 C720 삭제와 P180+C540 삭제를 비교했다. 미래 모델 완성 전에 예측을 저장했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D02 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

| 요청 | 탐지 점수 | 삭제 후 ASR |
|---|---|---|
| 억제 자료만 삭제 | 0.014216 | 96.17% |
| 독성 자료도 포함해 같은 수 삭제 | 0.000000 | 2.33% |

**해석 범위:** 안전 요청은 요청자 전체 자료 삭제가 아니다. 현재 재실행은 보존된 미래 모델을 이용하므로 당시의 사전 예측 시간 순서를 다시 만들지는 않는다.

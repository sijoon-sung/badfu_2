# 기존 16건의 순수 Conv 1스텝 노름 비율

**상태:** 완료

**판정:** 기존16건의 탐색적 분리를 확인했다.

## 가설 한 줄

KL·클리핑 없이 같은 원본에서 잰 Conv 기울기 비율은 공격과 대조를 구별한다.

## 실험 한 줄

R/F 평균 CE 기울기를 계산하고 layer4 Conv5개의 전체 F노름을 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D19 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격1.9608~3.5800, 대조0.1553~1.7440. 기존100스텝 비율과 달리 범위가 겹치지 않았다.

**해석 범위:** 기존 시드 71~74의 공격 4건과 대조 12건을 재사용한 탐색 결과다. 새 16개 독립 학습 실험이 아니다. 여러 검사 조건을 동시에 바꿨으므로 개선을 KL 제거 하나의 효과로 해석하지 않는다.

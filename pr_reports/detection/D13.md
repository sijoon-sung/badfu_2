# 기존 100스텝 Conv 복제 모델의 노름 비율

**상태:** 완료

**판정:** 이 노름 비율은 공격과 대조를 완전히 분리하지 못했다.

## 가설 한 줄

실제로 학습된 Conv 변화량을 쓰면 FC보다 공격과 대조가 더 잘 나뉜다.

## 실험 한 줄

KL 기준점500장과 클리핑을 쓴 기존 layer4 복제 모델의 원본 대비 변화량을 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D13 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격 1.0867~1.3387, 대조 0.5440~1.1123. 오라벨1.1123이 공격 최솟값1.0867보다 컸다.

**해석 범위:** 기존 시드 71~74의 공격 4건과 대조 12건을 재사용한 탐색 결과다. 새 16개 독립 학습 실험이 아니다.

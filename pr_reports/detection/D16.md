# 유지와 삭제 갱신의 코사인 방향

**상태:** 완료

**판정:** 공격이면 음의 코사인이라는 가설은 실패했다. 양수의 원인을 KL 하나로 단정할 수 없다.

## 가설 한 줄

공격 요청의 유지·삭제 갱신은 서로 반대 방향이다.

## 실험 한 줄

기존100스텝 복제 모델의 Conv 변화 방향을 비교하고 순수1스텝에서도 확인했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D16 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

기존 공격 코사인은 모두 양수0.2956~0.3490이었다. KL 없는 순수1스텝에서도 공격은 양수0.5659~0.7651이었다.

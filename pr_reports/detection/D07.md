# 요청 라벨 비율과 손실만으로 탐지하기

**상태:** 완료

**판정:** 단순 통계가 기존 쉬운 대조를 설명하지만 도전 대조까지 해결하지는 못했다.

## 가설 한 줄

간단한 요청 통계만으로 패치 탐지와 같은 구별을 할 수 있다.

## 실험 한 줄

라벨 집중도, 삭제 손실, 유지와 삭제의 평균손실 차이를 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D07 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

개발15건에서는 손실 차이와 최대 라벨 비율이 완전히 분리했다. 그러나 seed74 정상 클래스 편향은 라벨 비율에, 오라벨은 손실 차이와 라벨 비율 모두에 위험 판정을 받았다.

**해석 범위:** BAU 전체 방어 재현이 아니라 통계 기준선 비교다.

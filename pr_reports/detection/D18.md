# 두 복제 모델의 직접 차분

**상태:** 완료

**판정:** 직접 뺄셈으로 바꾸는 것만으로 탐지가 해결되지 않았다.

## 가설 한 줄

원본 기준 대신 유지 모델에서 삭제 모델을 직접 빼면 공격 고유 신호가 드러난다.

## 실험 한 줄

D=W_R−W_F의 노름과 채널 Gini를 계산했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D18 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

기존 직접 차분 노름: 공격0.09173~0.11538, 대조0.09132~0.14620. Gini도 겹쳤다. 앞선 Gini 계산은 이미 직접 차분을 사용했다.

**해석 범위:** 여러 학습 스텝의 공통 손실은 두 분기의 서로 다른 궤적에서 작용한다. 공통 효과가 완전히 제거된다는 보장은 없다.

# 전후 손실 차이로 독성 학습 샘플 찾기

**상태:** 완료

**판정:** 학습 샘플 적합도와 새 이미지의 백도어 일반화는 다르다.

## 가설 한 줄

삭제 전후에 손실이 더 개선된 잔류 샘플을 고르면 독성 자료가 모인다.

## 실험 한 줄

실제 잔류 자료의 저장 라벨에 대한 전후 손실을 비교하고 같은 제거 예산에서 자료 순위를 평가했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D36 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

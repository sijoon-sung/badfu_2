# 랜덤 입력 실패의 원인 분해

**상태:** 완료

**판정:** 범위 보정은 일부 개선했다. 배경별 반응과 확률 포화 문제까지 해결한 것은 아니다.

## 가설 한 줄

랜덤 입력의 픽셀 범위를 맞추면 기존 패치 탐지 신호가 회복된다.

## 실험 한 줄

attack74/noise74에서 같은 Gaussian 입력의 범위와 평균·분산만 맞췄다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D25 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격 점수0.003064→0.012658, 오라벨0→0.001078. 그러나 진짜 공격 패치를 준 보정 노이즈에서도 유지 분기의 증가가 가장 작아 짝 비교 점수는0이었다.

**해석 범위:** 두 건의 원인 진단이다. 전체16건에 보정 노이즈를 적용한 확인은 없다.

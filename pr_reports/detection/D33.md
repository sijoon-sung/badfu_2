# 쉽게 맞히는 정상 샘플 삭제의 오탐

**상태:** 진행 중 · 이 삭제 종류 21/90건

**판정:** 공격 없는 정상 요청에서도 큰 점수와 경보가 발생했다. 공격 점수만으로 완전 구별한다는 주장은 성립하지 않는다.

## 가설 한 줄

라벨 비율이 같아도 쉬운 정상 샘플 삭제는 비율 지표를 크게 만들 수 있다.

## 실험 한 줄

공격·억제 자료를 학습하지 않은 정상 모델을 사용했다. 무작위 삭제와 클래스별 삭제 개수는 같게 두고 각 클래스의 낮은 CE 샘플을 골랐다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D33 -Action Run
```

진행 중인 고정 실험을 확인하고, 종료된 미완료 작업만 같은 설정으로 이어서 실행한다. 같은 배치를 공유하는 지표 리포트는 작업을 중복 실행하지 않는다.

## 결과

| 지표 | 정상 요청의 위험 판정 | 점수 범위 |
|---|---|---|

| Conv 노름 | 21/21 | 2.068~18.885 |
| FC 잔차 | 16/21 | 0.471~13.340 |
| Conv 잔차 | 20/21 | 1.055~14.566 |

**해석 범위:** 의도적으로 구성한 정상 요청의 스트레스 시험이다. 실제 삭제 후 재학습·ASR 평가는 하지 않았다. 자연 발생 요청의 오탐률 추정이 아니다.

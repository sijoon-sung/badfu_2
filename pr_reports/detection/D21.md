# Conv 직교 잔차의 F노름 비율

**상태:** 완료

**판정:** 다섯 층 모두 기존16건에서 범위가 분리됐다.

## 가설 한 줄

Conv의 삭제 방향을 제거한 잔차 크기로 공격과 대조를 구별한다.

## 실험 한 줄

layer4 Conv5개 층마다 직교 잔차의 F노름 비율을 계산했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D21 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

| 층 | 공격 | 대조 |
|---|---|---|
| layer4.0.conv1.weight | 1.572~2.348 | 0.118~1.015 |
| layer4.0.conv2.weight | 1.356~2.141 | 0.123~1.001 |
| layer4.0.downsample.0.weight | 1.435~2.294 | 0.110~0.940 |
| layer4.1.conv1.weight | 1.603~2.310 | 0.105~1.063 |
| layer4.1.conv2.weight | 1.559~2.331 | 0.086~0.974 |

**해석 범위:** 기존 시드 71~74의 공격 4건과 대조 12건을 재사용한 탐색 결과다. 새 16개 독립 학습 실험이 아니다. 과거1.15~2.20이라는 수치는 F노름이 아니라 최대 특이값 기준이었다.

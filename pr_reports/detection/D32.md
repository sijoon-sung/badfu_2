# 다수 클래스에 집중한 정상 삭제

**상태:** 진행 중 · 이 삭제 종류 21/90건

**판정:** FC·Conv 노름과 FC 잔차의 오탐은 없었으나, Conv 잔차는 정상21건 중1건에 경보를 냈다.

## 가설 한 줄

정상 다수 클래스에 집중한 삭제를 공격으로 오인하지 않는다.

## 실험 한 줄

공격·억제 자료를 학습하지 않은 정상 모델을 사용했다. 자료가 많은 클래스부터10/30/60%를 정상 삭제 집합으로 골랐다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D32 -Action Run
```

진행 중인 고정 실험을 확인하고, 종료된 미완료 작업만 같은 설정으로 이어서 실행한다. 같은 배치를 공유하는 지표 리포트는 작업을 중복 실행하지 않는다.

## 결과

| 지표 | 정상 요청의 위험 판정 | 점수 범위 |
|---|---|---|
| FC 노름 | 0/21 | 0.145~1.559 |
| Conv 노름 | 0/21 | 0.233~1.379 |
| FC 잔차 | 0/21 | 0.108~0.940 |
| Conv 잔차 | 1/21 | 0.193~1.379 |

**해석 범위:** 의도적으로 구성한 정상 요청의 스트레스 시험이다. 실제 삭제 후 재학습·ASR 평가는 하지 않았다. 자연 발생 요청의 오탐률 추정이 아니다.

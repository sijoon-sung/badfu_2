# FC 직교 잔차의 F노름 비율

**상태:** 완료

**판정:** 기존16건에서는 분리됐다. 정상 Non-IID 효과 전체를 제거하는 식은 아니다.

## 가설 한 줄

삭제 방향과 평행한 성분을 제거한 유지 갱신이 공격에서 더 크다.

## 실험 한 줄

A에서 B 방향 투영을 빼고 잔차 F노름을 B의 F노름으로 나눴다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D20 -Action Run
```

저장된 갱신 배열에서 이 지표를 다시 계산한다. 추가 학습·이미지 로드는 없다.

## 결과

공격1.4785~2.1890, 대조0.0760~0.7882. 범위는 겹치지 않았다.

**해석 범위:** 기존 시드 71~74의 공격 4건과 대조 12건을 재사용한 탐색 결과다. 새 16개 독립 학습 실험이 아니다.

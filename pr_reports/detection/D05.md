# 연속 패치 최적화로 위험 입력 찾기

**상태:** 완료

**판정:** 탐지 통과 뒤 위험 입력을 제시하는 보조 수단으로 남긴다.

## 가설 한 줄

유지 분기의 반응 증가를 최적화하면 실제 삭제 후 위험해지는 입력을 찾을 수 있다.

## 실험 한 줄

실제 공격 패턴을 주지 않고 네 모서리와 모든 타겟에서 4×4 패치를 최적화했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D05 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

seed74에서 선택한 입력의 타겟 도달률이 삭제 전 11.28%에서 삭제 후 98.39%로 증가했다. 실제 트리거 ASR과 별도 지표다.

**해석 범위:** 최적화 점수 자체를 고정 패치 임계값 0.006으로 판정하지 않는다.

# 클래스 비율을 맞춘 정상 무작위 삭제

**상태:** 진행 중 · 이 삭제 종류 21/90건

**판정:** 현재 관측한 무작위 삭제에서는 네 주 지표의 오탐이 없었다.

## 가설 한 줄

클래스 비율을 유지한 정상 무작위 삭제에는 FC·Conv 경보가 드물다.

## 실험 한 줄

공격·억제 자료를 학습하지 않은 정상 모델을 사용했다. 클래스별 비율을 유지하며 정상 학습자료의10/30/60%를 무작위 삭제 집합으로 골랐다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D31 -Action Run
```

진행 중인 고정 실험을 확인하고, 종료된 미완료 작업만 같은 설정으로 이어서 실행한다. 같은 배치를 공유하는 지표 리포트는 작업을 중복 실행하지 않는다.

## 결과

| 지표 | 정상 요청의 위험 판정 | 점수 범위 |
|---|---|---|
| FC 노름 | 0/21 | 0.624~1.081 |
| Conv 노름 | 0/21 | 0.721~1.108 |
| FC 잔차 | 0/21 | 0.117~0.925 |
| Conv 잔차 | 0/21 | 0.332~0.720 |

**해석 범위:** 의도적으로 구성한 정상 요청의 스트레스 시험이다. 실제 삭제 후 재학습·ASR 평가는 하지 않았다. 자연 발생 요청의 오탐률 추정이 아니다.

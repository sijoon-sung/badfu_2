# 기존 16건의 순수 FC 노름 비율

**상태:** 완료

**판정:** 기존 16건에서 탐색적 분리를 확인했다.

## 가설 한 줄

유지 갱신 크기를 삭제 갱신 크기로 나누면 공격이 더 크다.

## 실험 한 줄

같은 원본에서 R/F의 평균 CE 기울기로 FC weight와 bias의 1스텝 갱신을 계산했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D11 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

공격 2.3423~4.7095, 대조 0.1538~2.2280. 관측 범위는 겹치지 않았다.

**해석 범위:** 기존 시드 71~74의 공격 4건과 대조 12건을 재사용한 탐색 결과다. 새 16개 독립 학습 실험이 아니다.

# 어려운 정상 샘플 삭제의 오탐

**상태:** 진행 중 · 이 삭제 종류 21/90건

**판정:** 현재 관측한 어려운 자료 삭제에서는 네 주 지표의 오탐이 없었다. 쉬운 자료 삭제와 반응이 달랐다.

## 가설 한 줄

라벨 비율이 같은 어려운 정상 샘플 삭제에도 비율 지표가 커진다.

## 실험 한 줄

공격·억제 자료를 학습하지 않은 정상 모델을 사용했다. 무작위 삭제와 클래스별 삭제 개수는 같게 두고 각 클래스의 높은 CE 샘플을 골랐다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D34 -Action Run
```

진행 중인 고정 실험을 확인하고, 종료된 미완료 작업만 같은 설정으로 이어서 실행한다. 같은 배치를 공유하는 지표 리포트는 작업을 중복 실행하지 않는다.

## 결과

| 지표 | 정상 요청의 위험 판정 | 점수 범위 |
|---|---|---|
| FC 노름 | 0/21 | 0.101~0.450 |
| Conv 노름 | 0/21 | 0.139~0.497 |
| FC 잔차 | 0/21 | 0.028~0.184 |
| Conv 잔차 | 0/21 | 0.066~0.318 |

**해석 범위:** 의도적으로 구성한 정상 요청의 스트레스 시험이다. 실제 삭제 후 재학습·ASR 평가는 하지 않았다. 자연 발생 요청의 오탐률 추정이 아니다.

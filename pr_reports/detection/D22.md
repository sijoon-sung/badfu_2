# 직교 잔차의 최대 특이값 비율

**상태:** 완료

**판정:** 재사용 사례의 분리는 확인했다. SVD가 F노름보다 새 정보를 준다는 근거는 아직 없다.

## 가설 한 줄

잔차의 최대 특이값은 공격만의 집중 방향을 강조한다.

## 실험 한 줄

같은 직교 잔차에서 최대 특이값을 B의 F노름으로 나눴다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D22 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

FC는 공격1.1836~2.0593, 대조0.0633~0.5572였다. Conv5개도 각각 분리됐다. 최대 특이값/잔차 F노름이라는 집중도 자체는 공격·대조가 겹쳤다.

**해석 범위:** 기존 시드 71~74의 공격 4건과 대조 12건을 재사용한 탐색 결과다. 새 16개 독립 학습 실험이 아니다.

# Conv 변화 부분공간의 정렬도

**상태:** 완료

**판정:** 개별 정렬도 범위로 완전 분리되지 않았다. 전체 벡터의 독립 검증은 하지 않았다.

## 가설 한 줄

상위 특이벡터 부분공간의 정렬도로 공격과 대조를 구별할 수 있다.

## 실험 한 줄

layer4의5개 Conv 행렬에서 상위 부분공간의 겹침을 계산했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D17 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

각 층의 공격·대조 범위가 모두 겹쳤다. 예를 들어 첫 Conv는 공격0.2372~0.3949, 대조0.1776~0.3986이었다.

# 삭제 요청과 잔류 자료의 상호작용으로 독성 자료 찾기

**상태:** 완료

**판정:** 이 구현의 상호작용 순위는 단순 기준선보다 나빴다. 주력으로 채택하지 않는다.

## 가설 한 줄

요청 자료의 유무에 따라 영향이 달라지는 잔류 자료가 실제 독성 자료다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D35 -Action Run
```

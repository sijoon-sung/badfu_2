# FC와 Conv를 함께 놓은 2차원 비교

**상태:** 완료

**판정:** 2차원 표시 자체는 가능하다. Conv를 추가한 실질적인 탐지 이득은 입증하지 못했다.

## 가설 한 줄

FC·Conv 두 지표를 함께 쓰면 한 지표보다 분리가 좋아진다.

## 실험 한 줄

같은16건의 FC 비율과 기존100스텝 Conv 비율을 2차원에 배치했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D14 -Action Run
```

저장된 갱신 배열에서 이 지표를 다시 계산한다. 추가 학습·이미지 로드는 없다.

## 결과

관측 점은 분리되지만 FC 단독으로 이미 분리됐다. 2차원 분류기를 학습하거나 새 요청의 오탐 감소를 확인하지 않았다.

**해석 범위:** FC는 순수1스텝, Conv는 KL을 쓴100스텝으로 검사 예산도 다르다.

# 정상 이미지 대신 랜덤 입력으로 패치 탐지

**상태:** 완료

**판정:** 기존 검사의 단순 랜덤 입력 대체는 실패했다.

## 가설 한 줄

랜덤 노이즈나 0 입력으로도 기존 패치 탐지를 유지할 수 있다.

## 실험 한 줄

같은16개 모델에 Gaussian 배경과0 배경을 넣어 고정 패치 반응을 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D24 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

Gaussian 점수: 공격0.000596~0.003064, 대조0~0.003183. 0입력도 공격0~0.111104, 대조0~0.062663으로 겹쳤다.

**해석 범위:** 복제 모델을 만드는 기존 단계에는 정상500장 기준점이 이미 사용됐다.

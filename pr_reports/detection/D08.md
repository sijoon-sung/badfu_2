# 기존 복제 모델의 FC와 BN 변화 확인

**상태:** 완료

**판정:** 기존 체크포인트의 FC·BN 차이만 읽는 방법은 사용할 수 없다.

## 가설 한 줄

저장된 복제 모델의 FC 또는 BN 차이만으로 탐지 점수를 만들 수 있다.

## 실험 한 줄

원본·유지·삭제 체크포인트의 FC와 BN running statistics를 직접 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D08 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

기존 복제 모델은 layer4만 학습했다. FC 변화와 BN 통계 변화는 모두 정확히 0이었다.

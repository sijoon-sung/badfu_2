# 채널별 변화 집중도

**상태:** 완료

**판정:** 이 복제 모델에서 공격만 희소하다는 가설은 지지되지 않았다.

## 가설 한 줄

공격의 변화는 정상 대조보다 소수 채널에 더 집중된다.

## 실험 한 줄

기존 layer4 두 복제 모델의 직접 차이에서 채널별 에너지와 Gini를 계산했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D15 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

Gini: 공격 0.5050~0.5226, 대조 0.5070~0.5646. 상위10% 채널 에너지 비중도 겹쳤다.

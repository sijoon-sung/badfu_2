# FC 갱신 합의 클래스 집중도

**상태:** 완료

**판정:** 공격만 집중한다는 가설을 지지하지 않았다. 두 갱신의 합은 중앙 2차 차분이 아니다.

## 가설 한 줄

유지·삭제 갱신의 합이 공격에서만 한 클래스에 집중된다.

## 실험 한 줄

같은 시작점에서 계산한 FC 평균 CE 갱신을 더하고 클래스별 행 노름 비중을 구했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D09 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

## 결과

최대 클래스 비중은 공격 41.78%, 안전 44.02%, 정상 클래스 편향 39.08%, 오라벨 44.79%였다. 최대 클래스는 모두 0이었다.

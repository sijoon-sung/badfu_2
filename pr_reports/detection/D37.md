# 전후 입력 기울기로 독성 샘플 찾기

**상태:** 완료

**판정:** 현재 입력 기울기 점수의 국소화 이득은 확보하지 못했다.

## 가설 한 줄

삭제 전후 입력 기울기 방향의 변화로 독성 자료를 찾을 수 있다.

## 실험 한 줄

잔류 샘플별 입력 기울기의 방향 변화, 노름 증가, 상위 스펙트럼을 같은 예산으로 비교했다.

## 실행 한 줄

```powershell
.\pr_reports\run.ps1 D37 -Action Run
```

로컬 PowerShell에서 실행하면 DISLAB의 보존 모델·자료로 재실행한다. 새 출력 폴더를 만들며 원본 결과는 덮어쓰지 않는다. GPU 작업이 진행 중이면 시작하지 않는다.

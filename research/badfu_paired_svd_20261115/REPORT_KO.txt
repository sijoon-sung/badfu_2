# P09 · 동일 이미지 짝 기반 SVD 방어 결과

기존 BadFU의 삭제 요청과 CIFAR-10 원본 짝을 확인했다. 사전 정의한 분류층 SVD 감쇠는 두 공격 모델에서 정상 효용 기준을 통과했고, 복구 후 ASR 감소와 원래 정답률 증가 5%p 기준을 두 모델 모두 놓쳤다.

## 삭제 요청과 클린 원본의 짝

- s20261020과 s20261023은 같은 위장 요청 850장을 사용했다. 저장된 학습 인덱스, 보관 요청 파일 SHA256, 원래 라벨, 원본 배열 및 승인된 모델과 최종 이력의 연결을 확인했다. 인덱스가 유일한 850쌍 모두 원래 라벨이 일치했다. 850쌍 모두 요청 이미지와 클린 원본에 픽셀 차이가 있었다.
- 큰 정상 19.336%와 22.790%의 실제 삭제 인덱스 해시를 검증해 각각 9,668장과 11,395장을 짝지었다. 학습 소스가 두 요청의 원본 clean 배열 사용을 기록한다. 모든 짝에서 픽셀이 일치해 동일 고정 백본에서 특징 차이가 0이다.

## 검산과 적용 범위

DISLAB CPU에서 네 조건을 한 번씩 실행했다. 17개 원격 영수증의 해시와 정수 기반 판정을 독립 검산했고 같은 P07 데이터 분할, 두 공격의 P08 무교정 기준, 두 정상의 이전 P07 클린 기준과 일치했다. 프로토콜과 동결 해시를 보존했다. 이 판정은 알려진 클린 원본 쌍, 고정 백본과 일회성 분류층 교정, 정해진 12단계 복구 경로에 한정된다. 정상 요청의 정확한 원본 대응은 정상 도메인 차이를 상쇄하므로 원본 대응이 불완전한 운영 조건의 증거로 사용하지 않는다. SVD 기저나 원이미지는 결과 파일에 저장하지 않았다.

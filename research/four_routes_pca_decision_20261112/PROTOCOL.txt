2026-11-12 KST · D23 · 큰 정상 삭제와 공격성 삭제의 기능 검사

가설. 실제 전환 중 공개 정상 이미지의 전후 특징 변화로 만든 PCA 부분공간의 직교 성분을 제외하면 원래 클래스로 돌아가는 사건이, 큰 정상 삭제보다 공격성 삭제에서 더 많이 남는다. D02/D06/D07/D08/D15/D18/D19/D20/D21/D22/T02/T03/T04/R03 관련. 새 관측은 PCA 직교 성분을 제외한 뒤 실제 두 분류기의 결정이 어떻게 바뀌는지다. D08과 D22는 반응 크기/전환율의 정상 겹침, T04는 body 의존 자체의 정상 겹침을 보였다. 정상 자료에서 충분히 관측되는 변화라면 정상 전후 변화를 학습한 부분공간에 남을 수 있다. 공개 자료에 없는 정상 도메인은 공격과 비슷한 직교 성분을 가질 수 있어 D22의 큰 삭제/어두운 두 반복과 BadFU 큰 참여자 삭제를 직접 시험한다. 공개 데이터 대표성 및 전후 특징 좌표의 대응을 가정한다.

모든 원 모델/입력 조건은 저장 D20/D21/D22에서 실제 해시·payload·case purpose 확인 뒤 읽기 전용으로 사용. 실제 트리거/목표/삭제 ID/역할은 평가 루프에 주지 않는다. 원 test 이미지에서 전후 모두 원정답 y, 기존 탐침 이미지에서 pre=y·post=선택 목표 t라는 native 사건을 먼저 확인한다. 네 경로 조건은 추가 교차 clean 두 정답 및 변환 입력에서 pre body+post head=y, post body+pre head=t를 요구한다.

PCA 특징 검사. 공개 fit320장만으로 전후 body 출력 차이 d=h1-h0의 평균 m과 중심화 PCA(누적 분산95%, 사전 고정)를 구한다. 시험 입력에서 h1을 h0+m+P(d-m)으로 잠시 대체한다. 네 경로를 만족한 실제 전환 중 이 수정으로 두 분류기가 모두 y로 돌아오고 동일 수정의 원본 이미지도 두 분류기에서 y인 사건을 센다. 보조 비교는 같은 차원 무작위 공간(고정 seed, 평균과 조건 동일), PCA 평행 성분을 대신 제외한 뒤 두 목표 예측이 남는 사건, 원본 이미지의 수정 전후 정확도다. FC 비교는 같은 fit320장의 pre 특징 PCA95%를 사용한다. post 분류기 가중치 변화의 직교 성분만 제외하고 fit 평균 위치의 로짓은 보존한다. 수정된 post head의 원본과 변형 입력이 둘 다 y인 native 사건을 센다. 모든 수정은 추론 중 대수적 조작이다. 원 모델과 원래 전환 증거는 그대로 사용한다.

FedUBA 주 검증. D22 실제 42개 체크포인트의 1/3/5/10/15/20R 및 새 정상 세 요청의 1/3/5/10R. 원 D22 공개 test와 탐침을 그대로 쓴다. 정상에서 선정한 6개 탐침의 최대 건수/900을 요청·라운드 점수로 삼는다. 나머지 진단 기원 4탐침은 별도 감도표에만 포함한다. 정상 보정은 저장 p00(균형5k), p01(class2 전부2486), p02(125) 각6R, 방법별 보정 최대치 초과일 때 경보. 보정 이후 정상 u00/u01/u02 각4R을 한 번 검사하며 요청 단위로 하나 이상 경보를 오경보로 센다. 진단 p03/p04는 6R 모두 표시, 10/15/20R 각 쌍 모두 경보와 별도 정상 3요청 오경보0을 채택 필요조건으로 둔다. 진단 공격 원 성능 미달, 한 원 FL 시드, 이 패널은 종말에서 정한 탐침을 이용한 회고 검사다. 42 체크포인트는 독립 학습 횟수가 아니다.

BadFU 보조 검증. D20 승인 모델의 실제 두 공격과 정상 네 쌍에서 기존 case별 baseline/route 두 조건을 각각 동일하게 재검사한다. 큰 정상 c00 또는 c01 하나와 정상 c02/c03을 보정하고 나머지 큰 정상을 보류하는 두 정해진 분할을 사용한다. 각 분할에서 보류 큰 정상 오경보0 및 두 공격 모두 경보를 요구한다. 양성 두 모델은 같은 두 분할에서 재사용된다. BadFU 기준은 그 두 탐색 조건에만 해당하며 임계값은 FedUBA와 독립으로 보정한다.

판정. 보정 최대치와 동률은 경보0. 보류 정상에 경보가 뜨거나 요구 양성이 누락되면 해당 조건의 기준 채택을 보류한다. PCA의 추가 가치는 네 경로 및 동일 차원 무작위 공간과 같은 보류 정상 오경보 수준에서 양성 검출이 늘어나는 경우만 인정한다. 다른 임계값·차원·패널을 사후 선택하지 않는다. 각 탐침 원 native 정수 재일치가 필수이며 해시·유한성·자원·동일성 실패는 해당 실행을 보존하고 중단한다. 실제 결과/오류/검산을 기존 PR에 연결한다.

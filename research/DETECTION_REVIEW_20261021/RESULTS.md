# 확장 탐지 실험 결과와 현재 판정

2026-10-21 · 선행 연구·관측 조건·수학 검토는 [검토 문서](REVIEW.md)

## 최신 실제 미지 트리거 검증

**가설 한 줄: 트리거를 모르는 상황에서도 학습한 변형과 실제 모델 전후 통계로 공격을 정상 non-IID 삭제에서 구별할 수 있다.**

실제 전후 8쌍에서 미지 변형 후보 720개, 15개 분류기의 최대 마진 통계, Conv 20개·BN 20개·FC 1개 세부 검사와 784개 모듈 교체를 완료했다. 원 공격의 γ 선택에서 제외했던 예약 320장에 탐침을 고정해 재평가했다. BadFU Paper32 공격 차분은 15.07pp, 정상 클래스 집중 삭제는 16.87pp였다. FUBA 공격은 83.86pp, 정상 삭제는 80.68pp였다. 단순 최대 반응·차분·가중치 변화만으로 두 공격과 정상 non-IID를 공통으로 분리했다고 말할 수 없다.

BadFU Paper32의 작은 최소 마스크와 FUBA 전후 정규화 마진의 차이가 후속 후보 신호다. 전체 결과·그림·수학적 반례는 [새 검증 보고](../UNKNOWN_TRIGGER_RUN_20261021/RESULTS.md)에 정리했다. 아래 기존 수치는 고정 후보 탐침 조건의 기록이며 새 미지 변형 학습과 구분한다.

**기존 고정 후보 조건의 판정:** BadFU에서는 국소 변형 반응의 전후 차분을 후속 검증할 가치가 있다. 여러 원본 클래스의 반응 일관성을 요구하는 점수는 정상 삭제 대조에서 작은 값을 보였다. 그러나 **BadFU·FUBA에 공통으로 통하는 탐지법을 확보했다고 말할 수 없다.** 특히 FUBA에서 큰 전체 변형 반응을 실제 공격 반응으로 해석할 근거가 부족하다.

## 정상 클래스 집중 삭제의 첫 완료 결과

**가설: 정상적으로 주된 클래스를 대량 삭제해도 국소 패치에 대한 여러 원본 클래스의 공통 반응은 BadFU 활성화보다 작게 유지된다.**

참여자0의 클래스1 데이터 3,558개를 전부 삭제한 실제 보존 데이터 재학습 40라운드가 완료됐다. 전역 클래스1은 5,000개에서 1,442개로 줄었다. 한 참여자의 해당 클래스 전체 삭제이며 전역 클래스 전체 삭제가 아니다. 같은 삭제 수의 무작위 삭제와 나머지 집중 삭제 조건은 진행 중이다.

| 조건 | 국소 패치 차분 %p | 국소 클래스 하위 사분위 %p | 전체 이미지 변형 차분 %p |
|---|---:|---:|---:|
| Paper32 위장 850개 삭제 | 77.331 | 71.955 | 9.160 |
| Paper32 정상 850개 삭제, 공격 잔존 | 1.655 | -0.261 | 12.456 |
| 새 정상 non-IID 시드, 무작위 850개 삭제 | -0.008 | 0.0002 | 3.946 |
| 정상 주된 클래스 3,558개 삭제 | 0.906 | -0.0159 | 19.175 |

각 점수는 선택 집합에서 자기 패치·출력 후보를 고른 뒤 확인 집합에서 측정했다. 차분 단위는 확률의 퍼센트포인트이며 탐지 정확도가 아니다. 조건 간 초기 모델·삭제 수가 다르고 단일 시드·공유 모델을 포함한다. 이 표를 동일 조건의 독립 반복이나 오탐률로 해석하지 않는다.

![패치 반응 구조](response_structure.png)

국소 차분으로 고른 후보에서 BadFU 위장 삭제의 9개 원본 클래스 평균은 모두 61.00~89.70%p였다. 기존 정상 무작위 삭제는 -0.52~5.15%p, 새 클래스 집중 삭제는 -2.17~5.88%p였다. 조건마다 자기 후보를 고르며 실제 공격 목표를 정답으로 제공하지 않았다. 이 결과는 국소 패치에 대한 여러 클래스의 공통 반응을 검증할 근거를 추가한다. 단순 변형 반응의 크기는 정상 집중 삭제에서도 커질 수 있다는 반례가 관측됐다.

전체 변형에서는 새 정상 집중 삭제의 클래스 하위 사분위도 11.411%p였다. 따라서 원본 클래스 일관성만 더하면 임의의 변형에서 정상과 공격이 구별된다는 주장은 성립하지 않는다. 기존부터 선택한 국소 후보와 전체 변형 후보를 따로 평가해야 한다. 현재 국소 결과를 전역 노이즈를 사용하는 FUBA에 그대로 적용해 공통 탐지라고 보고하지 않는다.

### 패치 선택성과 확률 편향을 분리하는 추가 분석

**가설: 여러 클래스의 공통 반응에서 일반적인 변형 반응을 빼도 BadFU의 국소 활성화 신호는 유지된다.**

기존에 계산한 변형별 차분에서 국소 32변형의 중앙값을 빼고 원본 클래스 하위 사분위로 모은 결과를 새 정상 조건에도 적용했다. 선택은 fit에만 의존했다. 확인 점수는 Paper32 위장 삭제 71.952%p, 기존 정상 삭제 -0.774%p, 새 정상 무작위 삭제 -0.832%p, 새 정상 집중 삭제 -0.0088%p였다. 이미 좋은 분리를 보인 자료에서의 사후 보완 분석으로서 원점수 대비 독립적인 성능 향상을 증명하지 않는다. 여러 패치에 반응하는 공격은 중앙값 차감으로 신호가 줄 수 있다.

**가설: 입력과 무관한 클래스별 로짓 편향은 확률 차분을 만들 수 있지만 로짓의 모델·입력 이중 차분에서는 정확히 상쇄된다.**

클래스 중심화 로짓을 c(z)=z-mean(z)라 하고 L=c(z1(Tx)-z0(Tx))-c(z1(x)-z0(x))라 둔다. 모든 입력 u에서 z1(u)-z0(u)=b인 경우 L=c(b)-c(b)=0이다. 반면 softmax는 비선형이므로 같은 주장이 확률 차분에 성립하지 않는다. 구성한 2클래스 예에서 pre 로짓은 clean [-4,0], patched [-3,0], post는 두 입력 모두에 [3,0]을 더한다. 패치의 로짓 효과는 바뀌지 않았는데 확률 차분은 20.162%p, 로짓 차분은 0이었다. 이는 구성한 수학적 반례이며 실제 non-IID 학습 결과로 세지 않는다.

중심화 로짓 점수는 기존 진단 코드에 이미 있었다. 새로 추가한 원본 클래스 하위 사분위 집계의 확인 점수는 Paper32 위장 삭제 6.416, 기존 정상 삭제 0.536, 새 정상 무작위 삭제 0.221, 정상 집중 삭제 0.184였다. 단위는 로짓으로 확률 %p와 다르다. 입력별 특징 변화나 온도 변화까지 제거한다는 증명은 아니며, 모델 간 로짓 스케일과 임계값 보정이 필요하다.

관측 배열의 reference ID 일치와 (49,320,10) 출력 모양을 검사했고 전후 배열 SHA를 보존했다. 재학습·모델 변경 없이 기존 반응 8쌍을 CPU에서 재분석했다. 상세 값과 원본 경로는 `response_structure.json`, 실행 코드는 `analyze_response_structure.py`다. 이 8쌍은 독립 학습 8회가 아니다.

## 실험 범위와 독립성

- BadFU 모델 **10개**, 실제 전후 쌍 **6개**. Paper32와 PGD64, 5인/6인 구성을 구분했다. 같은 초기화·학습 시드를 공유하며 삭제 후 모델도 일부 공유하므로 독립 학습 6회가 아니다.
- 기준 이미지 **320개**는 이전 측정에 사용한 320개와 겹치지 않는다. 클래스별 선택 16장·확인 16장씩으로 나눴다. 최종 클래스 점수의 비목표 확인 표본은 144개다.
- 고정 변형 **48개**, 점수 방식 **10개**, 진단 망각 모델 **10개**, 최적화 목적 2개 × 실제 전후 쌍 4개, reference class prior **41개**를 비교했다.
- 최초 모델 수집·방법 비교는 서버에서 **120.89초**에 완료했다. 이어 FUBA 실제 모델 2개와 가우시안 주변 반응의 통계를 추가 측정했다.
- 이 자료는 방법 개발용 사후 분석이다. 새 확인 이미지는 독립 학습 시드/모델을 대신하지 않으며, 여러 후보 중 최종 방법을 고른 뒤에는 새 모델 평가가 필요하다.
- 탐지 함수에 실제 공격 패턴·목표 클래스·ASR·악성 ID를 넣지 않았다. 실제 트리거·생성기는 점수를 고정한 뒤 평가자만 사용했다.
- 현재 **임계값, 정상 오탐률, AUROC, 검출률은 확정하지 않았다.**

## H1. 실제 전후 차분

**가설: 동일 입력 변형의 실제 모델 전후 차분은 정상 삭제보다 위장 삭제에서 크게 나타난다.**

| 조건 | 위장 삭제 차분 | 정상 삭제 차분 | 적용 범위 |
|---|---:|---:|---|
| Paper32 | **77.33%p** | **1.65%p** | 같은 공격 포함 pre 모델에서 위장 850개 또는 정상 850개 삭제 |
| PGD64·5인 | **90.87%p** | **-0.88%p** | 공격 전후와 공격 없는 정상 모델의 삭제 전후 |
| PGD64·6인 | **64.96%p** | **0.41%p** | 별도 위장/정상 참여자 삭제, 각 post는 해당 5인 결과와 공유 |

Paper32의 이전 값 78.12%p/0.17%p와 다른 것은 이번에 확인 이미지가 바뀌었기 때문이다. 같은 모델의 새 이미지 측정이며 새로운 학습 반복이 아니다. 음수는 선택 자료에서 고른 후보가 확인 자료에서 약해졌다는 뜻이며 공격 위험이 음수라는 뜻은 아니다.

오른쪽 아래의 모든 국소 패치를 빼면 위장 삭제 점수는 Paper32 **26.55%p**, PGD64·5인 **38.40%p**, PGD64·6인 **25.36%p**였다. 정상 대조는 각각 1.65%p, -0.88%p, 0.41%p였다.

**판정:** 현재 보존된 BadFU 모델 쌍에서는 방향이 유지된다. 정상 non-IID의 전반적 구별이나 탐지 성능 우위를 확정하지 않는다.

## H2. 원본 클래스별 반응 일관성

**가설: 원본 클래스별 평균 반응의 하위 사분위 점수는 소수 클래스의 변화가 만드는 정상 삭제 혼동을 줄인다.**

| 조건 | 위장 삭제: 평균 차분 | 위장 삭제: 클래스 하위 사분위 | 정상 삭제: 평균 차분 | 정상 삭제: 클래스 하위 사분위 |
|---|---:|---:|---:|---:|
| Paper32 | 77.33%p | **71.96%p** | 1.65%p | **-0.26%p** |
| PGD64·5인 | 90.87%p | **88.82%p** | -0.88%p | **-0.07%p** |
| PGD64·6인 | 64.96%p | **52.60%p** | 0.41%p | **-0.02%p** |

각 점수는 선택 집합에서 자기 변형·클래스를 따로 고르고, 확인 집합에 고정 적용했다. 하위 사분위는 클래스 평균들의 분위수이며, 통계적 신뢰구간 하한이 아니다.

**판정:** 다음 정상 모델 대조에서 검증할 후보. 이 표의 작은 정상 점수를 실제 오탐률 감소로 바꾸어 보고할 수는 없다. 공격 점수도 낮아지므로 같은 오탐률에서 검출률이 유지되는지 확인해야 한다. 특정 source class만 노리는 공격에는 감도가 떨어질 수 있다.

## H3. FC와 특징 정보

**가설: FC 이전 특징 기여는 FC 단독보다 삭제 후 활성화와 정상 변화를 구별하는 보조 정보를 준다.**

| 조건 | FC: 위장/정상 | FC 이전 특징: 위장/정상 |
|---|---:|---:|
| Paper32 | 0.445 / 0.492 | **3.701 / 0.401** |
| PGD64·5인 | 0.746 / 0.210 | **3.656 / 0.238** |
| PGD64·6인 | 1.345 / 0.524 | **3.135 / 0.327** |

각 항의 clean 기능 변화로 정규화한 점수다. FC 이전 특징에는 Conv와 BatchNorm 등이 포함된다. FC와 특징의 정규화 분모가 다르므로 서로의 절대 크기로 설명 비중을 계산하지 않는다.

**판정:** FC 단독을 주 탐지 점수로 두는 근거는 약하다. 특징 기여는 후속 보조 후보지만 추가 TPR/FPR 이점은 아직 검증되지 않았다. 순수 Conv 기능 교체 분석은 [앞선 실험](../STAGE1_BADFU_TEST_20261021/README.md)에 구분해 보존했다.

## H4. 최적화한 입력

**가설: 같은 예산의 두 모델 입력 최적화는 고정 패치보다 더 강한 활성화 차분을 찾는다.**

- 조건: 선택 자료의 고정 변형 점수로 목표 후보 2개를 고르고, 4모서리 5×5 패턴 또는 전체 입력의 L∞≤0.04 공유 변형을 각각 24스텝 최적화했다. 삭제 후 반응 최대화와 전후 차분 최대화의 예산은 같다.
- 한 모델 쌍·목적함수마다 후보 10개, 총 80개를 계산했다. 확인 점수로 후보를 다시 고르지 않았다.

| 전후 차분 | 고정 패치 | 최적화 변형 |
|---|---:|---:|
| Paper32 위장 삭제 | **77.33%p** | 8.17%p |
| Paper32 정상 삭제: 공격 잔존 | **1.65%p** | 7.24%p |
| PGD64 위장 삭제 | **90.87%p** | 68.45%p |
| PGD64 정상 삭제: clean | -0.88%p | -0.85%p |

삭제 후 모델만을 최대화한 입력은 Paper32 위장 삭제 모델에서 반응 98.77%p를 얻었지만, 이는 실제 트리거 ASR이 아니다. 공격이 남아 있는 정상 삭제 모델에서도 34.42%p였다.

**판정:** 이번 초기화·탐색 공간·24스텝 설정에서는 가설을 지지하지 않는다. 선택 집합 점수도 고정 패치보다 낮아 최적화/초기화 문제가 남는다. 이 결과는 Neural Cleanse나 FilterFL 전체 방법의 실패를 뜻하지 않는다. 최적화가 잘되더라도 정상 대조의 반응까지 올릴 수 있어 보정은 별도로 필요하다.

## 진단용 clean 망각

**가설: 고정 예산의 clean-loss ascent가 공격 모델의 숨은 패치 반응을 정상 모델보다 더 뚜렷하게 노출한다.**

조건: 전역 모델 복사본에 clean 손실을 높이는 SGD를 학습률 1e-4로 10스텝 수행했다. BatchNorm은 eval 모드로 고정했다. 실제 모델이나 삭제 결과를 수정하지 않았다. 원 MASA의 개별 모델 융합이나 EBYD 전체 파이프라인의 재현은 아니다.

| 모델 | 진단 전 패치 반응 | 진단 후 패치 반응 |
|---|---:|---:|
| Paper32 삭제 전 | 4.85%p | 5.61%p |
| Paper32 위장 삭제 후 | 81.43%p | 81.57%p |
| Paper32 정상 삭제 후: 공격 잔존 | 4.49%p | 3.94%p |
| Paper32 clean | 2.44%p | 2.77%p |

**판정:** 공격 모델과 clean 모델 모두 반응이 커질 수 있고 증가가 일관되지 않는다. 현재 예산에서 주 탐지법으로 채택할 근거는 없다. 단 한 설정이므로 진단 망각 계열 전체가 불가능하다고 결론 내리지 않는다.

## Reference class prior 변화와 가우시안 주변 반응

![혼동 보완 검사](nonIID_and_neighborhood.png)

**가설: 기준 자료의 클래스 비중만 바꿔도 평균 차분의 크기와 선택 좌표가 달라질 수 있다.**

조건: 균형 1개, 지배 클래스 비중 80%인 10개, Dirichlet 가중치 α=.1/.5/1.0에서 각 10개, 총 41개. 모두 같은 모델·이미지의 가중치 재분석이다.

- Paper32 위장 삭제 평균 차분: **61.40~87.17%p**, 정상 삭제: **-2.90~3.95%p**.
- PGD64·5인 위장 삭제: **79.38~94.99%p**, 정상 삭제: **-2.20~5.29%p**.
- 클래스별 평균을 고정해 균형화하면 비중 의존성은 정의상 제거된다. 클래스별 표본이 사라지거나 모델의 조건부 반응 자체가 바뀌는 상황까지 검증한 것은 아니다.

**판정:** 기준 자료의 빈도 편향이 점수 크기를 바꾸는 것을 확인했다. **non-IID 학습 41회로 세지 않는다.** 진짜 학습 분할 효과는 새 정상 모델 4쌍으로 따로 검사한다.

**가설 H5: CBD의 가우시안 주변 클래스 집중도 LDP 통계가 고정 패치와 다른 유효한 공격 신호를 제공한다.**

조건: BadFU 10모델과 FUBA 2모델. 예측 클래스별 2개 입력을 선택/확인 집합에서 따로 뽑고 입력당 가우시안 64개를 사용했다. σ=.01/.04/.1 중 선택 집합의 LDP가 가장 큰 σ를 확인에 고정했다. 이 통계는 Gaussian 노이즈에 대한 클래스 예측 빈도이며 softmax 확률 평균과 다르다.

예측 클래스 조건을 맞추려고 모델마다 고른 입력이 다르므로, 이 단일 모델 통계는 앞선 동일 입력의 실제 전후 차분과 구분한다.

| 모델 | 확인 LDP | 선택된 집중 클래스 |
|---|---:|---:|
| Paper32 삭제 전 | 0.488 | 6 |
| Paper32 위장 삭제 후 | 0.444 | 6 |
| Paper32 정상 삭제 후: 공격 잔존 | 0.475 | 6 |
| Paper32 clean | **0.565** | 6 |
| PGD64 위장 삭제 후 | 0.416 | 6 |
| PGD64 clean 삭제 후 | 0.413 | 6 |
| FUBA 삭제 전 | 0.371 | 6 |
| FUBA 삭제 후 | 0.450 | 6 |

모든 모델에서 σ=.1이 선택됐다. 실제 공격 목표는 BadFU 0, FUBA 8인데 주변 반응은 6에 집중됐다.

**판정:** 이번 σ 범위와 Monte Carlo 설정에서 원하는 공격/정상 순서가 나오지 않았다. 정상 shadow 보정과 원 CBD 인증을 재현하지 않았으므로 CBD 전체의 실패로 일반화하지 않는다. 큰 노이즈에서 일반적인 클래스 붕괴를 측정했을 가능성을 정상 대조와 함께 확인해야 한다.

## FUBA: 완료된 실제 전후 모델의 오류 복구와 검증

**가설: 삭제 전부터 활성화된 공격은 전후 변화만으로 평가하면 현재 위험과 활성화 증가를 혼동할 수 있다.**

![FUBA 검증](fuba_validity.png)

- 학습과 보존 참여자 재학습은 각각 100라운드 완료했다. 멈춘 부분은 후속 진단의 `list == class` 처리였다. Python 리스트에 클래스 비교를 하여 선택 이미지가 0개가 됐고, 이후 빈 텐서 reshape에서 실패했다.
- 호출부에서 라벨을 numpy 배열로 바꾸어 재검증했다. 향후 실행본에는 클래스별 최소 32개 검사도 추가했다. 학습된 가중치나 공격 핵심 코드를 수정하지 않았다.
- **동일한 삭제 전 공격 생성기, 동일 이미지** 400장(비목표 360장) 평가에서 ASR **99.72%→83.61%**, clean 정확도 **74.25%→73.00%**였다.
- 원 학습 로그의 ASR은 각각 약 98.19%와 98.87%다. 그 값은 평가 자료와 공격 생성기 조건이 다르므로 위 고정 입력 평가와 같은 값으로 취급하지 않는다.
- 국소 차분은 **2.16%p·선택 클래스 3**, 전체 변형 차분은 **32.73%p·선택 클래스 4**였다. 실제 공격 목표는 **8**이다.

**판정:** 높은 전체 변형 점수만으로 실제 FUBA 백도어를 발견했다고 보고하지 않는다. 정상 FUBA 대조도 아직 없다. 현재 모델은 삭제 전부터 ASR이 높아 잠복 성공·삭제 후 활성화 증가의 검증 사례로 사용할 수 없다. **FUBA 잠복 조건 재현 문제를 해결해야 한다.** 원 코드의 알려진 이슈가 원인인지 이번 측정만으로 단정하지 않는다.

보존 재학습 중 남은 악성 참여자가 기존 공격 프로토콜을 계속 수행한다. 이 전후 차이를 위장 제거만의 효과라고 분리해 해석하지 않는다.

BadFU 방어 설계 · 복구 전 구간의 정답 마진을 제약하는 교정
2026-11-15 KST · 합성 수학 검증과 실제 모델 효능을 구분

가설. 동일 후보·자료·교정 예산에서 교정 직후부터 후속 복구 끝까지 정답 마진을 제약하면, 직후만 검증한 방법보다 큰 정상 탈퇴의 클래스별 정답을 더 안정적으로 유지하면서 실제 BadFU 입력의 원래 정답을 회복하는 후보를 남길 수 있다.

1. 관측과 전제

R01/T01/P01/P02/P05/D01/D02/D06/D07/D08/D15/D18/N01/N02. D08의 공격 0.75848은 큰 정상 탈퇴 0.75525와 0.76188 사이였다. P05에서 교정 직후 두 큰 정상 탈퇴의 클래스 3 격차가 27·18장 생겼고, 다른 정상 조건에서 클래스 2 격차가 후속 갱신 중 3→9장으로 커졌다. 새 관측은 각 입력·라벨·복구 시점의 정답 점수 하한, 허용되는 교정 혼합의 비중, 실제 독립 표본의 정답 회복·유지·재오류다. 정상 집단은 교정으로 보호하며, 변화량은 공격 여부의 점수로 쓰지 않는다. 실제 백도어 입력의 반응은 P05에서 미측정이다.

삭제 영향이 이미 제거된 기준 분류층 W_base와 그 뒤의 고정 특징 φ(x)를 받는다. 편향은 특징의 마지막 1 좌표로 넣을 수 있다. 원래 백본, BN 및 전처리를 모든 후보와 시간에 고정한다. 교정 데이터, 보호 데이터, 후보 평가 데이터, 독립 최종 시험의 역할을 분리한다. 직접 검수한 독립 공개 자료나 신뢰가 별도 확립된 잔류 출처에서 라벨을 구할 수 있어야 한다. 유지 집합에 포함되는지와 대표하는 클래스·도메인의 범위를 기록한다. 승인할 복구 시나리오의 라벨·배치·가중치와 적용할 시간 길이를 미리 고정한다. 보호 표본이 부족한 클래스·도메인은 커버리지에 드러내며, 두 시점 모두 맞힌 사례만 사후 골라 성공으로 세지 않는다.

2. 실제로 적용할 복구 연산

각 허용 시나리오 s에서, n_t개 검증된 유지 특징으로 행렬 X_t (n_t×d)와 원래 정답의 one-hot Y_t (n_t×C)를 정한다. W는 C×d다. 실제 적용을 다음 제곱손실 SGD로 제한한다.

L_t(W) = ||X_t W^T − Y_t||_F²/(2n_t) + λ_t ||W − W_base||_F²/2.
A_t = I − η_t(X_t^T X_t/n_t + λ_t I),
B_t = η_t(Y_t^T X_t/n_t + λ_t W_base),
W_t = W_(t−1) A_t + B_t + E_t.

η_t > 0, λ_t ≥ 0, η_t||X_t^T X_t/n_t + λ_t I||₂ ≤ 1을 적용한다. 같은 λ_t에서도 시나리오마다 자료가 다를 수 있다. 서버가 신뢰 가능한 유지 자료나 통계로 명목 식을 직접 계산하고, 외부 추가 갱신 총합 E_t를 실제 가하기 전에 ||E_t||_F ≤ ε_t로 제한한다. 외부 갱신이 없는 경우 ε_t=0으로 둔다. 검증된 명목 경로를 서버가 만들 수 없거나 합산 잔차 상한을 집행할 수 없는 경우 적용을 보류한다. ε_t는 정상 또는 악성을 구별하는 탐지 점수가 아니다. 강제 상한으로 정상 희소 기여가 잘릴 수 있으므로 절단률·수용률과 그 집단의 효용을 독립 정상 대조로 확인한다. 전체 백본 SGD, 변하는 BN, 사후 바뀐 배치, 교차 엔트로피 복구를 동일 경로로 간주하지 않는다.

3. 명제와 증명

후보 W_j를 같은 삭제 후 백본 위에서 생성하고 W_base도 후보에 넣는다. 구현의 생성기는 허용된 정답 자료로 제곱손실의 정규화 강도를 달리한 ridge 헤드를 만든다. α_j≥0, Σα_j=1로 W(α)=Σα_j W_j를 정의한다. 명목 복구는 아핀 함수이므로 모든 허용 시나리오·시점에서 W̄_t(α)=Σα_j W̄_t(j)다. 따라서 각 경쟁 클래스 c≠y에 대한 m_t(x,y,c)=(e_y−e_c)^T W̄_t φ(x)는 α의 선형식이다.

동일 시작점에서 명목 경로와 외부 추가 갱신이 있는 경로의 차이는 Σ_(u=1)^t E_u A_(u+1)…A_t다. 빈 곱은 I다. 각 항의 원래 정답 y와 경쟁 클래스 c의 점수 격차 변화는 Cauchy–Schwarz에 의해 √2 ε_u ||A_(u+1)…A_t φ(x)||₂ 이내다. 따라서

r_t(x) = √2 Σ_(u=1)^t ε_u ||A_(u+1)…A_t φ(x)||₂,
실제 정답 마진 ≥ Σ_j α_j m_(j,t)(x,y,c) − r_t(x).

모든 c≠y에 대해 우변이 고정 양의 값 γ 이상이면 해당 입력의 예측은 y로 유지된다. 이 명제는 여러 참여자가 연속으로 갱신을 제안하더라도, 합산된 잔차 상한과 선언된 실제 복구 연산이 지켜지는 경로에 적용된다. 한 시점의 안전을 뒤 시점의 안전으로 추론할 수 없음을 합성 반례로 검산한다. 고정 표본 집합에서 확인한 마진 하한의 보장이다. 미지 입력 전체의 정확도·공격 억제·삭제 인증은 별도 주장이다.

4. 실제 방어 선택 규칙

보호 집합의 모든 (x,y), 경쟁 라벨, 허용 시나리오, 교정 직후 t=0과 이후 t=1…H에 대해 위 하한 ≥γ를 선형 제약으로 둔다. 보호에 쓰지 않은 별도 정답 자료로 클래스·도메인별 교차 엔트로피를 계산한다. 같은 정답의 모든 경쟁 마진 오차가 r_t 이하이면 실제 교차 엔트로피는 명목 손실+r_t 이하다. 교차 엔트로피의 볼록성으로, 혼합 분류기의 명목 손실은 후보 손실의 가중평균 이하다. 그룹 g에 대한 후보 상한 L_(j,s,t,g)를 미리 계산해 z ≥ Σ_j α_j L_(j,s,t,g)를 추가하고 z를 최소화하는 선형 계획을 푼다. 하나의 α를 모든 그룹과 시점에 쓴다. 계산 후 실제 혼합 가중치에서 마진을 재검사한다. 해가 없거나 보호 범위가 충분하지 않으면 교정 후보를 반환하지 않는다. 같은 삭제를 반영한 대체 경로가 별도로 검증된 경우에만 그 경로를 사용한다.

삭제 조건. W_base, φ, 학습 자료, 후보 선택 기준 및 각 복구 연산이 모두 허용된 유지 정보와 독립 자료에만 의존하도록 구현해야 한다. 정확한 유지집합 재학습에서 시작하면 동일한 방어 후처리를 적용한 재학습 파이프라인과의 비교가 성립한다. 비방어 재학습과 동일한 출력이나 기존 근사 FU의 삭제 품질을 새로 보증하지 않는다. 유지 자료에 남아 있는 독성이나 고정 특징에 이미 있는 백도어는 별도의 실측 대상이다. 고정 표본에서 같게 예측하는 두 모델이 표본 밖 특징 좌표에서 다를 수 있으므로 미지 트리거 전체를 수학으로 배제할 수 없다.

5. 합성 검산과 실제 모델 진입 조건

합성 검산은 앵커만 시험한 후보가 공통 후속에서 정상 정답을 잃는 2차원 예, 잡음 한도 포함/제외의 혼합 차이, 서로 다른 순서의 아핀 경로, 실제 상한 적용, 보호 제약이 불가능한 경우, 후보 생성 ridge 해, 그리고 확인 범위 밖에는 인증이 이어지지 않는 반례를 본다. 후보·루틴·출력을 고정한 뒤 실행한다. 합성 자료, NumPy/SciPy float64, CPU, 네트워크에서 원모델 또는 공격 데이터 로드 없음이다.

실제 모델 가설은 미검증이다. P05의 19.336%·22.790% 큰 정상 탈퇴 및 정상850부터 점검한다. 같은 승인 끝점·같은 백본·후보·학습/교정 예산을 사용해 무교정, 교정 직후 제약만 적용, 전 구간 명목 제약, 잔차 상한을 포함한 전 구간 제약을 비교한다. 같은 평균 손실·보류율에서 최악 클래스·독립 잔류 도메인 이득을 확인한다. P05의 전체 2%p, 클래스·참여자 5%p, 유한 삭제 감사 한도를 유지한다. 독립 시험에서 보호 효과가 사라지거나, 실행 가능한 교정이 사실상 0이거나, 정상 보류·절단률로만 효과를 얻으면 중단한다. 정상 조건 통과 후에만 카탈로그로 승인된 모델의 보관 공격 입력에서 ASR·원래 정답 회복·후속 재오류를 평가한다. 실제 트리거·타깃·역할·ASR은 서버 선택에 제공하지 않는다. 삭제 기준, 보호 표본 마진, 공격 억제를 각각 보고한다.

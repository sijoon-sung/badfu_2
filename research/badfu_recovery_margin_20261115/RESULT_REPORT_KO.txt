2026-11-15 KST · 로컬 및 DISLAB CPU · 실제 모델 효능 미검증

가설. 동일 교정 후보와 예산에서 복구 미래 시점을 정답 마진 제약에 넣으면, 교정 직후에만 통과하는 후보를 걸러내고 큰 정상 탈퇴의 정상 기능을 더 오래 유지하면서 실제 공격 입력의 원래 정답 회복이 가능한 교정 영역을 남길 수 있다.

결과. 강건한 연합 언러닝 선행 7개를 정리하고, 복구 전 구간 마진 하한을 이용한 교정 선택을 구현했다. 사전 문서·코드를 초안 PR #2의 8301de4b8ccd96a768126b5205c755c3c4ee9e48에 공개한 뒤 동일 파일 해시로 두 환경에서 합성 검산을 각각 한 번 수행했다. 로컬 Python 3.11.17/SciPy 1.17.1과 DISLAB Python 3.12.10/SciPy 1.15.3에서 6개 항목의 실제 결과가 일치했다. 두 환경 모두 CPU float64/NumPy 1.26.4다. 실제 체크포인트를 로드한 횟수와 GPU 사용은 0이다.

같은 후보와 정답을 사용했다. 명목 및 상한 포함 비중의 경계는 독립 유리수 계산과 비교했다. 52.38%는 이 예의 최적 비중이다. 실제 모델의 추천 교정 비율로 사용하지 않는다. 순서가 교환되지 않는 복구 연산의 적용과 혼합의 아핀성, 누적 마진·대리 손실 상한, 추가 갱신 절단 및 0 예산, ridge 후보 생성의 정상방정식과 별도 정상 표본 회복, 불가능한 해 보류와 네 유형의 잘못된 입력 거부, 보호 범위를 벗어난 특징의 반례를 검사했다.

구성. recovery_margin.py의 make_candidates는 삭제 후 가중치와 허용 정답 자료에서 분류층 후보를 만든다. make_step은 선언한 유지 자료로 복구 연산을 고정한다. select_head는 동일 혼합 비중의 모든 보호 표본·시점별 마진을 검사하고, 최악 그룹의 검증 대리 손실 상한을 최소화한다. 해가 없으면 None을 반환한다. 복구 시에는 동일 순서의 make_step 결과를 apply_step에 전달해 서버 상한이 실제로 적용되도록 한다. 모든 특징은 동일한 삭제 후 백본을 사용하고 편향이 있으면 마지막 좌표를 1로 붙인다. 각 함수의 자료 행은 샘플이고 학습 가중치 행은 클래스다. proxy_groups는 사전 고정한 클래스·출처 그룹 ID 벡터다. 보호·최종 확인 자료가 충분한지와 기준 모델의 삭제 품질은 호출 시스템에서 사전 확인한다.

재현. 이 저장소 루트의 기존 환경에서는 .\envs\badfu-original\python.exe research/badfu_recovery_margin_20261115/verify_synthetic.py 명령으로 합성 검산을 실행할 수 있다. NumPy와 SciPy가 필요한 CPU 코드다. 공개 artifact의 FREEZE.json, VERIFICATION_LOCAL.json, VERIFICATION_DISLAB.json에 실행 내용과 실제 버전을 남겼다.

수학 범위. 도출한 하한은 선언된 아핀 복구와 실제 적용되는 잔차 한도를 전제로 보호 표본의 정답을 유지한다. 같은 클래스의 보호 특징들을 convex combination한 특징 벡터에도 같은 선형 마진 하한이 이어진다. 실제 입력의 의미 라벨이 그 집합 전체에서 유지되는지는 별도의 과제 가정이다. 관측하지 않은 특징 방향은 일반 보장을 받지 않는다. 검산은 실제 BadFU ASR, 정당한 큰 정상 탈퇴의 데이터 분포, 장기 전체 모델 복구에 대한 결론을 내리지 않는다. 삭제 인증 자체와 백도어 억제 성공도 별도로 남아 있다. 실제 검증의 첫 입구는 P05의 19.336%·22.790% 정상 탈퇴와 동일 예산의 직후 제약 대조다.

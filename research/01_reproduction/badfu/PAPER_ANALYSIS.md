# BadFU 첫 독해

출발 문헌은 [BadFU arXiv v1](https://arxiv.org/html/2508.15541v1)이다. 기존 자체 실험의 성공·실패를 이 논문의 결론으로 승계하지 않는다.

[최신 재검증](PRE_ASR_REAUDIT.md)은 원문의 삭제 전 ASR·Dirichlet α와 실제 실행 조건을 대조하고, 같은 시작 모델에서 위장 배치를 바꾼 새 학습 결과를 정리한다.

## 논문의 핵심 구성

| 항목 | 저자의 설정 또는 결과 | 원문 위치 |
|---|---|---|
| 공격 권한 | 한 참여자가 로컬 데이터와 실제 학습된 데이터의 삭제 요청을 제어 | IV |
| 트리거의 범위 | BadNet의 국소 패치와 Blended의 영상 전체 워터마크 혼합을 각각 실험. BadFU 자체가 특정 패치 모양을 뜻하지 않음 | VI C, Table II와 IV |
| 독성 샘플 | 트리거와 타깃 라벨 | 식 5 |
| 위장 샘플 | 같은 트리거와 원래 라벨 | 식 6 |
| 작동 설명 | 손실과 갱신을 정상·독성·위장 항으로 분해 | 식 7과 8 |
| 대표 관측 | CIFAR-10 ResNet-18 BadNet ASR 21.55% → 재학습 99.32%, FedEraser 90.76% | Table I |
| 정상 삭제 대조 | 해당 CIFAR-10 BadNet ASR 21.55% → 10.22% | Table V |
| 방어 평가 | Median·Trimean과 Neural Cleanse를 시험 | VII G |

BadFU의 핵심은 **독성·위장 자료를 함께 학습한 뒤 위장 자료만 삭제하는 공격 절차**다. 국소 패치는 그 절차 안에 넣는 트리거의 한 종류다. Blended는 $T(x)=(1-\rho)x+\rho v$로 전체 무늬 v를 섞는다. 보존된 BadNet 준비 경로에는 위장 자료에 UBA-Inf 입력 교란을 추가하는 단계도 있으나, 이것을 Blended 트리거 자체와 혼동하지 않는다. [트리거 범위와 진단의 미탐 조건](../../03_detection/PATCH_VALIDITY.md).

## 여기서 바로 성립하지 않는 결론

손실을 세 항으로 쓰는 것만으로 서로 반대 방향의 갱신이나 위장 삭제 후 ASR 상승을 증명하지는 못한다. 전체 학습 경로와 시험 입력의 마진이 필요하다. 본문의 방법 설명은 공격을 이해할 출발점이지만 일반적인 활성화 충분조건과 신경망 방어 보장을 제공하는 정리로 읽을 수 없다.

이번 검토에서는 [두 특징의 선형 모형](../../04_theory/README.md)에 한해 독성·위장 수와 정규화 강도로 표현한 활성화 충분조건을 증명했다. 이는 원논문의 이론을 대신하는 신경망 증명이 아니라, 어떤 가정을 더해야 엄밀한 주장을 할 수 있는지 보여주는 첫 단계다.

정상 삭제 대조의 관측은 모든 정상 삭제의 안전성 정리가 아니다. 삭제 전 ASR이 0도 아니므로 잠복은 수치 기준을 먼저 정해야 한다. 특정 방어의 실패를 전체 방어의 불가능성으로 확대하지 않는다.

## 처음 검증할 가설

독성 샘플이 유지될 때 위장 삭제의 효과가 커지는가. 동일 시작 모델에서 위장만 삭제·독성만 삭제·양쪽 삭제·정상 대조 삭제를 비교한다. 삭제 없는 동일 예산 추가 학습도 넣어 단순 학습 연장의 효과를 구분한다.

# 처음 수행할 BadFU와 FUBA 검증

목적은 논문의 현상이 있는지, 실제 FU의 오차인지, FU 중 새 공격의 효과인지를 구분하는 것이다. 기존 저장 실험의 결론을 새 확인 결과로 세지 않는다.

## 검증 단계와 현재 상태

| 단계 | 무엇을 검증하는가 | 현재 상태 |
|---|---|---|
| 수식 | 삭제와 안전성의 관계 및 활성화 구성 예 | 명제와 증명 작성, 삭제 항등식 300조건·활성화 공식 1,200조건 검산 |
| 코드 함수 | 집계·FU 정규화·평가 분모와 선택 규칙 | 작은 CPU 입력 5항목 및 정적 코드 2항목 확인 |
| 실행 연결 | 데이터 생성·분할·체크포인트·원문 지표 대응 | 아래 설정을 기준으로 동결할 단계 |
| 이미지 실험 | CIFAR-10에서 삭제 전후 현상 재현 | 이번 재출발 검토에서는 새로 수행하지 않음 |
| 방어 | 같은 자료·계산·정상 기능 제약의 비교 | 가설 단계. 두 공격 방어 성공 미확인 |

## BadFU 학습 조건

N은 정상 데이터, P는 독성 샘플, C는 위장 샘플이다. 샘플의 원본 ID, 가공 ID, 라벨 변경, 소유 참여자와 중복을 기록한다.

| 조건 | 학습 데이터 | 필요한 이유 |
|---|---|---|
| 깨끗한 학습 | N | 트리거 모양 자체의 자연 오분류와 정상 성능 기준 |
| 일반 백도어 | N∪P | 위장 없는 활성 공격 기준 |
| 위장만 포함 | N∪C | 위장 데이터 자체가 만드는 변화 |
| 독성과 위장 포함 | N∪P∪C | 논문의 활성화 전 조건 |

같은 N, 공격 원본 풀, 시드 분리 원칙과 모델 초기화를 사용한다. 단일 실행의 세부 요청을 독립 시드로 세지 않는다. 독립 반복에서는 분할·모델 학습의 변동과 공격 데이터 생성의 변동을 구분한다.

## 동일한 삭제 전 모델에서 만들 비교

1. 삭제 없이 동일한 추가 학습 예산을 사용한다.
2. C만 삭제한다.
3. P만 삭제한다.
4. P와 C를 함께 삭제한다.
5. 삭제 수와 클래스 구성을 맞춘 정상 샘플을 삭제한다.
6. 정상 참여자 전체를 삭제한다. 샘플 삭제와 다른 단위로 보고한다.

각 요청에서 유지 데이터로 처음부터 재학습한 모델과 해당 FU 알고리즘을 구분한다. 저자 코드형은 분리된 위장 참여자 제거이며 논문 본문형은 한 참여자 내부 부분 삭제다. 둘 중 하나를 조용히 다른 것으로 치환하지 않는다. 저자 설정의 구현 차이를 바꾸면 원본 재현과 수정 실험으로 별도 이름을 부여한다.

## FUBA의 추가 분리

동일 FL 종료 모델에서 Adv-defender 삭제를 비교하되, 남은 공격자의 FU 업데이트를 정직한 학습으로 고정한 조건과 공개 코드처럼 악성 학습하는 조건을 나눈다. 후자는 기존 독성의 드러남과 새 주입을 모두 포함할 수 있다. FL 중 방어, FU 중 갱신 검사, FU 후 정화를 서로 다른 조치로 평가한다.

FUBA의 공격 강도 탐색 자료와 최종 평가 자료를 분리한다. 공식 본문·보충자료 확보 전에는 초록의 보편적 표현을 실험의 모든 가정으로 대신하지 않는다.

## 평가를 잠글 항목

- 정상 정확도와 클래스별 정확도, 삭제 전후 ASR 및 변화량을 함께 보고한다. ASR은 원래 타깃 클래스를 제외하고 원본 라벨로 제외 여부를 판단한다.
- 잠복은 두 수준으로 보고한다. 원문 정의와 별도로, 깨끗한 학습의 같은 트리거 반응 대비 어느 정도인지 기록한다. “삭제 전 ASR 0”을 기본 가정으로 두지 않는다.
- 공격 데이터를 아는 오라클 진단과 트리거·타깃을 모르는 방어를 분리한다. 실제 트리거는 방어 학습·임계값·후보 선택 이후 평가에만 사용한다.
- 탐지는 정상 오탐과 공격 탐지를 동시에 기록한다. 부정확한 FU나 비공격 대조를 무조건 정상이라고 표시하지 않는다.
- 정화는 정상 정확도 손실과 삭제 품질의 경험적 지표를 함께 기록한다. 유지 재학습과 유사하다는 지표가 보안을 보장하지는 않는다.
- 코드 해시·자료 분할·공격 생성·초기값·BN·환경·시드·중단/완료 상태를 저장한다. 결과를 보고 시드나 요청을 제외하지 않는다.

## 첫 이미지 실험의 진행 조건

먼저 한 데이터셋과 한 모델에서 원문형과 코드형 중 무엇을 실행할지 확정한다. 위 네 학습 조건과 요청 대조의 연결이 맞는지 확인한 뒤, 사전에 고정한 독립 시드 집합으로 확장한다. 연결 검사에서 재현 조건이 틀리면 방어 실험의 성능 경쟁으로 넘어가지 않는다.

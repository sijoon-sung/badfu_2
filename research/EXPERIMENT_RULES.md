# 가설을 먼저 쓰는 실험 정리 원칙

모든 새 실험과 수학 검증은 **한 줄의 가설 한 문장**으로 시작한다. 조건·결과·판정은 그 아래에 쓴다. 교수 미팅에서도 연구 주장과 그 주장을 반증할 실험을 먼저 보여준다.

## 제안·해석·실행 전 필수 확인

1. [연구 실험 인덱스](INDEX.md), [관련 실험 카드](EXPERIMENT_CARDS.md), 연결된 원 보고서와 정정을 읽는다. 관련 카드 ID를 새 제안·프로토콜에 남긴다.
2. **큰 정상 non-IID 탈퇴와 공격이 겹친 기존 반례를 먼저 설명한다.** 전후 차분·정상 참조·클래스 균등·협조자·함정을 추가했다는 사실은 해결 근거가 아니다. D02/D06/D07/D08/D15를 대조한다.
3. 새 관측을 실제로 어떻게 얻는지, 기존 반례와 어떤 검증 가능한 차이가 생기는지, 구별 실패 시 중단할 기준을 쓴다. 아직 근거가 없으면 미검증·보류로 표시한다. 기준 모델을 추가하는 N01도 이 조건을 따른다.
4. 결과를 [구조화 목록](experiment_registry.json)의 기존 카드 또는 새 카드에 연결하고 인덱스를 갱신한다. 원 보고서·실패 수치·모델 경로를 보존한다. `index_tools/rebuild_index.py --check`로 링크·문서 출처·생성본 일치를 확인한다.

## 공통 형식

```text
가설: [변경한 요인]은 [비교 대상]보다 [평가 지표]를 개선한다.
기존 근거: 관련 카드 ID / 기존 non-IID 반례 / 새 관측의 차이와 획득 조건.
조건: 서버가 얻는 정보 / 실제 모델의 출처 / 데이터와 삭제 단위 / 정상 non-IID 설정.
비교: 바꾼 요인 하나와 고정한 요인, 기준 방법, 별도 정상 보정 자료.
결과: 공격 탐지 건수/공격 요청 수, 대조 경보 건수/대조 요청 수, 독립 학습 수와 그래프.
판정: 지지 / 기각 / 조건부 증명 / 미검증 중 하나와 적용 범위.
반증 기준: 어떤 결과가 나오면 가설을 버리거나 좁힐 것인가.
```

- 한 가설에 ‘탐지·공격자 식별·정화’를 함께 넣지 않는다.
- ‘차분이 좋은가’처럼 모호한 질문 대신 어떤 반응의 차분이 어떤 정상 변화를 제거하는지 쓴다.
- 수학은 **가정 → 명제 → 증명 또는 반례 → 적용 범위**를 붙인다. 대수적 항등식을 실제 신경망 탐지 성능의 증명으로 바꾸지 않는다.
- 과거 FC·Conv 결과를 해석할 때도 **같은 대조 경보율에서 공격을 더 찾는지**를 구분한다. 이는 새 변화량 실험을 재개하라는 지시가 아니다.
- 2026-10-23 사용자 지시: 단순 변화량을 새 탐지 방법으로 제안하지 않는다. 파라미터/FC/Conv norm, cosine, CKA, RMS, 민감도 등 이름을 바꿔 같은 주장을 반복하지 않는다. 기존 관측은 보존하되 paired-probe H3의 후기 층 변화량 추천은 철회한다.
- 새 탐지 실험은 실제 공격 행동의 재현 여부를 검증해야 한다. 그 행동이 정상 큰 non-IID 탈퇴에서도 발생할 수 있는 이유와 중단 기준을 먼저 쓴다. 독립 정상 보정이 없으면 공격 판정 임계값이나 탐지 성공률을 만들지 않는다.
- 진단용 모델 편집은 후보를 찾기 위한 수단이다. 편집한 모델의 붕괴·손실 증가·변화량을 공격 증거로 삼지 않고, 후보를 고정한 뒤 수정하지 않은 승인 모델과 별도 정답 자료에서 확인한다. 입력 변형의 의미 보존도 별도 가정/검증으로 명시한다.
- 실행 중에는 결과를 ‘미완료’로 둔다. 가설·패턴·타깃·임계값을 확인 자료의 ASR에 맞춰 바꾸지 않는다.
- 공격 구성 여부와 실제 기능 위험을 별도 정답으로 보존한다. 잠복 성공 사례만 골라 전체 공격 탐지율로 보고하지 않는다.
- 84요청·12개의 시드와 분포 조합·10개 시드를 서로 바꿔 쓰지 않는다. 불확실성은 공유 모델과 학습 실행 단위로 다룬다.
- 실제 FU 모델, 유지 데이터 재학습 기준 모델, R/F 추가 학습 진단 모델, 단순 갱신 제외 모델을 구별한다.
- 그림은 어떤 가설을 검증하는지 제목에 쓰고, 축·단위·분모·자료 범위를 표시한다. 미검증 가설은 결과 그래프 대신 관계도로 표시한다.

## 교수 미팅의 순서

| 순서 | 보여줄 내용 | 핵심 질문 |
|---|---|---|
| 1 | 연구 주장 한 문장 | 무엇을 새로 알아내려는가 |
| 2 | 가장 가까운 선행 방법과 관측된 한계 | 이미 한 일과 남은 문제가 무엇인가 |
| 3 | 제안 방법과 서버 관측 조건 | 실제 구할 수 있는 정보로 가능한가 |
| 4 | 가설 한 줄로 시작하는 검증 카드 | 어떤 결과가 주장을 지지하거나 반박하는가 |
| 5 | 현재 판정과 다음 반증 실험 | 어디까지 주장하고 무엇을 더 확인할 것인가 |

현재 실험 판정은 [연구 인덱스](INDEX.md)를 우선한다. [2026-10-20 연구 주장과 검증 카드](05_meetings/20261020/CLAIM_BOARD.md)는 당시 미팅 형식과 주장의 기록이다.

# 주요 논리에서 제외한 시도

실행 실패나 음성 결과도 재시도를 막는 근거는 남긴다. 현재 질문을 지지하지 않는 세부 기록을 본문에 모두 펼치지는 않는다. 다음은 영구적인 무용성 판정이 아니라 이번 연구 범위에서의 선별이다.

| 묶음 | 앞에서 제외한 이유 | 남길 교훈 |
|---|---|---|
| 갱신 집중도·코사인 부호·부분공간 정렬·직접 차분 | 초기 대조의 범위가 겹치거나 공격 고유성 부족 | 변환을 바꾸는 것만으로 식별되지 않음 |
| 무작위 배경으로 패치 검사 대체 | 기존 신호를 유지하지 못함 | 정상 입력의 역할을 없앴다고 주장할 수 없음 |
| 타깃 로짓 마스킹·특이성분 제거 | 원래 정답 복구 또는 정상 성능 보존 실패 | 공격 억제와 정상 기능 복원을 구분 |
| 요청 조건부 독성 샘플 식별과 추가 제외 재학습 | 단순 기준선보다 약하고 시드 의존적 | 탐지 신호가 곧 샘플 위치는 아님 |
| 전체 클라이언트 삭제 강제 | 효과와 권한을 검증하지 않은 아이디어 | 동일 크기 비공격 대조 삭제와 혼동 금지 |
| 순차 삭제 색감·질감 모형 | 고정 특징 학습기 범위의 중간 위험 | 실제 전체 신경망 FU의 결론으로 확대 불가 |

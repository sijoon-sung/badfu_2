가설: 정상 기능을 약화한 진단용 복사본에서 탐색하면, 수정하지 않은 실제 모델에서 재현되는 활성화 오류를 더 발견하고 큰 정상 탈퇴와 구별한다.

실험 상태
이 문서는 실행 조건 설명이다. 완료 여부와 판정은 COMPLETE.json, INDEPENDENT_REPLAY.json, RESULTS_KO.txt에서 확인한다.
실행 전 PROTOCOL.json에 조건·입력 체크포인트·탐색 코드의 해시를 고정했다. 이 설명 및 사후 보고 코드는 탐색기를 수정하지 않는다.

어떤 행동을 찾는가
서버가 보유한 삭제 전 모델 f_pre와 삭제 후 모델 f_post, 정상 이미지의 정답 y를 사용한다.
동일한 변형 규칙 T와 탐색으로 정한 표적 클래스 c에 대해 다음 네 조건을 모두 만족하는 이미지를 센다.
f_pre(x)=y, f_post(x)=y, f_pre(T(x))=y, f_post(T(x))=c, 단 y≠c.
새 확인 이미지 여러 장에 같은 규칙 T를 적용한다. 이미지마다 정답을 보며 별도로 최적화하지 않는다.
분모는 표적 외 9개 클래스의 전체 확인 이미지 900장이다. 원본을 모두 맞히는 표본 수는 별도로 보존한다.
이 수치는 실제 공격 트리거의 ASR이나 공격 확률이 아니다. 정상 모델에서도 생길 수 있는 기능적 오류의 재현 비율이다.
FC·Conv 변화량, 노름, 확률 차분을 공격 판정 점수로 사용하지 않는다.

비교 절차
직접400: 수정하지 않은 삭제 후 모델에서 변형 후보를 400회 최적화한다.
직접800: 동일한 탐색 경로를 800회까지 연장한 사전 지정 비교군이다.
노출400: 삭제 후 모델의 진단용 복사본에서 정상 정답 손실을 높인 뒤 변형 후보를 400회 최적화한다.
세 방법 모두 수정하지 않은 원래 삭제 전·후 모델의 별도 선택 자료에서 후보를 정한다.
모든 후보 선택을 잠근 다음, 별도 공개 확인 자료와 정상 협조 참여자 자료에서 재검사한다.
진단용 모델의 붕괴 자체는 공격 증거로 세지 않는다. 복사본에서만 생긴 오류는 원래 모델의 성공으로 세지 않는다.

추가로 필요한 조건
서버는 삭제 전·후 글로벌 모델과 입력 기울기에 접근할 수 있어야 한다.
정상 라벨이 있는 공개 자료와 진단용 복사본을 만드는 계산 여유가 필요하다.
별도 확인에는 정상이라고 신뢰하는 참여자 1·2·3의 각 512개 자료를 사용하는 상황을 모사했다.
협조 참여자 자료는 후보 선택 이후에만 사용한다. 원래 FL 학습에 포함된 자료이며 새로운 독립 학습 표본은 아니다.
Paper32 정상850삭제 기록은 모든 비교에서 협조 자료에서 제외한다.
개별 이미지·인덱스·모델·탐침 가중치는 DISLAB에 남긴다. 로컬로는 집계 결과와 그래프만 가져온다.

입력 모델과 대조군
실제 FL 학습 시드: 20261020, 20261023. 두 시드는 같은 데이터 분할을 사용한다.
q00: 시드20261020, 공격 위장850개 삭제 전후.
q01: 같은 시드의 감염 모델에서 정상850개 삭제 전후.
q10: 시드20261023, 공격 위장850개 삭제 전후.
q11: 같은 시드의 정상 모델에서 정상850개 삭제 전후.
q12: 같은 시드의 정상 모델에서 가장 큰 참여자4의 9,668/50,000개(19.336%) 삭제 전후.
각 삭제 후 모델은 유지 자료 전체 재학습 결과다. 근사 FedEraser로 명명하지 않는다.
q12는 큰 정상 non-IID 탈퇴 대조이며, 공격850개 삭제와 삭제량까지 같게 맞춘 인과 실험은 아니다.
FUBA는 승인된 잠복 활성화 전후쌍이 없어 이번 실험에 포함하지 않는다.

자료와 탐색 예산
이전 paired-probe 실험에서 사용한 공개 이미지1,640개를 제외하고 새로 균등 분할한다.
노출500장, 탐색320장, 선택320장, 최종 확인1,000장은 서로 겹치지 않는다.
그러나 CIFAR 전체 테스트 자료는 과거 모델 평가에 사용된 적이 있어 연구 전체의 완전히 새로운 외부 검증 세트는 아니다.
마스크: 위치를 지정하지 않고 연속 마스크 총량≤16, 패턴값0~1.
가산 변형: 이미지 전체에 공통인 변형, L∞≤0.04.
입력 의존 변형: 같은 고정 생성 규칙이 새 이미지에 적용됨, L∞≤0.04.
모든10개 표적, 두 탐색 초기값, 세 변형 종류를 각 방법에 똑같이 적용한다.
원래 공격 위치·표적·생성기·ASR은 탐색에 제공하지 않는다.
진단 노출은 최대20에포크, 정답률10% 이하 또는 손실40 이상에서 중단한다. 복사본만 갱신한다.
노출400과 직접400의 입력 탐색 횟수는 같지만 노출 비용이 추가된다. 직접800도 정확히 같은 연산량 비교는 아니다.

큰 정상 탈퇴의 행동 비율과 공격의 행동 비율이 겹치면 이번 구별 가설을 기각한다.
노출 복사본에서만 잘 작동하면 원본으로의 재현 실패다.
탐색 실패는 원래 모델이 안전하다는 뜻이나 모든 탐지가 불가능하다는 증명이 아니다.
자료 두 시드·큰 정상 탈퇴 한 건으로 운영 임계값, 오탐률, 탐지율을 산출하지 않는다.

이번 경로가 실패하면 층·거리·가중치의 사후 변경으로 성공을 만들지 않는다.

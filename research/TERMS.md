# 공통 용어

| 용어 | 사용할 의미 |
|---|---|
| 정상 데이터 N | 공격을 위해 가공하지 않은 학습 데이터 |
| 독성 샘플 | 트리거를 넣고 공격 타깃 라벨을 부여한 샘플 |
| 위장 샘플 | 같은 트리거를 넣고 원래 라벨을 유지한 샘플 |
| P와 C | 각각 독성 샘플 집합과 위장 샘플 집합. BadFU 위장 삭제에서 R=N∪P, F=C |
| 트리거 | 입력에 적용해 특정 오분류를 유도하는 패턴 또는 변환 |
| 입력 패치 또는 국소 패치 | 입력 영상의 일부 영역을 정해진 색·무늬로 대체하는 변환. 실제 공격 트리거와 같다고 가정하지 않음 |
| 진단 입력 또는 probe | 모델 반응을 검사하기 위한 입력. 악성 입력이라는 의미가 아님 |
| 패치 반응 | 같은 모델에서 국소 변환 입력과 원본 입력의 타깃 확률 또는 로짓 차이. 확률·로짓 중 무엇인지 명시 |
| 이중 차분 | 변형 입력과 원본 입력의 반응 차이를 두 모델 사이에서 다시 빼는 측정. non-IID 제거·인과 식별을 자동 보장하지 않음 |
| 트리거 역추정 또는 trigger inversion | 특정 타깃으로 예측하게 만드는 입력 패턴·마스크를 최적화해 찾는 과정. 고정 후보군 진단과 구분 |
| 백도어 노출 또는 backdoor exposure | 모델을 변형해 숨은 백도어 기능을 드러내는 진단 |
| 앞단 특징 변화 | 분류층 직전 특징의 변화. Conv 외에 BN 등도 포함되므로 순수 Conv 인과 효과라 부르지 않음 |
| ASR | 원래 타깃 클래스가 아닌 시험 입력에 트리거를 적용했을 때 타깃으로 예측하는 비율. 원문과 다른 분모는 함께 명시 |
| 잠복 | 삭제 전 공격이 억제된 상태. 삭제 전 ASR과 깨끗한 학습 기준을 함께 제시하며 0을 자동 가정하지 않음 |
| 유지 데이터 재학습 | 삭제 후 남은 데이터로 고정된 학습 알고리즘을 처음부터 다시 실행하는 비교 기준 |
| 유지 데이터 R | 삭제 후에도 남는 데이터. 요청자 내부인지 전체 집합인지 명시 |
| 삭제 대상 데이터 F | 이번 요청이 지우려는 데이터 |
| 저손실 정상 샘플 삭제 | 삭제 전 정상 모델의 정답 라벨 CE가 낮은 순으로 클래스 안에서 선택 |
| 고손실 정상 샘플 삭제 | 같은 CE가 높은 순으로 선택. 반드시 오답인 샘플이라는 뜻은 아님 |
| 층화 무작위 삭제 | 같은 클래스별 할당량 안에서 무작위 선택 |
| 비공격 대조 삭제 | 비교를 위해 구성한 비공격 조건. 안전성이 보장된다는 뜻은 아님 |
| 진단 복제 모델 | R 또는 F로 검사하기 위해 학습한 복제본. 실제 FU와 구분 |
| 실제 FU | 지정한 언러닝 알고리즘으로 얻은 삭제 모델. 차감 대용 연산과 구분 |
| 요청 건수 | 35/36의 분모 36은 검사한 요청 수. 삭제 샘플 수나 독립 FL 시드 수가 아님 |
| 정화 성공 | 공격 완화와 정상 성능 및 삭제 목표를 함께 평가한 결과 |
| FUBA | 공식 명칭 FUBA를 사용. Adv-attacker와 Adv-defender는 모두 공격 체계 내부 역할 |
| 오라클 진단 | 실제 트리거·독성 ID 등 방어자가 모르는 정답 정보를 제공한 가능성 검사 |

저손실·고손실·층화 무작위 비교는 클래스별 삭제 수를 맞춘 조건이다. 손실은 특정 모델과 시점에서 계산한 상대 순위다. 미래 결과를 보고 기준을 바꾸지 않는다.

“쉬운 자료·어려운 자료” 대신 선택 기준을 쓴다. “35/36”만 쓰지 않고 “위험 요청 탐지 35건 / 공격 요청 36건”처럼 분자·분모의 대상을 적는다. 요청·샘플·참여자·독립 학습 시드의 수를 서로 바꿔 쓰지 않는다.

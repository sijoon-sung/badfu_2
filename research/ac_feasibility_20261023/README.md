# A/C 사전 검증 — 2026-10-23

**모델 선택 정정:** 이번 실행은 낮은 삭제 전 ASR을 갖춘 DISLAB 5인 재현 모델 대신, 사전 ASR 약80%인 과거 seed42 6인 분리형을 선택했다. 이 선택은 목표 검증에 부적합했다. 결과는 실행 경로 점검으로만 보존하고, 목표한 잠복 공격에 대한 A/C 가설 판정에서는 제외한다. [출처 재감사](SOURCE_AUDIT.json)에 실제 DISLAB 파일·해시와 올바른 재현 모델의 기존 전체 평가를 기록했다. 확인된 Paper32 전후 ASR은16.14%→99.99%, 추가 seed20261023의 기존 전체 평가 기록은14.29%→100%다. 이 올바른 모델로 A/C를 다시 실행한 결과는 아직 없다.

가설 C: 실제 잔류 참여자의 정상 데이터에서 삭제 전후 손실 변화의 집단 간 분산은 위장 참여자 삭제 때 정상 참여자 삭제보다 커진다.

가설 A1: 정상 활성도가 낮은 마지막 특징 채널의 5%·10%를 가리고 정상 데이터로 미세조정하면, 삭제 후 ASR을 정상 정확도 손실 2%p 이내에서 낮춘다.

가설 A2: 분류기 헤드를 재초기화하거나 10% 섞어 교란한 뒤 삭제 전 모델의 정상 출력으로 증류하면, 같은 정확도 제약에서 ASR을 낮춘다.

각 가설을 별도로 판정한다. 실행 성공과 방어 성공을 구분한다.

## 판정과 반증

A의 작은 선별 기준은 **정상 자료로 선택한 후보의 평가 ASR≤10%, 무처리 대비 평가 정확도 하락≤2%p**다. 전체 후보의 곡선은 원인 진단용이며 ASR로 선택한 방법을 서버 방법으로 제시하지 않는다. 평가400장은 작은 진단 표본이고 이전에 노출된 자료이므로 새로운 확증 시험이 아니다.

C는 공통 집단에서 공격 삭제의 분산이 정상 삭제보다 작거나 같으면 이 체크포인트에서 제안한 방향성이 지지되지 않는 것으로 판정한다. 커도 독립 정상 보정·별도 확인 집합이 없으므로 TPR/FPR이나 일반 탐지 성공을 주장하지 않는다.

유망한 결과가 있어도 삭제 크기·시작 모델을 맞춘 정상 대조, 최대 정상 참여자 삭제, 독립 FL 시드, 보류 로컬 자료, FUBA 재현이 필요하다. 기존 FUBA 재현은 진행 중이어서 이 사전 검증이 FUBA 방어를 검증했다고 보지 않는다. 삭제 전 교사는 삭제할 정보의 영향을 전달할 수 있으므로 증류의 공격 억제와 망각 품질은 별개다.

## 제안문에서 정정할 주장

| 기존 표현 | 검증 가능한 표현 |
|---|---|
| 이력 탐지는 완전히 닫힌 문 | 기존 점수의 오탐과 겹침을 확인했다. 모든 이력 방법의 불가능성 증명은 아니다. |
| 정상 탈퇴는 잔류 손실이 안정적 | 정상 non-IID 변화도 참여자별 손실 분산을 만들 수 있다. 별도 대조로 시험한다. |
| 백도어 활성화는 정상 입력의 로짓 충격을 필연적으로 만든다 | 정상 출력이 모두 같은데 트리거 ASR만0→100인 명시적 반례가 있다. |
| 단순 GD 실패는 강한 국소 최솟값 때문이다 | 현재 자료는 미세조정 실패만 보여준다. 손실 지형의 원인은 측정하지 않았다. |
| 백도어 채널은 반드시 정상 데이터에서 휴면한다 | Fine-Pruning을 시험할 가정이다. BadFU layer4에서의 사실로 확인되지 않았다. |
| pre 교사가 정상 경계와 안전한 망각을 보장한다 | 정상 출력 증류는 트리거 밖의 행동과 삭제 품질을 보장하지 않는다. |

Fine-Pruning은 기존 방어 후보다. [원논문](https://arxiv.org/abs/1805.12185)은 pruning과 fine-tuning을 결합한 실증 결과를 제시하며, 여기의 BadFU·FUBA 성공을 보장하지 않는다. [지식 증류 원논문](https://arxiv.org/abs/1503.02531)도 삭제 보장 정리로 사용하지 않는다.

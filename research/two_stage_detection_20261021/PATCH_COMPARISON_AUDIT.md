# 패치 성능이 달라 보인 이유와 실제 언러닝 전후 결과 재점검

기준일 2026년 10월 21일

## 결론

**기존 패치 방법이 갑자기 작동하지 않게 됐다는 결론은 잘못이다. 직전 검사는 비교 모델과 점수 정의가 달랐다.** 특히 주 결과에서 실제 언러닝 후 모델을 마지막 라운드의 제출 하나를 제외한 모델로 바꿨고, 역할 추정의 실패까지 함께 설명했다. 이 결과로 실제 언러닝 전후 패치 비교를 기각할 수 없다.

보존된 실제 전후 결과는 계속 유효하다. BadFU Paper32에서 위장 삭제 반응 차분은 77.33%p, 같은 pre 모델의 정상 삭제는 1.65%p였다. 이전 84요청의 고정 점수도 다시 계산해 공격 11/12, 대조 경보 3/72가 그대로임을 확인했다. **clean 기준 자료 의존성과 신규성 확보가 주요 고민이라는 기존 판단은 유지된다.**

## 1 무엇을 바꿨는가

| 구분 | 이전 좋은 결과의 조건 | 직전 체크포인트 파일럿 | 결론에 주는 영향 |
|---|---|---|---|
| 실제 전후 모델 | pre와 실제 보존 데이터 재학습 post | 전역 모델과 마지막 제출 하나를 제외한 집계가 주 비교 | 삭제로 풀리는 과거 전체 억제를 직접 측정하지 않음 |
| 옛 84요청 진단 | pre에서 R F를 각각 추가 학습한 두 진단 갈래 | R F 진단 갈래를 만들지 않음 | 예전에 효과가 있던 대조 정보가 빠짐 |
| 패치 선택과 점수 | 양의 활성화 증가 또는 두 갈래의 동시 증가 | 참여자별 절댓값 방향 선택 최대값 및 별도 상쇄 점수 | 같은 방법의 동일 조건 재현이 아님 |
| 공개 입력 예산 | 84요청은 선택 200 확인 200, 최근 실제 전후는 160 160 | 선택 80 확인 80 | 표본 변동이 달라질 수 있으나 단독 원인은 미분리 |
| 고정 패치 후보 | 옛 4×4 무작위 패턴 포함, 최근 전후는 3×3 5×5 | 3×3 5×5 검정 흰색 체커 RGB | 후보가 바뀐 효과를 별도로 입증하지는 않음 |
| Conv FC | 실제 전후의 FC 특징 및 별도 Conv 기능 비교 존재 | 직전 새 추론에는 FC 특징을 수집하지 않음 | FC Conv 전후 방법의 재실행 실패라고 할 수 없음 |
| 1단계와 2단계 | 모델 위험 신호와 역할 식별은 별도 검증 | 부호를 ID 역할로 해석하는 추가 검사 포함 | 역할 오지목은 패치 전후 위험 신호의 실패와 다름 |

위 변경이 모두 발생했으므로 전체 성능 차이를 어느 한 요인 탓으로만 돌리지 않는다. 아래에서는 입력과 점수를 고정하고 **비교 모델 축만** 바꾼 대조를 검산했다.

## 2 같은 입력에서 비교 모델만 바꿔 본 결과

**가설: 같은 pre 모델과 같은 패치를 써도 실제 FU 결과를 최신 제출 제외로 대체하면 활성화 신호가 약해진다.**

조건은 보존된 BadFU full6 실행이다. 같은 공개 이미지 320장, 선택 160장 확인 160장, 같은 32패치, 같은 pre, 같은 후보 클래스 0과 오른쪽 아래 3×3 체커를 고정했다. 로컬에 저장된 로짓 특징 출력으로 다시 계산했다.

| 비교 | 패치 확률 반응의 차분 | FC 이전 특징의 로짓 반응 기여 |
|---|---:|---:|
| pre → 기존 실제 FU 결과 | **19.66%p** | **2.538** |
| 같은 pre → 마지막 위장자 제출만 제외 | **2.55%p** | **0.677** |

최신 제출 하나를 제외하는 연산은 전체 학습에서 쌓인 그 참여자의 영향을 삭제하지 않는다. 따라서 “삭제 후 억제가 풀리는가”에 대한 실제 FU 모델의 신호를 그대로 대표할 수 없다. 이 사례에서는 입력이나 후보를 바꾸지 않아도 신호가 크게 달라졌다.

FC와 앞단 특징 분해의 최대 재구성 오차는 2.7×10⁻¹⁴ 미만이었다. 특징 항에는 Conv와 BN 등 FC 이전 전체 경로가 들어간다. 두 비교 모델 간 차이는 이 사례에서 직접 확인했지만, FUBA 파일럿의 모든 실패 원인을 이 하나로 증명한 것은 아니다. [원본 출력 대조 재계산](comparison_audit_v1/model_axis_control.json)

## 3 예전 성공 결과가 사라졌는가

### 84요청의 R F 진단

**가설: 보존된 원래 점수식을 그대로 적용하면 이전의 탐지 결과가 재현된다.**

원 코드에서 점수식 `max(0,min(retained_gain,branch_contrast))`와 임계값 0.006을 직접 읽어 저장된 84개 대비값의 판정을 다시 계산했다. 결과는 공격 11/12, 대조 3/72, 기술적 AUROC 0.9896으로 이전과 일치한다. 유지 갈래만 쓰면 대조 경보가 16/72였으므로, 두 갈래를 대조한 이점도 보존돼 있다.

이것은 점수 산술과 판정의 재계산이다. 원래 84개 모델의 학습과 로짓 추론을 다시 수행한 것은 아니다. 대조 72개는 여러 비공격 요청 구성이며 독립 정상 학습 72회가 아니다. 당시 방법에는 공개 clean 외에 요청자의 R F 자료와 진단 학습도 필요했다. [재계산](comparison_audit_v1/legacy_patch_replay.json)

### 실제 언러닝 전후의 패치

아래는 기존 완료 실행의 공개 입력 확인 점수다. 각 후보는 선택 자료에서 정하고 확인 자료에 고정했다. 이번에는 로컬에 전달된 클래스별 평균의 산술을 재검증했다. 원본 모델과 전체 특징 배열은 원격 실행기에 있는 기록이어서 새 모델 추론이나 원격 체크포인트의 새 해시 검사는 수행하지 않았다.

| 실제 전후 조건 | 위장 삭제 패치 차분 | 정상 삭제 패치 차분 |
|---|---:|---:|
| Paper32 5인 혼합형 | **77.33%p** | **1.65%p** |
| PGD64 5인 혼합형 | **90.87%p** | **−0.88%p** |
| PGD64 6인 분리형 | **64.96%p** | **0.41%p** |

Paper32는 같은 공격 포함 pre 모델에서 위장 850개 삭제와 정상 850개 삭제를 비교한다. PGD64의 정상 대조는 공격 없는 모델의 정상 삭제다. 일부 post를 공유하므로 독립 6개 학습의 검증으로 합치지 않는다. 값은 ASR이 아니라 **패치 입력과 원본 입력의 평균 타깃 확률 차이가 모델 전후 얼마나 달라졌는가**다. [완료 실측 원본](../DETECTION_REVIEW_20261021/fixed_scores_frozen.json) · [기존 결과 해석](../DETECTION_REVIEW_20261021/RESULTS.md)

별도의 더 오래된 시드 71도 저장된 원본 로짓에서 다시 계산했다. 실제 유지 재학습 전후 차분 **26.93%p**, 독성이 없는 대조에서 같은 좌표의 차분 **1.65%p**가 이전과 일치했다. [시드 71 로짓 재계산](comparison_audit_v1/seed71_recomputed.json)

## 4 Conv FC의 전후 비교는 어떻게 됐는가

| Paper32의 실제 전후 지표 | 위장 삭제 | 정상 삭제 | 현재 해석 |
|---|---:|---:|---|
| 패치 확률 반응 차분 | 77.33%p | 1.65%p | 큰 관측 차이가 유지됨 |
| 정규화 FC 기능 기여 | 0.445 | 0.492 | 이 조건에서는 분리 신호가 약함 |
| 정규화 FC 이전 특징 기여 | **3.701** | **0.401** | 보조 신호가 유지됨 |

각 방법은 자기 선택 집합에서 후보를 따로 고르고 고유한 정상 변화량으로 나눈다. FC와 특징 점수의 절댓값을 서로 더하거나 설명 비율로 읽지 않는다. [같은 전후 쌍의 원자료](comparison_audit_v1/recent_actual_pairs.json)

앞선 확인 이미지 집합에서 Conv만 교체한 기능 분석도 위장/정상 **1.886/0.381**이었다. 반면 Conv 가중치 이동량은 **8.13%/7.63%**로 비슷했다. 즉 “Conv를 봤다”는 표현 안에도 가중치 거리와 입력에 대한 기능 변화라는 다른 검사가 있었다. [Conv 기능 분석과 FC 분해](../STAGE1_BADFU_TEST_20261021/README.md)

따라서 남길 방향은 **실제 pre/post 패치 반응을 주 관측으로 유지하고 특징 Conv 기능을 보조 근거로 평가하는 것**이다. 큰 내부 변화만으로 공격을 확정하거나, 옛 R/F 기울기 비율과 실제 FC Conv 기능 기여를 같은 방법으로 취급하지 않는다.

## 5 BadFU가 되는데 FUBA가 안 된다고 볼 수 있는가

현재 실패 자료로는 그렇게 결론 내릴 수 없다. 핵심 전제인 **삭제 전에는 억제되고 삭제 후에 공격이 증가하는가**부터 달랐다. 완료된 FUBA 실제 모델 쌍을 같은 삭제 전 생성기와 같은 입력으로 평가한 결과는 ASR **99.72% → 83.61%**였다. 이 쌍은 낮은 잠복에서의 활성화 증가 사례가 아니다. 전후 증가 탐지기가 그 전제를 만족하지 않는 모델에서 약한 값을 냈다고 해서, 잠복 활성화를 탐지하는 원리가 실패했다고 할 수 없다. [FUBA 고정 입력 평가](../DETECTION_REVIEW_20261021/fuba/evaluation_only.json) · [실제 비교와 제한](../DETECTION_REVIEW_20261021/fuba/protocol.json)

다만 “실제 트리거에서 공격이 증가한다”와 “우리 후보 패치에도 증가가 나타난다”는 별도 조건이다. 실제 트리거를 T★, 진단 패치를 τ라 하면 `ΔASR(T★)>0`만으로 모든 τ의 반응 증가가 보장되지는 않는다. 국소 트리거와 입력 의존 생성기가 다른 방향을 사용할 수 있기 때문이다. **유효한 잠복 활성화 쌍을 확보한 뒤 같은 입력 예산의 패치 검사를 적용하는 것이 다음 비교**다. 그 전에 FUBA에서 패치가 원리적으로 안 된다고 주장할 근거도 없다.

저장소의 FUBA와 별도 FedUBA 문헌의 이름은 구분한다. 이 문서에서 위 ASR을 확인한 것은 `stcebra/FUBA` 실행이다. 서로 다른 구현의 결과를 옮겨 쓰지 않는다.

## 6 clean 자료와 신규성에 관한 판단

**공개 clean 입력이 필요하다는 제약은 그대로다.** 현재 전후 검사는 clean 기준 이미지를 바탕으로 원본 패치 반응을 비교하고, 라벨로 클래스 균형과 후보 타깃 제외를 수행한다. 옛 R F 진단에는 사설 유지 삭제 자료도 필요했다. 직전의 다른 파일럿 결과가 이 의존성을 해결하거나 기존 성공을 무효화한 것은 아니다.

**신규성 고민도 그대로다.** 입력 변형으로 모델을 검사하고 두 모델의 변화를 보는 것만으로 충분한 새 기여가 되는지는 근접 선행과 비교해야 한다. 현재 근거는 “방법의 작동 신호가 사라졌다”가 아니라 “BadFU의 제한된 실제 전후 조건에서 좋은 신호가 있으므로, clean 자료 조건과 새 기여 및 정상 non-IID 일반화를 더 검증해야 한다”에 해당한다.

향후 평가는 동일한 실제 pre/post와 동일한 입력 예산에서 패치 단독 대비 Conv 특징이 추가 정보를 주는지, 정상 삭제가 같은 신호를 만드는지, 더 약한 clean 자료 조건에서도 작동하는지를 구분해야 한다. 이것을 한 번에 바꾸고 결과를 같은 방법의 성공 실패로 비교하지 않는다.

## 검증 범위

이번 점검은 새 FL FU 학습 없이 수행했다. 옛 84개 점수 판정, 시드 71 원본 로짓, 같은 pre와 공개 입력에서 실제 FU 대 최신 제출 제외의 출력 및 FC 특징 분해를 재계산했다. 최근 원격 완료 실험은 로컬 JSON의 클래스별 평균과 메타데이터를 대조했다. 원본 점수와 모델은 수정하지 않았다. [검증 기록과 근거 해시](comparison_audit_v1/VALIDATION.json)

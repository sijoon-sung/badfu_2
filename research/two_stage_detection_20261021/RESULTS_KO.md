# 저장 체크포인트를 사용한 두 단계 탐지 실측

기준일 2026년 10월 21일

**해석 정정:** 이 파일럿의 주 결과는 마지막 제출분 제외 검사다. 실제 언러닝 전후의 기존 패치 방법이 실패했다는 결과가 아니다. 이전 성공과 실제 전후 Conv FC 분석은 [비교 조건 재점검](PATCH_COMPARISON_AUDIT.md)을 따른다.

## 판정

**단순한 최신 제출 제외 패치 점수는 두 계열을 안정적으로 분리하지 못했다.** 원점수와 정상 변화 보정은 BadFU 두 공격 구성에 경보를 냈지만 FUBA 공격을 놓쳤고, 보정 외 정상 실행 두 개 중 하나에 경보를 냈다. 상쇄 기준은 FUBA 공격에 경보를 냈지만 BadFU 혼합형을 놓치고 정상 두 실행 모두에 경보를 냈다. 정상 변화 보정이 이 표본에서 원점수보다 판정을 개선했다는 가설은 지지되지 않는다.

BadFU 분리형은 주입자 ID0와 위장자 ID5의 순위가 각각 1위였다. 그러나 고정한 역할 임계값을 넘지 못해 모두 미판정이었다. FUBA는 위장자 ID4를 주입자로, 정상 ID11과 ID14를 위장자로 잘못 지목했다. 순위 성공과 임계값을 적용한 역할 식별 성공은 다른 결과다.

## 1 실행 조건과 완료 범위

**가설 1**: 정상 입력 변화로 보정한 패치 점수는 정상 보정 실행보다 공격 구성 실행에서 크다.

**가설 2**: 같은 패턴과 클래스의 부호 있는 기능 기여는 분리형의 실제 주입 억제 역할과 일치한다.

- 기존 전역 모델 7개와 마지막 라운드의 개별 제출을 GPU에서 새로 추론했다. 새 FL 학습과 새 FU는 실행하지 않았다.
- 32개 패치와 10개 클래스를 탐색했다. 선택 80장과 확인 80장은 서로 겹치지 않으며 이전 탐지의 720장과도 겹치지 않는다.
- 정상 BadFU 42와 정상 FUBA 42만 계열별 임계값 보정에 사용했다. FUBA 정상 43 44는 보정 외 비교다. 이 시드들은 앞선 연구에서도 관찰한 실행이므로 새 방법의 완전한 독립 검증은 아니다.
- 48개 최신 제출 제외 모델과 기존 실제 BadFU FU 끝점 2개를 계산했다. 전역 모델 포함 총 57개 모델 상태를 새로 추론했다.
- 탐지 점수 저장 후에 역할 정답을 붙이고 별도 200장으로 실제 공격 입력 평가를 했다. ASR 분모는 타깃 클래스 20장을 제외한 180장이다.
- 기기 NVIDIA GeForce RTX 4060 Laptop GPU, PyTorch 2.4.1+cu118. 탐지 측정 시간 69.65초이며 학습 시간이나 문헌 조사 시간은 포함하지 않는다.

한 시드의 BadFU 두 구성을 서로 독립인 학습 시드로 세지 않는다. 공격 학습 시드는 계열당 42 하나다. FUBA 모델의 원본 공격 과정에서 test 자료를 참조한 이력이 있어 새 probe가 원래 공격 선택과 완전히 독립이라고 보장하지 않는다.

## 3 2단계 역할 식별

| 조건 | 실제 역할 | 부호 순위 | 고정 임계값을 적용한 결과 |
|---|---|---|---|
| BadFU 분리형 | 주입 ID0 위장 ID5 | 주입 ID0 1위 위장 ID5 1위 | 양쪽 모두 미판정 |
| BadFU 혼합형 | ID0 안에 P C 공존 | 참여자 순기여만 관측 | 내부 P C 분리 불가 |
| FUBA 공격 | 주입 ID0 1 2 3 위장 ID4 | 관측된 주입 ID1 6위 ID3 4위 위장 ID4 8위 | ID4를 주입으로 ID11 14를 위장으로 오지목 |

FUBA 마지막 라운드에는 주입자 4명 중 ID1 ID3만 참여했다. 전체 주입자 기준 recall은 0/4, 관측된 주입자 기준은 0/2다. 위장자 recall은 0/1이다. BadFU 분리형의 역할별 recall은 각각 0/1이고, 두 역할의 동시 확정은 두 분리형 조건 모두 실패했다. 성공한 1단계만 통과시켜도 확정 역할의 전체 과정 성공은 0/2다.

정상 43에서 8명 중 5명, 정상 44에서 8명 중 3명을 잘못 역할로 지목했다. **두 정상 실행의 16개 관측 참여 중 8개 오지목**이며 독립 16학습을 뜻하지 않는다. 보정 패치 경보로 2단계를 제한하면 정상 43의 5/8 오지목이 남고, 상쇄 경보로 제한하면 8/16이 남는다.

BadFU 역할 임계값은 ±0.318199다. 실제 주입자 점수는 +0.220371, 위장자는 -0.244109로 순위는 맞지만 임계값을 넘지 않았다. 선택한 후보 클래스는 7이고 실제 공격 타깃은 평가상 0이다. 따라서 이 순위가 실제 트리거를 찾았다는 증거도 아니다. FUBA는 후보 클래스 6에서 실제 위장자의 부호가 양수여서 잘못된 역할로 해석됐다. 실제 타깃 8을 미리 주면 되는지에 대한 오라클 재설정은 주 결과에 넣지 않았다.

![기능 기여와 실제 역할 대조](figures/stage2_roles.png)

**판정**: 공통 후보 좌표의 부호를 악성 역할로 바로 번역하는 가설은 FUBA에서 기각됐다. BadFU의 기술적 순위 관측은 후속 이력 분석의 출발점으로 남기되, 임계값을 사후에 낮춰 식별 성공으로 바꾸지 않는다.

## 4 실제 공격 입력과 기존 FU 참고

| 저장 모델 | 정상 정확도 % | 고정 실제 공격 입력 타깃 성공률 % |
|---|---:|---:|
| badfu_clean5 | 81.50 | 0.56 |
| fuba_clean_s42 | 78.00 | 97.22 |
| fuba_clean_s43 | 80.00 | 71.11 |
| fuba_clean_s44 | 72.50 | 83.89 |
| badfu_cover5 | 84.50 | 16.11 |
| badfu_full6 | 83.50 | 81.67 |
| fuba_attack_s42 | 76.00 | 99.44 |
| badfu_fu_remove5 | 81.50 | 100.00 |
| badfu_fu_remove1 | 80.50 | 13.89 |

이 표는 200장 표본의 새 측정이다. 기존 1만 장 전체 평가와 표본 오차가 있으므로 숫자가 완전히 같아야 하는 검사가 아니다. FUBA에는 동결한 학습된 생성기의 같은 픽셀 입력을 모든 모델에 사용했다.

BadFU 분리형의 기존 위장 ID5 삭제 FU는 ASR 81.67%에서 100.00%로 18.33%p 증가했고, 정상 정확도는 83.50%에서 81.50%로 2.00%p 감소했다. 사후 블라인드 패치 비교도 클래스 0 후보에서 +0.127511을 보였다. 다만 pre부터 ASR이 높아 낮은 잠복 상태의 미래 활성화 예측 성공으로 세지 않는다. 대응 정상 FU 보정이 없어 이 +0.127511에 FL 제출 제외용 임계값을 적용하지 않았다.

BadFU 혼합형에서 기존 정상 ID1 삭제 FU는 ASR 16.11%에서 13.89%로 감소했다. 사후 패치 확인 점수는 −0.002771로 선택 방향이 확인 자료에서 유지되지 않았다. 이 쌍은 C만 삭제한 실행이 아니므로 혼합형 위장 삭제 활성화의 정답을 제공하지 않는다.

FUBA는 공격 모델에서 99.44%지만 공격 학습이 없는 정상 모델에서도 71.11–97.22%였다. 이는 학습된 생성기 입력이 정상 모델에도 전이한다는 관측이다. 높은 ASR만으로 모델에 악성 학습이 있었음을 증명할 수 없다. 같은 시드 정상 42 대비 증가도 2.22%p에 그친다. 원본 공격의 test 접근과 생성기 평가 조건을 함께 고려해야 한다. 이전 별도 생성기 대조에도 같은 전이가 기록돼 있다. [기존 생성기 대조](../stage1_20261020/generator_controls.json)

## 5 실패 조건을 어떻게 좁힐 것인가

1. **관측**: 원점수와 보정 모두 FUBA 공격보다 정상 43에서 높다. **현재 해석**: 전체 변화 크기를 나누는 것만으로 공격 특이성이 생기지 않는다. 분모가 실패의 유일 원인이라는 뜻은 아니다.
2. **관측**: 상쇄는 정상 43 44에도 크며 혼합형 공격은 작다. **현재 해석**: 정상 클래스 차이도 상쇄를 만들고 같은 참여자 내부 상쇄는 ID별 합계에 숨을 수 있다.
3. **관측**: FUBA의 후보 클래스와 역할 부호가 실제 타깃 역할과 다르다. **원인 가설**: 고정 패치 범위 또는 좌표 선택이 공격 방향을 놓쳤거나 최신 제출만으로 역할이 안정되지 않을 수 있다. 두 원인을 분리해 입증한 것은 아니다.
4. **관측**: BadFU 순위는 맞아도 정상 최대값 임계 아래다. **판정**: 순위와 보정 판정의 차이이며 낮은 임계값을 사후 선택할 근거가 아니다.

다음 연구는 [보고서의 신규성 후보](REPORT_KO.md)의 실제 요청 조건부 검사로 이어진다. 같은 삭제 요청의 실제 FU와 무삭제 대조를 붙이고, 이력의 추가 정보와 요청 기여 일치성을 별도로 평가해야 한다. 이번 실패는 MASA Neural Cleanse 등 다른 논문의 공식 구현 실패를 뜻하지 않는다.

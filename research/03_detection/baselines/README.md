# 탐지 기준선

유지·삭제 대상 데이터의 클래스 구성, 평균 손실, 진단 갱신 크기를 먼저 본다. 기존 일부 대조는 이 통계만으로 설명됐으므로 패치 점수의 성능 전체를 새로운 정보로 해석할 수 없다.

기존법의 우선 비교 후보는 [Neural Cleanse 공식 구현](https://github.com/bolunwang/backdoor)이다. 고정 패치 32개 검사나 자체 차분 역합성은 정식 NC 재현이 아니다. 역합성의 성공 여부와 이상치 판정을 분리한다. 정상 이질성 통제는 [MASA](https://arxiv.org/html/2411.01040v1)를 참고하되, 우리 R/F 기울기 검사와 같은 연산으로 부르지 않는다.

**다음 확인 하나:** 일반 활성 백도어와 정상 모델에서 기존법의 연결을 확인한 뒤 같은 실제 삭제 전후 모델로 비교한다.

# 기울기 크기 비율

분류상 [삭제 전후 갈래의 FC·Conv 분석](../../02_pre_post_detection/fc_conv/README.md)에 속한다. 이 문서의 기존 연산은 실제 FU 전후가 아닌 R/F 기울기 진단이며, [발전 후보 비교](../../BEST_CANDIDATES.md)에서 그 한계와 새 분석을 연결했다.

패치 검사보다 적은 진단 비용으로 구별하려고, 동일 모델에서 유지 데이터 R과 삭제 대상 데이터 F의 평균 CE 기울기를 계산했다. 크기 비율은 `q = R 기울기 크기 / F 기울기 크기`다. 모델을 갱신하는 실제 FU와 다르다.

## 남길 결과와 해석

초기 16요청에서 분리가 관측됐으나 시드·클래스 편향을 늘리면 미탐과 대조 경보가 나왔다. 공격 없는 정상 모델의 저손실 삭제 36요청에서 FC 경보 35건, Conv 경보 36건이었다. 층화 무작위 삭제 36요청에서는 각각 0건이었다.

같은 모델·삭제 수·클래스별 할당량을 맞춘 비교에서도 삭제 기울기 크기의 감소가 비율을 키웠다. 따라서 큰 비율을 공격의 충분조건으로 쓰는 해석은 버린다. 남길 가치는 **정상 데이터 선택만으로 오탐이 발생하는 반례와 원인 분해**다.

[직교 잔차 변형](variants/orthogonal_residual/README.md)은 이 비율에서 파생했다. 최대 특이값, 채널 집중도, 코사인 부호 등 세부 시도는 새 주력 방법으로 각각 펼치지 않고 [보관 목록](../../../90_archive/README.md)에 묶었다.

**재검토 조건:** 데이터 선택과 기울기 분모를 통제한 뒤에도 새 점수가 정상 대조와 공격을 구별한다는 근거가 생길 때다.

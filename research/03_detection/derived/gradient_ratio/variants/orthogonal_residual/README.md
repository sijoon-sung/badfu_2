# 기울기 직교 잔차 비율

**부모 방법:** [기울기 크기 비율](../../README.md). 삭제 대상 기울기 방향과 평행한 유지 기울기 성분을 제거해 공격 고유 변화가 남는지 검사했다.

잔차 비율 `s = q × sqrt(1 − cos²)`이므로 크기 비율 q의 영향을 자동 제거하지 않는다. 평행·반평행이면 잔차가 0이 되는 한계도 있다.

초기 요청에서의 분리는 있었으나 정상 데이터로도 큰 잔차를 만들 수 있었고, 저손실 정상 삭제에서 경보가 관측됐다. “직교화하면 정상 이질성이 제거된다”는 주장은 채택하지 않는다. 독립된 완성 탐지법 대신 부모 방법의 한계 확인으로 남긴다.

# 패치 반응의 두 분기 대조

**관측 종류: 삭제 전 R/F 추가 학습 진단.** 두 분기는 ‘삭제한 모델 / 삭제하지 않은 모델’이 아니다. `shadow`는 각 자료의 CE를 줄이는 추가 학습을 하며, F를 받은 분기도 F를 다시 학습한다. R로만 추가 학습한다고 기존에 학습한 F의 영향이 삭제됐다고 보장되지 않는다.

**질문:** 유지 데이터로 진단 학습한 분기의 패치 반응 증가를, 삭제 대상 데이터 분기의 반응과 대조하면 위험한 위장 샘플 삭제를 구별하는가.

두 분기는 진단을 위한 복제 모델이다. 삭제 대상 데이터 분기의 학습을 실제 FU로 해석하지 않는다. 고정 패치 검사에서 연속 패치 최적화로 파생했지만, 연속 최적화 점수 단독 판정에는 비공격 대조 반례가 나왔다. 연속 탐색은 후보 입력을 찾는 보조 방식으로 묶는다.

[두 탐지 경로의 검토](../../TWO_ROUTE_REVIEW.md)에서는 이 실험을 사전 위험 예측의 보조 자료로 분류한다. 학습 이력 기반 예측이나 실제 언러닝 전후 감지의 검증을 대신하지 않는다.

## 남길 결과

보존된 공통 84요청 스냅샷에서 공격 12건 중 11건을 탐지했고 비공격 대조 72건 중 3건에 경보했다. 72건 전부가 순수 정상 삭제는 아니다. 추가 정상 기준 데이터와 100스텝 진단 계산이 필요하다.

**짚을 포인트:** 점수식 자체의 이득과 정상 데이터·추가 학습의 이득을 구분해야 한다. [Neural Cleanse](https://github.com/bolunwang/backdoor)의 전체 재현과 동일한 방법은 아니다.

**다음 확인 하나:** 저손실 정상 샘플 삭제를 포함한 고정 정상 대조에서 임계값을 바꾸지 않고 검사한다.

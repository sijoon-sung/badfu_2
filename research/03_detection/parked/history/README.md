# 이전 이력 탐지 구현과 한계

이 문서의 보류는 이전 점수와 구현에 대한 판단이다. 현재의 [이력 기반 위험 예측 경로](../../01_history_prediction/README.md) 전체를 폐기한다는 뜻은 아니다. [두 경로의 검증 검토](../../TWO_ROUTE_REVIEW.md)에서 실제 FU 위험과의 연결을 다시 평가한다.

현재 모델에서 보이지 않는 억제 기여를 과거 갱신에서 찾으려 했다. HRAC 후보 점수 → 정상 실행 크기 보정 → GLR 구간 누적과 정상 기여 설명 집합으로 확장했다.

**남길 관측:** 요청자 후보는 단순 기준선도 찾았다. 정상 실행 간 12/40 경보는 보정으로 줄었지만, 같은 정상 보정 자료를 맞추면 새로운 점수의 우월성이 남지 않았다. GLR 최대값은 한 라운드 잔차로 설명됐고 정상 설명 집합은 11요청 모두 미판정이었다.

**보류 이유:** 이력의 존재보다 같은 정보·보정 예산에서 추가로 얻은 탐지 근거가 필요하다. 이력이 전혀 없어서 실패한 것은 아니다. 누적 기여 차감은 실제 FU와 분리한다.

재검토하려면 최근 요청과 과거 궤적의 모델·자료 대응부터 맞추고, 같은 정상 보정 자료를 쓰는 단순 기준선과 비교한다. [UnlearnGuard](https://arxiv.org/html/2501.17396v1)의 FU 중 새 악성 업데이트 검사와 잠복 독성의 정직한 삭제는 적용 범위가 다르다.

# 입력 패치 진단의 정의와 차분의 검증

**먼저 구분할 것:** [패치 실험의 두 비교 축과 타당성](PATCH_VALIDITY.md). 한 모델의 원본/패치 차이는 입력 민감도이며, 실제 FU 전후 검증에는 동일한 두 입력을 실제 pre/FU 모델 모두에 넣은 네 출력이 필요하다. 기존 84요청의 두 갈래 모델 비교는 실제 FU 전후와 구분한다.

**유지할 아이디어는 ‘입력에 패치를 붙이면 공격을 안다’가 아니라 ‘같은 입력 변환에 대한 모델 간 반응 차이를 비교한다’이다.** 기존 R/F 진단의 관측 결과는 유용하지만, 정상 non-IID 전체를 제거한다는 보장은 없다. 아래에서 기존 방법·새 관측기·발전 제안을 구분한다.

## 용어와 입력 변환

| 용어 | 사용할 의미 | 선행 용례 |
|---|---|---|
| 입력 패치 또는 국소 패치 | 영상의 일부 영역을 정해진 픽셀로 대체하는 입력 변환 | Neural Cleanse의 마스크 기반 트리거 주입식 |
| 진단 입력 또는 probe | 모델 반응을 측정하기 위한 입력 | ULP의 모델 진단 입력 |
| 트리거 | 공격자가 특정 오분류와 연결한 입력 조건 | 고정 패치 외에 입력별 변형도 가능 |
| 트리거 역추정 또는 trigger inversion | 의심 타깃으로 보내는 패턴과 마스크를 최적화해 찾는 과정 | Neural Cleanse |
| 백도어 노출 또는 backdoor exposure | 모델을 변형해 숨은 백도어 기능을 드러내는 진단 | EBYD의 Clean Unlearning |
| 패치 반응 | 국소 변환 전후 타깃 확률 또는 로짓 차이 | 우리 측정량의 기술적 명칭이며 독립된 표준 알고리즘명은 아님 |

Neural Cleanse의 주입식과 같은 표기로, 픽셀 범위는 [0,1]이고 마스크는 색 채널에 방송한다.

$$T_{m,v}(x)=(1-m)\odot x+m\odot v.$$

여기서 $m$은 위치·크기, $v$는 넣는 색·무늬다. 고정된 이진 마스크라면 해당 영역만 덮어쓴다. **진단 패치는 실제 공격 트리거를 알고 넣는 것이 아니다.** 고정 후보군의 반응을 보고 있을 뿐이다. [Neural Cleanse 원문 Eq. 2](https://bolunwang.github.io/assets/docs/backdoor-sp19.pdf).

정상 참조 집합 $Q$에서 후보 타깃 $k$의 원래 클래스는 제외하고, 확률 반응을 다음처럼 정의한다.

$$r_\theta^Q(\tau,k)=\mathbb E_{(x,y)\in Q,\ y\ne k}[p_\theta(k\mid T_\tau x)-p_\theta(k\mid x)].$$

이는 **평균 타깃 확률의 증가량**이다. 실제 트리거의 ASR도, 타깃 예측 비율 자체도 아니다.

## 보존된 기존 코드가 실제로 한 일

| 항목 | 보존 소스에서 확인한 조건 |
|---|---|
| 시작 모델 | 실제 삭제 전 모델 $\theta_0$ |
| 유지 진단 모델 | $\theta_R=\mathrm{TrainDiag}(\theta_0,R)$, 요청자 유지 자료 R로 정답 CE를 낮추는 추가 학습 |
| 삭제 자료 진단 모델 | $\theta_F=\mathrm{TrainDiag}(\theta_0,F)$, 삭제 대상 F로 정답 CE를 낮추는 추가 학습 |
| 진단 학습 | 두 모델 각각 SGD 100단계, lr 0.01, batch 32, layer4만 갱신, BN 통계·FC 고정, gradient clip 1 |
| 정상 기능 보존 | 별도 정상 참조 500장에 원모델과의 KL 손실, 가중치 2 |
| 패치 후보 | 4개 모서리 × 8개 무늬, 모두 4×4, 합계 32개 |
| 무늬 | 검정·흰색·체커·역체커·고정 시드 무작위 4개 |
| 선택과 확인 | 정상 입력 200장으로 후보와 타깃 선택, 다른 200장으로 점수 확인 |
| 후보 선택 | 개발 자료에서 $r_R-r_0$가 최대인 패치와 타깃, 절댓값 최대가 아님 |
| 판정 입력 | 세 모델의 정상·변형 입력 로짓, 실제 트리거·ASR은 판정에 입력하지 않음 |

확인 자료에서 선택된 동일한 $(\hat\tau,\hat k)$에 대해

$$a=r_R-r_0,\qquad b=r_R-r_F,\qquad S=\max(0,\min(a,b)),\qquad \mathrm{alarm}=\mathbb 1\{S>0.006\}.$$

**$\theta_F$는 삭제를 완료한 모델이 아니다.** 삭제 대상 데이터로 오히려 추가 학습한 진단 갈래다. 실제 미래 정답은 유지 자료로 같은 초기화에서 40라운드 FedAvg를 다시 학습한 모델에 연결되어 있었다. 따라서 ‘진단 입력이 실제 FU 전후가 아니다’와 ‘실제 유지 재학습 정답이 없다’를 혼동하지 않는다.

임계값 0.006은 **평균 확률 대비 0.6%p**이며 ASR 0.6%가 아니다. 보존 구현은 서버가 개인 R/F를 직접 읽는다. 공개 정상 자료만 있는 서버에 그대로 배치할 수 있다는 주장은 성립하지 않는다.

## 서로 다른 세 구현

| 구분 | 비교하는 모델 | 입력과 점수 | 현재 의미 |
|---|---|---|---|
| 기존 두 갈래 진단 | 원모델·R 추가 학습·F 추가 학습 | 4×4 패치, $\max(0,\min(a,b))$ | BadFU 형태의 통제 실험 84요청 근거 |
| 새 학습에 붙인 수동 관측 | 이전 전역 모델·현재 전역 모델, 또는 초기·현재 | 3×3/5×5 후보, 절댓값으로 방향 선택, 두 갈래 대조 없음 | 서버가 볼 수 있는 이력 기준선 |
| 실제 FU 전후 비교 제안 | 서버가 보존한 삭제 전 모델·실제로 반환된 FU 후보 | 고정 입력 변환, 확률/로짓 차분 및 FC/앞단 특징 | 두 공격과 정상 FU에서 검증할 방법 |

새 관측기는 패턴 크기·무늬·선택 방향·비교 모델을 함께 바꿨다. **기존 진단을 동일하게 재실행한 결과라고 부르지 않는다.** 새 관측기의 초기 점수만으로 기존 두 갈래 진단이 쓸모없다고 결론내릴 수 없다.

## 수학 검증 1

**가설: 로짓 이중 차분은 입력에 무관한 클래스 편향 변화를 정확히 제거한다.**

- 조건: $z_1(u)=z_0(u)+c$가 원본 $u=x$와 변형 $u=T_\tau x$ 모두에서 성립하며 $c$는 입력에 무관한 클래스 벡터다.
- 측정: $D_z=[z_1(T_\tau x)-z_1(x)]-[z_0(T_\tau x)-z_0(x)]$.
- 증명: $D_z=[z_0(T_\tau x)+c-z_0(x)-c]-[z_0(T_\tau x)-z_0(x)]=0$.
- 판정: **조건부 증명.** 클래스별 로짓의 고정 선형 대비에도 같은 항등식이 성립한다. 모든 non-IID 변화를 제거한다는 증명은 아니다.

## 수학 검증 2

**가설: 확률 이중 차분도 정상적인 클래스 사전확률 변화의 영향을 완전히 제거한다.**

- 조건: 이진 분류의 보정된 로그 오즈 $z$, 시그모이드 $\sigma$, 정상 클래스 사전확률만 바뀌어 $z_1=z_0-0.5$가 된다.
- 구성: $z_0(x)=0$, $z_0(T_\tau x)=1$이고 클래스 조건부 가능도비는 고정한다. 공격 학습이나 독성 데이터가 없다.
- 결과: 원래 반응 $\sigma(1)-\sigma(0)=0.23105858$, 변경 후 반응 $\sigma(0.5)-\sigma(-0.5)=0.24491866$, 차분은 **0.01386008**이다.
- 판정: **기각.** 확률의 비선형성 때문에 정상 사전확률 변화에도 1.386%p 신호가 생긴다. F 진단 모델이 원래 편향을 유지하는 구성에서는 기존 두 대비 $a,b$가 모두 이 값이므로 0.006을 넘는다. 실제 CNN에서 해당 최적화 경로가 발생했다는 실측은 아니다.

이진 label shift의 가정은 베이즈 로그 오즈 $z(x)=\log[p(x\mid1)/p(x\mid0)]+\log[\pi_1/\pi_0]$에서 사전확률 항만 바꾼 것이다. 위 수치와 부호는 [60자리 정밀도 검산](validation_20261020/differencing_math.json)으로 확인했다.

## 수학 검증 3

**가설: 로짓 이중 차분은 모든 정상 non-IID 변화의 영향을 제거한다.**

- 조건: 같은 원본과 변형에서 정상 특징의 이득만 $z_1=1.2z_0$로 바뀐다.
- 결과: $z_0(x)=0$, $z_0(T_\tau x)=1$이면 $D_z=0.2$다.
- 판정: **기각.** 로짓 변경도 특징·경계·BN 변화까지 자동 제거하지 않는다. 정상 FU를 실제 실행한 독립 보정 집합이 필요하다.

**차분은 두 축의 변화량이지 공격 여부 판정 그 자체가 아니다.** ‘변형−원본’ 뒤 ‘후−전’을 계산한다고 해서 정상 효과가 인과적으로 제거되지는 않는다. 동일 반응이라는 가정 또는 관측된 정상 변화 분포가 별도로 필요하다.

## 수학 검증 4

**가설: FC 가중치나 앞단 특징이 크게 바뀌면 출력도 반드시 크게 바뀐다.**

같은 입력에서 $z_i=W_i h_i+b_i$일 때 정확한 대칭 분해는

$$\Delta z=\underbrace{\Delta W\frac{h_0+h_1}{2}+\Delta b}_{FC\ 성분}+\underbrace{\frac{W_0+W_1}{2}\Delta h}_{앞단\ 특징\ 성분}.$$

- 증명: 전개하면 $W_1h_0$와 $W_0h_1$ 교차항이 상쇄된다.
- 반례: $h_1=2h_0$, $W_1=W_0/2$, 편향 고정이면 출력은 같다. 검산 예에서 FC 성분은 $-1.5$, 앞단 특징 성분은 $+1.5$로 합계 0이다.
- 판정: **기각.** 내부 거리 자체는 공격 증거가 아니다. 합이 실제 로짓 변화와 일치하는지 검사한 뒤 독립 정상 자료에서 추가 탐지력을 평가한다. 앞단 특징에는 Conv 외에 BN도 포함된다.

## 가장 가까운 선행 방법과 비교

| 선행 방법 | 원리 | 우리의 차별화 후보와 반드시 비교할 지점 |
|---|---|---|
| [Neural Cleanse](https://bolunwang.github.io/assets/docs/backdoor-sp19.pdf) | 타깃별 작은 트리거를 역추정하고 마스크 크기 이상치 검사 | 고정 후보 측정은 역추정이 아님. 단일 모델 NC와 실제 FU 전후 NC를 모두 비교해 추가 FU 정보의 효과를 분리 |
| [Universal Litmus Patterns](https://arxiv.org/abs/1906.10842) | 여러 정상·백도어 모델로 진단 패턴과 모델 판별기를 학습 | ‘입력 반응으로 모델 진단’은 선행 아이디어. 우리의 후보는 실제 삭제 요청에 따른 변화의 대조 |
| [STRIP](https://arxiv.org/abs/1902.06531) | 입력을 다른 입력과 합성하고 예측 엔트로피로 악성 입력 탐지 | 판단 단위가 추론 입력이다. FU 요청·모델 위험 탐지와 목적 차이이며, 같은 조건에서 실패를 실측한 것은 아님 |
| [MASA](https://arxiv.org/html/2411.01040v1) | 개별 모델의 정상 손실을 높이는 unlearning과 누적 손실, 사전 모델 혼합으로 non-IID 완화 | non-IID를 이미 다룬다. 우리의 R/F 정답 추가 학습과 다르며 같은 정상 자료·계산량으로 비교 필요 |
| [EBYD](https://arxiv.org/html/2410.19427v1) | 정상 기능을 약화하는 Clean Unlearning으로 백도어를 노출한 뒤 탐지·제거 | 모델을 바꿔 숨은 공격을 드러낸다는 발상은 선행됨. 실제 요청 조건의 반응 차이가 더 주는 정보가 기여 후보 |
| [Adversarial Patch](https://arxiv.org/abs/1712.09665) | 모델 학습을 오염시키지 않고도 최적화된 국소 패치로 타깃 오분류 유도 | 높은 패치 반응만으로 악성 학습을 입증할 수 없는 이유 |

BadFU 원문 Table VI는 CIFAR-10에서 Median·Trimean 이후 활성화 ASR 96.33%·76.97%를 보고하고, Table VII는 NC의 타깃 누락과 정상 클래스 경보를 보고한다. 이는 **해당 논문의 실험 근거**다. 우리가 같은 예산·설정으로 재현해 모든 선행 방법의 실패를 확인했다는 뜻은 아니다. [BadFU 방어 실험](https://arxiv.org/html/2508.15541v1#S7.SS7).

## 서버에서 얻을 수 있는 정보와 완화 조건

| 경로 | 필요한 정보 | 구할 수 있는 이유 또는 추가 가정 |
|---|---|---|
| 실제 FU 전후 검사 | 보존 pre 모델, 실제 FU 후보, 별도 정상 참조 입력 | 서버가 기존 전역 모델을 보존하고 실제 FU 결과를 반환받는 설정. 사후 진단 또는 배포 전 후보 검사 |
| 이력 예측 | 요청 이전 모델·갱신 이력과 요청 대상 | 저장된 범위만 사용. 미래 FU 모델을 입력하면 사전 예측이 아님 |
| 기존 R/F 진단 | 요청자의 개인 유지·삭제 자료 | 기존 코드에는 직접 접근. 일반 FL에서는 별도 권한이나 검증 가능한 협력 계산이 필요 |
| 무삭제 대조 모델 | 같은 시작점에서 삭제 없이 실제 계속 학습한 결과 | 참여자 추가 협력과 계산이 필요. 무료로 얻는 반사실 모델로 가정하지 않음 |
| 실제 ASR | 실제 공격 트리거와 타깃 | 연구 평가자만 사용. 탐지 서버 입력에서 제외 |

현재 주된 발전 경로는 **공개 정상 참조 입력과 실제 FU 전후 모델을 이용한 반응 비교**다. 정답 공격자·위장자·실제 트리거는 필요 정보로 추가하지 않는다. 요청자 R/F에 접근할 수 있는 강화 조건은 별도의 상한 비교로 남긴다.

## 다음에 비교할 구체적인 방법

**가설: 실제 FU 전후의 입력 반응 차분은 같은 입력 예산의 FU 후 단일 모델 반응보다 정상 대조 경보를 줄인다.**

조건은 서버가 실제 pre/FU 후보와 정상 참조 자료를 보유하는 경우다. 참조 자료를 후보 선택 집합 $Q_d$와 확인 집합 $Q_v$로 분리한다. 비교 방법 사이에서는 동일한 후보군·입력·추론 횟수 상한을 사용한다. 현재 수동 이력 관측의 3×3/5×5 결과는 별도 기준선으로 유지한다.

| 비교 방법 | 후보를 고르는 개발 점수 | 확인 자료 점수 |
|---|---|---|
| FU 후 단일 모델 | $r_{FU}^{Q_d}(\tau,k)$ 최대 | 선택 후보의 $r_{FU}^{Q_v}$ |
| 확률 전후 차분 | $r_{FU}^{Q_d}-r_{pre}^{Q_d}$ 최대 | 선택 후보의 $D_p=r_{FU}^{Q_v}-r_{pre}^{Q_v}$ |
| 로짓 전후 차분 | 같은 차분을 타깃 로짓 대비로 계산 | 선택 후보의 $D_z$ |
| 개인 R/F 접근 상한 | 기존 개발 점수 $r_R-r_0$ | 기존 $\max(0,\min(a,b))$ |

로짓 대비는 $\ell_k(x)=z_k(x)-\frac1{K-1}\sum_{j\ne k}z_j(x)$로 정하고, 위 $r$의 확률을 $\ell$로 바꾼다. 양의 반응 증가를 보는 선택 규칙은 확인 결과를 보기 전에 고정한다. 로짓 버전의 임계값에 기존 확률 임계값 0.006을 그대로 쓰지 않는다.

각 방법은 **별도 정상 학습의 실제 FU 요청만으로** 운영 목표 경보율의 임계값을 정한다. 고정된 임계값을 독립 정상·공격 학습에 적용하고, 학습 실행별 결과와 요청별 결과를 함께 보고한다. 유한한 정상 표본의 목표 경보율을 모집단 보장으로 바꾸지 않는다.

FC·앞단 특징은 같은 패치의 로짓 차분을 분해한 두 성분을 따로 보존한다. 두 성분을 단순히 더하면 원래 로짓 차분이므로 새로운 측정량이 생기는 것은 아니다. 성분별 크기·방향·상쇄가 실제 정상·공격에서 달라 추가 판별에 도움이 되는지를 별도로 검증한다.

판정은 **미검증**이다. 이 설계에서는 서버가 구할 수 없는 $\theta_F$ 대조를 빼므로, 기존 두 갈래의 효과가 유지된다고 가정하지 않는다. 기존 진단의 관측 근거와 실제 배치 가능한 방법 사이의 차이가 이 후속 실험의 핵심이다.

고정 국소 후보군으로 FUBA의 입력 의존 변형을 충분히 덮는지는 미검증이다. 후보 확장을 하더라도 정상 모델의 일반 적대적 취약성과 구별해야 한다. 추정 패턴이나 높은 반응만으로 공격자 신원·독성 데이터 ID를 얻었다고 하지 않는다.

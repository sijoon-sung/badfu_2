## 발견하고 수정한 평가 형식 차이

기존 벡터화 평가는 값은 NCHW 순서이지만 메모리에는 channels-last 형식으로 배치된 텐서를 입력했다. 저자 DataLoader는 contiguous NCHW 텐서를 입력한다. 전체9000장의 정규화 입력값 차이는0인데, 이 형식 차이로 정상 모델의 예측5개가 달라졌고 타깃 예측 수는127→125개가 됐다. ASR은1.4111%→1.3889%다. 이는 동일 입력값·동일 모델에서 텐서 형식만 바꾸어 재현한 계산 경로 차이다.

`author_aligned_evaluation.py`는 정규화 뒤 `.contiguous()`를 적용한다. 이 평가에서 정상 모델의9000개 예측은 저자 입력 형식과 전부 같았다. 공격 pre·post의 최종 ASR14.29%/100%는 바뀌지 않았다. 수정 평가기와 저자 원 평가기의 세 모델 지표도 일치했다.

**모델·학습 갱신은 바꾸지 않았다.** 원래 평가 기록은 보존하고, 새 형식의 평가를 별도 버전으로 기록한다. 진행 중인 동결 실험의 코드를 중간에 바꾸거나 이 문제 때문에 재학습하지 않는다. 성능 수치는 평가 버전을 명시해서 인용한다.

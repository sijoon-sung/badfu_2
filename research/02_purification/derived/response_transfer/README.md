# 삭제 전후 반응 전이

**질문:** 정상 입력의 출력은 삭제 후 모델을 따르면서, 입력 변형에 대한 반응만 삭제 전 모델에서 가져오면 불필요한 정상 기능 변화를 줄일 수 있는가.

정상 미세조정과 삭제 후 자기증류에서 파생했다. 고정 변형 → 학습률 축소 → 반복 입력 탐색으로 발전시킨 세부 과정은 한 방법의 변형으로 묶는다.

## 남길 결과

공격 4개 FL 시드의 조정된 BadFU형 실험에서, 동일한 검증 KL 상한 0.010일 때 평균 ASR은 자기증류 29.19%, 반응 전이 17.36%였다. 상한 0.020에서는 15.03%와 16.74%로 우열이 바뀌었다. 같은 상한이며 실제 사용 KL의 완전 일치는 아니다. 원논문 전체 규모의 재현 결과도 아니다.

## 짚을 포인트

이 방법의 가치는 “두 모델을 쓴다”가 아니라 **정상 변경을 작게 허용할 때 삭제 전 정보가 추가 이득을 주는가**이다. [SAU](https://proceedings.neurips.cc/paper_files/paper/2023/hash/520425a5a4c2fb7f7fc345078b188201-Abstract.html)와의 관계도 이 정보·예산 차이로 비교해야 한다. 회원 추론 진단 하나로 인증된 망각을 주장하지 않는다.

**다음 확인 하나:** 선택 규칙과 정상 변경 상한을 미리 고정한 새 FL 시드에서 삭제 후 자기증류와 비교한다.

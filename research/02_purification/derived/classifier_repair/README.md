# 마지막 분류층 교정

**질문:** 특징 추출기를 유지한 채 마지막 분류층을 교정해 정상 성능을 보존할 수 있는가. 이 방법은 반응 전이와 다른 가지다.

## 남길 결과

저자 코드 계열 한 실제 FU 후 모델에서 ASR 99.51%가 11.58–12.62%로, 정상 정확도 86.96%는 86.94–87.04%로 관측됐다. 값의 반복은 독립 FL 시드가 아니라 패치 집합의 시드다. 해당 계열의 삭제 전 ASR이 이미 높았다는 조건을 함께 유지한다.

패치 수를 늘려도 단조 개선되지 않았고, FU 후 모델에서 통하던 반례 보강은 유지 데이터 재학습 모델에서 크게 악화됐다. 저장 후보군을 분석하면 후보 생성과 후보 선택이 다른 문제였다. 정규화 선택 점수의 개선은 사후 분석이다.

**짚을 포인트:** 좋은 후보가 없었는지, 좋은 후보를 잘못 골랐는지부터 구분한다. 패치 수 증가와 반례 보강은 이 교정의 변형으로만 관리한다.

**다음 확인 하나:** 정규화한 선택 규칙을 먼저 고정해 새 모델 쌍에서 동일 후보 생성 절차로 비교한다.

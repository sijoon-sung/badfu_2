# 차분 탐색과 CVaR 정화 보류

삭제 후에 증가한 변형 반응을 찾고 이를 억제하려 했다. 평균 차분 → 상위 위험에 집중하는 CVaR → 클래스별 정상 성능 제약으로 파생했다.

한 실제 FU 후 모델에서 평균 차분은 ASR 99.00→1.44%였으나 정상 정확도는 85.20→71.70%였다. 정상 성능 제약을 건 방법은 후보를 모두 거절하고 원래 모델로 복귀했다. 이 모델 쌍은 삭제 전 ASR도 80.11%라 강한 잠복 사례가 아니다.

**보류 이유:** 정상 성능을 보존하는 후보를 얻지 못했다. 현재 최적화 경로의 실패이며 차분 정보 전체가 무용하다는 증명은 아니다.

재검토한다면 CVaR를 더 복잡하게 하기 전에 단순 정상 미세조정부터 정확도가 크게 손상되는 원인을 확인한다.

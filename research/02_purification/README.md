# 3단계 — 식별 정보에 근거한 정화

[세 단계 연구 기준](../RESEARCH_STAGES.md)에 따라 공격 탐지와 공격자·위장자 식별 뒤에 정화를 평가한다. 무엇을 실제로 추정했고 그 정보로 어떤 정화를 할 수 있는지는 [정보별 연결표](DETECTION_TO_PURIFICATION.md)를 먼저 본다. 2단계가 틀렸을 때의 피해와 전체 과정의 성공률도 평가한다.

출발 질문은 **삭제된 데이터의 효과를 되살리지 않으면서, 남은 백도어를 줄이고 정상 기능을 유지할 수 있는가**다. 먼저 [방어 가설과 반증 실험](FOUNDATION_HYPOTHESES.md)을 읽는다.

유지 독성이 드러나는 경로에는 FU 후 정화와 안전한 재학습을 검토한다. FU 중 새로운 악성 갱신에는 갱신 검사도 비교한다. 한 시점의 방어를 두 공격 전체의 해결책으로 부르지 않는다. [수학적 조건](../04_theory/README.md)과 실제로 인증할 수 있는 조건도 구분한다.

처음 비교할 대상은 정상 미세조정·삭제 후 자기증류·정식 Fine-Pruning·SAU다. 자료와 계산 예산, 정상 정확도 손실, 삭제 품질을 맞춘 뒤 새 방법의 필요성을 판단한다. 현재 두 공격에 대한 방어 성공을 확인한 상태는 아니다.

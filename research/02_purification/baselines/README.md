# 정화 기준선

삭제 후 모델 그대로, 정상 데이터 미세조정, 삭제 후 자기증류를 기본 비교로 둔다. 비교할 것은 같은 자료와 계산량에서 얻는 ASR 감소와 정상 성능 손실이다.

기존 강한 미세조정은 ASR을 낮춰도 정상 정확도를 크게 잃었다. 반응 전이 비교에서는 수정량을 충분히 허용하면 자기증류가 더 강했다. 따라서 복잡한 정화법을 만들기 전에 단순 기준선의 학습률과 선택 절차를 맞춰야 한다.

**다음 확인 하나:** 같은 시작 모델·정상 데이터·정상 성능 허용량에서 미세조정과 자기증류의 비교선을 먼저 만든다. 실제로 쓴 KL이 같다는 주장과 같은 KL 상한을 적용했다는 주장을 구분한다.

# 실제 언러닝 전후 능동 진단 검증

**ASR 재현 타당성 정정:** [후속 원인 감사](../asr_root_cause_20261022/REPORT_KO.md)에서 원 FUBA 시험 분할과 저자 평가 함수로 삭제 전 공격 모델 ASR 98.18%, 정상 학습 모델에 같은 생성기를 적용한 ASR 95.01%를 확인했다. 아래 FUBA 보존 쌍은 정상 기능을 유지한 모델 비교라는 의미에서만 유효하다. 잠복 후 활성화를 재현한 쌍이 아니므로 FUBA 잠복 공격 탐지의 성공·실패를 확정하는 근거로 사용하지 않는다. 점수와 원래 집계 파일은 보존하며 해석 정정은 [별도 기록](REPRODUCTION_VALIDITY_ADDENDUM.json)을 따른다.

**가설 한 줄: 같은 잔류 참여자가 같은 개입에 보이는 언러닝 전후 응답은 공격과 큰 정상 non-IID 참여자 탈퇴를 구별한다.**

**이번에 검증한 주 지표로는 공통 구별에 실패했다.** BadFU에서 공격 점수는 큰 정상 탈퇴 두 점수 사이에 놓였다. 정상 기능이 유지된 FUBA 보존 전후에서도 정상 점수가 공격보다 높았다. FUBA 최대 참여자 8.610% 탈퇴의 단축 FU 모델은 정상 정확도가 붕괴해 탐지 성능 근거에서 제외한다. 그 조건의 기능 유지 대조는 아직 확보하지 못했다.

추가 관측 조건은 공개 정상 자료, 전후 글로벌 모델 보존, 같은 잔류 참여자들을 다시 연결하는 기능과 지정한 진단 계산을 수행하는 응답이다. 위조 응답에 대한 저항성, 안전 집계, 신뢰 실행 환경을 구현한 시스템 평가는 아니다. BadFU는 자료 수에 비례해, FUBA는 잔류 참여자를 균등하게 집계한다. FUBA의 삭제 자료 비중을 원 학습의 집계 가중치와 혼동하지 않는다.

재사용한 정상 큰 탈퇴 두 후 모델은 앞선 로컬 RTX 4060 환경에서 계산됐고, 이번 추가 FU는 DISLAB RTX 3080에서 계산했다. 동일 계산 규칙을 사용한 대조이며 하드웨어까지 같은 재실행이라고 부르지 않는다. 진단 응답 계산은 모두 DISLAB에서 수행했다.

## 네 모델에서 실제 새 응답 계산

| 모델 시점 | 음의 진단 교란 | 양의 진단 교란 |
|---|---|---|
| 삭제 전 | θ전−v에서 같은 잔류 자료로 계산 | θ전+v에서 같은 잔류 자료로 계산 |
| 삭제 후 | θ후−v에서 같은 잔류 자료로 계산 | θ후+v에서 같은 잔류 자료로 계산 |

삭제된 자료를 다시 요구하지 않는다. 저장된 옛 업데이트를 교란 모델에 더하는 방식으로 새 응답을 대체하지 않았다. 시점 t의 집계 응답과 공개 정상 응답으로 Rₜ=(Uₜ⁺−Uₜ⁻)/(2‖v‖), R_Cₜ를 계산한다. 주 점수 D는 ‖(R후−R_C후)−(R전−R_C전)‖를 공개 응답 두 norm의 합과 10⁻⁸로 나눈 값이다. 작은 개입이 두 시점 모두 공개 정상 정확도 하락 1%p 이하, logit RMS 0.1 이하가 되게 크기를 정했다. 별도 확인에서 개입 자체의 최대 정확도 하락은 0.625%p였다.

## 정상 기능이 유지된 비교 결과

**가설 한 줄: 공격의 응답 차이는 큰 정상 탈퇴의 응답 차이보다 일관되게 크다.**

| 실제 비교 | Conv D | FC D | 정상 정확도 전→후 % | 평가 전용 ASR 전→후 % |
|---|---:|---:|---:|---:|
| BadFU 위장 850장 삭제 | 0.75848 | 0.47062 | 90.00 → 81.88 | 18.75 → 99.65 |
| 정상 큰 참여자 22.8% 삭제 | 0.76188 | 0.43559 | 88.75 → 80.62 | 2.08 → 1.04 |
| 정상 큰 참여자 19.3% 삭제 | 0.75525 | 0.35156 | 88.75 → 81.25 | 2.08 → 1.74 |
| BadFU 보존 전후 위장 삭제 | 0.70794 | 0.41335 | 90.00 → 88.75 | 18.75 → 100.00 |
| 감염 모델의 정상 자료 삭제 | 0.70360 | 0.41162 | 90.00 → 87.50 | 18.75 → 17.71 |
| FUBA 보존 전후 억제자 삭제 | 0.77774 | 0.07045 | 68.75 → 74.38 | 97.92 → 81.60 |
| 정상 보존 전후 참여자 삭제 | 0.82753 | 0.09382 | 73.44 → 73.12 | 93.06 → 87.15 |

- **BadFU 큰 정상 탈퇴:** 공격 0.75848은 정상 19.336% 탈퇴 0.75525와 정상 22.790% 탈퇴 0.76188 사이에 있다. 이번 자료의 D 하나에 단조 임계값을 적용해서는 양쪽 정상 대조와 공격을 모두 분리할 수 없다.
- **BadFU 같은 감염 출발 모델:** 위장 850장 삭제와 정상 850장 삭제의 Conv D는 0.70794와 0.70360이다. FC D도 0.41335와 0.41162로 가깝다. ASR은 18.75→100.00%와 18.75→17.71%로 크게 달랐지만, 이 점수의 간격은 작았다. 독립 학습 실행으로 분리 성능을 입증한 결과가 아니다.
- **FUBA 기능 유지 보존 전후:** 공격 Conv D 0.77774보다 정상 D 0.82753이 높았다. FC D도 공격 0.07045, 정상 0.09382로 정상에서 더 컸다. 이 정상 요청은 실제 전체 자료의 6.268%인 3,134장을 가진 참여자 삭제다.
- 클래스 균등 FC는 BadFU 큰 탈퇴 대조에서 순위 차이가 있었지만 FUBA 보존 전후의 순서는 반대였다. 사전 명시한 12개 지표 조합 중 위 세 유효 대조에서 모두 공격 점수가 높았던 조합은 **0개**였다. 이는 임의의 다른 분류기가 불가능하다는 증명이 아니다.

정상 최댓값은 비교 기준이며 보정된 임계값이 아니다. 이 소수의 같은 학습 시드·여러 삭제 요청으로 FPR이나 TPR을 추정하지 않는다. 학습 방향 3개도 독립 FL 학습 반복이 아니다.

## FUBA에서 ASR을 정답으로 쓰면 생기는 문제

**가설 한 줄: 공격 실행의 고정 생성기에 대한 높은 ASR은 독성 학습 모델에만 나타난다.**

실제 s20261020 실행의 삭제 전 집계 생성기를 정상 학습 모델에도 적용했다. 정상 모델 정확도는 73.44%였지만 ASR은 이미 **93.06%**였다. 정상 참여자 삭제 후에도 정상 정확도 73.13%, ASR **87.15%**였다. 공격 모델 ASR은 97.92→81.60%로, 삭제 후 증가한 잠복 활성화 사례도 아니었다.

따라서 이 보존 FUBA 조건에서 높은 ASR을 곧바로 독성 학습·악성 삭제 요청의 정답으로 놓으면 안 된다. 생성기의 정상 모델 전이가 함께 나타났다. 이 측정은 잘못된 s42 생성기를 섞은 결과가 아니라 **해당 s20261020 실행의 고정 생성기**를 사용한 교차 대조다. 원 저자의 마지막 개별 생성기 train 모드 수치와 달리, 이번 평가는 고정 집계 생성기의 eval 모드다.

ASR은 서버 탐지 점수 60개 조건을 저장·해시 고정한 뒤 평가에만 사용했다. 평가 입력은 클래스 균형 320장 중 원래 목표 클래스 32장을 제외한 288장이다.

## BadFU 저자 원 FedEraser 추가 확인

**가설 한 줄: 원 저자 FedEraser의 실제 전후에서도 같은 잔류 참여자의 능동 응답 차이를 계산할 수 있다.**

원래 위장 참여자 5를 전후 모두 제외하고 잔류 참여자 0–4의 같은 2,560장 표본과 가중치를 사용했다. Conv D는 **0.70060**, 정상 정확도는 **87.50→85.94%**, ASR은 **80.56→99.65%**였다. 이 값은 별도 저장한 저자 원 FU 조건이며 5시점 변형·전체 재학습과 합치지 않는다. 대응하는 동일 저자 FU 정상 대조가 없어 이 한 점만으로 분리 성능을 확정하지 않는다. 삭제 전부터 높은 ASR을 잠복 공격 예측 성공으로 해석하지 않는다.

## 왜 같은 잔류 집합만으로 해결되지 않았는가

같은 잔류 집합은 구성 변경 자체를 통제한다. 그러나 작은 개입에 대한 대칭 응답은 주로 모델의 손실 곡률 H(θ)를 읽으며, 전후 응답은 그 변화량을 읽는다. 큰 정상 참여자 탈퇴도 정상 특징과 곡률을 바꾼다. 클래스 비중을 균등하게 맞춰도 클래스 안의 입력 분포와 없는 클래스의 영향은 남는다.

따라서 추가 관측은 실제로 확보했지만, 이 관측을 공격에 특이적인 특징으로 바꾸는 데 성공하지 못했다. BadFU에서 실제 공격 활성화와 정상 탈퇴를 비교했는데도 주 점수가 겹친 것이 이번의 직접적인 반례다. 이 결과로 모든 능동 진단의 불가능성을 증명하지 않는다.

## 계산 검증과 해석 범위

- 주 비교 10쌍×2개 층×3개 방향=60조건과 저자 FU 추가 6조건을 실행했다. FUBA 효용 붕괴 3쌍은 탐지 성능 근거에서 제외했다.
- 원본 자료·분할·라벨·기록된 가중치 대응을 검증했다. FUBA 모든 노드의 원 분할도 동일했다.
- 전체 모델과 재사용 계산의 출력·기울기가 공개 사전 검사에서 일치했고, 본 검사에서도 512개 특징 캐시를 원 모델과 비교해 최대 출력 오차 0을 확인했다.
- 주 점수의 저장 성분 720개를 다른 계산식으로 재계산해 최대 오차 0을 확인했다. 이 통과는 계산 무결성을 뜻하며 탐지 가설의 성공을 뜻하지 않는다.
- 점수와 개입 선택식은 계산 재사용 수정 전후 동일했다. 원본 모델과 고정 점수 파일의 해시도 유지됐다.
- 계열별 주 원 학습 시드는 하나이고, 저자 BadFU 추가 조건은 별도 seed42 실행이다. 독립 반복 일반화와 낮은 FPR은 검증하지 않았다.
- 참여자가 지정한 감사 계산을 수행하는 조건이다. 진단을 알아보고 위조 응답을 보내는 적응 공격의 저항성은 입증하지 않았다.

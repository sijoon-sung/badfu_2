# 실제 언러닝 전후 능동 진단 결과

**가설 한 줄: 동일한 잔류 참여자가 동일한 개입에 보이는 언러닝 전후 응답 변화는 큰 정상 non-IID 참여자 전체 삭제와 공격을 구별한다.**

**사전 고정한 주 점수로는 두 공격을 큰 정상 non-IID 삭제와 공통으로 구별하지 못했다.** 보존된 원 실행의 유지 자료 전체 재학습 전후 4쌍과 동일한 FedEraser 변형의 전후 6쌍을 나눠 검사했다. 개인 자료와 생성기는 DISLAB 내부에 남겨 계산했다.

추가 관측 조건은 공개 정상 과제 자료, 전후 모델 보존, 같은 잔류 참여자들을 다시 연결할 수 있는 기능, 그리고 표준화한 진단 손실을 계산해 주는 참여자 응답이다. 이번 구현은 DISLAB 내부 시뮬레이션이며 안전 집계나 신뢰 실행 환경을 구현한 시스템 평가는 아니다.

## 실제 모델과 고정 잔류 조건

| 조건 | 실행 내용 |
|---|---|
| BadFU 원 실행 | dominant 0.7, 40라운드, 로컬 5 epoch, 배치 32인 Paper32의 실제 독성·원래 라벨 위장 자료와 보존 전후 모델 |
| FUBA 원 실행 | Dirichlet α=0.5, 100라운드, 배치 64인 s20261020의 원 MPI 학습·전체 유지 자료 재학습 모델, 실제 20개 분할과 해당 실행의 생성기 |
| 동일 FU 비교 | 보존 5개 시점, 실제 제출됐던 잔류 참여자만 1 epoch 재보정, 이전 업데이트 norm과 새 방향을 결합하는 FedEraser 변형 |
| 정상 큰 탈퇴 | BadFU 11,395/50,000=22.790%, 9,668/50,000=19.336%; FUBA 4,305/50,000=8.610% |
| 전후 고정 | 같은 잔류 참여자, 같은 개인 입력·라벨, 같은 집계 가중치, 같은 교란 방향과 크기 |
| 진단 자료 | 잔류 참여자별 실제 자료에서 최대 512장을 미리 고정. FU 자체에는 전체 해당 자료 사용 |
| 서버 개입 | 마지막 Conv와 FC에 무작위 두 방향·실제 FU 방향의 작은 양·음 교란. 공개 정상 500장으로 두 시점 모두 정확도 하락 1%p 이하와 logit RMS 0.1 이하 확인 |
| 새 응답 | 각 교란 모델에서 새로 계산한 1회 평균 CE 업데이트. 원래 비중과 참여자 내부 클래스 균등 비중 분리 |
| 탐지 금지 정보 | 실제 트리거, 생성기, 목표 라벨, ASR, 역할, 개인 자료·클래스 빈도 |

FUBA 감사는 참여자 내부에서 **해당 실행의 삭제 전 생성기와 30% 마스크를 고정**해 새 CE 응답을 계산하는 조건이다. 전체 MPI 생성기 재최적화·협력 학습·gamma 선택을 진단마다 재실행한 것이 아니다. 악성 참여자가 진단을 알아보고 깨끗한 대리 응답을 반환하는 경우의 저항성도 이 결과로 입증하지 않는다.

BadFU는 잔류 자료 수에 비례해, FUBA는 잔류 선정 참여자에게 균등하게 집계한다. FUBA의 8.610%는 자료 비중이며 원 학습의 집계 가중치 8.610%라는 뜻이 아니다. FUBA 평가용 ASR도 고정한 삭제 전 집계 생성기의 eval 모드로 계산했으며, 원 저자의 마지막 개별 생성기 train 모드 수치와 구분한다.

정상 BadFU 22.8%·19.3% 대조는 이미 완료된 동일한 5시점·1 epoch·SGD·배치·분할·BN 규칙의 모델을 재사용했다. 그 두 가중치의 SHA256을 확인했다. 나머지 동일 FU 비교의 후 모델은 이번에 실제로 계산했다. 보존된 전체 재학습 전후와 5시점 FU 변형을 같은 삭제 알고리즘의 반복으로 합치지 않는다.

## 사전 고정한 주 점수

**가설 한 줄: 클래스 균등 Conv 응답의 전후 변화는 정상 자료량이 큰 참여자 삭제보다 공격에서 더 크다.**

한 방향의 검사는 아래 네 모델에서 새 응답을 받는다. 삭제 전후 모델은 실제 다른 단계의 모델이고, 작은 양·음 교란은 그 각각에 적용하는 진단 개입이다.

| 모델 시점 | 작은 음의 교란 | 작은 양의 교란 |
|---|---|---|
| 삭제 전 | θ전−v에서 같은 잔류 자료로 계산 | θ전+v에서 같은 잔류 자료로 계산 |
| 삭제 후 | θ후−v에서 같은 잔류 자료로 계산 | θ후+v에서 같은 잔류 자료로 계산 |

집계 개인 응답 U와 공개 정상 응답 U_C로 각 시점의 차분 R=(U+−U−)/(2‖v‖)를 계산했다. 주 점수는 ‖(R후−R_C후)−(R전−R_C전)‖를 공개 응답 두 norm의 합과 10⁻⁸로 나눈 D다. 세 방향 중 최댓값을 사용하기로 결과 전 고정했다. FC, 원래 클래스 비중, 전후 이상 수준과 평균 업데이트 변화는 별도 민감도 지표로 보존했다.

- BADFU: 공격 0.75848, 정상 최댓값 0.76188; 공격이 더 큼 = False.
- FUBA: 공격 0.33722, 정상 최댓값 1.0146; 공격이 더 큼 = False.

보존된 실제 전체 재학습 전후도 별도로 비교했다.

- BADFU 보존 전후: 공격 0.70794, 대조 0.7036; 공격이 더 큼 = True.
- FUBA 보존 전후: 공격 0.77774, 대조 0.82753; 공격이 더 큼 = False.

BadFU의 s02는 감염된 같은 출발 모델에서 850장 정상 자료만 삭제한 요청이다. 따라서 공격 모델의 존재와 악성 삭제 요청의 구별을 분리해서 보아야 한다. 이 요청을 깨끗한 모델의 정상 대조와 합쳐 FPR을 추정하지 않으면서, s01과의 요청 구별 대조로 명시했다.

이 정상 최댓값은 **이번 자료의 비교 기준이며 보정된 임계값이 아니다.** 같은 몇 개 모델로 임계값을 정하고 FPR·TPR을 계산하지 않았다.

두 계열의 공격 점수가 두 계열 전체의 모든 정상 점수보다 높은 순서가 성립하는지도 별도로 기록했다: **False**. 계열 내 순위와 하나의 공통 임계값 가능성을 혼동하지 않는다. [사전 명시한 민감도 지표](PREDECLARED_SENSITIVITIES.json)는 주 점수를 대체해 최고 성능을 고르는 데 쓰지 않았다.

정상 정확도는 320장, ASR은 원래 목표 클래스 32장을 제외한 288장이다. 이 공개 확인 자료는 앞선 연구에도 사용했으며 새 연구 시험 집합으로 부르지 않는다. ASR은 전체 60개 진단 점수가 저장·해시 고정된 뒤 별도로 계산했다. 높은 전이 ASR만으로 정상 학습 모델을 독성 학습 모델이라고 판정하지 않는다. 감염 모델의 정상 요청 s02도 깨끗한 정상 요청과 구분해 표시했다.

진단 교란 자체의 확인 정확도 최대 하락은 0.625%p였다. 이 값과 FU로 인한 정확도 변화는 다르다. 표의 FU 정확도 하락을 숨기거나, 효용이 나쁜 FU 결과를 탐지기의 성공으로 바꿔 해석하지 않는다. 5개 보존 시점의 변형은 원 저자 전체 보존 일정의 재현이나 정확한 망각 인증이 아니다.

## 저자 코드의 실제 FedEraser 추가 확인

**가설 한 줄: 원 저자 FedEraser의 실제 전후에서도 같은 잔류 참여자의 능동 응답 차이가 관측된다.**

주 비교 결과를 읽어 방법을 고르기 전에 별도 조건을 고정하고, 보존된 저자 full6 → fu_remove5 전후를 추가로 검사했다. 원래 위장 참여자 5를 전후 모두 제외하고 잔류 참여자 0–4의 같은 자료·표본·가중치를 사용했다. 앞선 전체 재학습 전후나 5시점 FU 변형과 구분한다.

- 주 지표와 같은 클래스 균등 Conv 최대 D: **0.7006**.
- 정상 확인 정확도: **87.50% → 85.94%**.
- 평가 전용 ASR: **80.56% → 99.65%**.
- 추가 진단 6조건, 같은 잔류 참여자 5명, 고정 개인 표본 총 2560장. 이 쌍에 대응하는 동일 원 저자 절차의 깨끗한 정상 FU 대조는 없어 이 값만으로 분리 성능을 확정하지 않는다.

삭제 전 ASR이 높은 보존 쌍을 잠복 공격의 예측 성공으로 해석하지 않는다. 이 추가 확인의 점수도 ASR 평가 전에 별도로 고정했다.

## 결과가 의미하는 정보

작은 교란의 대칭 응답은 대략 −ηH(θ)v인 손실 곡률을 측정한다. 전후 비교는 그 곡률의 변화를 읽는다. 큰 정상 기여의 삭제도 모델의 표현과 곡률을 바꿀 수 있으므로, 추가 응답이 생겼다는 사실만으로 공격 특이성이 보증되지는 않는다. 클래스 균등 계산도 클래스 내 입력 분포와 없는 클래스의 차이까지 제거하지 않는다.

같은 잔류 집합을 쓰면 참여자 구성 변경 자체의 영향을 제외할 수 있다. 이번 결과는 그 조건에서 실제 새 응답을 계산한 비교이며, 삭제 전 모델 하나에만 합성 패턴을 붙인 검사는 아니다. 역할 식별과 정화 성공은 이 실험의 판정 대상에 포함하지 않는다.

## 검증과 범위

- 전후 10쌍, 각 2개 층과 3개 교란 방향, 총 60개 진단 조건을 완료했다. 한 조건에서 전후와 양·음 모두 새로 계산했다.
- 저장된 집계 벡터에서 점수를 다른 코드 식으로 다시 계산했다. 최대 절대 오차는 0였다.
- 점수 함수는 집계 응답·공개 정상 응답·교란 norm만 인자로 받는다. 실제 변형이나 ASR은 검사 인자로 받지 않는다.
- 각 쌍에서 잔류 참여자와 입력·라벨 표본을 한 번 만들고 전후·모든 방향에서 그대로 재사용했다. 원본 모델 파일 해시도 확인했다.
- 계열별 원 학습 시드는 20261020 하나이며 공격·정상 조건별 궤적을 재사용한다. 세 방향이나 여러 삭제 요청을 독립 FL 학습 시드로 세지 않는다.
- 공개 입력의 원래 전체 모델과 캐시 계산을 비교한 사전 검증에서 출력과 선택한 그룹의 기울기가 일치했다. 전체 진단 과정에서도 각 새 특징 캐시의 출력을 원 모델과 비교했다.

# 영향력 기반 탐지 검증 최종 결과

2026-10-22 · 사용자 PC RTX 4060 Laptop · **7개 완전 이력 쌍, 2개 부분 이력 사례, 실제 전후 모델 8쌍**

**가설 한 줄: 의심 입력과 정상 참조 입력의 이력 영향을 함께 비교하면 정상 non-IID와 공격의 혼동이 줄어든다.**

정상 참조 보정 이후에도 BadFU 공격 학습 모델과 정상 non-IID 모델의 점수가 겹쳤다. 이 절차로 두 공격을 공통 탐지했다고 주장할 수 없다.

## 무엇을 검증했는가

- 실제 참여자 제출과 글로벌 모델에서 입력 손실 기울기와 업데이트의 내적을 계산했다. 원 논문식 내적, 실제 집계 가중 내적, 저자 코드의 업데이트 방향 정규화를 비교했다.
- 트리거·실제 목표 클래스·ASR·악성 역할 정답은 점수 계산기에 주지 않았다. 기존 fit 자료에서 클래스별 후보를 고정하고, 예약 공개 자료에서 세 source 예와 정상 클래스 참조·다섯 무작위 참조를 검사했다.
- 자연 이미지 지지 집합은 클래스별 첫 이미지 총 10장이다. 이들에서 만든 변형 예 30개, clean 참조 10개, 무작위 참조 50개를 사용했다. 예약 풀 320장을 전부 사용한 탐지 성능 검증으로 해석하지 않는다.
- 전체 등록 참여자를 포함하며 선택된 다섯 체크포인트에 한 번도 참여하지 않은 경우 영향은 0으로 초기화했다. 삭제 후 명단에서는 실제 삭제한 참여자를 제외했다.
- 다음은 FLForensics의 점수와 공개 군집화 코드를 미지 입력 후보에 적용한 검증이다. 원 논문은 이미 확보한 의심 오분류 입력에서 추적을 시작한다. 원 학습 벤치마크 전체, 실제 사고 입력 제공 조건, 역 Hessian 영향력 함수를 재현한 것은 아니다.

## 실제 판정과 오탐

## 근사 타당성과 실패 해석

**가설 한 줄: 라운드별 기울기와 실제 업데이트의 내적은 해당 라운드의 실제 손실 변화를 충분히 예측한다.**

참조 보정 점수를 J=-sum_t (g_s-g_r)^T delta_i라고 두면, 정상 변화 delta_N이 소거되려면 (g_s-g_r)^T delta_N이 작아야 한다. non-IID라는 이유만으로 이 직교 조건이 성립하지 않는다. 정상 모델의 적대적 취약성을 찾은 입력도 정상 학습 업데이트에 선택적인 영향을 받을 수 있다. 이는 참조를 빼면 정상 변화가 자동 제거된다는 보장이 없음을 뜻한다.

또한 실제 손실 변화는 1차 파라미터 항 + 비선형 파라미터 잔차 + BN buffer 변경 효과로 나뉜다. 근사 오차가 크다는 사실만으로 영향 순위도 반드시 실패한다고 결론 내리지는 않는다. 실제 사고 입력을 제공한 조건, 더 많은 체크포인트, 새로운 정상·공격 학습 시드를 나눠 검증해야 한다.

## 검산과 완료 범위

- 이력 파일 70개 SHA256 확인 완료. 서로 다른 조회 후보 때문에 체크포인트-후보 문맥 80개, 단일 입력 기울기 7200개를 계산했다.
- 전체 영향과 층별 합의 최대 오차는 3.99e-12, 실제 집계 파라미터 재구성 최대 오차는 3e-07였다.
- FUBA에서 발견한 FP32 합산 오차를 같은 입력 벡터의 독립 FP64 합산으로 확인했다. 허용 오차를 늘리지 않고 전체 이력 점수를 FP64 합산으로 재계산했다. 초기 결과와 실패 기록은 별도 보존했다.
- 과거 PGD64 두 사례는 삭제 후 이력이 없어 전후 모델 검증과 삭제 전 이력만 포함했다. 없는 궤적을 만들어 채우지 않았다.
- PUMA 전체 재가중, IndirectVerify 사전 검증 샘플 삽입, 학습 Hessian 역행렬을 이용한 삭제 영향 예측은 이번 완료 범위에 포함되지 않는다.

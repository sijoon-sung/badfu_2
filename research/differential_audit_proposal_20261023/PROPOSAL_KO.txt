가설: 삭제 전 정답·삭제 후 표적 오답인 변형 규칙을 직접 찾고 독립 정상 참여자에서 확인하면, 최소 변형 비용보다 같은 정상 오탐률에서 공격성 삭제를 더 많이 찾는다.

권고
최소 비용 점수 자체를 주력으로 밀지 않는다. 다음 주력 후보는 '언러닝 전후 기능 차이에 대한 능동 검증'이다.
제안은 성공을 보장하는 방법이 아니다. 차이를 찾는 목적을 바꾸고, 추가 정상 자료에서 그 차이가 실제인지 검증하는 연구 설계다.
공격자·위장자 식별은 별도2단계로 유지한다. 이번1단계의 목표는 위험한 삭제 결과를 정상 삭제와 구별하는 것이다.

현재 자료의 범위
research/00_trajectories/README.md와 catalog.json을 우선 확인했다.
현재 FUBA에는 승인된 잠복 활성화 전후쌍이 없다. 수정 후보의 저장 무결성과 공격 억제 성공을 구별한다.
BadFU 큰 정상 참여자 삭제의 미완료31라운드를 최종 대조로 사용할 수 없다.
과거 FUBA 비용 점수11.30/27.49는 해당 실패 조건의 진단이다. 유효한 잠복 FUBA에 대한 기각 실험으로 확장하지 않는다.
이 제안에서 실제 FL 학습이나 새 체크포인트 탐지 실험은 수행하지 않았다. mechanism_check.py는 구성한 수학적 예시만 검사한다.

현재 방식이 놓칠 수 있는 이유
1. 입력 범위: 공통 변형 하나는 이미지마다 다른 변형 규칙을 놓칠 수 있다. 전역 잡음이라는 이유만으로 놓친다는 뜻은 아니다.
2. 목적함수: 삭제 후 모델에서만 탐색하면 삭제 전에도 있던 가까운 일반 오분류 경로를 다시 찾을 수 있다.
3. 요약 손실: 기존 경로 비용0.01, 새 공격 경로 비용0.04이면 최소 비용은 전후 동일하다. 결과가 다른데 점수는 같을 수 있다.
4. 정상 편중: 큰 정상 참여자 탈퇴도 특정 클래스의 경계·강건성·Conv/FC 반응을 바꾼다. 변화량 자체에 악성 표지는 없다.
5. 자료 적합성: 삭제 전부터 활성화된 공격, 다른 학습 실행의 정상 대조, 미완료 FU는 목표 잠복 활성화 검증을 대체하지 못한다.
위1~4는 구조적 한계/가능한 원인이다. 각각이 실제 FUBA 실패의 원인이라고 모두 인과적으로 입증한 것은 아니다.

바꾸려는 핵심
기존: 각 모델의 오분류 비용을 따로 최소화하거나, post만 속이는 입력을 찾은 뒤 전후에 교차 적용한다.
제안: 탐색 단계부터 pre는 원래 정답을 유지하고 post만 잘못된 목표를 출력하도록 동시에 최적화한다.
이미지별로 새 최적화를 반복하는 것과, 탐색 자료에서 T_psi(x)를 학습한 뒤 새 이미지에 그대로 적용하는 것을 구별한다.
후자는 이미지마다 다른 변형도 허용하되, 배운 하나의 규칙이 다른 입력에도 작동하는지 시험할 수 있다.
그 규칙을 찾았다고 실제 공격 트리거나 G를 복원했다고 부르지 않는다. 정상 적대적 취약성에도 이런 규칙이 있을 수 있다.

서버 입력
필수: 요청 직전의 실제 분류기 f_pre, 배포 전 삭제 후보 f_post, 같은 과제의 정상 이미지와 정답, 입력 기울기.
권장 추가 조건: 별도 정상 검증 자료를 가진 신뢰 가능한 잔류 참여자 집합 R, 고정한 평가 절차와 클래스 가중치.
진짜 트리거, 실제 목표, ASR, 공격 역할, 삭제된 원자료, 존재하지 않는 깨끗한 post 분류기는 받지 않는다.
R은 서버가 신뢰할 수 있는 정상 협조자를 확보했다는 추가 가정이다. 신뢰할 수 없는 참여자의 임의 응답을 정답처럼 믿지 않는다.
삭제한 참여자는 R에 포함하지 않는다. 동일 R이 동일한 자료와 가중치로 pre/post를 함께 평가한다.
각 클래스·도메인에 정상 검증 자료가 없으면 그 영역은 판정 보류한다. 참여자 수만 늘어도 대표성이 생기는 것은 아니다.

실행 구조
실제 삭제 전/후 분류기
  → 공개 정상 탐색 자료에서 전후 차이를 직접 키우는 후보 T_psi를 찾음
  → 후보와 모든 하이퍼파라미터를 고정
  → 별도 정상 이미지와 동일한 정상 잔류 참여자들에서 전후를 동시에 검사
  → 큰 정상 참여자·희소 클래스·도메인 탈퇴의 정상 기준 분포와 비교
  → 위험 경보 / 검사 통과 / 자료 부족에 따른 판정 보류
경보를 악의적 의도의 증명으로 부르지 않는다. 검사 통과도 임의의 모든 숨은 트리거 부재 증명은 아니다.

입력 탐색의 수식
서버의 정상 탐색 자료를(x,y), 탐색 목표를c!=y라 한다. 모든 클래스를 탐색하고 실제 공격 목표를 입력하지 않는다.
J_c(T)=E[log p_post(c|T(x)) + lambda*log p_pre(y|T(x))] - beta*complexity(T).
이 목적은 기존의 '두 모델 모두 잘 속이는' 쉬운 방향에 머무는 것을 억제한다. 성공/정상 구별을 보장하는 식은 아니다.
T의 허용 범위는 사전에 선언한다. 국소 마스크, 전역 가산 변형, 입력 의존 변형을 같은 판정 절차로 검사한다.
실제 공격의 위치·패턴·생성기를 후보 정의에 복사하지 않는다. 변형 예산과 탐색량은 공격 결과를 보기 전에 고정한다.
입력 영역과 라벨 유지 조건도 고정한다. 작은 norm이 의미 보존을 자동으로 증명하지 않으므로 과제별 유효성 검사 또는 별도 정답 검수가 필요하다.

독립 확인의 관측
B(x)=1{f_pre(x)=f_post(x)=y}.
W_c(x,T)=B(x)*1{f_pre(T(x))=y and f_post(T(x))=c and c!=y}.
새 표적 오류율 A_c(T)는 전체 정상 확인 자료의 y!=c인 샘플을 분모로 한 W의 비율이다.
B로 제한한 조건부 비율과 B의 전체 커버리지도 함께 보고한다. 일부 쉬운 샘플만 남겨 큰 비율로 포장하지 않는다.
이는 실제 공격 G로 측정한 ASR이 아니다. 서버가 찾은 탐색 입력에서의 기능 검사다.
필요하면 확률 반응의 차분도 보존한다:
D_c(x,T)=[p_post(c|T(x))-p_post(c|x)]-[p_pre(c|T(x))-p_pre(c|x)].
확률 차분은 정상 기능 변화를 자동으로 제거하지 않으며, 확률 보정 차이도 영향을 줄 수 있다. 주 확인은 실제 정답/오답 사건과 커버리지다.
Conv/FC는 이런 기능 오류가 나타난 입력에서 어느 층 반응이 달라졌는지 읽는 보조 분석으로 둔다.

정상 non-IID 대조가 여전히 필요한 이유
큰 정상 탈퇴도 pre 정답/post 오답 사례와 적대적 강건성 하락을 만들 수 있다.
따라서 위 관측이 생긴다는 사실만으로 공격이라 판정하지 않는다. 정상 삭제에서도 같은 전체 탐색/최댓값 선택을 실행해야 한다.
여러 목표와 여러 변형을 검사한 뒤 최댓값을 쓰면, 정상 보정에서도 같은 최댓값을 계산해 다중 탐색의 경보 증가를 포함한다.
정상 보정 실행과 공격 성능 확인 실행은 학습 실행 단위로 분리한다. 같은 모델의 여러 삭제 요청/여러 라운드를 독립 시드로 세지 않는다.
클래스 비중을 균등화해도 클래스 내·도메인 분포 차이는 남는다. 클래스 보정만으로 non-IID가 해결된다고 주장하지 않는다.

기존 능동 함정과의 차이
research/active_unlearning_audit_20261022의 FC 대칭 차분은 같은 특징에서 CE 라벨 항을 소거했다.
이번 제안은 클래스별 정답을 이용한 전후 기능 사건을 새 비공개 자료에서 관측한다. 같은 FC 곡률 점수를 다시 이름 붙인 것이 아니다.
클라이언트 피드백 발상 자체는 BaFFLe/CrowdGuard에 이미 있다. FU 실제 전후 탐색과 결합한 성능/신규성은 별도 검증해야 한다.

검증 카드 H0: 기제 점검
가설: 전후 기능 차이를 직접 탐색하면 최소 변형 비용이 놓친 새 오류 구간을 찾을 수 있다.
조건: 두 개의 구성한1차원 분류기. 기존 오분류 구간은 같고 post에 새 구간만 추가한다. 실제 BadFU/FUBA 실험이 아니다.
비교: 이상적 최소 비용 대 선언한 입력 범위의 전후 차이 탐색.
결과: MECHANISM_CHECK.json에 저장. 같은 최소 비용이어도 새 구간의 기능 차이는 양수다.
판정: 이 예시에서 기제는 확인 가능. 실제 정상 non-IID와의 구별은 미검증.
반증 범위: 전후 차이 탐색이 모든 백도어를 찾거나 정상 삭제를 배제한다는 명제로 확장하지 않는다.

검증 카드 H1: 탐색 목적 변경
가설: 전후를 함께 최적화한 탐색은 post만 최적화한 탐색보다 같은 정상 오탐률에서 공격성 삭제를 더 찾는다.
조건: 승인된 실제 전후 모델. 먼저 badfu.paper32.s20261020을 retrain_activation 용도로 선택한다.
비교: 같은 T 구조/예산/초기화/자료에서 post-only와 paired objective만 바꾼다. 서버 정상 확인 자료에서 먼저 확인한다.
결과: 미실행. 선택한 모델은 select_case.py의 출력으로만 얻으며 DISLAB에서 해시와 payload_key를 검증해야 한다.
판정: 미검증.
반증 기준: 승인 사례에서도 새 오류 후보가 없거나 정상 삭제가 같은 점수를 보이면 탐색 목적 변경만의 효과를 주장하지 않는다.

검증 카드 H2: 정상 참여자의 추가 정보
가설: 동일한 정상 잔류 참여자의 독립 확인은 공개 자료만 검사할 때보다 큰 정상 탈퇴의 오탐을 줄인다.
조건: 후보 T는 확인 전에 고정, 동일 R/가중치/자료, 삭제 자료 재사용 없음, 정답과 평가 실행의 신뢰 보장.
비교: post-only/paired search × 공개 확인/정상 참여자 확인의2×2비교. 보조 관측 유무의 추가 가치를 분리한다.
결과: 미실행. 과거 교란 파일럿96응답은 이 검증의 완료 결과가 아니다.
판정: 미검증.
반증 기준: 비공개 확인에서도 정상/공격이 겹치거나 대표성 부족으로 판단이 불안정하면 추가 정보만으로 해결됐다고 하지 않는다.

검증 카드 H3: 범위 검증
가설: 같은 고정된 검사 절차는 국소 BadFU와 입력 의존 FUBA 모두에서 큰 정상 non-IID 탈퇴보다 높은 새 표적 오류를 보인다.
조건: FUBA부터 올바른 잠복 활성화 재현을 확보. 같은 정확도 보존 기준, 삭제 단위, 고정 잔류 검증 집합을 적용한다.
정상 대조: 임의 삭제, 위장 삭제와 장수 맞춘 삭제, 가장 큰 정상 참여자 전체 삭제, 희소 클래스/도메인 집중 참여자 전체 삭제.
시드: 실제 FL 학습 시드를 바꾸고 자료 분할도 별도 축으로 바꾼다. 탐색 시작점 반복은 독립 FL시드가 아니다.
공격 일반화: 개발에 쓰지 않은 공격군/트리거 위치/입력 의존 변형을 확인에 사용한다. 전체 공격군을 보고 임계값을 고르지 않는다.
결과: 미실행. 큰 정상 삭제31라운드와 FUBA의 삭제 전100라운드를 완성된 대조쌍으로 넣지 않는다.
판정: 미검증.
반증 기준: 두 공격 중 하나에서만 통하면 그 범위를 명시한다. 같은 오탐률에서 추가 탐지가 반복되지 않으면 범용 주력 주장을 중단한다.

진행 우선순위
1. 기존 승인 전후 모델로 H1의 계산 가능성과 독립 정상 이미지에서의 새 오류를 검사한다. 이를 위해 FL부터 다시 학습하지 않는다.
2. 큰 정상 탈퇴와 정상 기준 분포를 완성한 뒤 H1/H2의 오탐 비교를 한다. 미완료 대조를 다른 과거 모델로 메우지 않는다.
3. 재현이 통과한 FUBA를 동일 고정 절차로 평가한다. 재현 실패를 탐지 실패/성공으로 세지 않는다.
4. 두 방향 모두 겹치면 작은 점수 변형을 계속 늘리지 않는다. 공격 의도 판별 주장 대신, 추가 정보가 명시된 배포 전 위험 검증/정화 문제로 범위를 조정할지 판단한다.
5. 정화는 별도 가설이다. pre를 그대로 복구하면 삭제 대상 영향이 되살아날 수 있어 성공한 정화/언러닝으로 부를 수 없다.

범용의 뜻
특정 위치/패턴/목표를 미리 알아야만 가능한 검사가 전부라는 결론은 아니다.
동일 검사 절차로 여러 변형군을 탐색하는 것은 가능하지만, 허용 입력·계산 예산·정상 정답·검증 자료 범위가 필요하다.
아무 제한 없는 모든 숨은 트리거를 유한 기능 검사로 빠짐없이 찾았다고 보장할 수는 없다. 이는 모든 white-box 방법이 불가능하다는 증명이 아니다.
목표 주장은 '선언한 변형 범위와 정상 검증 조건에서 검증된 공격군을 구별한다'로 둔다.

발상과 선행
DeepXplore(2017): 여러 모델의 기능 불일치를 입력 탐색 목표로 사용. 우리 제안은 실제 FU 전후의 선택적 오류를 목표로 한다.
https://arxiv.org/abs/1705.06640
Input-Aware Dynamic Backdoor Attack(NeurIPS2020): 입력 의존 비재사용 트리거. 공통 델타만으로 범용을 주장하기 어렵다는 근거.
https://papers.neurips.cc/paper_files/paper/2020/hash/234e691320c0ad5b45ee3c96d0d7b8f8-Abstract.html
BaFFLe(ICDCS2021): 여러 참여자 자료와 클래스별 성능 피드백. 정상 협조자의 독립 확인 발상과 직접 관련.
https://arxiv.org/abs/2011.02167
CrowdGuard(NDSS2024): 참여자의 로컬 자료/은닉층 피드백과 TEE 기반 검증. 이번 제안의 동일 FU전후 기능 검사와 대상이 다르다.
https://www.ndss-symposium.org/ndss-paper/crowdguard-federated-backdoor-detection-in-federated-learning/
MASA(WACV2025): 개별 제출 모델의 진단 망각과 융합을 이용한 non-IID대응. 기존 우리의 전역 확장 진단을 저자 전체 벤치마크 재현으로 부르지 않는다.
https://openaccess.thecvf.com/content/WACV2025/papers/Xu_Identify_Backdoored_Model_in_Federated_Learning_via_Individual_Unlearning_WACV_2025_paper.pdf
Malicious Forgetting(INFOCOM2026): 실제 FU공격과 방향 부분공간 편차 탐지를 함께 제시. 공개 초록을 확인했으며, 본문 조건/코드 검토 전 범용 성능을 추정하지 않는다. 직접 비교해야 할 선행 후보.
https://ieeexplore.ieee.org/abstract/document/11571403
위 선행은 구성 요소의 발상 근거이며 제안의 FUBA성능이나 신규성을 보장하지 않는다.

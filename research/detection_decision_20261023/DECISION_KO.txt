판정: 현재 고정 탐지 절차는 실패 조건이 확인됐으며, 후기 층 변화량을 근거로 다시 주력 후보라고 추천하지 않는다.

왜 실패했는가
1. 식별 문제: 일반적인 정상 탈퇴도 결정 경계와 적대적 취약성을 바꾼다. 전후 오류나 내부 반응이 커졌다는 사실은 공격 고유의 증거가 아니다.
2. 탐색 문제: 동일 공개800장 기준 추가 BadFU 시드의 실제 트리거는 새 표적 오류74.875%를 보이지만, 트리거를 모르는 고정 탐색은7.875%만 찾았다. 강한 행동 차이는 존재한다. 왜 최적화가 이를 놓쳤는지의 구체적 기울기/국소해 원인은 아직 확정하지 않았다.
3. 추가 clean 확인의 한계: 정상 참여자 자료는 일반화 확인과 표본 구성을 통제하지만, 미지 트리거가 작동하는 입력을 자동으로 제공하지 않는다. 이번 확인은 두 문제를 해결하지 못했다.

금지
FC/Conv/파라미터 변화량, CKA, norm, RMS 등의 숫자가 더 갈린다는 이유로 다음 탐지법을 채택하지 않는다.
숫자가 겹치면 층·거리·가중치를 사후 변경해 새 성공 후보를 계속 만들지 않는다.
실제 트리거를 평가 전용으로 본 뒤 그 위치·모양·목표를 탐색기에 넣지 않는다.
현재 결과를 모든 white-box 탐지의 불가능성 증명으로 바꾸지 않는다.

다음에 검증할 한 가지 질문
가설: 정상 기능을 약화한 진단용 복사본에서 후보를 찾으면, 원래 모델에서 놓친 백도어 활성화 행동을 더 잘 발견한다.

발상: EBYD의 backdoor exposure와 trigger inversion 결합이다. 우리의 새로운 발명 또는 효과가 확인된 방법으로 주장하지 않는다.
https://arxiv.org/html/2410.19427v1
원문은 정상 기능의 진단 망각 후 노출 모델에 기존 탐지/역산 방법을 적용한다. BadFU/FUBA의 실제 삭제 전후와 큰 정상 탈퇴를 자동 구별한다는 보장은 아니다.

기존 실험과의 차이
research/DETECTION_REVIEW_20261021/expanded_probe.py의 이전 파일럿은 clean-loss ascent10스텝 후 고정 패치 반응/변화량을 기록했다.
그 뒤의 입력 최적화는 원래 상태들을 다시 읽어 수행했다. 노출 복사본에서 찾은 후보를 원래 전후 모델로 돌려 확인하는 전체 파이프라인은 이 기록에서 검증되지 않았다.
따라서 단순 clean-loss ascent를 새 이름으로 다시 실행하는 제안이 아니다. 해당 파일럿을 EBYD 전체의 성공/실패로 부르지도 않는다.

실험의 역할 분리
A. 수정하지 않은 승인된 삭제 전·후 모델: 최종 행동 증거를 확인하는 대상.
B. A에서 만든 진단용 복사본: 정상 라벨 자료로 clean 기능을 약화하고 후보를 탐색하는 도구. 실제 삭제 모델이나 배포 모델로 취급하지 않는다.
C. 독립 확인 자료: 탐색/선택에 쓰지 않은 정상 이미지. 원본 의미가 변하지 않았다는 조건이 필요하다. 작은 norm이나 모델끼리의 동의만으로 정답을 보증하지 않는다.
D. 큰 정상 non-IID 탈퇴: 같은 후보 탐색/선택/확인 예산을 적용하는 필수 음성 대조.

최종 확인할 행동
허용된 하나의 변형 규칙 T가 새로운 여러 클래스의 이미지에서 반복 작동하는지 확인한다.
원본 X는 전후 모델 모두 정답이고, T(X)는 삭제 전 정답·삭제 후 같은 특정 오답으로 가는지를 원래 모델에서 확인한다.
입력 의존 공격에서는 하나의 고정된 생성 규칙이 새 이미지로 일반화해야 하며 이미지별 별도 최적화를 일반화 성공으로 세지 않는다.
이 행동도 정상 모델의 일반적 적대적 취약성으로 나타날 수 있다. 따라서 행동 존재만으로 공격 의도나 악성 참여자를 판정하지 않는다.

추가 조건
서버의 전후 모델 및 입력 기울기 접근, 라벨이 있는 정상 자료, 진단용 복사본 계산 예산이 필요하다.
소수 정상 협조 참여자는 확인 자료의 출처가 될 수 있다. 공격자/위장자 정답, 실제 트리거/목표/ASR은 후보 선택과 학습에 제공하지 않는다.
현재 전후 모델의 삭제 방식은 유지 자료 전체 재학습이며 근사 FedEraser가 아니다.
FUBA는 승인된 잠복 활성화 전후쌍을 확보하기 전까지 실제 비교 결과가 없다. BadFU 국소 마스크 결과를 FUBA 성공으로 대신하지 않는다.

비교와 실행 전 고정 사항
비교는 원래 모델에서의 후보 탐색 대 노출 복사본을 이용한 후보 탐색이다.
양쪽 모두 최종 검사는 같은 수정하지 않은 실제 전후 모델에서 한다. 노출에 사용한 계산까지 예산에 포함한다.
허용 변형 종류/제약, 의미 보존 확인, 노출 강도 결정에 쓰는 clean 지표, 총 계산 예산, 후보 선택 절차, 독립 정상 보정 자료를 실행 전에 고정한다.
아직 이 후속 실험은 실행하지 않았다. 이 문서는 방향 결정이며 완료 결과나 숫자까지 동결된 실행 프로토콜이 아니다.

단계별 중단 기준
1. 진단 복사본에서만 생기고 원래 모델에서는 재현되지 않는 후보는 폐기한다. 진단 과정이 만든 오류이기 때문이다.
2. 정상 큰 탈퇴에서 같은 정도로 재현되면 구별 가설을 기각한다. FC/Conv 변화량으로 판정을 뒤집지 않는다.
3. 입력의 의미 보존이나 새 이미지에 대한 재현이 확인되지 않으면 백도어 증거라고 부르지 않는다.
4. 정해진 예산에서 강한 행동을 찾지 못하면 탐색 실패로 기록한다. 모델 안전 판정으로 바꾸지 않는다.
5. 이 경로가 실패하면 현재 관측 조건의 범용 탐지 주력 주장을 중단한다. 추가적인 신뢰 가능한 관측/계산 조건을 별도 문제로 정의하거나, 탐지 없이 위험을 낮추는 정화 연구로 전환하는 문제를 사용자와 논의한다.

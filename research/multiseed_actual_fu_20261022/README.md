## 재개 전 상태 — 2026-10-23

고정된 모델과 사용 범위는 [궤적 목록](../00_trajectories/README.md)을 따른다.

- BadFU seed20261023: `attack_pre`, `attack_FU`, `normal_pre`, `normal_same850_FU`는 각40라운드 완료. 전역 모델 이력과 최종 파일은 보존돼 있다.
- `normal_big4_FU`는31/40에서 CUDA illegal memory access로 중단. 그 뒤 단계와 다음 시드는 완료되지 않았다.
- 개별 참여자 갱신 텐서는 저장하지 않고 해시만 남겼다. 전역 이력으로 쓸 수 있지만 개별 제출 재집계의 새 검증은 지원하지 않는다.
- FUBA seed20261023: 공격100라운드는 저장됐으나 사전 억제 재현 실패(원 평가 ASR98.69%)로 후속 삭제가 중지됐다. 정상 대조는2/100, 뒤 시드는 미실행이다.
- `FU`라는 기존 경로 이름만으로 근사 FedEraser 결과라고 판단하지 않는다. 이 실행의 완료 BadFU 삭제 후 모델은 유지 자료 전체 FL 재학습이다.

이 정리는 원본 체크포인트·오류 기록을 보존하며 학습을 재개하지 않는다.

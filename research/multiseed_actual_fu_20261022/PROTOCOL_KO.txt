가설 H1: 정확도를 유지한 실제 언러닝 전후에서 클래스별 상대 유도 비용 감소는 공격 삭제와 큰 정상 non-IID 참여자 탈퇴를 구별한다.
조건: 실제 초기화와 로컬 학습 난수를 바꾼 학습 시드 20261023·20261024·20261025. 탐색 초기화 2회는 학습 반복 수로 세지 않는다. 분포는 고정해 학습 난수의 영향을 본다.
BadFU: 5참여자·dominant0.7·40라운드·로컬5epoch·배치32·SGD0.01·원본 plain 위장850개. 원 소스의 local_train/FedAvg 실행.
BadFU 대조: 위장850개 삭제 / 같은 원본 인덱스의 정상850개 삭제 / 정상 최대 참여자4 전체19.336% 삭제 / 감염 모델에서 같은 정상 참여자4 삭제 / 정상 모델의 절대 최대 참여자0 전체22.790% 삭제.
FUBA: stcebra/FUBA의 명시적 수정 후보 구현. 20참여자·Dirichlet0.5·참여율0.4·100라운드·배치64. 공개 코드 epoch1·22배치 상한·역할 반복 횟수를 유지하므로 논문 전체 하이퍼파라미터 재현이라고 주장하지 않는다.
FUBA 대조: 위장 참여자4 삭제 / 정상 모델에서 동일 참여자4 삭제 / 가장 큰 정상 참여자 전체 삭제 / 감염 모델에서 동일 정상 참여자 삭제. 모든 조건을 같은 학습 시드·분할·초기값·FU 예산으로 맞춘다.
언러닝: 유지 자료를 대상으로 초기 상태부터 전체 예산 재학습한다. FUBA FU에는 기존 후보 구현의 gamma1 재주입이 있으므로 순수한 잠복 해제와 구별해 표기한다. 보존5시점 단축FU와 섞지 않는다.
추가 서버 조건: 실제 전후 모델·입력 기울기·레이블을 아는 정상 이미지320+320장. 최종400장은 선택에 사용하지 않는다. 실제 트리거·목표·ASR·공격자 역할은 제공하지 않는다.
고정 탐지: 전역 가산 변형10목표·탐색1200단계·초기화2회·독립 보정 성공률95%·이전 연구의 세기 후보와 상대 비용식을 그대로 사용한다. 40% 탐색 경보 기준은 이전 다른 학습 실행에서 가져온 것이며 1% 오경보율 보장이 아니다.
결과: 각 시드의 전후 정상 정확도·클래스 정확도·평가자 전용 ASR·정상 생성기 전이·탐지 점수·경보·탐색 미성립을 그래프로 함께 출력한다.
판정: 양쪽 CA80% 이상·전후 하락2%p 이하·정상 모델과의 전 CA 차이2%p 이하를 사전 연구 기준으로 삼는다. 실패한 시드도 삭제하지 않는다. 이 수치는 논문 저자의 허용 오차가 아니다.
반증 기준: 정상 큰 탈퇴 점수가 공격과 겹치거나, 탐색이 성립하지 않거나, 정확도 유지/공격 재현 조건을 통과하지 못하면 해당 조건에서 성공했다고 주장하지 않는다.

가설 H2: 원시 Conv·FC 변화량이나 정상 출력 변화보다 상대 유도 비용이 큰 정상 탈퇴의 공통 변화를 더 잘 줄인다.
조건: 동일한 실제 모델·동일한 정상 입력으로 모든 Conv·FC의 클래스 평균 활성과 파라미터 상대 L2, 정상 출력·CE 변화를 함께 계산한다.
결과·판정: 새 결과를 보고 FC/Conv 임계값을 만들지 않는다. 변화량만으로 공격 고유 원인을 증명하지 않으며 재학습의 채널 대응 문제를 명시한다.

이름: BadFU와 stcebra/FUBA가 이번 대상이다. 별도 논문·저장소인 ity207/FedUBA는 포함하지 않는다.
실행: DISLAB에서 BadFU는 기존 FUBA 학습과 메모리를 나눠 실행한다. 새 FUBA 시드 실행은 기존 유한 실험이 끝난 뒤 자동으로 이어진다. 최종 판정과 그래프까지 같은 유한 작업에 포함된다.

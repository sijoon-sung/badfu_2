# 실험의 원 기록과 검증 자료

[저장소 첫 화면](../README.md) · [실험 과정 목록](../experiments/README.md)

이 폴더는 실험 당시의 보고서, 설정, 결과 파일과 정정을 보관한다. **실험 과정을 읽으려면 [분야별 목록](../experiments/README.md)에서 시작한다.**

| 찾는 자료 | 위치 |
|---|---|
| 현재 판단과 중요한 반례 | [연구 인덱스](INDEX.md) |
| 가설·조건·정상 대조·결과·해석 범위 | [실험 카드](EXPERIMENT_CARDS.md) |
| 실험 ID와 원 보고서의 연결 | [실험 등록부](experiment_registry.json) |
| 기존 폴더와 실험 카드의 대응 | [전체 폴더 색인](EXPERIMENT_FOLDERS.md) |

| 새 실험을 제안하고 기록하는 기준 | [실험 원칙](EXPERIMENT_RULES.md) |

날짜가 붙은 폴더는 원래 경로를 유지한다. 이전 보고서의 ‘진행 중’, ‘다음 실험’은 작성 당시의 상태이며 현재 판단은 인덱스와 연결된 정정을 기준으로 읽는다.

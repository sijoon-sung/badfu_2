# 삭제 전후 모델을 사용하면 무엇이 나아지는가

2026-10-21 · 기존 실제 체크포인트 8개·4쌍의 관측값 재분석 · 추가 학습 없음

**가설: 삭제 전후 반응 차분은 삭제 후 단일 모델 반응보다 정상적인 배경 변화를 줄여 활성화 사례와 대조 사례의 점수 간격을 키운다.**

**판정: 정상적인 변화의 상쇄는 확인했다. 관측 점수 간격이 더 커지는 것은 조건에 따라 달랐으며, 일관된 탐지 성능 우위는 확인하지 못했다.**

![전후 모델 변화 비교](model_delta_comparison.png)

## 실제로 비교한 세 가지

| 방법 | 계산 | 의미 |
|---|---|---|
| 삭제 후 모델만 | \(R_1=p_1(Tx)-p_1(x)\) | 지금 모델이 패치에 얼마나 반응하는가 |
| 같은 패치 입력에서 모델 전후 | \(G_T=p_1(Tx)-p_0(Tx)\) | 패치 이미지의 출력이 삭제 후 얼마나 바뀌었는가 |
| 모델 전후와 입력 전후를 함께 비교 | \(D=[p_1(Tx)-p_0(Tx)]-[p_1(x)-p_0(x)]=R_1-R_0\) | 일반적인 모델 변화와 비교해 패치 반응이 얼마나 더 바뀌었는가 |

여기서 확률은 특정 클래스의 예측 확률이다. 클래스·패치는 선택 이미지 160개에서 고르고, 별도 확인 이미지 160개에 그대로 적용했다. 실제 트리거·목표 클래스·ASR은 계산에 넣지 않았다. 실제 삭제 전 모델과 보존 데이터 재학습으로 얻은 삭제 후 모델을 사용했다. 동일 모델 복사본을 비교한 것이 아니다.

## 1. 같은 패치·클래스로 네 칸을 비교한 결과

Paper32 주 비교에서 각 쌍의 차분 선택 규칙으로 고른 좌표를 고정해 확인했다. 아래 각 행에서는 두 실제 모델에 동일한 이미지·패치·클래스를 적용했다. 두 행 사이에는 선택 좌표가 다르다.

| 삭제 요청 | 삭제 전 패치 반응 \(R_0\) | 삭제 후 패치 반응 \(R_1\) | 전후 차분 \(D\) |
|---|---:|---:|---:|
| 위장 데이터 삭제 | 3.26%p | 81.38%p | **78.12%p** |
| 정상 데이터 삭제 | 0.85%p | 1.01%p | **0.17%p** |

정상 삭제의 경우 같은 클래스의 확률은 clean 이미지에서 **+2.29%p**, 패치 이미지에서 **+2.46%p** 변했다. 패치 입력의 모델 변화만 보면 2.46%p이지만, clean 입력에도 비슷한 변화가 있어 이를 빼면 0.17%p이다. 이 사례는 전후 차분이 일반적인 변화를 줄이는 이유를 보여준다.

위장 삭제에서는 clean 확률 변화 **-1.15%p**, 패치 확률 변화 **+76.97%p**로 양상이 달랐다. 둘의 차이는 78.12%p이다.

이 상쇄는 모든 정상 변화에 대한 보장은 아니다. 클래스·변형별 공통 성분만 제거하며, 정상 삭제가 패치 반응 자체를 바꾸면 잔차가 남을 수 있다.

## 2. 삭제 후 모델만 보는 방법보다 더 좋은가

세 방법 모두 동일한 후보·선택/확인 분할을 사용하고, 각 방법이 자기 선택 집합에서 별도로 변형·클래스를 골랐다. 위의 고정 좌표 설명표와 아래의 방법별 선택 결과를 구분해야 한다.

| Paper32 국소 전체 | 위장 삭제 | 정상 삭제 | 관측 점수 간격 |
|---|---:|---:|---:|
| 삭제 후 모델의 패치 반응만 | 81.38%p | 4.87%p | 76.51%p |
| 패치 입력의 모델 전후 변화만 | 76.97%p | 2.46%p | 74.51%p |
| 모델·입력 전후 차분 | 78.12%p | 0.17%p | **77.95%p** |

이 조건에서는 차분이 대조 점수를 줄이면서 점수 간격을 **1.44%p** 늘렸다. 그러나 다른 조건에서는 그 간격이 줄었다.

| 조건 | 삭제 후 모델만: 간격 | 전후 차분: 간격 | 차분 적용 시 변화 |
|---|---:|---:|---:|
| Paper32 국소 전체 | 76.51%p | 77.95%p | **+1.44%p** |
| Paper32 공격 위치 제외 | 29.59%p | 26.93%p | -2.66%p |
| PGD64 국소 전체 | 92.29%p | 88.84%p | -3.45%p |
| PGD64 공격 위치 제외 | 42.52%p | 37.55%p | -4.97%p |

점수 간격은 정확도·AUROC·검출률이 아니다. 한 모델 쌍씩의 값이므로 정상 점수를 낮췄다는 사실을 오탐률이 낮아졌다고 바꿔 말할 수도 없다. 서로 다른 학습 조건을 독립 반복 시드처럼 합치지 않는다.

전체 이미지 변형에서는 Paper32의 위장 삭제 차분이 6.28%p, 정상 삭제가 10.20%p였다. 전후 차분을 쓰더라도 변형 자체가 공격 신호를 건드리지 못하면 유효한 구별 근거가 되지 않는다.

## 3. FC·Conv에도 이 비교를 적용했는가

앞선 FC·상류 특징 점수는 이미 실제 삭제 전후의 \(W_1-W_0\), \(h_1-h_0\)를 사용했다. FC 단독 정규화 점수는 Paper32에서 0.462 대 0.426으로 비슷했고, 상류 특징 기여는 3.296 대 0.414로 차이가 났다. 따라서 전후 비교만 추가하면 FC도 좋아진다고 해석할 수는 없다.

Conv 가중치의 전후 이동량 역시 8.13% 대 7.63%로 비슷했다. 사후 분석용 혼합 모델로 분리한 Conv 기능 기여는 1.886 대 0.381이었다. 가중치 변화와 입력에 대한 기능 변화를 계속 구분해야 한다.

## 현재 사용할 해석과 다음 검증

현재는 **‘삭제에 의해 새로 증가한 패치 민감도’의 주 점수로 전후 차분을 두고, 삭제 후 단일 모델 점수를 비교 기준으로 유지**하는 것이 합리적이다. 관측 점수 간격만으로 우열을 확정하지 않는다.

다음 검증에서는 정상 non-IID의 여러 시드·분할·삭제 요청을 별도 보정군/평가군으로 나누고, 동일한 정상 오탐률에서 두 방법의 활성화 검출률을 비교해야 한다. 이때 삭제 전후 모두 높은 반응을 보이는 이미 활성화된 공격은 차분이 작을 수 있으므로 별도 조건으로 포함한다. 차분은 공격 존재 자체보다 활성화 증가를 측정한다.

현재 Paper32 정상 삭제 후에도 공격·위장 데이터는 남아 있다. PGD64 정상 대조는 공격이 없는 모델의 삭제다. 두 대조의 의미를 혼동하지 않는다.

`protocol.json`과 `results.json`에 전체 값·선택 좌표·네 칸 확률을 보존했다. 최초 패치 차분 점수와 재계산 값의 오차는 네 쌍 모두 1e-12 미만이다. 새 독립 실험이 아닌 동일 관측값의 사후 재분석이다.

서버 탐지 방법의 차이와 추가 관측 조건 검증

이번 동일 언러닝 절차의 BadFU 대조에서는 새로운 두 초기화 묶음으로 전체 알고리즘을 반복해도 공격과 큰 정상 삭제의 순서가 유지됐다. 독립 연합학습 반복과 운영 오탐률은 아직 검증하지 않았다.

무엇이 다른가
- 정확도·가중치 변화: 정상 이미지나 파라미터가 전체적으로 얼마나 달라졌는지 측정한다.
- 현재 후보: 정상 이미지들을 한 목표 클래스로 보내는 미지 공통 변형을 찾아, 동일 성공률을 달성하는 비용이 전후 모델에서 얼마나 달라지는지 측정한다.
- 실제 트리거 위치나 패턴을 준 국소 패치 검사가 아니다. 부호가 있는 3x32x32 공통 가산 변형을 10개 목표 각각에 최적화한다.
- 정상 모델도 공통 변형에 취약할 수 있으므로 공통 변형 존재 자체를 공격 증거로 삼지 않는다.
- 구체적인 정상 요청 사례: 기존 감염 모델에서 정상 참여자가 삭제되면 한 시험 변형의 목표 예측률이 20.28%에서 92.22%로 증가했지만, 전후 각각의 저비용 후보를 비교한 원 비용 감소는 19.40%였다. 패턴 방향의 변화와 최소 비용 자체의 감소를 구분할 필요가 있다.

서버에 필요한 추가 정보/기능
1. 실제 삭제 전후 글로벌 분류기와 입력 기울기를 계산할 수 있는 접근. 실제 삭제 후 후보 모델을 배포 전에 검사한다.
2. 같은 분류 과제의 라벨 있는 정상 기준 이미지. 이번 비교는 탐색 80 또는 320장 + 독립 보정 320장이다.
3. 연구 검증용 별도 400장. 이 자료는 후보/목표/임계값 선택에 쓰지 않았다. 운영 탐지의 매회 입력 요구량과 구분한다.
4. 실제 공격 트리거, 목표 클래스, 공격자 역할, 개인 학습 자료, 공격 생성기, ASR은 탐지 입력에 주지 않았다.
5. 정상 삭제 기준군과 독립 학습 반복이 운영 임계값/오탐률 검증에 필요하다. 이번 소수 상관된 쌍으로 해당 수치를 주장하지 않는다.

실험 H1
가설 한 줄: 독립 정상 이미지로 후보를 확인하고 탐색 이미지를 늘리면 비용 비교의 과적합과 초기화 의존이 줄어든다.
조건: 같은 모델/공개 이미지 분할, 80장 대 320장; 2초기화; 클래스당 1,200회; 10개 클래스 전체 탐색.
조건: 보정 규칙/변형 세기 후보를 최종 평가 분석 전에 고정했다. 규칙은 공통 가산 변형 배율 1, 1.25, 1.5, 2, 3, 4와 원 후보의 합집합이다.
조건: 95% 탐색 성공률과 95% 독립 보정 성공률을 모두 만족하는 후보 중 최소 비용. 인증된 전역 최소는 아니다.
결과: 탐색 80장 / 탐색 성공률만 적용 / 평균 확인 성공률 85.71% / 확인 90% 충족 22/120클래스 후보
결과: 탐색 80장 / 독립 성공률·세기 보정 / 평균 확인 성공률 95.99% / 확인 90% 충족 120/120클래스 후보
결과: 탐색 320장 / 탐색 성공률만 적용 / 평균 확인 성공률 93.24% / 확인 90% 충족 115/120클래스 후보
결과: 탐색 320장 / 독립 성공률·세기 보정 / 평균 확인 성공률 95.78% / 확인 90% 충족 120/120클래스 후보

실험 H2
가설 한 줄: 큰 정상 삭제의 여러 클래스 공통 비용 감소를 빼면 특정 클래스에 집중된 백도어 비용 감소가 남는다.
정의: C전,c와 C후,c는 95% 탐색·보정 성공률을 만족하는 후보 비용. q_c=C후,c/C전,c.
보정 점수: S=100*max_c(1-q_c/median_{k!=c}(q_k)). 전체 10개 클래스가 유효해야 주 점수로 취급한다.
수학 확인: 모든 비용이 같은 배율 a로 바뀌면 q_c=a이므로 S=0. 특정 클래스만 추가로 b배가 되면 해당 추가 감소는 100*(1-b).
한계: 이 식은 클래스마다 다른 정상 non-IID 변화까지 없애는 정리가 아니다. 아래 실제 정상 대조로 따로 검사한다.

동일 언러닝 절차 대조 결과: 탐색 320장 + 보정 320장
실제 트리거·실제 목표는 점수 선택에 사용하지 않았다. 아래 목표 예측률은 진짜 트리거 ASR이 아니다.
사례 | 원 감소 점수 | 공통 변화 보정 점수 | 자동 선택 목표 | 같은 후 모델 변형을 전 -> 후에 적용한 확인 목표 예측률
공격: 위장 자료 삭제 | 71.02% | 58.88% | 0 | 18.61% -> 97.50%
정상: 데이터 22.8% 참여자 삭제 | 33.16% | 22.76% | 9 | 74.17% -> 93.89%
정상: 데이터 19.3% 참여자 삭제 | 29.19% | 14.95% | 7 | 81.11% -> 91.67%
정상 분류 정확도(별도 400장):
공격 전후 88.25% -> 79.00%.
정상 22.8% 삭제 86.50% -> 79.50%; 정상 19.3% 삭제 86.50% -> 80.50%.
동일 절차는 정상·공격 모두 정확도가 하락하는 5시점 언러닝 변형이다. 원 논문 수준의 정확도 유지 조건을 충족했다고 해석하지 않는다.
서로 다른 2초기화 묶음 2회 전체 반복: 공격 최저 58.88%, 정상 최고 22.76%.
전체 10클래스 비용 유효: True. 자동 선택 후보의 전/후 확인 성공률 모두 90% 이상: True.
첫 묶음의 초기화 1개씩만 비교한 결과는 계산 예산을 절반으로 줄인 민감도 검사다. 두 초기화를 합치는 원래 알고리즘의 완전한 반복과 구분한다.

공통 변형 방식의 적용 범위
- 여러 정상 입력에 통하는 하나의 변형 방향을 찾는 탐색이다. 입력마다 다른 생성기 전체를 탐색한 것은 아니다.
- 언러닝이 특정 목표로 가는 경로를 더 쉽게 만드는 현상을 검사한다. 삭제 전부터 활성화된 공격의 존재를 증가량 하나로 모두 검출한다는 주장이 아니다.
- 따라서 BadFU 일부 결과를 FedUBA 전체나 모든 공격 형태로 확대하지 않는다. 수정 FedUBA의 실제 전후 검증은 별도다.
- 이 점수는 모델의 취약성 증가 신호다. 삭제 요청자의 악의적 의도나 공격자·위장자 ID를 증명하는 결과가 아니다.
- 클래스 공통 감소 보정만이 분리를 만든 유일 원인이라고 주장하지 않는다. 원 점수도 함께 제시했고, 정상 이미지 수·성공률 조건·탐색의 변화가 함께 검증 대상이다.

재현/자료 조건
- 로컬 12모델·8쌍, DISLAB 동일 5시점 FU 5모델·3쌍. 모델과 전후 쌍을 공유하므로 독립 학습 반복 수와 같지 않다.
- 동일 FU는 원 논문 전체 언러닝 하이퍼파라미터 재현이 아니라 기존 5시점 FedEraser 변형이다. 정상 정확도도 함께 하락하는 조건임을 기록한다.
- 로컬/DISLAB 공개 입력 내용 및 분할 해시, 공유 분류기 해시가 동일함을 확인했다. 모든 선택을 동결한 뒤 확인 자료를 평가했다.
- 원본 분류기/변형 후보/개인 자료를 DISLAB에서 가져오지 않았다. 허용 목록의 수치 JSON만 전송했다.
- 모든 비용을 다시 계산하고 별도 torchvision 모델을 구성해 최종 예측률을 재생했다. 검증 상태: 로컬/DISLAB 모두 passed.

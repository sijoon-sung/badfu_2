넓은 주장부터의 순서와 새 관측
G0 출처: PDF/저자 ZIP/고정 Git blob 동일성, 필수 의존성, 실제 실행 가능성을 확인한다.
G1 알고리즘 계약: 수정하지 않은 upstream 함수의 AST를 분리하여 CPU에서 실행한다. (a) shuffle=True/batch1 민감도 순위가 원 데이터셋 ID와 일치하는지, (b) 순차 로더 양성 대조, (c) 선택 참여자 위치와 실제 클라이언트 ID의 대응을 고정한 합성 자료로 확인한다. 합성 모델은 순위를 미리 알 수 있게 만들며 공격 성능을 뜻하지 않는다. AST 분리는 누락 모듈을 임의 구현하여 전체 실행한 것과 다르다.
G2 재현: G0/G1을 통과하고 필요한 구현/자료 출처 및 논문의 불명확한 조건을 고정한 별도 profile이 있어야 전체 실자료 학습에 진입한다. 원본 FL/실제 FU, 같은 고정 trigger의 pre/post 및 benign-FU ASR-B, clean CA, 샘플 ID·역할·요청 수·optimizer/RNG·전체 로그·해시가 필요하다. 논문 결과를 복사하여 자체 실측으로 적지 않는다.
G3 탐지 적용: G2의 전후 모델과 같은 FU/분할의 정상 작은 삭제 및 큰 non-IID 삭제를 먼저 확보한다. 독립 정상 보정과 서버가 얻을 수 있는 새 행동 관측의 사전 근거가 없으면 탐지 실행은 보류한다. 모델 재현만으로 탐지기를 검증했다고 하지 않는다.

큰 정상 non-IID 반례
D08 공격0.75848은 정상0.75525/0.76188 사이이며 D15 추가 시드 공격7%는 큰 정상8%보다 작았다. 본 감사는 이 반례를 해결하는 새 탐지 점수가 아니다. 새 관측은 코드의 표본 정체 보존과 실제 동작 계약으로, 공격 양성 자료의 적격성을 검증한다. 향후 공격 행동도 큰 정상 삭제에서 나타날 수 있으므로 같은 FU·정상 대조·독립 보정 없이 악성 판정을 만들지 않는다. 과거 D18 한 시드의 분리와 D19 부적격 FUBA 결과는 보존한다.

비교와 범위
저자 ZIP 대 고정 GitHub; 논문 식(5)-(8)/Algorithm1 대 해당 함수; shuffled 대 sequential 로더; 선택된 참여자 위치 대 전체 참여자 ID. 기존 실제 모델은 선택하거나 수정하지 않는다. source 함수 전체 실행/성능 재현과 합성 계약 검증은 구분한다.

중단 규칙
- 출처 해시 불일치면 보존 후 즉시 중단한다.
- 필수 함수/모델 정의의 권위 있는 출처가 없거나 샘플/소유권 계약이 깨지면 untouched-paper 재현과 대규모 학습 진입을 중단한다. 동작을 추측하여 채우거나 조용히 고치지 않는다. 이미 정한 유한 CPU 계약 검사는 원인 확인을 위해 마친다.
- 실제 학습을 못 했다면 ASR/CA/탐지율을 생성하지 않는다. 전체 학습은 이 감사 코드에서 실행하지 않는다. 별도 수정 구현은 변경 목록과 고정 profile의 새 제안이며 본 감사 통과로 세지 않는다.
- 탐지 관측이 정상 큰 삭제와 겹치거나 정상 오탐을 독립 보정할 수 없으면 넓은 탐지 주장을 보류/축소한다.
- 완료된 FUBA v2-v7의 trainer/controller/observer/evaluator/export를 재실행하지 않는다. GPU의 다른 작업을 종료하지 않는다.

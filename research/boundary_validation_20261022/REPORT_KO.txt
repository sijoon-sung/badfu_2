제안한 역산 비용 차분 방법의 독립 검증
실행일: 2026-10-22 / 로컬 RTX 4060 / 실제 삭제 전후 BadFU 모델

결론: 일부 BadFU 쌍에서 신호가 있지만, 큰 정상 non-IID 참여자 삭제까지 안정적으로 구별하는 탐지법으로 확인되지는 않았다.
제안자의 원 스크립트가 없으므로 동일 수치의 정확한 재현은 아니다. 두 가지 가능한 목적함수를 명시하여 독립 구현했다.

가설 한 줄: 공격 삭제 후에는 특정 클래스로 오분류시키는 변형 비용이 정상 non-IID 삭제보다 더 크게 줄어든다.

조건
- 실제 보존된 분류기 13개, 전후 비교 8쌍. 모델과 시드를 공유하므로 8회의 독립 공격 재현이 아니다.
- 실제 공격 트리거, 위치, 목표 클래스, 역할, ASR, 공격 생성기를 탐지 입력으로 사용하지 않았다.
- 정상 공개 이미지 80장으로 탐색, 겹치지 않는 160장으로 확인. 이전 진단에도 쓰인 공개 자료이며 완전히 새로운 최종 벤치마크는 아니다.
- 10개 목표 클래스를 모두 탐색. 클래스당 800회, 초기화 2개. 이 초기화 반복을 연합학습 시드 반복으로 해석하지 않는다.
- 목표 예측률 95% 이상인 탐색 후보 가운데 가장 작은 비용을 저장. 후보와 목표 선택에 확인 자료를 쓰지 않았다.
- 추가 확인 기준 90%는 결과의 일반화 점검용이며 임계값 보정에 쓰지 않았다.

정의
C_hat_c(M) = 유한 탐색 후보 중 목표 예측률 >= 95%를 만족하는 가장 작은 비용.
S = max_c {100 * (C_hat_c(M_before)-C_hat_c(M_after))/C_hat_c(M_before)}.
공통 가산 섭동: T(x)=clip(x+delta,0,1), 비용=sum(abs(delta)), 3x32x32.
마스크·패턴: T(x)=(1-m)*x+m*p, 비용=sum(m), 1x32x32. 위치는 주지 않는다.
서로 다른 두 비용의 절댓값을 직접 비교하지 않는다. 둘 다 인증된 전역 최솟값이나 일반적인 결정경계 거리는 아니다.

해석
1. 공통 가산 섭동은 잠복 BadFU에서 클래스 0 비용 135.10 -> 32.51, 75.94% 감소를 보였다. 후 모델의 확인 성공률은 95.83%다. 실제 목표 0과의 일치는 점수 동결 후 평가에서만 확인했다.
2. 두 탐색 결과를 합친 공통 가산 섭동 점수에서는 보존된 공격/정상 사례의 순서가 나뉘지만, 개별 초기화로 보면 공격 최저 30.20%와 정상 최고 46.37%로 순서가 뒤집힌다. 학습 시드 일반화나 운영 임계값이 검증된 것은 아니다.
3. 마스크·패턴 점수는 정상 무작위 삭제와 정상 주요 클래스 삭제에서도 공격만큼 또는 더 크게 감소했다. 현재 구현/탐색 예산에서 이 점수는 안정적인 분리 지표가 아니다.
4. 다수 후보가 탐색 성공률 95%와 달리 확인 성공률 90%에 미달했다. 탐색 이미지에서의 과적합과 유한 최적화 편차가 비용 비교에 섞였을 수 있다.
5. 제안문이 강조한 기존 6인 모델의 클래스 6 비용 변화는 공통 가산 섭동에서 공격 약 12% 감소, 정상 삭제에서는 소폭 증가로 나타났다. 다만 실제 BadFU 목표는 0이며, 클래스 6만 관찰해 일반 탐지 성능이나 실제 트리거 복원을 주장할 수 없다.
6. 정상 참여자 전체 삭제 대조는 22.79%, 19.336%의 자료를 삭제한 실제 정상 FU 모델이다. 이 두 정상 대조끼리는 동일 5시점 FedEraser 변형을 썼다. 부모 공격 비교의 저자 FU/유지자료 재학습과 절차가 전부 같지는 않으므로 일치 조건의 인과 비교라고 주장하지 않는다.
7. 기존 6인 공격 모델은 삭제 전부터 ASR이 높았다. 잠복 활성화 검증은 Paper32 쌍을 중심으로 해석한다.
8. 이번 결과는 BadFU에 한정한다. 수정 FedUBA의 전체 재학습/실제 FU 쌍이 완료되기 전에는 공통 탐지 성공을 주장하지 않는다.

계산 검증
- 원 체크포인트 SHA256, 탐색/확인 자료 비중복, 모든 후보 비용의 재계산을 확인했다.
- 별도 분류기 생성 및 전처리로 확인 자료 전체를 다시 계산했다. 원 배치와 다른 배치의 최대 예측률 차이는 VERIFIED.json에 보존했다.
- 탐색 결과와 프로토콜의 해시를 동결했다. 정상 라벨과 실제 목표를 뒤늦게 점수 선택에 사용하지 않았다.

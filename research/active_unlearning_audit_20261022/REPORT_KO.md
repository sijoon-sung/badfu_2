# 언러닝 중 능동 진단을 통한 추가 관측 설계

**연구 가설 한 줄: 서버가 선택한 작은 개입에 대해 잔류 참여자가 새로 계산한 반응을 언러닝 전후로 비교하면, 수동적인 모델 차분보다 공격과 정상 non-IID 삭제를 구별할 정보가 늘어난다.**

서버가 진단용 모델을 보내고 새로운 반응을 받는 방향으로 확장한다. 1차로 FC와 마지막 Conv 교란, 원래 클래스 비중과 균등 비중을 비교하는 응답 통제 파일럿을 완료했다. 일부 Conv 조건에서 차이가 보였으나 공통 탐지기는 확보하지 않았다. 실제 FU 전후에 같은 잔류 참여자를 검사하는 검증은 아래 후속 프로토콜이다.

# 서버가 만드는 함정의 의미

| 항목 | 실행할 개입 | 새로 받는 관측 | 해석 조건 |
|---|---|---|---|
| 가중치 교란 | 같은 출발 모델의 선택한 층에 작은 양·음 교란을 적용 | 각 진단 모델에서 새로 계산한 참여자 업데이트 | 저장된 이전 업데이트를 더해서 대체할 수 없음 |
| 학습 목적 변경 | 참여자 내부에서 클래스별 평균 손실을 균등하게 가중 | 원래 비중과 균등 비중의 응답 | 클래스 비중의 영향만 일부 줄임. 클래스 내 분포 차이는 남음 |
| 언러닝 방향 검사 | 실제 전후 가중치 차이 방향을 조금 되돌리거나 더 진행시킴 | 같은 잔류 집합이 그 방향을 얼마나 복구하는지 | 다음 실험의 후보. 큰 정상 삭제도 같은 복구를 보일 수 있어 대조 필수 |

여기서 함정은 **서버가 의도적으로 바꾼 조건에 대한 반응을 측정하는 능동 진단**이다. 공격자의 트리거를 알아내서 입력에 붙이는 방식이 아니다. 서버가 선택한 교란 방향과 크기는 알지만 실제 트리거·목표 라벨·ASR·역할 정보는 판정에 넣지 않는다.

BadFU는 미리 준비한 독성·위장 자료로 정상 학습 절차를 따를 수 있다. 따라서 암호나 계산 지시를 어겼는지만 검사하는 함정은 이 공격을 포괄하지 못한다. 추가 응답을 정직하게 계산한 경우와 진단을 알아보고 정상 응답을 위조한 경우를 따로 검증해야 한다.

# 관련 연구와 차이

[HoneyFL](https://ietresearch.onlinelibrary.wiley.com/doi/full/10.1049/ipr2.70201)은 신뢰할 수 있는 참여자가 방어자 소유 패턴 HoneyDoor와 라벨 대응 관계 HoneyMap을 학습시킨다. 검사 시 원래 입력과 HoneyDoor를 붙인 입력의 예측이 그 관계를 지키는지 판단한다. 식 13–14와 Algorithm 4의 대상은 추론 시 입력이다. 공격 입력이 들어오지 않은 상태에서 언러닝 요청의 악성 여부를 판정하는 방법으로 바로 옮길 수는 없다. 적응 공격 MHLM 평가에는 HoneyMap을 얻는 주기에 제한도 있다.

[BackdoorIndicator](https://arxiv.org/html/2405.20862v1#S3.SS3)는 서버가 OOD 진단 과제를 먼저 심고 참여자의 새 학습 이후 과제 유지율을 검사한다. 앞선 [우리 파일럿](../server_features_20261022/REPORT_KO.md)에서는 정상 기능 손상과 편중 정상 학습의 높은 유지율이 나타났다. 이번 검사는 별도 OOD 분류 과제를 심지 않고, 공개 정상 과제에서 변화가 작은 가중치 개입과 새 응답을 측정한다.

능동 개입이라는 발상에는 이 두 선행을 참고했다. 클래스 균등 응답, FU 전후 동일 잔류 집합, FU 방향 교란을 조합하는 부분은 이번 연구 설계다. 해당 조합의 독창성이나 효과를 선행 논문의 성능으로 보증하지 않는다.

# 완료한 응답 통제 파일럿

## 작은 FC와 Conv 개입

**가설 한 줄: 작은 가중치 교란에 대한 참여자의 새로운 반응은 큰 정상 non-IID 기여와 독성 학습을 구별한다.**

| 조건 | 설정 |
|---|---|
| 출발 모델 | 보존된 정상 학습 BadFU 계열 모델 1개와 FUBA s42 계열 모델 1개 |
| 모델 관계 | 두 계열의 개별 정상 출발 모델. 독립 학습한 정상·공격 모델을 FU 전후 쌍으로 취급하지 않음 |
| 진단 위치 | 최종 FC와 마지막 잔차 블록의 Conv2 가중치 |
| 교란 | 선택한 그룹 norm의 1%부터 시작. 공개 정상 성능 조건을 넘으면 절반씩 감소 |
| 개입 유효 조건 | 공개 정상 500장에 대해 양·음 양쪽 정확도 하락 1%p 이하, logit RMS 변화 0.1 이하 |
| 추가 확인 | 개입 선택에 쓰지 않은 정상 320장. 이전 연구에서 사용한 자료이며 새 연구 시험 집합은 아님 |
| 참여자 응답 | 고정된 BN과 특징 계산 조건에서 선택한 그룹에 대한 평균 CE 기울기로 한 번의 SGD 업데이트 계산. 학습률 0.01 |
| 정상 자료 | 균형 256장, 편중 256장, 같은 편중 풀의 1,024장 |
| 공격 관련 자료 | 독성 25%, 독성 25%와 위장 25% 혼합, 원래 라벨을 유지한 억제 자료 25% |
| 개인 자료 생성 | 원 BadFU 트리거·보존 위장 이미지, FUBA s42의 고정 생성기는 참여자 시뮬레이터 내부에서만 사용 |
| 반복 | 진단 시드 2개. 같은 사전 학습 모델을 공유하므로 독립 FL 학습 시드 2개가 아님 |
| 완료량 | 진단 조건 8개, 역할별 점수 48개, 새로운 개인 응답 96건. 각 응답은 원래 비중과 균등 비중 벡터를 함께 반환 |

FUBA의 생성기·공격자·억제자 전체 최적화를 재현한 실험은 아니다. 25% 혼합 비율과 한 번의 평균 기울기는 감사 조건을 통제하기 위한 설정이다. 정상 4배 자료 조건도 전체 참여자 탈퇴가 아니다. **실제 FU 탐지율과 실제 공격자의 식별 성능으로 보고하지 않는다.**

FUBA s42의 이 생성기는 추가 독성 학습을 하지 않은 정상 학습 모델에도 높은 전이 공격률을 보였던 자산이다. 따라서 이 출발 모델과 변형 입력에 대한 응답을 잠복 백도어의 활성화 검증으로 해석하지 않는다. 이번 점수에는 ASR을 사용하지 않았다.

서버가 전송한 진단 모델을 θ±v라 하고, 개인 자료의 평균 손실을 Lᵢ라고 두면 새 응답은 다음과 같다.

\[
U_i^{\pm}=-\eta\nabla_g L_i(\theta\pm v),\qquad
R_i=\frac{U_i^+-U_i^-}{2\|v\|}.
\]

공개 정상 자료 C에서도 같은 응답을 계산하여 다음 점수를 고정했다.

\[
S_i=\frac{\|(U_i^+-U_i^-)-(U_C^+-U_C^-)\|_2}{2\|v\|_2}.
\]

큰 값은 **공개 정상 반응과 다르다**는 뜻이다. 악성이라는 뜻이 되려면 정상 non-IID와의 구별이 별도로 검증돼야 한다. 역할 정보를 사용한 임계값 학습은 하지 않았다.

**결과:** 모든 진단 조건이 공개 500장에 대한 유효 조건을 통과했다. 별도 확인 320장에서 교란으로 인한 최대 정확도 하락은 **0.625%p**였다. 이 값은 진단 개입의 영향이며 최종 FU 정확도나 방어 성공률이 아니다.

![응답 통제 파일럿 결과](PILOT_RESULTS.png)

그림의 막대는 두 진단 시드의 최솟값과 최댓값이며 신뢰구간이 아니다. 위장·억제 역할 자료는 실제 공격 준비 과정을 단축한 통제 자료다. 특히 올바른 라벨을 붙인 변형 입력은 정상 증강에도 쓰일 수 있으므로 그 자료에 대한 반응만으로 악의적 의도를 판정할 수 없다.

## 클래스 균등 응답

**가설 한 줄: 참여자가 내부에서 클래스 비중을 균등하게 맞춘 응답은 정상 편중 때문에 생기는 경보를 줄인다.**

참여자는 자신에게 있는 클래스 집합 Kᵢ에 대해 내부에서 아래 손실을 계산한다. 서버는 원자료나 클래스별 개수를 받지 않고 결과 벡터만 받는다.

\[
L_i^{bal}=\frac{1}{|K_i|}\sum_{c\in K_i}
\frac{1}{n_{ic}}\sum_{j:y_j=c}\ell(f_\theta(x_j),c).
\]

**결과:** FUBA FC의 정상 편중 4배 자료 평균 S는 원래 비중 0.001260에서 균등 비중 0.000337로 낮아졌다. 그러나 독성 자료도 0.001665에서 0.000494로 낮아져 정상 편중 0.000503과 겹치는 수준이 됐다. 클래스 비중을 보정하면 자동으로 공격만 남는다는 주장은 성립하지 않았다.

BadFU 마지막 Conv에서는 정상 평균의 최댓값 0.001506보다 공격 관련 자료 평균의 최솟값 0.001779가 높았다. 균등 비중에서도 역할 평균의 순서는 유지됐다. FUBA 마지막 Conv의 균등 비중 평균은 독성 0.00000641, 정상 편중 0.00000625로 가까웠고 두 시드 범위가 겹쳤다. **Conv는 후속 검사 후보로 남기되 평균의 순서를 공통 탐지 성공으로 바꾸지 않는다.**

## FC 함정의 수학 검증

**가설 한 줄: 고정된 특징의 FC 교란에 대한 CE 기울기 차이는 같은 입력의 라벨만 바꿔도 변하지 않는다.**

특징 h(x)를 고정하고 최종 FC를 z=Wh+b라 두면, 단일 샘플의 평균 업데이트 차이는 다음과 같다. bias는 상수 1 특징을 붙여 W에 포함할 수 있다.

\[
\nabla_W\ell=(p-e_y)h^T,
\qquad U(W+V)-U(W-V)=-\eta(p_+-p_-)h^T.
\]

라벨 항 eᵧ가 정확히 사라진다. 이번 자연 비중의 한 번짜리 FC 대칭 응답은 같은 입력에 붙인 악성 라벨을 직접 읽지 못한다. 개인 입력 특징과 모델의 확률 곡률 차이는 읽을 수 있다. 다단계 학습, 움직이는 특징, 라벨에 의존하는 균등 가중치까지 라벨 불변이라고 확장하지 않는다.

두 계열의 실제 특징 64개에 원래 라벨, 모두 0, 라벨 순환을 적용해 FP64로 확인했다. 대칭 응답의 최대 상대 오차는 **3.67×10⁻¹³**인 반면 평균 업데이트는 크게 달라졌다. 따라서 FC 대칭 차분 하나만 공격 목적의 증거로 사용하지 않는다.

# 실제 언러닝에 붙일 후속 검증

**가설 한 줄: 같은 잔류 참여자들이 언러닝 전후 동일한 진단 개입에 보이는 반응 차이는 큰 정상 참여자 삭제와 공격성 삭제를 구별한다.**

1. 요청 직전 모델 θ전과 배포 전 후보 θ후를 보존한다. 모델 배포를 완료한 뒤가 아니라 후보 검증 중에 진단한다.
2. 삭제 대상 자료를 제외한 **같은 잔류 참여자 집합 R**을 전후 모두 검사한다. 참여자 구성이나 집계 가중치가 바뀌는 효과를 모델 변화로 오인하지 않도록 고정한다.
3. 같은 작은 방향 v를 두 모델에 각각 ±로 적용한다. 무작위 방향을 기준선으로 두고 관측 가능한 실제 FU 가중치 차이 방향도 별도 비교한다. 두 시점 모두 공개 정상 개입 조건을 만족하도록 크기를 정한다.
4. R이 각 진단 모델에서 응답을 **새로 계산**한다. 삭제한 자료를 다시 요구하지 않는다. 원래 비중과 클래스 균등 비중을 분리해 반환한다.
5. 개인 식별이 필요 없는 1단계에서는 고정 가중치로 집계한 응답도 검사할 수 있다. 이 경우 안전 집계에 필요한 별도 실행과 프로토콜을 검증해야 한다. 이번 파일럿은 개별 벡터가 보이는 조건이다.
6. 전후 응답 차이와 전후 이상 수준을 함께 보존한다. 삭제 전부터 활성화된 공격을 증가량만 검사하여 놓치지 않도록 한다.
7. 큰 정상 참여자 전체 삭제, 주요 클래스 집중 삭제, 일반 임의 삭제, 정상 자료 증강·도메인 변화가 같은 검사를 통과해야 한다. 임계값을 정할 정상 학습 실행과 성능을 확인할 학습 실행을 분리한다.

후보 집계 관측은 다음과 같이 정의할 수 있다. ε는 공통 방향 d의 크기이며 전후 같은 방향과 크기를 사용한다.

\[
\bar U_{t,g}^{\pm}=\sum_{i\in R}w_i U_{i,t,g}(\theta_t\pm\epsilon_g d_g),
\quad R_{t,g}=\frac{\bar U_{t,g}^{+}-\bar U_{t,g}^{-}}{2\epsilon_g},
\quad \Delta R_g=R_{후,g}-R_{전,g}.
\]

대칭 차분은 작은 ε에서 해당 진단 손실의 방향 곡률을 읽는다. 원래 업데이트의 평균도 함께 보존하여 라벨 의존 정보를 잃지 않게 한다. 이 벡터들을 공격과 정상으로 분류하는 규칙은 아직 검증되지 않았다. FC는 수학 검증 대조, Conv는 후속 주 후보로 둔다.

| 공격 범위 | 국소 트리거뿐 아니라 전역·입력 의존 변형도 포함 |
| 시간 범위 | 잠복 후 활성화와 삭제 전 이미 활성화된 공격을 별도 보고 |
| 진짜 추가 관측 | 옛 업데이트 재사용이 아니라 교란된 모델에서 새 계산 수행 |
| 적응 공격 | 진단임을 알아본 참여자의 응답 위조·깨끗한 대리 응답도 검사 |
| 일반화 | 독립 학습 실행과 별도 정상 임계값 보정으로 확인 |

서버 내부에서 저장 가중치에 연산만 더하는 것과 달리 새 참여자 응답은 개인 목적 함수에 대한 추가 관측이다. 다만 악성 참여자가 임의 응답을 낼 수 있는 조건에서는 신뢰할 수 있는 실행, 검증 가능한 응답, 또는 믿을 수 있는 참여자의 추가 검증 중 어떤 조건을 둘지 정해야 한다. 신뢰 실행을 가정해도 독성 자료로 정상 연산을 수행하는 BadFU를 자동으로 막는 것은 아니다.

정상과 공격이 이 추가 관측까지 똑같이 만들면 해당 관측만 쓰는 판정도 둘을 구별할 수 없다. 이는 모든 함정이 불가능하다는 결론이 아니라, 성공 주장을 하려면 어떤 추가 관측에서 차이가 생겼는지 밝혀야 한다는 조건이다.

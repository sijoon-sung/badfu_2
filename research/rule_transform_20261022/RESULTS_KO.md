# 학습한 변환 규칙으로 수행한 언러닝 전후 공격 탐지

2026년 10월 22일 · 저장 체크포인트를 이용한 탐색 실험

**가설:** 공격 모양을 지정하지 않고 입력 의존 변환 규칙과 목표 관계를 함께 학습하면, 공격 방식이 달라도 같은 절차로 독립 입력에서 악성 기능의 전후 변화를 찾아낼 수 있다.

## 구현한 규칙

패치 위치·크기·색 목록을 사용하지 않았다. 하나의 규칙 `Tθ(x)`가 입력에서 색 치환, 혼합 게이트, 가산 변화, 2차원 좌표 흐름을 출력한다. 이들을 합쳐 입력을 변환하므로 국소 변화와 전체 변화, 입력마다 달라지는 변화, 공간 왜곡을 같은 구조에서 표현할 수 있다. 입력은 이미지뿐이며 정답 트리거, 목표 클래스, 공격 이름, 참여자 역할을 규칙에 넣지 않았다.

목표 관계는 두 가지 초기화로 탐색했다. 하나는 공통 목표 클래스를 학습하고, 다른 하나는 원본 클래스마다 다른 목표를 학습한다. 96단계에서 목표 관계를 고정하고 총 480단계까지 규칙을 최적화했다. 전후 모델의 예측을 함께 사용하며, 원본 내용 보존을 위해 전 모델의 원래 예측과 특징, 저주파 이미지 변화를 제약했다. 이미지별 평균 절대 픽셀 변화는 0.06 이하, 흐름은 좌표별 3픽셀 이하로 제한했다. 이는 운영상 보존 조건이며 의미가 완전히 보존된다는 증명은 아니다.

## 실험과 독립 확인

13개 모델 쌍에서 합성 입력 40장과 깨끗한 이미지 40장을 각각 사용했다. 두 목표 관계와 160·320·480단계 저장본 중 후보를 **탐색 자료만으로 선택한 뒤** 독립 합성 입력 40장과 실제 이미지 400장으로 확인했다. 실제 확인 이미지 400장은 기존 탐색·확인 이미지 ID를 제외하고 새로 고정했으며, 규칙 학습이나 후보 선택에 쓰지 않았다. 알려진 공격 방식에 따라 탐색 코드나 임계값을 바꾸지 않았다.

경보는 원본을 두 모델 모두 맞힌 표본에서 변환 후 전 모델은 원래 클래스, 후 모델은 고정한 목표를 예측하는 전환을 측정한다. 유효 표본 최소 18개, 클래스별 최소 2개, 5개 이상 클래스에서 각 80% 이상 전환해야 한다. **데이터 없는 운영 판정은 독립 합성 입력만 사용한다.** 실제 이미지 400장은 평가자의 전이 확인에만 쓰며 운영에 요구하지 않는다. 원시 점수의 `primary_alarm`은 합성 확인과 실제 확인을 모두 통과한 전이 검증 성공이고, 아래 경보 표는 별도로 계산한 운영 판정이다.

## 판정과 해석

이전에 탐색 자료만으로 고정한 fixed48 후보를 같은 실제 확인 400장에 다시 적용한 참고 결과는 데이터 없는 모드 0/4, 대조 0/9; 깨끗한 이미지 모드 1/4, 대조 0/9였다. 새 규칙과 후보 선택 방식 및 탐색 비용이 다르므로 동일 예산의 우열 비교로 해석하지 않는다. [고정 후보 재평가 기록](FIXED_BASELINE_REPLAY.json).

이번 실행만으로 범용 탐지 가설을 지지할 수 없다. 규칙을 넓게 표현할 수 있다는 것과 공격 기능을 자동으로 찾아낸다는 것은 서로 다른 검증 항목이다. 독립 확인에 실패한 높은 탐색 전환율은 공격 탐지 성공으로 세지 않았다.

규칙은 다양한 변화를 표현하지만 학습 입력 40장과 각 목표 관계 한 초기화라는 탐색 한계가 있다. 목표가 잘못 선택되거나 정상 모델에도 가능한 입력별 적대 변형을 학습할 수 있다. 따라서 탐색 자료에서만 큰 전환이 나와도 숨겨진 공격 조건을 복원했다고 해석하지 않는다. 이번 실험에서는 추가 확인 결과를 보고 재시작, 목표 관계, 예산 또는 경보 기준을 바꾸지 않았다.

보존된 공격은 BadFU와 FUBA IBA 두 계열이다. 독립적으로 학습한 공간 왜곡 공격이나 개발에 사용하지 않은 공격 계열의 체크포인트가 없으므로, 이 규칙이 모든 공격을 탐지한다고 주장할 수 없다. 특히 보존된 FUBA는 언러닝 전에도 공격 기능이 활성화된 사례여서, 이번의 강한 전후 전환 조건에 실패하는 원인을 탐색 실패 하나로 단정할 수 없다.

모델 쌍 13개 중 9개는 보존 데이터 재학습, 2개는 저자 FedEraser, 2개는 정상 클라이언트 삭제에 적용한 FedEraser 변형이다. 모델을 공유하므로 독립 학습 13회로 세지 않는다. 클라이언트 갱신 기록을 통한 위장자·공격자 식별은 이번 입력 규칙 탐색의 결과에 포함하지 않았다.

## 선행연구와 차별화 조건

[UNICORN ICLR 2023](https://arxiv.org/html/2304.02786)은 입력 공간 변환을 함께 역산해 여러 종류의 트리거를 다뤘다. 따라서 변환 함수를 학습한다는 사실 자체를 신규성으로 주장하면 안 된다. 이번 구현은 UNICORN의 정확한 재현이 아니다.

[BEAGLE 저자 구현](https://github.com/Megum1/BEAGLE)은 소수의 공격 예시에서 트리거 주입 함수를 분해하고 스캐너를 구성한다. 우리는 공격 예시를 탐색 입력으로 주지 않는 조건을 유지했다. [FreeEagle USENIX Security 2023](https://www.usenix.org/conference/usenixsecurity23/presentation/fu-chong)은 깨끗한 표본 없이 복잡한 백도어를 탐지하는 선행연구이므로, 데이터가 없다는 조건만으로도 신규성을 주장할 수 없다.

차별화 후보는 변환 학습 자체보다 **언러닝 전후 모델로 같은 기능의 해제를 찾고, 정상 non-IID 삭제와 구분한 뒤 그 기능을 참여자 갱신 기록에 연결하는 것**이다. 이번 결과가 그 성능과 신규성을 입증한 것은 아니다.

## 검증 기록

원본 체크포인트 해시, 탐색 자료만 사용한 후보 선택, 규칙 저장본 해시, 목표 관계의 비동일 클래스 조건, 모든 확인 입력의 변화 예산을 확인했다. 학습된 규칙을 사용해도 전후에 같은 모델을 대입하면 전후 목표 전환과 차분은 0이었다. 400장 확인 ID가 이전 탐색·확인 ID와 겹치지 않음을 재확인했다.

실행 중 Windows 상태 파일 잠금으로 한 비교가 중단됐다. 저장 재시도만 추가하고, 완료된 11개 결과를 보존한 채 중단된 목표 관계를 같은 설정에서 다시 실행했다. 모델과 탐색·판정 조건은 바꾸지 않았다. [복구 기록](RECOVERY_01.json).

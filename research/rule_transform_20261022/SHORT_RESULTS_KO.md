# 변환 규칙을 학습한 범용 탐지 실험 요약

2026년 10월 22일

**가설:** 공격 모양을 지정하지 않은 변환 규칙을 학습하고, 그 규칙의 언러닝 전후 효과가 독립 입력에 재현되는지 확인하면 여러 공격에 같은 탐지 절차를 적용할 수 있다.

패치 후보 목록을 사용하지 않고, 색 치환·가산 변화·공간 왜곡을 함께 출력하는 입력 의존 규칙 `Tθ(x)`를 구현했다. 모델 쌍마다 규칙을 새로 학습하되 탐색 코드와 판정 기준은 공통으로 사용했다. 목표 클래스도 주지 않았다. 공통 목표와 클래스별 목표 관계를 각각 학습하고, 96단계에서 관계를 고정한 뒤 총 480단계까지 최적화했다.

저장 모델 쌍 13개를 합성 입력 40장과 깨끗한 이미지 40장으로 각각 검사했다. 후보를 탐색 자료만으로 고정한 후, 독립 합성 입력 40장과 실제 확인 이미지 400장으로 확인했다. 경보는 유효 표본 18개 이상, 원본 클래스 5개 이상에서 각각 80% 이상 전후 목표 전환이 발생하는 경우다. **데이터 없는 운영 판정은 합성 확인만 사용한다. 실제 이미지 400장은 평가자의 전이 확인 자료다.**

| 결과 | 데이터 없이 학습 | 깨끗한 이미지로 학습 |
|---|---:|---:|
| 악성 요청 경보 | 0/4 | 0/4 |
| 대조 요청 경보 | 0/9 | 0/9 |

대조 요청 9건에는 감염 모델에서의 정상 삭제 요청 2건이 포함된다.

대표 BadFU의 깨끗한 이미지 학습 전환율은 100%였지만 실제 확인에서는 **14.0%**였다. 정상 클래스 집중 삭제도 학습에서는 100%, 실제 확인에서는 **28.2%**였다. FUBA 공격의 실제 확인 전환율은 합성 입력 학습 시 **46.2%**, 깨끗한 이미지 학습 시 **52.8%**였지만 경보 기준을 충족하지 못했다. 이 수치는 학습한 목표 관계에 대한 전환이며 실제 트리거 ASR이 아니다.

**판정: 현재 규칙 탐색으로 범용 탐지를 입증하지 못했다.** 표현 범위를 넓힌 규칙도 소수 학습 입력에 맞는 적대 변형을 찾을 수 있으므로, 높은 학습 전환율을 탐지 성공으로 세면 안 된다. 제한된 목표 관계 초기화와 40장 학습에서의 일반화가 이번 최적화의 병목 후보다. 이 결과는 범용 탐지가 원천적으로 불가능하다는 결론은 아니다.

검증 범위는 저장된 BadFU와 FUBA IBA다. 독립적으로 학습한 왜곡 공격과 개발에 사용하지 않은 공격 계열은 아직 검사하지 않았다. 13개 비교는 재학습 9개·저자 FedEraser 2개·정상 FedEraser 변형 2개이며 독립 학습 13회가 아니다. 갱신 기록을 통한 위장자·공격자 식별도 이번 결과에 포함하지 않았다.

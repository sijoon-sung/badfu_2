# 수정 FedUBA 실제 재학습

**실행 위치 변경:** 사용자 요청으로 학습을 DISLAB의 `D:/FUBA_CORRECTED_20261022`로 이전했다. 로컬의 7라운드 결과는 보존하고 학습 프로세스는 중단했다. DISLAB의 수정 전 다른 시드 실행도 검증된 80라운드 기록을 보존하고 중단했다. 참여자별 난수 상태가 없어 정확한 이어 학습으로 주장할 수 없으므로 동일한 초기 조건에서 다시 시작한다. 아래의 로컬 `study_s20261020_v1`은 이전 기록이며, 현재 진행 상태는 DISLAB에서 확인한다.

**가설 한 줄: 공격 강도 선택·일관성 손실·위장 업데이트 구성을 수정하면 삭제 전 억제와 삭제 후 활성화가 회복된다.**

확인된 논리 오류를 수정한 별도 후보 구현으로 초기값부터 학습한다. 원 저자 소스와 과거 모델은 수정하지 않는다. 논문 전체 본문을 이번에 다시 확인한 공식 재현이라고 부르지 않는다. 일관성 계수와 위장 벡터는 기존 논문 독해 기록에 근거한 복원 후보이며, 그 결과로 타당성을 판정한다.

## 사전 검증

강도 경계·통과 후보 없음·비단조 후보 점수, 제곱 L2 값과 기울기, 위장 변위 기준점을 검사했다. 원 저자 고정 소스 145파일 해시 확인도 통과했다. 작은 1라운드 실행에서 공격자 4명과 위장자 1명의 실제 MPI 분기, 전체 업데이트 저장과 집계 재구성 검증을 통과했다. 이 작은 실행의 정확도·ASR을 공격 재현 결과로 해석하지 않는다.

최초 실행은 MPI 샌드박스 통신 제한으로 시작하지 못했다. 다음 작은 실행은 인위적인 프로세스별 메모리 상한 때문에 실패했다. 상한을 제거하고 불필요한 생성기 그래프를 없앤 세 번째 작은 실행이 완료됐다. 배치를 줄이거나 실패 기록을 지우지 않았다.

## 자동으로 이어지는 유한 실험

1. 수정한 공격 학습 100라운드.
2. 같은 초기값·분할의 정상 학습 100라운드.
3. 위장 참여자를 제거한 유지 자료 전체 재학습 100라운드.
4. 정상 모델에서 같은 참여자를 제거한 전체 재학습 100라운드.
5. 정상 모델에서 큰 정상 참여자를 제거한 전체 재학습 100라운드.
6. 같은 감염 초기 모델의 유지 자료에서 큰 정상 참여자만 제거하고 위장은 남긴 전체 재학습 100라운드.

재학습형 FU에서 잔류 공격자의 γ=1 재주입을 명시한다. 따라서 삭제 후 위험 변화에는 재주입이 포함될 수 있으며 순수한 잠복 해제만으로 해석하지 않는다. 단계 6에서 정상 요청 후에도 위험이 커지면 요청은 정상으로 유지하고 모델 위험 정답을 따로 기록한다.

## 서버 관측과 평가 분리

서버 관측은 별도로 보류한 정상 이미지 320장에서 클래스별 정확도·CE·출력 확률과 레이어별 클래스 평균 활성, 전 라운드 대비 출력 변화·KL을 저장한다. 실제 트리거·생성기·목표·ASR·역할 정답을 이 계산기에 전달하지 않는다. ASR은 원 코드 평가 로그로 별도 보존하고 전체 서버 관측 해시를 고정한 뒤 같은 생성기에 대한 정상 모델 전이와 전후 모델을 평가한다.

**후속 가설 한 줄: 같은 감염 출발 모델에서 위장 삭제와 큰 정상 탈퇴의 서버 관측 차이는 기존 총점이 놓친 클래스·레이어 구조에 남는다.**

후속 차이 탐색은 탐색 결과로 표시한다. 결과를 본 뒤 정한 특징·임계값으로 검출률을 확정하지 않고 별도 정상·공격 학습 실행에서 검증해야 한다. 이 실험에 신뢰할 수 있는 정상 협조 클라이언트라는 새 가정을 몰래 추가하지 않는다.

진행 상태는 `study_s20261020_v1/STATE.json`, 실제 라운드는 각 단계의 `LIVE.json`, 수정 분기 실행은 `correction_trace/`를 따른다. 완료 후 평가 JSON·그래프·보고서가 같은 연구 폴더에 생성된다.

# 삭제와 백도어 안전성의 기초 명제

아래는 이번 검토에서 전개한 조건부 명제와 증명이다. 알려진 기본 성질을 문제에 맞게 정리한 것이며 문헌적 신규성을 주장하지 않는다. 신경망 BadFU·FUBA에 대한 무조건적인 공격 성공 또는 방어 보장이 아니다.

## 1 삭제 정확성과 공격 억제는 같은 목표가 아님

데이터를 정상 집합 N, 독성 집합 P, 위장 집합 C로 나눈다. 삭제 대상은 C이고 유지 집합은 R=N∪P다. 학습 알고리즘 A와 그 무작위성의 분포를 고정한다. p는 A(R)의 모델 분포, q는 언러닝 결과 U(A(R∪C),C)의 모델 분포다. 트리거 변환 T, 타깃 t, 원래 타깃 클래스가 제외된 시험 분포 Q는 학습 무작위성과 독립적으로 고정한다.

모델 θ의 공격 성공률을 a(θ)=Pr_Q[argmax f_θ(Tx)=t]∈[0,1]로 정의한다.

**명제 1.** TV(p,q)≤ε이면

$$|\mathbb E_q a-\mathbb E_p a|\leq\epsilon.$$

**증명.** 임의의 [0,1] 값 함수 h에 대해 E h=∫₀¹Pr[h>s]ds다. 따라서

$$|\mathbb E_qh-\mathbb E_ph|
\leq\int_0^1|q(h>s)-p(h>s)|ds
\leq\operatorname{TV}(p,q).\quad\square$$

유지 데이터 재학습의 기대 ASR이 a₀ 이상이면 언러닝의 기대 ASR도 a₀−ε 이상이다. 기대 ASR≤ρ인 방어를 동시에 요구하면 ε≥a₀−ρ가 필요하다. ε<a₀−ρ인 두 요구는 양립하지 않는다.

**범위.** 같은 고정 알고리즘 A의 재학습 분포가 위험할 때의 결론이다. 안전한 학습 알고리즘 A_safe를 새로 정의하고 그 재학습을 기준으로 삼는 접근까지 불가능하다는 뜻은 아니다. 정상 입력의 예측 유사성이나 작은 가중치 거리만으로 위 TV 가정이 성립하지 않는다. 기존 FU 코드의 ε를 여기서 인증한 것도 아니다.

## 2 선형 모형에서는 위장 삭제 효과를 정확하게 계산할 수 있음

각 샘플은 특징 x와 실수 라벨 y를 갖는다. 손실은 **합**으로 정의하고 λ>0는 삭제 전후 같은 값으로 둔다.

$$J_R(w)=\frac12\sum_{i\in R}(x_i^\top w-y_i)^2+\frac\lambda2\|w\|^2,
\qquad L_C(w)=\frac12\sum_{i\in C}(x_i^\top w-y_i)^2.$$

$$A_R=\lambda I+X_R^\top X_R,\quad b_R=X_R^\top y_R,\quad
G_C=X_C^\top X_C,\quad d_C=X_C^\top y_C.$$

A_R는 양의 정부호이므로 두 최적해는 유일하다.

$$w_{pre}=(A_R+G_C)^{-1}(b_R+d_C),\qquad
w_{post}=A_R^{-1}b_R.$$

**명제 2.**

$$w_{post}-w_{pre}
=A_R^{-1}(G_Cw_{pre}-d_C)
=A_R^{-1}\nabla L_C(w_{pre}).$$

**증명.** 삭제 전 정지 조건에서 A_Rw_pre=b_R+d_C−G_Cw_pre다. 이를 A_R(w_post−w_pre)에 대입하면 G_Cw_pre−d_C가 된다. A_R⁻¹을 곱하면 끝난다. □

특징 u의 출력 변화는 uᵀA_R⁻¹∇L_C(w_pre)다. 따라서 위장 샘플의 기울기 크기만으로 출력 변화의 부호를 정할 수 없다. 곡률과 평가 방향이 필요하다. 다중 클래스 선형 회귀에서는 각 출력 열에 같은 항등식을 적용하고 타깃과 경쟁 클래스의 점수 차이를 본다.

**정규화 주의.** 평균 손실과 같은 λ를 삭제 전후 사용하면 정규화에 따른 정규화항의 상대 강도가 바뀐다. 위 식을 그대로 복사하지 말고 해당 목적함수의 A_R와 삭제 전 행렬을 다시 정의해야 한다.

### 이 구성에서 공격이 활성화되는 충분조건

정상 데이터 n개는 (−1,0), 라벨 −1과 (+1,0), 라벨 +1에 절반씩 놓는다. 독성 p개는 (−1,1), 라벨 +1이고 위장 c개는 같은 특징에 라벨 −1이다. n은 양의 짝수, n>λ>0라 하자. 두 번째 특징은 트리거이고 공격 타깃은 +1이다.

**명제 2a.** τ=nλ/(n+2λ)라 놓으면, p>τ이고 c>p−τ일 때 위장 삭제 전 트리거 점수는 음수, 정확히 삭제한 뒤 점수는 양수다. 정상 정확도는 양쪽 모두 100%다.

**증명.** k=p+c, d=p−c라 쓰면 정상 방정식은

$$A=\begin{pmatrix}n+k+\lambda&-k\\-k&k+\lambda\end{pmatrix},\qquad b=\begin{pmatrix}n-d\\d\end{pmatrix}.$$

행렬식 D=n(k+λ)+2kλ+λ²는 양수이며 역행렬 계산으로

$$w_1=\frac{n(k+\lambda)-\lambda d}{D},\qquad
w_2-w_1=\frac{(n+2\lambda)(p-c)-n\lambda}{D}.$$

w₁의 분자는 (n−λ)p+(n+λ)c+nλ>0이므로 정상 두 입력의 부호는 항상 맞는다. 트리거 입력 (−1,1)의 점수는 w₂−w₁이다. c>p−τ이면 삭제 전 점수는 음수이고, c=0으로 다시 최적화하면 p>τ에 의해 양수다. □

이는 지정한 데이터 계열의 충분조건이다. 서로 충돌하는 라벨과 두 특징으로 만든 예에서 **부정확한 FU 없이도** 활성화가 가능함을 보이며, 실제 이미지에서 필요한 p·c의 경계를 예측하는 공식은 아니다.

## 3 비선형 목적함수에서는 추가 가정이 필요함

J_α(θ)=J_R(θ)+αL_C(θ), α∈[0,1]를 생각한다. 각 α에서 유일한 최적해 θ_α가 존재하고, 목적함수가 두 번 연속 미분 가능하며, 해가 미분 가능하게 연결되고 H_α=∇²J_α(θ_α)가 가역이라고 가정한다. 예를 들어 전 구간에서 균일한 강볼록성과 적절한 매끄러움 조건으로 이 상황을 확보할 수 있다.

**명제 3.**

$$\frac{d\theta_\alpha}{d\alpha}
=-H_\alpha^{-1}\nabla L_C(\theta_\alpha),\qquad
\theta_0-\theta_1=\int_0^1H_\alpha^{-1}\nabla L_C(\theta_\alpha)d\alpha.$$

**증명.** ∇J_R(θ_α)+α∇L_C(θ_α)=0을 α로 미분하면 H_αθ′_α+∇L_C(θ_α)=0이다. 역행렬을 곱하고 α에 대해 적분한다. □

한 지점의 H⁻¹∇L_C를 전체 삭제 효과로 대체하는 것은 별도의 근사다. 신경망의 비볼록성·해 이동·BN·여러 로컬 스텝이 있는 FedAvg에는 위 전역 최적화 가정을 자동 적용할 수 없다. FUBA의 임의 갱신 조작도 고정 데이터 목적함수의 기울기라고 가정할 수 없다.

## 4 정상 입력의 출력만 보는 검사는 관측하지 않은 방향을 결정하지 못함

정상 입력이 x=(s,0)에만 존재하고, 방어자는 이 입력들의 출력만 질의할 수 있다고 하자. 모델은 f_a(s,t)=s+at이고 이진 분류는 부호로 정한다.

**명제 4.** a=0과 a=2의 모델은 모든 허용 정상 질의에서 같다. 그러나 입력 (−1,1)에 대해서는 각각 음성과 양성을 예측한다. 두 모델을 동일 사전 확률로 선택하면 정상 질의 기록만 이용한 식별기의 평균 오류는 1/2 이상이다.

**증명.** 모든 허용 질의에서 f_0(s,0)=f_2(s,0)=s다. 적응적으로 질의해도 동일한 답을 받으므로 기록의 분포가 같다. 기록에 대한 임의의 결정 규칙은 두 경우를 구분할 수 없다. 반면 f_0(−1,1)=−1, f_2(−1,1)=1이다. □

**범위.** 정상 출력만 이용한 식별의 한계다. 전체 가중치·다른 입력·학습 이력을 관측하는 방어의 불가능성이나 모든 정화의 불가능성을 뜻하지 않는다. 관측하지 않은 방향까지 모두 바꾸는 정화는 별도의 효용·망각 평가를 받아야 한다.

## 5 방어 보장을 쓰려면 입력 범위와 기준 모델을 명시해야 함

안전하다고 검증한 기준 모델 f₀와 정화 후보 f₁을 둔다. 원래 타깃 클래스를 제외한 시험 분포에서, 허용 변형 δ∈Δ 전체에 대해 올바른 클래스 y의 기준 마진이 γ>0 이상이라고 하자.

$$f_{0,y}(x+\delta)-\max_{j\ne y}f_{0,j}(x+\delta)\geq\gamma.$$

추가로 모든 클래스 j와 같은 입력 범위에 대해 |f₁,j−f₀,j|≤η라고 하자.

**명제 5.** γ>2η이면 후보 모델도 Δ 내에서 정답을 예측한다. 실제 트리거가 Δ에 속하면 해당 범위에서 ASR은 0이다.

**증명.** 임의의 j≠y에 대해 f₁,y−f₁,j≥f₀,y−f₀,j−2η≥γ−2η>0이다. □

특징맵 φ를 고정한 선형 분류기 Wφ(x)에서는 각 행의 변경 크기가 최대 r이고 ‖φ(x+δ)‖≤B이면 η≤rB다. 코시 슈바르츠 부등식으로 각 로짓의 변경을 제한하면 된다. 특징맵도 바꾸는 신경망 정화에는 그 변화까지 포함한 별도 상계가 필요하다.

**실제 남은 문제.** 공격받지 않은 기준 모델, 변형 집합 Δ, 그 전체에서의 γ·η를 어떻게 확보할지가 방어 연구다. 정상 검증셋의 평균 KL 또는 역합성으로 찾은 유한 패치 몇 개만으로 위 가정을 인증하지 않는다.

## 6 작은 구성 예와 검산 범위

정상 데이터 20개는 (+1,0)에 라벨 +1인 10개와 (−1,0)에 라벨 −1인 10개다. 독성 6개는 (−1,1)에 라벨 +1, 위장 18개는 (−1,1)에 라벨 −1이고 λ=1이다. 별개 레코드가 같은 특징을 가질 수 있는 구성 예이며 BadFU의 이미지 생성 과정을 재현한 것이 아니다.

| 상태 | 정확한 가중치 | 정상 정확도 | 원래 음성 입력의 트리거 예측 |
|---|---|---:|---|
| 독성과 위장 포함 | (512/549, 76/183) | 100% | 음성으로 유지 |
| 위장만 정확히 삭제 | (134/153, 82/51) | 100% | 공격 타깃 양성으로 전환 |
| 독성과 위장을 함께 삭제 | (20/21, 0) | 100% | 음성으로 유지 |

[실행 코드](verify_linear_example.py)는 유리수 연산으로 해와 삭제 항등식 300조건, 위 활성화 공식 1,200조건을 정확히 확인했다. 세 클라이언트로 나눈 데이터의 가중 FedSGD 한 스텝 기울기와 중앙 기울기의 일치도 확인했다. 여러 로컬 스텝의 FedAvg를 재현한 것은 아니다.

트리거 특징의 좌표를 알고 0으로 만드는 진단에서는 공격이 사라졌다. 이는 **알려진 트리거 특징을 쓰는 오라클 비교**이며 미지 트리거 방어 성능이 아니다. 유지 데이터 최적해를 바꾸므로 명제 1의 정확한 기존 재학습 기준과도 다르다.

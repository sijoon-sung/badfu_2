# P08 · 보관 BadFU 직후 교정의 실제 효과

가설은 P07 직후 마진 교정이 두 보관 BadFU 모델의 공격 성공률을 줄이고 원래 정답을 회복한다는 것이었다. 직접 대조에서 효과 기준을 충족한 공격 모델은 0/2였다. 새 BadFU 학습 없이 승인된 기존 두 체크포인트를 사용했다.

| 모델 | 시점 | ASR 무교정 → 교정 | 원래 정답률 무교정 → 교정 | 정상 정확도 무교정 → 교정 |
|---|---|---:|---:|---:|
| BadFU s20261023 | 교정 직후 | 100.00% → 100.00% | 0.00% → 0.00% | 90.63% → 90.69% |
| BadFU s20261023 | 복구 12단계 16/16 | 100.00% → 100.00% | 0.00% → 0.00% | 90.25% → 90.31% |
| BadFU s20261023 | 복구 12단계 24/8 | 100.00% → 100.00% | 0.00% → 0.00% | 90.31% → 90.25% |
| BadFU s20261020 | 교정 직후 | 100.00% → 99.93% | 0.00% → 0.07% | 88.13% → 88.00% |
| BadFU s20261020 | 복구 12단계 16/16 | 100.00% → 100.00% | 0.00% → 0.00% | 87.13% → 86.94% |
| BadFU s20261020 | 복구 12단계 24/8 | 100.00% → 100.00% | 0.00% → 0.00% | 86.88% → 87.06% |
| 감염 모델의 정상 850장 삭제 | 교정 직후 | 15.00% → 16.94% | 74.86% → 73.13% | 87.63% → 87.19% |
| 감염 모델의 정상 850장 삭제 | 복구 12단계 16/16 | 20.14% → 22.01% | 69.58% → 68.13% | 87.00% → 87.44% |
| 감염 모델의 정상 850장 삭제 | 복구 12단계 24/8 | 18.68% → 20.28% | 70.83% → 69.38% | 87.19% → 87.13% |

기존 보관 시험의 타깃 제외 1,440장과 겹치지 않는 적합 분할을 사용했다. 정상 정확도는 별도 정상 1,600장이다. s20261023에서 원래 정답을 회복한 입력은 0장이다. s20261020에서 직후 1장이 회복됐고 두 복구 경로 끝에 다시 0장이 됐다. 감염 모델에서 정상 850장을 삭제한 대조에서는 직후 목표 예측이 216장 → 244장으로 증가했다.

공격 시험은 적합에 쓰지 않았다. 기준은 각 공격 모델과 시점에서 ASR 감소와 원래 정답률 증가 각각 5%p, 두 복구 경로의 정상 전체 손실 최대 2%p와 클래스·출처 손실 최대 5%p였다. P07의 큰 정상 non-IID 대조와 전 구간 LP 불능 결과를 유지한다. 현재 결과는 P08의 직후 교정과 두 보관 모델의 유한 평가 범위다.

입력 봉인과 해시를 확인했고 수신 영수증 13개의 SHA256, P07과 동일한 데이터 분할, 원시 개수에서 다시 계산한 판정을 검증했다. 시점별 원격 영수증은 작업공간에 보존했다.

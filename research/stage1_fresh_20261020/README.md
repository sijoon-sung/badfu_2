# 새 학습 실행기의 소스와 과거 상태 기록

실제 DISLAB 궤적의 최신 검증과 모델 선택은 [궤적 목록](../00_trajectories/README.md)을 따른다.

이 폴더에는 실행기, 이전 장비의 일부 저장본, 전송 스냅샷이 함께 있다. `experiment_manifest.json`의 상태 문장을 실시간 진행 상태로 사용하지 않는다. Paper32의 실제 기준 궤적은 DISLAB의 `runs/badfu_paper32_plain_s20261020`이며, 원본 위치·파일 해시·모델 추출 키는 고정 목록에 있다. 로컬의 같은 이름 폴더가 모든 실제 가중치를 갖는다고 가정하지 않는다.
